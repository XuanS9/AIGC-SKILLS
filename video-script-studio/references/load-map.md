# 最小加载与规则归属

本页是任务路由与读取范围的唯一维护点。入口负责核心契约，下表模块负责各自详规；其他模块只引用，不再维护另一套强制全读列表。按任务读取适用章节是完整读取该章节，不是仅看grep命中。工具截断时按offset续读所选章节；未读不得记已读。

## 读取纪律

1. 先读根入口，再识别本轮输出类型、范围、授权和已有证据。模块不是一律全读，任务不是一律完整制作。
2. 首次视频创作/完整改写：叙事规划的标准格式与相关事件/分组章节、导演决策流程、导演编译的对应章节、导演模板；首次完整创作另读完整演出范本。选定章节读完整，模板填写区与实际采用示例不截读。
3. 已授权局部修词/修错：读当前契约、受影响条目/依赖/接缝、对应规则及修改后复查。未变且未受影响内容可以引用原证据/版本，不重加载全部方法库，不再请求同一授权。新设计、改剧情/对白/布局仍按样本流程。
4. 人物接表演与适用FACS；非人只读非人适配及通用行为，不套人类器官。对白/声效接音频适用章节，空间/场景接布局与总表，动作接动作导演。纯景观、产品、音频或工具咨询不强制人物/故事模板。
5. 仅使用Higgsfield平台/具名控件/执行工具时读取平台指南和相应模块；普通文本编排不因知识库存在就额外加载Cinema、Canvas、CLI等。
6. Seedance未指定版本沿入口默认2.5：读2.5对应模式与实际输出模板。2.0/Pro只在用户指定、模型比较或对应诊断时加载；不因“任何Seedance”全读2.0。编辑/延伸选实际模型的源时间线章节。首次创作读 [2.5 模块](higgsfield-seedance-2-5.md) 的速查、共享叙事规划、模式路由、参数面、核心公式、参考职责、多参考五步、长视频阶段、括号语法、参考图视频音频职责、硬限制、提交前检查与项目约定；真人角色公式、编辑/延伸/组合模式、情绪运镜术语、2.0/2.5 选择和 Dreamina 独有功能在对应任务时读取。
7. 规格只读输出模态和所选模型条目；过期时读模型规格维护。参考风格只读当前项目美术与适用转译章节。未生成结果记待核验。
8. 实际读取与正文落点归既有project/总表；没有工作区在块外说明。读取减少不减少规则落实、语义审阅或适用自动检查。

**按内容自动接入**（无需用户点名模块；实际读取与落点记入 [统一调用与验收总表](production-checks.md#统一调用与验收总表)）：

- 人物表演（含动作、无对白和背景人物）：[acting](higgsfield-acting.md) 人物档案、身体、眼神与验收规则及 [FACS 身体微反应](higgsfield-facs.md#物理微节拍脸以外的身体physical-micro-beats--the-body-beyond-the-face)；精细表情、特写按需读完整 FACS 工作流。非人角色读 [非人适配](higgsfield-acting.md#非人角色表演适配)，不默认用人类 FACS。
- 剧情创作与改写：[scene-engine](higgsfield-scene-engine.md) 内部检查目标、障碍、策略、反转与价值变化；专门审计时才展示报告，不给无人风景或纯功能演示强加反转。
- 多场景、关联提示词或分镜交付：[shotlist](higgsfield-shotlist-director.md)，沿用素材、编号、状态和工具检查；仅需提示词时交块结构，分镜任务按其原生 HTML 等契约交付。
- 对白、具体声效、音乐同步或附带音轨：[audio](higgsfield-audio.md)，先区分原样输出、节奏驱动和表演参考；纯音频任务保留原输出。
- 角色进出门或方向颠倒诊断：[门槛方向锁定](spatial-layout.md#32-进出门门槛方向锁定)，核对具名门两侧的状态转移，不以进出画判断。
- 动作、打斗、追逐：[动作导演](fight-director.md)（档案、交锋、三强度与速度轴、联合任务检查）。
- 角色资产提示词：完整读取 [角色资产交付规范](template-character-asset-delivery.md)，先给资产样本；仅要角色视频时沿用已确认身份与参考职责，不输出资产提示词，缺素材说明缺项、不自动开启资产制作。
