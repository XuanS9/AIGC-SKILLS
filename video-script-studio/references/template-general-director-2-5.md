# 跨类型完整导演提示词架构（含 Seedance 2.5 编译）
镜长、切点与节奏复核见 [事件驱动的镜长与节奏](shot-rhythm.md)。


来源：用户提供的「小师妹六段仙法」范本，提炼的是编排方法，不是官方参数或已验证的效果结论。所有题材的完整视频提示词默认用此格式与段内写法（剧情、动作、风景、音乐、动画、科普等），单镜头也保留完整演出细节。[模型指南](higgsfield-seedance-2-5.md)、[多参考模板](template-omni-reference-2-5.md)、[编辑与延伸工作流](higgsfield-seedance-2-5-mode-playbooks.md) 及其他模型能力继续有效。

本模板落实 [全包统一导演编排](narrative-planning.md)：完整视频提示词按 **Higgsfield 块结构** 交付——`[角色]` … `[生成目标]` → `[具体情节]` → `[视觉风格]` → `[镜头]` → `[声音]` → `[保持一致]`，各题材沿用相同结构、改写具体内容。**运镜在段头写简称、在 `运镜：` 行写量；音效写在当段 `声音：` 行；对白（英文）照 Higgsfield 写在 `[声音]`，每句一行并标时间段。**剧情阶段、镜头、生成片段分别决定；JSON、HTML、代码、局部编辑与延伸等专门格式仍保留，将完整演出内容映射到相应字段。

**默认交付标准：**先执行 [导演决策流程](directorial-shot-design.md#导演决策流程)，确定主次、信息、调度与切/留取舍，再读取 [完整演出范本](template-full-performance-example.md) 参考动作因果、视听和接续的具体程度。范本不决定本片镜头密度、字数或动作数量；连接段可简明，核心选择与余波有完整窗口。下方模板用于编译已定导演方案，不替代判断；单镜头、安静剧情也写足必要行为与状态。

## 1. 块结构（Higgsfield / Dreamina Seedance 2.5 标准）

依据：Higgsfield 的 Seedance 2.5 omni-reference 模板、Higgsfield 运镜与 measurable-language 规范、Dreamina 官方提示词指南，以及本工作室的表演模块。块结构照 Higgsfield，块标签与描述用中文，对白原句用英文。不需要的块直接删掉，空块是噪音不是结构。

| 块 | 作用 | 写什么 |
|---|---|---|
| `[角色]` | 人物映射 | 首行 `恰好 N 人，不出现其他人：名字…`；每人一行 `名字 对应 @名字。本段状态：…`（座位或站位、持物、伤势、湿污、服装破损等本段特有状态，不重写基础外观）；两人以上每人写 `身高 N cm`，生物不计人数、可写体长；有登记音色时附 `音色：…`（原样复制）。无参考素材时写人数与每人一个可见标记 |
| `[道具]` | 道具映射与归属 | `道具 对应 @道具。本段状态：…`（完好/破损、开合、亮灭）；数量与归属写 `恰好 1 把，开场在某人右手` |
| `[场景]` | 场景映射 | `场景 对应 @场景。` 后写本段用到的地标方位（如“岩台在画面右上且高”）与天气、时段；末尾 `场景只含参考所示内容，不增加家具或房间。` |
| `[动作与声音参考]` | 动作/声音参考 | `@视频 定义某动作的节奏`；参考视频里有别的人或场景时写 `不用其中人物与场景`。 |
| `[生成目标]` | 一句话讲清本条事件与变化 | 中文一句，用中文名，不用 `@` |
| `[具体情节]` | 按时间段写画面上发生的事 | 每段一行段头 `起s-止s｜景别｜视场角N°｜运镜`，下面分项写（见下表），以 `→ 结束：` 收尾 |
| `[视觉风格]` | 光、色、材质 | 光源方向（画面左/右）、色温 K、反差、材质；只写一次 |
| `[镜头]` | 总体运镜约束 | `各段视场角段内不漂移，一段只做一个主运动。`；有切镜时 `只在指定处切镜，镜头不会自行切换。` |
| `[声音]` | 对白与全片声音 | 有台词先写 `对白语言：英语。`，再每句一行 `起s-止s｜说话人＋状态＋说：{English line}`；无对白写 `本段无对白（设计）。`；有人物时第一行是定位秒的 `0s-1s｜<名字>轻声：{Hm.}`；现场声底噪；音乐（仅用户要求）`(…)`；末尾 `NO BGM。` |
| `[保持一致]` | 跨段不变项 | 数量与持物链、人物在画面左/右（左右均以镜头为准）、身份与服装；末尾 `无字幕、无水印。` |

### [具体情节] 每段的分项

| 行 | 必写 | 写什么（Higgsfield / Dreamina / 表演模块） |
|---|---|---|
| 段头 | 是 | `起s-止s｜景别｜视场角N°｜运镜`。景别用标准词（远景/全景/中景/中近景/近景/特写），切镜写 `切至…`；视场角只用锚点 84/63/47/29/18/12°；运镜写简称（固定、缓慢推近、横移、环绕…） |
| `画面：` | 是 | 前景、中景、背景各有什么；人物和物件在画面哪一侧（左右以镜头为准）；光从哪里来 |
| `运镜：` | 是 | 方式＋角度（平视/俯/仰/过肩/主观）＋起止景别＋距离或时长＋跟谁。固定写“固定，平视，不推拉”。动起来就写量：“用 5 秒从中景推近到特写”“7 秒只后拉 10–15 cm”“以 2 km/h 横移跟随林岚”。一段只做一个主运动；起止景别要能做到 |
| `动作：` | 是 | 起势→过程→结果；幅度用 cm，用时用秒，速度用 km/h；道具事件写先后（按下→下压 3 mm→咔哒→灯亮）。运镜幅度大的段，动作少写（每5秒1–2个主要动作） |
| `表情：` | 是 | 刺激→第一反应→2–4 个线索变化→落点。只写当前景别看得清的：近景/特写写眼睑、眉心、嘴角、鼻翼、呼吸、喉结；中景写抬眼、低头、肩、手；远景写姿态与呼吸。眼神写“看向哪里、在确认什么”。关键一拍可加一句（潜台词：…） |
| `听者：` | 两人以上同框时 | 画面里其他人的可见反应，各自由听到/看到的信息触发 |
| `声音：` | 有才写 | `<音效>`，写清是什么接触发出的声音 |

段内不写台词。有人说话的段，在 `动作：`/`表情：` 写看得见的说话动作（开口、换气、下颌、肩），台词本身写进 `[声音]`，时间段落在这一段之内。动作描述里出现的台词会被模型演成行为（Higgsfield / Dreamina 规则）。
| `→ 结束：` | 是 | 一个看得见的结束状态：位置、持物与左右手、视线。Clip 最后一段写“最后一秒…静止，镜头停住” |

### 细节写法

不设字数上限。写长的目的是让模型少猜，每句都要落到看得见、量得出的东西上；堆形容词、重复说同一件事不算细节。每段按下面的清单检查：

| 项 | 写到什么程度 | 太简略的写法 → 写足的写法 |
|---|---|---|
| 画面 | 至少两个方位：前景/中景/背景，加画面左/右/上/下 | “客舱里” → “前景是驾驶员的后背在画面左下，中景后排三人从左到右坐着，右舷窗外是午后雨林” |
| 运镜 | 方式、角度、起止景别、距离或秒数、跟谁 | “推近” → “平视，用 3 秒从中景前推约 40 cm 到近景，焦点跟着父亲的眼睛” |
| 动作 | 起势→过程→结果，幅度 cm、用时秒、先后词 | “她递钥匙” → “她先用拇指把钥匙从掌心推到指尖，再把手前伸约 20 cm，停在柜台中央” |
| 表情 | 刺激→第一反应→2–4 个线索→落点 | “他很紧张” → “听到机身一震，他眉心先收紧，喉结滚动一下，指节在扶手上发白，然后硬挤出一个笑” |
| 听者 | 每个同框的人各一个可见反应 | “大家在听” → “卢卡斯憋着笑看父亲的手；母亲的拇指在父亲手背上停住” |
| 声音 | 什么和什么接触、在哪一侧 | “有声音” → “<金属扶手被指甲刮过的短促一声，在画面左侧>” |
| → 结束 | 位置、持物与左右手、视线、镜头是否停住 | “结束” → “父亲的右手放在膝上，左手仍被母亲握着，视线停在母亲脸上” |

`director_contract_lint.py` 对其中可字面判断的项给 WARN：画面方位词少于 2 个；2 秒以上的段动作没有量或先后。

#### 角色进出门

涉及进出门先读取[门槛方向锁定](spatial-layout.md#32-进出门门槛方向锁定)，使用该节方向卡、回归情境及两个完整小样。将门两侧的起态、跨门方向、结果侧写进现有`画面：`/`动作：`/`→ 结束：`，观察关系写进`运镜：`；这不是额外栏目，也不属于要删除的资产外观复述。交付前遮住摘要动词反推方向，正文证据与用户意图必须一致。

### 模型可读性（Higgsfield / Dreamina Seedance 2.5 标准）

依据：字节《Dreamina Seedance 2.5 提示词指南》及 Higgsfield 写提示词规范，见 [Seedance 2.5 详规](higgsfield-seedance-2-5.md)。每次生成都从零开始，模型只读得懂画面上的事；给审稿人看的说明一律留在复制块外。

| 规则 | 要求 | 不要写 |
|---|---|---|
| `@` 只在素材映射里 | `@` 只出现在 `[角色]` `[道具]` `[场景]` `[动作与声音参考]`；其余用中文名，首次出场附一个可见标记 | “@工头 抓住绳子” |
| 素材行写本段状态 | `名字 对应 @名字。本段状态：坐姿/持物/伤势/湿污/所在位置` | 重写基础外观；只写“@Runa：融季谋生状态” |
| 人数与场景锁 | `恰好 N 人，不出现其他人`；`场景只含参考所示内容` | 不写，模型会加人、加家具 |
| 只写可见的事 | 动作、表情线索、物件、空间、声音 | 镜头编号、落幅、起幅、机位、关系中景、省略、承接、“完成后才”“确认…才” |
| 上下文隔离 | 每条复制正文自足 | 场景编号、批次号、“同上”“上一镜”“as above” |
| 每段一个结束状态 | `→ 结束：` 写位置、持物、视线 | 结束理由或给下一段的说明 |
| 情绪 2–4 个线索 | 眼、眉、嘴、呼吸、手中选 2–4 个 | 罗列所有面部细节 |
| 切镜锁定 | 有 `Cut to` 时 `[镜头]` 写 `只在指定处切镜，镜头不会自行切换。` | 不写，任由模型自行加切 |
| 一条只做一件事 | 动作物理与细腻表演、动作与对白在同条互相挤压时拆成两条 | 把告别表演和负重失衡塞进同一个30秒 |
| 写足细节 | 不设字数上限；每段按[细节写法](template-general-director-2-5.md#细节写法)写清方位、量和先后，每件事只说一次 | `[视觉风格]`/`[保持一致]` 复述具体情节；为凑字数堆形容词 |

`director_contract_lint.py` 检查其中可字面判断的项（FAIL）：块顺序与必有块、段头格式与视场角锚点、每段必写分项、对白/音效所在行与 `对白语言`、静音不进 `()`、`@` 位置、元语言、素材人数行与每人身高、场景锁、切镜锁定、复述；以及 WARN（不影响退出码）：Clip 边界、画面方位词不足、动作缺量或先后、景别/视场角/运镜单调、同框 5 人以上、台词超出段长、画中画、运镜未写量或时长不足、运镜冲突、近景表情线索不足或过多、缺听者、大运镜段动作过多。表演是否只做一件事、线索是否恰当仍由人工判断。

**视频一律不出现字幕：**不写字幕内容，不用 `【】`，`[保持一致]` 固定写 `无字幕、无水印。`（剧情需要的画内标牌/标志属可见景物、不是字幕）。

### 量化值（Higgsfield measurable-language）

按需写，只在镜头需要时写，不为凑格式硬填：两人以上写每人身高 cm（生物不计人数，可写体长 m）；速度 km/h；色温 K（同场固定）；雾浓度 % 或可见距离 m；重物 kg；道具事件写顺序（按下→下压 3 mm→咔哒→灯亮）；数量写 `恰好 1 个`。英文块标签（`[Characters]` 等）、`【】` 标题、旧四段式标题与旧 `[阶段N | …]` 块均已停用，lint 报 FAIL。静音要求不写进 `()`。

### 运镜幅度与时长

运镜幅度越大，段落要越长，否则模型会做成跳切或抖动。以下是 Higgsfield 示例换算的起步参考（`director_contract_lint.py` 据此给 WARN，不是硬上限）：

| 运镜 | 建议最短 | 例 |
|---|---|---|
| 固定 | 不限 | — |
| 微推/微拉（≤20 cm） | 3 秒 | 7 秒只后拉 10–15 cm |
| 推拉一个景别 | 3–4 秒 | 用 4 秒从中景推到近景 |
| 推拉两个景别以上 | 6–8 秒 | 用 8 秒从中景推到特写（Higgsfield 原例） |
| 横移/跟拍 | 按距离÷速度 | 3 米、2 km/h 约 5.4 秒 |
| 环绕 | 90° 约 4–6 秒；180° 约 8–12 秒 | — |
| 升降/揭示 | 5–8 秒 | — |

运镜可以跟情绪走（可选）：紧张时手持轻微晃动，悲伤时缓慢下沉，崩溃时缓慢后拉把人物“留给画面”；也可以固定不动让表演自己承担。

`【】` 在 Dreamina 括号语法里是字幕，所以块标签一律用方括号 `[ ]`。Clip 边界规则见 [Clip 边界隔离](narrative-planning.md#clip-边界隔离强制)：第一段是约1秒定位秒（全景，按戏份可用中景，人物到位、不说台词、不做动作），`[声音]` 写这一秒里一人轻声 `{Hm.}`，用来让模型锁定站位；最后一段写最后一秒静止。

## 1.5 一次交付：导演方案＋提示词＋生成风险

目标是第一次交付就能用：用户看导演方案就能判断方向，提示词按方案编译，风险提前标出。三部分一起交，不另开一轮确认；只有改变已确认剧情、对白、揭晓节点或镜序时才先问。

### 写之前：补齐事实

先列出本条要用的事实，按 `project.md` → `asset-registry.json` → 资产提示词 → 剧本的顺序查找：

| 事实 | 例 |
|---|---|
| 人物身高、生物体长/翼展 | 父亲 182 cm；古鳄约 9 米 |
| 座位/站位与朝向 | 前排右艾莉娅，回身面向后排 |
| 持物与左右手 | 手机在艾莉娅右手 |
| 本段特有状态 | 系安全带、湿透、左臂受伤 |
| 场景地标方位 | 岩台在画面右上且高 |
| 对白原句与说话人 | 对白台词总表 |

查不到的一次问齐，不分几轮问。用户说“你定”或没回答时，助手给出取值，块外标 `占位：…`，正文照常写数值；用户确认后写回 `project.md`，以后不再问。不在正文里写“待定”。

### 导演方案（块外，放在提示词上方）

十几行即可，用户一眼能判断方向：

```text
导演方案｜Clip <批-序>
意图：观众先看到<…>，后知道<…>；情绪从<…>到<…>。
立场：<悬念：观众先知道危险 / 惊奇：跟着人物同时揭晓 / 客观>，理由：<…>。
镜头表：
  <起-止s>｜<景别>｜<观看任务：这一镜让观众看到或明白什么>｜<切出理由>
  …
节奏：<哪里放慢、哪里收紧、揭晓前在哪留空>。
揭晓：<哪一镜、属于谁、通过什么渠道察觉>。
占位：<助手代定、待用户确认的取值>。
```

镜头表只写观看任务和切出理由，不重复提示词里的画面细节。

### 镜头变化

20 秒以上的 Clip 至少用 3 种景别、3 档视场角，至少有一个有动机的运镜；不连续 3 段用同一景别。变化来自观看任务的切换（空间 → 接触 → 反应 → 威胁），不为凑种类硬加。`director_contract_lint.py` 对这几项给 WARN。

### 生成风险（块外，放在提示词下方）

交付前按下表检查，命中的写进块外“生成风险”，每条给备选写法，由用户选：

| 风险 | 为什么 | 备选写法 |
|---|---|---|
| 同框 5 人以上 | 模型容易混脸、丢人或多出人 | 多人镜头 ≤3 人入画，其余用背影、虚化或出画 |
| 画中画（屏幕、镜子、倒影里的人物） | 屏幕内画面常变形或和画外不一致 | 只拍屏幕的光照在脸上；或切到被拍的人 |
| 台词在时间段内说不完 | 英文约 2.5 词/秒，超了会被截断或加速 | 加长对白行的时间段，或拆到相邻段 |
| 一段两个主动作 | 模型常只做一个或混在一起 | 拆成两段，或把次要动作改成状态 |
| 资产未生成就写特写 | 特写最依赖参考，无参考时脸和细节会漂 | 先出图；或改成中景、剪影 |
| 生物正脸、开口、大幅变形 | 结构容易崩 | 剪影、局部、过肩 |

前三项和人数由 lint 给 WARN，其余靠人工检查。没有命中时写“生成风险：未发现”。

## 2. 写作流程

1. 继承用户已确认的素材、类型、剧情、结局、时长、画幅和速度。按 [项目资产总表](asset-registry.md) 读取既有名称、调用名、文件和可用状态，资产锁定栏与分段正文沿用总表；未上传的参考在规划阶段用占位符，提交生成前替换或删除。
2. 先判断模式：新生成用 t2v 或 omni_reference；编辑交代唯一母片、修改范围和原时间线继承；延伸对齐前/后边界状态。后两者用原模式工作流，再按需加入本架构的视听与阶段内容。
3. 每份素材明确绑定对象与职责，独立资产直接引用，不重写形态和外观；按需注明本段状态/年龄版本。标签与实际平台槽位须可追溯；干扰背景和多视图排版在块外说明清理。分段正文使用同一资产名及必要动作关系，避免换称谓造成身份歧义。
4. 先确定本片段起因、主要事件与结果，用一句具体的话概括主要内容；不把风格、运镜或空泛“呈现过程/落在结果”写入概述。先定本段结果再倒推阶段。**切段由剧情事件、因果、信息揭示和状态变化决定：先问"哪里发生新的可见事件或状态转折"再开新段。**每段承担一个主要变化，反应与微动作服务该变化。阶段数、单段时长、总长由剧情与平台总时长共同决定，可不等长。阶段不等于镜头，一个连续镜头可跨多阶段。
4.0 先执行 [多线叙事与交叉剪辑](narrative-planning.md#多线叙事与交叉剪辑)：识别有效行动线与故事时间，确定单线/交叉理由、各线首次露出、回切和汇合；观众看见与角色知情分开。先定成片顺序再映射生成，约30秒不支配叙事；不擅改已确认揭示。
4.02 按 [独立生成与同场切镜](narrative-planning.md#独立生成与同场切镜)选择生成边界：同场戏可跨Clip反打、反应或交叉剪辑，不要求每条完整事件/换场；避免精确首尾动作相位依赖，先切镜再按需移动内容，不为凑30秒塞起手。
4.05 按 [动作同步、接缝去重与整场节奏](narrative-planning.md#动作同步接缝去重与整场节奏) 锁定必要先后与并行、命中窗口、跨段已完成事件和累计等待，再估计成片时长。
4.1 执行 [导演决策流程](directorial-shot-design.md#导演决策流程)，确定核心重点/必要支撑/连接，用调度呈现变化，并比较切镜/镜内交接/停留。再按 [多景别与多角度覆盖](directorial-shot-design.md#剧情驱动的多景别与多角度覆盖) 选择观察距离和视点，进行删并；主观、手部、轨迹等不是必填栏目。保留已确认的一镜到底及揭晓，不让操作准备抢走选择与后果。
5. 每段展开关键状态、动作起始与发展、对象响应、主体接续、可见结果和下一段入口，用具体细节写清画面层次、镜头观察位置/景别/跟随方向与声音。同一次生成的段落写本片段内声源变化，独立分镜各自描述本镜现场声。特效片补形态、尺度、材质、运动及残留；无特效片以表演、道具、材料或自然变化落实同等可执行性。演出放不下时减冗余或按授权调整编排，保留已确认事件。
6. 镜长与切镜计数按 [事件驱动的镜长与节奏](shot-rhythm.md) 与入口 [镜长与切镜计数](../SKILL.md#镜长与切镜计数)：不规定每个 Clip 的分镜数量；真实切镜独立编号及起止时间，连续运镜写清过程与起止景别，同镜推近、移焦即使分成多个时间段也仍是同一镜头。单条上限与超量处理按 [30 秒硬上限](narrative-planning.md#单个clip的30秒硬上限与超量处理)。时间段连续覆盖目标时长，转场计入段内，尾帧含在最后一段；时间码表达节奏、时机和交接目标，逐帧精确节拍需后期验证。
7. 相同地点保持空间与后果；多场景在切换处明确地点、时间和保留项。**大幅度物理空间转移必须写成真实切镜/分镜或甩镜过桥**，按 [拆镜或甩镜过桥](directorial-shot-design.md#大幅度空间转移必须拆镜或用甩镜头过桥)。道具交接、换装、清理、修复、倒叙、复位按剧情发生并说明原因与节点。
8. 默认交付「导演方案＋独立平台设置＋完整可复制演出提示词＋生成风险」（见 [§1.5](#15-一次交付导演方案提示词生成风险)）。仅用户要精简、只改局部或目标格式有硬限制时才缩写/编译，完整任务保留演出母稿。检查重复、矛盾和超载。适用时执行 Seedance lint，规则检查不代表效果验收。

### 从仙侠案例不继承为默认值的内容

仙侠案例的当前格式改写见 [动作演出范本](template-action-example-xianxia.md)。

- 段数、单段秒数、0帧爆发不继承。缺省 Seedance 2.5、16:9、中文；成片时长继承用户预算，每个 Clip 总时长≤30秒，模型上限更短时取更短值；在该范围内按演出负荷编组，不预设镜数。先定镜头观看任务和切点，再把连续内容映射进片段。
- 全程悬浮、只放大招、魔潮递增、满屏特效、高速甩镜是该片的动作设计。剧情可沉默，道具特写可停留，风景可静镜，音乐视频可按乐句切分。
- 冰蓝/紫金/玄金、UE 风格、胶片颗粒、六种法相是美术选择；其他任务用自己的色彩、材质、照明与风格。
- 「每段视觉不同」指阶段能被辨认（动作、信息、构图、景别、关系或物体状态），同一风格内允许有意义的视觉重复或音乐母题。
- 「永久保留破坏」泛化为「在所处时间线上继承应保留的结果」，不是所有视频都产生损坏或残骸。
- 「高潮汇聚」可以是情绪回应、功能成果、空间揭示或主题回收，不强制每类短片都有高潮。
- 「最高优先级」表达提示词内部创作优先级，不保证像素级一致或改变模型能力。

### 处理原范本的局部冲突

- 经文/符号是场内图形，字幕/水印/界面是画面叠加。需要经文时写清它不是字幕，用明确的允许内容与位置代替笼统的「禁止一切文字」。以下规则按本片已确认媒介、场内图形与声音需求编译；未明确授权不添加字幕或水印。
- 魔潮持续填补用于交战阶段，全部消散或倒下后切终场状态。残影、烟雾可衰减，破坏与残骸在被处理前继续存在。
- 主体辨识优先于特效密度：需识别人物的镜头留出面部可读窗口，背拍、远景和有动机的遮挡除外。
- 特效占比、成千数量、极多运镜是设计意图而非精确承诺，用可见规模、空间层次和主次关系表达；用户要求精确数字时列入视觉验收。
- 分辨率、帧率、HDR、引擎版本靠平台设置而非文本。8K 等风格词不等于输出规格，按当前平台实际支持填参数，不默认附加 60fps、8K 或某平台上限。

## 4. 不同类型的替换方法

各类型沿用第3节完整栏目及范本的逐段写法，箭头表不是最终提示词。剧情展开表演与关系回应，风景展开视线遮挡解除与自然运动，音乐舞蹈展开身体/队形/乐句呼应，教程展开可见操作与验证。每段仍交代画面与结果、运镜、声音与衔接，题材安静或无人物也保持细节。

| 类型 | 阶段推进示例 | 响应/反馈 | 需继承的状态 | 运镜与结尾重点 |
|---|---|---|---|---|
| 动作/追逐 | 发现威胁→交锋→局势变化→结果 | 对手反制、障碍与受力结果 | 相对位置、武器归属、消耗与破坏 | 攻防因果可见，按结局收束 |
| 情绪/剧情 | 建立关系→触发事件→选择→回应 | 视线、呼吸、手部与对方反应 | 情绪进程、道具交接、座位与轴线 | 留表演时间，尾帧落在关系变化 |
| 美食/手作 | 原料/部件→操作→状态变化→成果 | 受热、折叠、混合、连接 | 数量、形态、熟度、台面与工具位置 | 关键步骤可辨认，不靠跳切伪造过程 |
| 旅行/风景 | 局部引入→空间展开→主体关系→余韵 | 云、风、光、水面与人流 | 地理关系、光向、天气和行进方向 | 可静可动，换场明确 |
| 音乐/舞蹈 | 乐句引入→动作变化→主题回归→收势 | 身体动作、队形与灯光呼应 | 主体身份、服装、队形和动作方向 | 音乐节拍引导，精确同步后期校准 |
| 科普/教程 | 问题→演示→观察→结论 | 实验或操作的可见结果 | 装置结构、条件、步骤与数据含义 | 正确性与可读性优先 |

## 5. 三个泛化小样

以下小样只演示写法，均未调用视频生成，时长不是目标。实际项目里同场相邻事件要按“时长向30秒靠近”合进同一条。

### 情绪剧情：交还钥匙（16秒，五个镜头，含一次大幅后拉）

```text
[角色]
恰好 2 人，不出现其他人：林岚、周远。
林岚：短发、灰色毛衣，身高 165 cm。
周远：深色衬衫，身高 178 cm。

[道具]
钥匙：恰好 1 把，黄铜，带一个小钥匙环，开场在林岚右手。

[生成目标]
林岚在沉默中把钥匙推还给周远，周远收下，两人短暂对视后林岚垂下目光。

[具体情节]
0s-1s｜双人全景｜视场角84°｜固定
画面：木桌横在画面中部，林岚坐画面左，周远坐画面右，侧窗在画面左后方。
运镜：固定，平视，不推拉。
动作：两人坐着不动，钥匙在林岚右手掌心，手背贴着桌沿。
表情：林岚低着头，肩膀微缩；周远看着她，双手交叠放在桌上。
听者：周远目光落在林岚的手上，喉咙轻动一下。
→ 结束：两人坐定，钥匙仍在林岚掌心。

1s-4s｜切至双人中景｜视场角47°｜固定
画面：前景是木桌边缘，两人在中景，窗光从画面左侧落到桌面。
运镜：固定，平视，不推拉。
动作：林岚低头看掌心的钥匙，右手用约 1 秒缓慢落到桌面，手指仍压住钥匙。
表情：林岚睫毛下垂，下唇轻抿，呼吸放浅。（潜台词：她不想先开口。）
听者：周远的视线随她的手下移，交叠的手指收紧。
声音：<钥匙轻触木桌，一声轻响>。
→ 结束：钥匙贴住桌面，在林岚右手指下；两人都没抬头。

4s-7s｜切至桌面近景｜视场角29°｜固定
画面：桌面占满画面，钥匙在中央偏左，两只手分别从画面左、右进入。
运镜：固定，俯角约 30°，对焦在钥匙上。
动作：林岚用指尖把钥匙向前推约 20 cm 到桌面中央，手退回近侧桌沿；周远的右手从画面右侧伸来，停在钥匙旁。
表情：林岚推完后手指微微蜷起，指尖发白；周远的手先停顿半秒才伸出。
声音：<金属擦过木面，短促摩擦声>。
→ 结束：周远指尖触到钥匙，林岚的手已离开钥匙。

7s-10s｜切至周远侧面近景｜视场角29°｜固定
画面：周远侧脸在画面右，背景是虚化的窗光。
运镜：固定，平视，焦点锁在周远眼睛上。
动作：周远右手把钥匙收进掌心慢慢握紧，然后抬眼看向画面左侧的林岚。
表情：眉心微收，嘴唇抿紧，喉结动了一下，呼吸停半拍后嘴唇分开，低声说出一句。（潜台词：他想留她，但不肯直说。）
声音：<钥匙环轻碰指节>。
→ 结束：钥匙握在周远右手，他的目光停在林岚脸上。

10s-16s｜切至双人中景｜视场角47°｜缓慢后拉
画面：两人隔桌相对，林岚在画面左，周远在画面右，窗光从画面左侧落到桌面。
运镜：用 5 秒从双人中景缓慢后拉到双人全景，后拉约 1.5 米，最后 1 秒停住。
动作：林岚抬眼与周远对视约 1 秒，随后垂下视线看向桌面。
表情：林岚抬眼时呼吸一顿，眼眶微红，下颌绷紧后放松。
听者：周远没有动，握钥匙的手停在桌面，目光一直停在她脸上。
→ 结束：最后一秒镜头停住，两人静止，周远握着钥匙，林岚看着桌面。

[视觉风格]
侧窗柔光从画面左侧射入，色温 4000K，明暗反差低；木桌与毛衣的织纹清晰，黄铜钥匙有细小高光。

[镜头]
各段视场角段内不漂移，一段只做一个主运动。只在指定处切镜，镜头不会自行切换。

[声音]
对白语言：英语。
0s-1s｜周远轻声：{Hm.}
8s-10s｜周远低声说：{Keep it.}
现场声为房间底噪与窗外远处车流。NO BGM。

[保持一致]
钥匙始终只有 1 把：林岚右手 → 桌面中央 → 周远右手。林岚在画面左，周远在画面右，左右均以镜头为准。无字幕、无水印。
```

### 生活片段：夜读开灯（16秒，五个镜头，含一次横移）

```text
[角色]
恰好 1 人，不出现其他人：读者。
读者：深色针织衫。

[道具]
折叠台灯：恰好 1 盏，带 2 个铰链，开场灯臂折叠、灯光关闭。

[生成目标]
读者展开折叠台灯并点亮书页，把手落到页边准备夜读。

[具体情节]
0s-1s｜书桌全景｜视场角84°｜固定
画面：夜里的书房，书桌横在画面中部，读者坐在桌前面向桌面；台灯在画面右侧，画面左侧摊开一本书；窗外透进柔和侧光。
运镜：固定，平视，不推拉。
动作：读者双手放在桌沿，坐着不动。
表情：读者目光落在折叠的台灯上，嘴唇微闭。
→ 结束：读者坐定，台灯仍折叠。

1s-4s｜切至桌面中近景｜视场角47°｜固定
画面：前景是桌沿，台灯与读者双手在中景，书在画面左侧虚化。
运镜：固定，俯角约 20°。
动作：读者左手压住台灯底座，右手握住灯头，用约 1 秒握稳。
表情：读者垂眼看灯头，嘴角放松。
→ 结束：右手握稳灯头，左手仍压住底座。

4s-8s｜切至灯臂近景｜视场角29°｜横移
画面：灯臂与两个铰链在画面中央，读者右手从画面左侧进入，背景是虚化的书架。
运镜：以约 0.2 km/h 向画面右侧横移约 20 cm，跟随灯头，最后 1 秒停住。
动作：右手抬起灯头，依次转开两个铰链，每个用约 1 秒，左手一直压住底座。
表情：手指关节微微发力，呼吸平稳。
声音：<铰链转动，轻微摩擦声>。
→ 结束：灯臂完全展开，镜头停住。

8s-12s｜切至开关与书页近景｜视场角29°｜固定
画面：开关在画面右下，书页在画面左侧，灯头从画面右上方伸入。
运镜：固定，焦点锁在开关上。
动作：右手把灯头转向书页后松开；左手手指按下开关，开关下压约 3 mm 后回弹，台灯在咔哒之后才亮起。
表情：读者的目光跟着指尖，按下时屏住呼吸半秒，灯亮后眉眼舒展。
声音：<开关咔哒一声>。
→ 结束：灯光稳定，暖光落在书页上，双手已离开灯具。

12s-16s｜切至桌面中景｜视场角47°｜固定
画面：读者在画面中央，台灯在画面右侧，书在画面左侧被暖光照亮。
运镜：固定，平视，不推拉。
动作：读者右手从灯旁收回，先落在页边，再用指尖把翘起约 1 cm 的纸角压平。
表情：读者眉眼舒展，目光落到第一行字上，呼吸放慢。
声音：<纸张轻微摩擦声>。
→ 结束：最后一秒手停在页边不动，镜头停住。

[视觉风格]
点灯前为场外柔和侧光，色温 5600K；点灯后台灯暖光从画面右上方补入，色温 3200K。针织纹理与纸张纹理清晰。

[镜头]
各段视场角段内不漂移，一段只做一个主运动。只在指定处切镜，镜头不会自行切换。

[声音]
本段无对白（设计）。
0s-1s｜读者轻声：{Hm.}
现场声为房间底噪。NO BGM。

[保持一致]
始终只有 1 盏台灯、2 个铰链；底座在画面右侧，书在画面左侧；展开与点亮之后状态保持。无字幕、无水印。
```

### 风景展示：晨雾山谷（14秒，四个镜头，含一次升降揭示）

```text
[角色]
恰好 0 人：画面中没有人物和动物。

[生成目标]
清晨的视野从带露松枝展开到雾中的河流与山脊，最终呈现完整山谷。

[具体情节]
0s-1s｜谷沿全景｜视场角84°｜固定
画面：近处一丛松枝位于画面左下，谷底河流在薄雾中，远处山脊在画面上方。
运镜：固定，平视，不推拉。
动作：画面里只有雾层缓慢流动。
表情：不适用，画面中没有人物。
→ 结束：画面静止。

1s-4s｜切至松枝特写｜视场角12°｜固定
画面：一根松枝从画面左下斜伸到右上，针叶尖挂着水珠，背景是虚化的谷底。
运镜：固定，焦点锁在水珠上。
动作：水珠贴住针叶，枝梢在约 7 km/h 的轻风中小幅摆动约 1 cm。
表情：不适用，画面中没有人物。
声音：<叶片细微摩擦声>。
→ 结束：枝梢回到原位，水珠仍挂在针叶上。

4s-7s｜切至谷底远景｜视场角63°｜固定
画面：河流从画面左下蜿蜒到右上，薄雾覆盖谷底，雾浓度约 40%。
运镜：固定，略俯拍。
动作：雾层以约 1 km/h 顺谷流动，一处河湾从雾隙中显露。
表情：不适用，画面中没有人物。
声音：<远处水声与零星鸟鸣>。
→ 结束：河湾清楚可见。

7s-14s｜切至谷沿全景｜视场角84°｜升降揭示
画面：近处松枝在画面左下，谷底河流在中景，远处山脊在画面上方被暖光照亮。
运镜：用 6 秒从松枝高度缓慢升高约 3 米，越过松枝揭示完整山谷，最后 1 秒停住。
动作：晨光先照亮山脊边缘，随后沿坡面向下铺开；谷底冷色薄雾用约 5 秒缓慢退到坡脚。
表情：不适用，画面中没有人物。
声音：<山风轻响>。
→ 结束：最后一秒镜头停住，完整山谷在画面中，晨光与薄雾不变。

[视觉风格]
低角度晨光从山脊方向照来，受光处色温约 4000K，谷底阴影约 7000K；约 200 米外的河道仍可辨。

[镜头]
各段视场角段内不漂移，一段只做一个主运动。只在指定处切镜，镜头不会自行切换。

[声音]
本段无对白（设计）。NO BGM。

[保持一致]

```

> 三个小样都按 Clip 边界规则：第一段是定位秒（全景、固定，人物到位），有人物时 `[声音]` 写 `0s-1s｜<名字>轻声：{Hm.}`（风景 `恰好 0 人` 时不写），最后一段写最后一秒静止。有大运镜的段（钥匙的后拉、台灯的横移、山谷的升降）都写了距离或时长，并给了足够秒数。

## 6. 交付前检查

每次修改后执行 [修改后标准复查闭环](production-checks.md#修改后标准复查闭环)，读回最终完整条目及受影响接缝/依赖，失败先修复再重跑；样本与已授权完整稿均不豁免。

按 [统一调用与验收总表](production-checks.md#统一调用与验收总表) 记录证据；人物描写默认调用已有表演模块并做 [表演证据验收](higgsfield-acting.md#表演证据验收)，短Clip先做 [生成分组验收](narrative-planning.md#生成分组与短段例外验收)。以下检查不是额外用户审批。

- 概述是本段主要内容的一句具体概括，与本段分镜对应，无空泛导演套话、风格/运镜堆叠或后续剧透；各块不复述独立资产的形态和外观。
- 素材标签可追溯，参考有实际职责；独立资产只补必要状态/年龄版本。干扰背景或多视图在块外安排清理，未绑定不称可提交。
- 去掉意图说明，只看正文能否理解场景重点、选择与后果？候选镜删并后是否损失理解或情绪压力？总目标、各段结果、结局与尾帧一致；主体可以是人、产品、动物、环境或抽象形态。
- 时间段连续，不用固定镜数验收；3秒是镜长复核阈值，不是硬上限或固定镜长；超过3秒按具体表演与切点依据复核，实际切镜与镜内景别变化表达清楚；每个 Clip 的声明时长与所有片内时间段终点均≤30秒，尾帧与转场计入预算。超量内容压缩或顺延，接缝与对白覆盖重核。
- 每段主要变化可观察，镜头关注点明确，回应与下一段有因果或信息联系。
- 关键表情、物件、接触在所选景别确实可读；没有因默认中远景而漏掉信息，也没有无功能的重复特写。当前取景只写可见细节，特写与较大景别切换后视线、轴线、手别/持有链、动作相位一致。
- 多角度不改变固定地理或凭空添加结构；样本的景别数、秒数不变成配额，增加细节镜头不挤掉必要动作与对白。
- 进出门按[门槛方向锁定](spatial-layout.md#32-进出门门槛方向锁定)核定位秒、跨门与末态；正文只写入画/出画或走向门口，不能替代目标侧证据。
- 对照完整范本检查可执行性：具体动作、对象响应、镜头职责、必要视听与接续清楚；去重前后核对同时/先后、触发时机、持续动作与跨段相位是否等义。只删无新增约束的复述。
- 固定项、可变项和变化节点区分清楚；后果继承，无故复原、复制或身份互换被排除。
- 类型特有要求不误变成通用规则；安静、慢速、静镜、多场景、字幕、品牌和非写实风格按用户需要保留。
- 约束短而具体，优先用可执行的正向描述，与需要的经文、商标、字幕、结局或特效衰减不冲突。
- 平台的模式与参数经流程核验；编辑与延伸保留原工作流。无生成结果时只报告结构检查，效果待视听验收。
