# 跨类型完整导演提示词架构（含 Seedance 2.5 编译）

来源：用户提供的「小师妹六段仙法」范本，提炼的是编排方法，不是官方参数或已验证的效果结论。所有题材的完整视频提示词默认用此格式与段内写法（剧情、动作、风景、音乐、动画、科普等），单镜头也保留完整演出细节。[模型指南](higgsfield-seedance-2-5.md)、[多参考模板](template-omni-reference-2-5.md)、[编辑与延伸工作流](higgsfield-seedance-2-5-mode-playbooks.md) 及其他模型能力继续有效。

本模板落实 [全包统一导演编排](narrative-planning.md)：完整视频提示词按**四段式标准格式**交付——【参考素材职责】→【一句话概述】→【具体情节】（按时间轴分镜）→【全局补充】，各题材沿用相同四段、改写具体内容。**运镜写在【具体情节】的时间段正文内、与该段动作同步，不单列「运镜」栏；声音写在其发生处、紧贴发声动作；对白用 `说话人+状态/语气+说话动词「台词」`，音效与音乐用自然句。**剧情阶段、镜头、生成片段分别决定；JSON、HTML、代码、局部编辑与延伸等专门格式仍保留，将完整演出内容映射到相应字段。

**默认交付标准：**先执行 [导演决策流程](directorial-shot-design.md#导演决策流程)，确定主次、信息、调度与切/留取舍，再读取 [完整演出范本](template-full-performance-example.md) 参考动作因果、视听和接续的具体程度。范本不决定本片镜头密度、字数或动作数量；连接段可简明，核心选择与余波有完整窗口。下方模板用于编译已定导演方案，不替代判断；单镜头、安静剧情也写足必要行为与状态。

## 1. 四段式架构

| 段 | 作用 | 泛化内容（含原七层归属） |
|---|---|---|
| 参考素材职责 | 引用本段独立资产及必要职责 | 直接 `@资产`，按需注明状态/年龄版本或动作/声音参考职责；基础形态和外观由资产提供，干扰内容清理留块外 |
| 一句话概述 | 让模型理解本片段主要内容 | 主体＋必要情境＋主要事件＋关键变化或结果；一个完整句子，风格与运镜进入具体情节/全局补充 |
| 具体情节 | 目标变成按时间轴的可观察分镜 | （原“全局视听/主体行为与节奏/分段演出”落到每段）每个时间段写：景别+机位；当前取景可见的空间层次与运动；主体动作（含幅度与速度）及本镜可读的表情或物件细节；关键表演 beat 在物理动作后按需补一句简短潜台词；光线；运镜（起手→路径→落幅+与上镜衔接）；段末明确结束状态；对白用 `「」` 紧贴说话动作，音效与音乐用内联自然句。身份/数量/位置/朝向/持有/损伤/破坏段间继承，跨片段音频交后期 |
| 全局补充 | 全片一致性、跨段继承与排除 | （原“全局视听的全局项＋结尾状态与交接＋约束与排除”）风格/光向/空间轴线一次交代、主体基线、全片结局与尾帧、少量关键排除、字幕/水印/声音开关（默认 NO BGM） |

核心循环：**起始状态 → 主体行动 → 可见响应 → 主体接续 → 结束状态 → 下一段继承**。响应可来自对手、人物表情、物体运动、光影或环境，不必是冲突或特效。以连贯正文展开过程，一个完整阶段不压成一句概括。

## 2. 写作流程

1. 继承用户已确认的素材、类型、剧情、结局、时长、画幅和速度。按 [项目资产总表](asset-registry.md) 读取既有名称、调用名、文件和可用状态，资产锁定栏与分段正文沿用总表；未上传的参考在规划阶段用占位符，提交生成前替换或删除。
2. 先判断模式：新生成用 t2v 或 omni_reference；编辑交代唯一母片、修改范围和原时间线继承；延伸对齐前/后边界状态。后两者用原模式工作流，再按需加入本架构的视听与阶段内容。
3. 每份素材明确绑定对象与职责，独立资产直接引用，不重写形态和外观；按需注明本段状态/年龄版本。标签与实际平台槽位须可追溯；干扰背景和多视图排版在块外说明清理。分段正文使用同一资产名及必要动作关系，避免换称谓造成身份歧义。
4. 先确定本片段起因、主要事件与结果，用一句具体的话概括主要内容；不把风格、运镜或空泛“呈现过程/落在结果”写入概述。先定本段结果再倒推阶段。**切段由剧情事件、因果、信息揭示和状态变化决定：先问"哪里发生新的可见事件或状态转折"再开新段。**每段承担一个主要变化，反应与微动作服务该变化。阶段数、单段时长、总长由剧情与平台总时长共同决定，可不等长。阶段不等于镜头，一个连续镜头可跨多阶段。
4.0 先执行 [多线叙事与交叉剪辑](narrative-planning.md#多线叙事与交叉剪辑)：识别有效行动线与故事时间，确定单线/交叉理由、各线首次露出、回切和汇合；观众看见与角色知情分开。先定成片顺序再映射生成，约30秒不支配叙事；不擅改已确认揭示。
4.05 按 [动作同步、接缝去重与整场节奏](narrative-planning.md#动作同步接缝去重与整场节奏) 锁定必要先后与并行、命中窗口、跨段已完成事件和累计等待，再估计成片时长。
4.1 执行 [导演决策流程](directorial-shot-design.md#导演决策流程)，确定核心重点/必要支撑/连接，用调度呈现变化，并比较切镜/镜内交接/停留。再按 [多景别与多角度覆盖](directorial-shot-design.md#剧情驱动的多景别与多角度覆盖) 选择观察距离和视点，进行删并；主观、手部、轨迹等不是必填栏目。保留已确认的一镜到底及揭晓，不让操作准备抢走选择与后果。
5. 每段展开关键状态、动作起始与发展、对象响应、主体接续、可见结果和下一段入口，用具体细节写清画面层次、镜头观察位置/景别/跟随方向与声音。同一次生成的段落写本片段内声源变化，独立分镜各自描述本镜现场声。特效片补形态、尺度、材质、运动及残留；无特效片以表演、道具、材料或自然变化落实同等可执行性。演出放不下时减冗余或按授权调整编排，保留已确认事件。
6. 不规定每个 Clip 的分镜数量，不设单镜3秒上限或固定镜长；按剧情、动作、对白与表演选择持续镜头、镜内交接或真实切镜。“同镜继续”、推近、移焦即使分成多个时间段也仍是同一镜头。每个 Clip 总时长≤30秒，放不下的内容压缩或顺延到下一条，保留自然语速、关键因果和对白完整。时间段连续覆盖目标时长，转场计入段内，尾帧含在最后一段。时间码表达节奏、时机和交接目标，逐帧精确节拍需后期验证。
7. 相同地点保持空间与后果；多场景在切换处明确地点、时间和保留项。**大幅度物理空间转移必须写成真实切镜/分镜或甩镜过桥**：A空间先落离开末态，明确切至B或沿同向运动模糊甩入B，再在B空间建立入口/地标并承达到达状态；不能只用“从A来到B”的单画面运镜描述。只有用户锁定且路线可达的一镜到底才例外，并补中间地标、经过时间和摄影机路径。道具交接、换装、清理、修复、倒叙、复位按剧情发生并说明原因与节点。
8. 默认交付「独立平台设置＋完整可复制演出提示词」。仅用户要精简、只改局部或目标格式有硬限制时才缩写/编译，完整任务保留演出母稿。检查重复、矛盾和超载。适用时执行 Seedance lint，规则检查不代表效果验收。

### 从仙侠案例不继承为默认值的内容

- 段数、单段秒数、0帧爆发不继承。缺省 Seedance 2.5、16:9、中文；成片时长继承用户预算，每个 Clip 总时长≤30秒，模型上限更短时取更短值；在该范围内按演出负荷编组，不预设镜数。先定镜头观看任务和切点，再把连续内容映射进片段。
- 全程悬浮、只放大招、魔潮递增、满屏特效、高速甩镜是该片的动作设计。剧情可沉默，道具特写可停留，风景可静镜，音乐视频可按乐句切分。
- 冰蓝/紫金/玄金、UE 风格、胶片颗粒、六种法相是美术选择；其他任务用自己的色彩、材质、照明与风格。
- 「每段视觉不同」指阶段能被辨认（动作、信息、构图、景别、关系或物体状态），同一风格内允许有意义的视觉重复或音乐母题。
- 「永久保留破坏」泛化为「在所处时间线上继承应保留的结果」，不是所有视频都产生损坏或残骸。
- 「高潮汇聚」可以是情绪回应、功能成果、空间揭示或主题回收，不强制每类短片都有高潮。
- 「最高优先级」表达提示词内部创作优先级，不保证像素级一致或改变模型能力。

### 处理原范本的局部冲突

- 经文/符号是场内图形，字幕/水印/界面是画面叠加。需要经文时写清它不是字幕，用明确的允许内容与位置代替笼统的「禁止一切文字」。以下规则按本片已确认媒介、场内图形与声音需求编译；未明确授权不添加字幕或水印。
- 魔潮持续填补用于交战阶段，全部消散或倒下后切终场状态。残影、烟雾可衰减，破坏与残骸在被处理前继续存在。
- 主体辨识优先于特效密度：需识别人物的镜头留出面部可读窗口，背拍、远景和有动机的遮挡除外。
- 特效占比、成千数量、极多运镜是设计意图而非精确承诺，用可见规模、空间层次和主次关系表达；用户要求精确数字时列入视觉验收。
- 分辨率、帧率、HDR、引擎版本靠平台设置而非文本。8K 等风格词不等于输出规格，按当前平台实际支持填参数，不默认附加 60fps、8K 或某平台上限。

## 3. 可直接改写的完整模板

替换尖括号内容，删除无关字段与未使用参考。按 [信息归属与去重规则](narrative-planning.md#规则优先级与信息归属) 写作：全局固定项一次交代，分段写行动与变化；括号内候选细节不要求全填。运镜写入分段时间戳内、与动作同步，不单列运镜栏；起始与衔接融入正文；独立生成块补足必要上下文，不留模板说明与占位符。局部时序绑定需要时明确"在何动作过程中判断/反应""待何条件成立才接下一动作""另一主体此时仍在做什么"并保留跨段动作相位。

```text
【参考素材职责】
<本段角色/生物的直接@引用；按需补状态/年龄版本>。
<本段道具的直接@引用；按需补持有/交接/破损状态>。
<本段具体场景图片的真实引用；必要时注明使用时段>。
<有动作/音频参考才写：真实@视频 用于 指定动作/运镜/节奏；真实@音频 用于 指定声线/声音>。

【一句话概述】
<主体> 在 <理解事件所需的情境/地点> <主要行动或遭遇>，<关键变化或本段结果>。

【具体情节】
<起-止时间>：<景别+机位/观察方向>。<本镜实际可见的空间层次与运动，特写不强塞全景>。<主体动作（含幅度与速度）；按可见范围选写表情变化、手部操作或道具状态，不硬填看不见的脸部细节；关键表演 beat 需要时，在物理动作后紧接一句直白潜台词，例如“（潜台词：不是害怕，而是在拖延，等对方先露出破绽）”；有对白时在触发处写说话人+状态/语气+说话动词「原句」，音效与音乐内联到发生动作>。<光源方向、硬柔与对比>。<固定观察或运镜路径与落幅；切入时承接上一镜动作、视线或声源，正文不写“剧情作用”>。段末：结束时画面里能看到 <明确结束状态/构图>。
<起-止时间>：<按新的观看对象选景别/机位，或继续同一镜头；从上一段持续动作相位接入，不重演准备姿势>。<本镜可见的动作/表情/物件细节与空间锚点，继承手别、持有链、位置、光源和状态；关键心理意图需要显影时，物理动作后补一句简短潜台词，其他段落省略；声音写在其发生的动作句中，只写适用项>。段末：<结束状态>。
<按已定戏剧主次与信息交接增减时间段，必要时停留、镜内调度或剪切；连接可合并，核心选择及余波有读清窗口，时长按真实动作和对白负荷分配，不以镜头均长作配额，可不等长；各段承接身份、数量、归属、朝向、持有关系、伤势/疲劳与破坏累计，需要清理/修复/换场/复位时写明节点。最后一段完成结局并含尾帧时间>。

【全局补充】
全程保持 <主体身份、服装、体型与有依据的站位/座位连续性>；场景固定布局与光源位置不变（<地标连接、高差、相对地标的光向>），本镜画面左右与光线投影随明确机位推导。运动/对峙保持清楚的轴线关系（<所在轴线侧；需要越轴时用连续运镜或重新建立镜交代>），接近/经过/离开的相对位置随时间自洽。<跨段状态继承要点；需要的清理/修复/换场/复位节点>。<本任务尚需明确的正向状态、数量与归属事实；前文已明确的不重复>；<需要时说明已确认的场内标牌/商标，不把它们编为字幕>。无字幕、无水印；<声音开关：默认 NO BGM，只保留对白、环境声与动作音效>。
```

平台设置写在提示词代码块之外、不在代码块内另加【模型与规格】栏：平台与模型、模式、总时长、画幅、实际支持的分辨率/帧率、声音开关等，只列本模式可设置项，未核验的标待核验。声音与对白写在【具体情节】其发生的时间段内、紧贴发声动作，用 `说话人+状态/语气+说话动词「台词」`（如 `母亲放柔声音说「You can let go now.」`），音效与音乐用自然句（不单列声音栏、不堆到片尾）；无对白片段显式标“本段无对白（设计）”。默认无字幕，画内标牌属于景物而非字幕。

### 单镜头精简写法（仅用于明确精简请求或硬限制下的提交版本）

默认完整交付仍按上文和完整范本展开，不因只有一个镜头而自动用本节。

```text
<参考映射及必须保持的属性，没有参考则删>。
<主体> 在 <环境> 中从 <初始状态> 完成 <主要动作>，<环境/对象的可见响应>，最后停留在 <结束状态>。
<光色与材质>；<景别、关注点与运镜>；<必要声音>。
全过程保持 <本镜必要的数量、归属与持续状态事实>。
```

## 4. 不同类型的替换方法

各类型沿用第3节完整栏目及范本的逐段写法，箭头表不是最终提示词。剧情展开表演与关系回应，风景展开视线遮挡解除与自然运动，音乐舞蹈展开身体/队形/乐句呼应，教程展开可见操作与验证。每段仍交代画面与结果、运镜、声音与衔接，题材安静或无人物也保持细节。

| 类型 | 阶段推进示例 | 响应/反馈 | 需继承的状态 | 运镜与结尾重点 |
|---|---|---|---|---|
| 动作/追逐 | 发现威胁→交锋→局势变化→结果 | 对手反制、障碍与受力结果 | 相对位置、武器归属、消耗与破坏 | 攻防因果可见，按结局收束 |
| 情绪/剧情 | 建立关系→触发事件→选择→回应 | 视线、呼吸、手部与对方反应 | 情绪进程、道具交接、座位与轴线 | 留表演时间，尾帧落在关系变化 |
| 美食/手作 | 原料/部件→操作→状态变化→成果 | 受热、折叠、混合、连接 | 数量、形态、熟度、台面与工具位置 | 关键步骤可辨认，不靠跳切伪造过程 |
| 旅行/风景 | 局部引入→空间展开→主体关系→余韵 | 云、风、光、水面与人流 | 地理关系、光向、天气和行进方向 | 可静可动，换场明确 |
| 音乐/舞蹈 | 乐句引入→动作变化→主题回归→收势 | 身体动作、队形与灯光呼应 | 主体身份、服装、队形和动作方向 | 音乐节拍引导，精确同步后期校准 |
| 科普/教程 | 问题→演示→观察→结论 | 实验或操作的可见结果 | 装置结构、条件、步骤与数据含义 | 正确性与可读性优先 |

## 5. 三个泛化小样

以下为当前四段式文本小样，仅演示跨题材迁移，均未调用视频生成，**不是默认交付的细致程度基准**。无参考标签的例子采用纯文字描述；项目实际风格从美术设定继承。时间与镜头数只来自各自事件，不作新任务配额；持续镜头超过3秒不构成错误，仍须满足整条 Clip≤30秒与演出可读性。

### 情绪剧情：交还钥匙（12秒，四镜，克制节奏）

```text
【参考素材职责】
本段采用纯文字描述，无参考素材。林岚与周远隔桌相对而坐，唯一一把钥匙起初在林岚右手。
【一句话概述】
林岚在沉默中把钥匙推还给周远，周远收下，两人短暂对视后林岚垂下目光。
【具体情节】
0s-3s：侧面双人中景，林岚低头看掌心钥匙，右手落到桌面，周远的目光随她的手下移；固定观察，侧窗柔光沿桌面照亮指尖，明暗反差低。钥匙轻触木桌发出轻响，段末钥匙贴住桌面、仍在林岚指下。
3s-6s：沿右手动作切至桌面斜侧近景，林岚把钥匙推到桌面中央，金属擦过木面发出短促摩擦声；她的手退回近侧桌沿，周远右手从远侧伸来。固定机位保留同一侧窗光，段末周远指尖已触及钥匙。
6s-9s：沿接触相位切至周远侧面中近景，他右手将钥匙收进掌心，林岚的手仍在对侧桌沿；他慢慢抬眼看向林岚，收拢时钥匙环轻碰指节。窗侧柔光照亮手背与侧脸，段末钥匙在周远右手，目光已抵达林岚。
9s-12s：以周远视线切回同轴线双人中景，林岚抬眼回应短暂对视，最后垂下视线，周远仍握住钥匙；固定机位保留两人的坐位和低反差窗光，窗外远处车流声持续，段末林岚看向桌面。
【全局补充】
钥匙始终只有一把，沿林岚右手、桌面中央、周远右手转移；两人坐位与窗的位置连续。本段无对白（设计）。无字幕、无水印。NO BGM，只保留环境声与动作音效。
```

### 生活片段：夜读开灯（15秒，五镜，不加速操作）

```text
【参考素材职责】
本段采用纯文字描述，无参考素材。一盏带两个铰链的折叠台灯在桌右侧，桌左侧摊开一本书；开场灯臂折叠、灯光关闭。
【一句话概述】
读者展开折叠台灯并点亮书页，把手落到页边准备夜读。
【具体情节】
0s-3s：桌面斜侧中近景，读者左手压住台灯底座，右手握住灯头；固定机位看清底座与书的位置，场外柔和侧光照出手背轮廓，段末右手已握稳灯头，房间底噪持续。
3s-6s：沿右手起提切至灯臂近景，右手抬起灯头、依次转开两个铰链，左手持续压住底座，机构转动发出轻微摩擦声；侧向小幅平移跟住展开路径，柔和侧光照亮连接处，段末灯臂已展开。
6s-9s：沿灯头移动切回斜侧中近景，右手把灯头转向左侧书页后松开，左手从底座边缘移到开关旁；固定观察，侧光沿灯臂呈柔和明暗，段末灯头指向书页、灯仍关闭。
9s-12s：沿左手落点切至开关与书页近景，左指轻触开关发出轻响，台灯亮起，暖色光从右上方落到书页，左手收回；固定机位保留由暗到亮的柔和过渡，段末灯光稳定、双手已离开灯具。
12s-15s：沿书页受光切至桌面中景，读者右手落在页边，指尖压平纸角，发出细小纸张摩擦声；固定机位呈现台灯与书的关系，暖色柔光照亮阅读区域，段末手停在页边准备阅读。
【全局补充】
始终是一盏台灯，两个铰链与灯臂连接连续；底座留在桌右侧，书在左侧，展开与点亮分别发生后持续保留。本段无对白（设计）。无字幕、无水印。NO BGM，只保留房间底噪与动作音效。
```

### 风景展示：晨雾山谷（10秒，四镜，局部到整体）

```text
【参考素材职责】
本段采用纯文字描述，无参考素材。松枝位于谷沿观察点，河流穿过谷底，远处山脊承接晨光。
【一句话概述】
清晨的视野从带露松枝展开到雾中的河流与山脊，最终呈现完整山谷。
【具体情节】
0s-2s：谷沿松枝特写，水珠贴住针叶，枝梢在轻风中小幅摆动，近处响起细微叶片摩擦；固定机位，低角度晨光从山脊方向柔和照亮水珠，段末枝梢摆到取景边缘。
2s-5s：以枝梢运动切至同一观察点的谷底远景，河流在薄雾间时隐时现，雾层缓慢顺谷流动；固定观察，散射晨光保留河道轮廓，远处水声和零星鸟鸣持续，段末河湾从雾隙显露。
5s-8s：以河湾通往远山的方向切至山脊远景，山脊边缘受暖色晨光照亮，谷底仍覆冷色薄雾；固定机位看见雾从坡脚缓慢经过，山风轻响，段末山脊与雾层界线清楚。
8s-10s：以同一山脊位置切回谷沿全景，近处松枝、谷底河流和远处山脊形成统一地形关系；固定观察，晨光与薄雾保持原状态，自然声持续，段末完整山谷仍在画面中。
【全局补充】
松枝观察点、河道和山脊沿同一地形连接；清晨光源方向与天气连续。本段无对白（设计）。无字幕、无水印。NO BGM，只保留风、叶片、水流与鸟鸣。
```

## 6. 交付前检查

每次修改后执行 [修改后标准复查闭环](production-checks.md#修改后标准复查闭环)，读回最终完整条目及受影响接缝/依赖，失败先修复再重跑；样本与已授权完整稿均不豁免。

按 [统一调用与验收总表](production-checks.md#统一调用与验收总表) 记录证据；人物描写默认调用已有表演模块并做 [表演证据验收](higgsfield-acting.md#表演证据验收)，短Clip先做 [生成分组验收](narrative-planning.md#生成分组与短段例外验收)。以下检查不是额外用户审批。

- 概述是本段主要内容的一句具体概括，与本段分镜对应，无空泛导演套话、风格/运镜堆叠或后续剧透；四栏不复述独立资产的形态和外观。
- 素材标签可追溯，参考有实际职责；独立资产只补必要状态/年龄版本。干扰背景或多视图在块外安排清理，未绑定不称可提交。
- 去掉意图说明，只看正文能否理解场景重点、选择与后果？候选镜删并后是否损失理解或情绪压力？总目标、各段结果、结局与尾帧一致；主体可以是人、产品、动物、环境或抽象形态。
- 时间段连续，镜头数量和时长由叙事与演出负荷决定，不用固定镜数或3秒门槛验收；每个 Clip 的声明时长与所有片内时间段终点均≤30秒，尾帧与转场计入预算。超量内容压缩或顺延，接缝与对白覆盖重核。
- 每段主要变化可观察，镜头关注点明确，回应与下一段有因果或信息联系。
- 关键表情、物件、接触在所选景别确实可读；没有因默认中远景而漏掉信息，也没有无功能的重复特写。当前取景只写可见细节，特写与较大景别切换后视线、轴线、手别/持有链、动作相位一致。
- 多角度不改变固定地理或凭空添加结构；样本的景别数、秒数不变成配额，增加细节镜头不挤掉必要动作与对白。
- 对照完整范本检查可执行性：具体动作、对象响应、镜头职责、必要视听与接续清楚；去重前后核对同时/先后、触发时机、持续动作与跨段相位是否等义。只删无新增约束的复述。
- 固定项、可变项和变化节点区分清楚；后果继承，无故复原、复制或身份互换被排除。
- 类型特有要求不误变成通用规则；安静、慢速、静镜、多场景、字幕、品牌和非写实风格按用户需要保留。
- 约束短而具体，优先用可执行的正向描述，与需要的经文、商标、字幕、结局或特效衰减不冲突。
- 平台的模式与参数经流程核验；编辑与延伸保留原工作流。无生成结果时只报告结构检查，效果待视听验收。
