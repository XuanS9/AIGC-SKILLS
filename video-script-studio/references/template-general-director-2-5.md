# 跨类型完整导演提示词架构（含 Seedance 2.5 编译）

来源：用户提供的「小师妹六段仙法」范本，提炼的是编排方法，不是官方参数或已验证的效果结论。所有题材的完整视频提示词默认用此格式与段内写法（剧情、动作、风景、音乐、动画、科普等），单镜头也保留完整演出细节。[模型指南](higgsfield-seedance-2-5.md)、[多参考模板](template-omni-reference-2-5.md)、[编辑与延伸工作流](higgsfield-seedance-2-5-mode-playbooks.md) 及其他模型能力继续有效。

本模板落实 [全包统一导演编排](narrative-planning.md)：七层既是规划信息也是默认可见输出格式，各题材沿用相同栏目顺序、改写具体内容。**运镜统一写在分段演出的时间戳正文内、与该段动作同步，不单列独立「运镜」栏。**剧情阶段、镜头、生成片段分别决定；JSON、HTML、代码、局部编辑与延伸等专门格式仍保留，将完整演出内容映射到相应字段。

**默认交付标准：**先完整读取 [小师妹·五法归墟完整范本](template-full-performance-example.md) 再写新提示词，以其动作展开、对象响应、视听层次、状态累积和尾帧细节为基准。下方填空模板用于组织信息，不替代完整演出正文；单镜头、安静剧情也是完整版。

## 1. 七层架构

| 层 | 作用 | 泛化内容 |
|---|---|---|
| 资产锁定 | 谁、什么、哪里保持一致 | 角色身份、产品结构、道具归属、地点布局、参考职责、允许变化与排除项 |
| 一句话总合成 | 全片围绕一个可见目标 | 视频类型＋主体＋环境＋核心事件＋阶段进程＋结局 |
| 全局视听与空间 | 统一画面规则、本片段声音边界 | 风格、材质、光向、色彩、空间关系、运动速度；声源只在当前生成片段内指定 |
| 主体行为与节奏 | 主体怎样行动、环境怎样回应 | 主体目标、动作方式、配角/物体/环境响应、速度曲线、允许停顿与转场 |
| 分段演出 | 目标变成可观察的过程，上一段发生的事仍成立 | 承接状态→主要变化→响应/反馈→结果；身份、数量、位置、朝向、持有关系、情绪、形变、损伤等段间继承，跨片段音频交后期；配合景别、运镜、声音、转场 |
| 结尾状态与交接 | 结局落到最后的画面与声音（输出目标，非输入帧） | 主体位置与动作、最终物体/环境状态、余韵、停留时长或下一段接口 |
| 约束与排除 | 集中防本任务最可能的偏离 | 少量具体问题，与正向目标一致；平台设置另列 |

核心循环：**起始状态 → 主体行动 → 可见响应 → 主体接续 → 结束状态 → 下一段继承**。响应可来自对手、人物表情、物体运动、光影或环境，不必是冲突或特效。以连贯正文展开过程，一个完整阶段不压成一句概括。

## 2. 写作流程

1. 继承用户已确认的素材、类型、剧情、结局、时长、画幅和速度。按 [项目资产总表](asset-registry.md) 读取既有名称、调用名、文件和可用状态，资产锁定栏与分段正文沿用总表；未上传的参考在规划阶段用占位符，提交生成前替换或删除。
2. 先判断模式：新生成用 t2v 或 omni_reference；编辑交代唯一母片、修改范围和原时间线继承；延伸对齐前/后边界状态。后两者用原模式工作流，再按需加入本架构的视听与阶段内容。
3. 每份素材明确「绑定对象、采用属性、保留程度、不采用内容」。有真实资产标签原样引用，否则用平台支持的编号。标签用于资产映射，分段正文用稳定主体名称＋必要可见标识，避免同一角色因换称谓被生成成多人。
4. 写一句总目标，先定结局再倒推阶段。**切段由剧情事件、因果、信息揭示和状态变化决定：先问"哪里发生新的可见事件或状态转折"再开新段。**每段承担一个主要变化，反应与微动作服务该变化。阶段数、单段时长、总长由剧情与平台总时长共同决定，可不等长。阶段不等于镜头，一个连续镜头可跨多阶段。
5. 每段展开关键状态、动作起始与发展、对象响应、主体接续、可见结果和下一段入口，用具体细节写清画面层次、镜头观察位置/景别/跟随方向与声音。同一次生成的段落写本片段内声源变化，独立分镜各自描述本镜现场声。特效片补形态、尺度、材质、运动及残留；无特效片以表演、道具、材料或自然变化落实同等可执行性。演出放不下时减冗余或按授权调整编排，保留已确认事件。
6. 时间段连续覆盖目标时长，转场计入段内，尾帧含在最后一段。时间码表达节奏、时机和交接目标，逐帧精确节拍需后期验证。
7. 相同地点保持空间与后果；多场景在切换处明确地点、时间和保留项。道具交接、换装、清理、修复、倒叙、复位按剧情发生并说明原因与节点。
8. 默认交付「独立平台设置＋完整可复制演出提示词」。仅用户要精简、只改局部或目标格式有硬限制时才缩写/编译，完整任务保留演出母稿。检查重复、矛盾和超载。适用时执行 Seedance lint，规则检查不代表效果验收。

### 从仙侠案例不继承为默认值的内容

- 段数、单段秒数、0帧爆发不继承。缺省 Seedance 2.5、16:9、中文；时长继承用户预算，未定则生成片段默认以模型单次上限（约 30 秒）为目标。先定镜头观看任务和切点，再把连续内容映射进片段。
- 全程悬浮、只放大招、魔潮递增、满屏特效、高速甩镜是该片的动作设计。剧情可沉默，道具特写可停留，风景可静镜，音乐视频可按乐句切分。
- 冰蓝/紫金/玄金、UE 风格、胶片颗粒、六种法相是美术选择；其他任务用自己的色彩、材质、照明与风格。
- 「每段视觉不同」指阶段能被辨认（动作、信息、构图、景别、关系或物体状态），同一风格内允许有意义的视觉重复或音乐母题。
- 「永久保留破坏」泛化为「在所处时间线上继承应保留的结果」，不是所有视频都产生损坏或残骸。
- 「高潮汇聚」可以是情绪回应、功能成果、空间揭示或主题回收，不强制每类短片都有高潮。
- 「最高优先级」表达提示词内部创作优先级，不保证像素级一致或改变模型能力。

### 处理原范本的局部冲突

- 经文/符号是场内图形，字幕/水印/界面是画面叠加。需要经文时写清它不是字幕，用明确的允许内容与位置代替笼统的「禁止一切文字」。商标和需要的字幕同理。
- 魔潮持续填补用于交战阶段，全部消散或倒下后切终场状态。残影、烟雾可衰减，破坏与残骸在被处理前继续存在。
- 主体辨识优先于特效密度：需识别人物的镜头留出面部可读窗口，背拍、远景和有动机的遮挡除外。
- 特效占比、成千数量、极多运镜是设计意图而非精确承诺，用可见规模、空间层次和主次关系表达；用户要求精确数字时列入视觉验收。
- 分辨率、帧率、HDR、引擎版本靠平台设置而非文本。8K 等风格词不等于输出规格，按当前平台实际支持填参数，不默认附加 60fps、8K 或某平台上限。

## 3. 可直接改写的完整模板

替换尖括号内容，删除无关字段与未使用参考。按 [信息归属与去重规则](narrative-planning.md#规则优先级与信息归属) 写作：全局固定项一次交代，分段写行动与变化；括号内候选细节不要求全填。运镜写入分段时间戳内、与动作同步，不单列运镜栏；起始与衔接融入正文；独立生成块补足必要上下文，不留模板说明与占位符。局部时序绑定需要时明确"在何动作过程中判断/反应""待何条件成立才接下一动作""另一主体此时仍在做什么"并保留跨段动作相位。

```text
【资产与参考锁定】
<真实参考标签/编号> 对应 <主体名称>：采用 <身份/形态/服装/结构/材质等>，保留程度为 <完整保留/指定部分保留/属性迁移到指定对象/宽松引导>；不采用 <参考背景/多视图排版/无关人物等>。
<真实参考标签/编号> 对应 <道具或场景>：采用 <属性>，保持 <数量、归属、空间锚点>；允许 <有剧情依据的变化>，不采用 <无关内容>。
<如有动作或音频参考，分别指明继承的动作、节奏、声音和不继承的属性>。

【一句话总合成】
一支 <类型与风格> 视频：<主体> 在 <环境> 中完成 <核心事件>，由 <起点> 经 <关键变化> 到达 <明确结局>，整体节奏为 <节奏曲线>。

【全局视听与空间】
视觉：<光源方向、色彩、材质、景深或画面风格中真正必要的内容；先定一个整体画质基调，默认电影级写实质感（干净通透的画面、真实材质与表面细节、有层次的光比与动态范围、恰当景深与空气透视、稳定自然的镜头质感），再落到本片具体的光色、材质与空间，不停在“电影级/大片感”空词；分辨率、帧率等规格数字仍靠平台设置>。
空间：<主体与关键地标的位置、行进方向、前后层次；如需换场说明切换点>。
镜头基调：<固定观察/克制跟随/手持/快速运动等，服务于观看目标>。
声音：<只写本生成片段实际需要的现场环境声、对白和动作音效；默认 NO BGM。参考音频只用于指定属性，不保证其他独立片段声纹一致>。

【主体行为与节奏规则】
<主体的当下任务与动作方式；必要的速度、强度、停顿或呼吸基线。人物按原 acting/FACS 规则选择当前景别可读的线索，产品或环境写自身响应规律；具体触发与变化留在对应段落>。

【分段演出】
第1段（<起止时间>）<段落任务>
<从关键起始状态展开本段主要变化：触发、具体行动、对象响应、主体接续与可见结果，自然接入下一段。运镜在本段时间戳正文内与动作同步写出：起始机位与景别→关注对象、实际路径与观看目的→结束构图，按需说明切镜依据，不另起独立运镜栏。按需明确动作的同时/先后关系及仍在持续的过程；把目光、微表情、受力和气息绑定到发生它们的动作，不让模型另停一拍逐项表演>。
画面与结果：<仅补正文未交代的视觉层次、环境作用或持续后果，不复述动作；无需的形态、尺度、材质细节不填>。
声音：<与事件同步的声音、对白或声音变化；不重复全局策略和已写清的呼吸过程，静音任务简写“静音”>。

第2段（<起止时间>）<段落任务>
<从上一段尚在持续的动作相位接入新的行动、响应与接续，不从准备姿势重演；有停顿或时间跳跃则按剧情明确。运镜同样写在本段时间戳正文内、与动作同步（机位/景别、关注对象、路径及结束构图；静镜写明固定观察什么），不单列运镜栏。固定项沿用，变化写明，不能只剩招式名或抽象情绪>。
画面与结果：<正文之外需要强调的可辨视觉变化或持续结果>。
声音：<本镜可听的现场声与动作触发音效；同一生成片段内部可描述变化，独立生成时不写“沿用上一镜”>。

<按剧情事件与状态转折增减段落，并按每段演出负荷分配不等或等长时间；不要为了套用范本而补齐段数。各段正文承接上一段的身份、数量、归属、朝向、持有关系、伤势/疲劳与破坏累计，需要清理/修复/换场/复位时写明节点与依据，不单列连续性栏。最后一段完成结局并包含尾帧时间>。

【结尾状态与交接】
最后 <所需停留时间/瞬间>：<主体位置、朝向、姿态或持续动作>；<道具和环境最终状态>；<声音/光影余韵>。<如需接下一段，注明交接状态>。

【关键约束与排除】
<针对本任务最重要的少量排除项，如身份互换、产品结构漂移、道具无故复制、已发生结果复原、未要求的字幕或水印>。
<仅在需要时说明允许的场内文字、商标、字幕、镜头遮挡等例外>。
```

平台设置写在提示词代码块之外、不在代码块内另加【模型与规格】栏：平台与模型、模式、总时长、画幅、实际支持的分辨率/帧率、声音开关等，只列本模式可设置项，未核验的标待核验。音频语法：音乐 `()`、音效 `<>`、对白 `{}`、字幕 `【】`；只有有意生成的文字才写为字幕内容。

### 单镜头精简写法（仅用于明确精简请求或硬限制下的提交版本）

默认完整交付仍按上文和完整范本展开，不因只有一个镜头而自动用本节。

```text
<参考映射及必须保持的属性，没有参考则删>。
<主体> 在 <环境> 中从 <初始状态> 完成 <主要动作>，<环境/对象的可见响应>，最后停留在 <结束状态>。
<光色与材质>；<景别、关注点与运镜>；<必要声音>。
全过程保持 <关键连续项>，排除 <本任务最可能的偏离>。
```

## 4. 不同类型的替换方法

各类型沿用第3节完整栏目及范本的逐段写法，箭头表不是最终提示词。剧情展开表演与关系回应，风景展开视线遮挡解除与自然运动，音乐舞蹈展开身体/队形/乐句呼应，教程展开可见操作与验证。每段仍交代画面与结果、运镜、声音与衔接，题材安静或无人物也保持细节。

| 类型 | 阶段推进示例 | 响应/反馈 | 需继承的状态 | 运镜与结尾重点 |
|---|---|---|---|---|
| 动作/追逐 | 发现威胁→交锋→局势变化→结果 | 对手反制、障碍与受力结果 | 相对位置、武器归属、消耗与破坏 | 攻防因果可见，按结局收束 |
| 情绪/剧情 | 建立关系→触发事件→选择→回应 | 视线、呼吸、手部与对方反应 | 情绪进程、道具交接、座位与轴线 | 留表演时间，尾帧落在关系变化 |
| 美食/手作 | 原料/部件→操作→状态变化→成果 | 受热、折叠、混合、连接 | 数量、形态、熟度、台面与工具位置 | 关键步骤可辨认，不靠跳切伪造过程 |
| 旅行/风景 | 局部引入→空间展开→主体关系→余韵 | 云、风、光、水面与人流 | 地理关系、光向、天气和行进方向 | 可静可动，换场明确 |
| 音乐/舞蹈 | 乐句引入→动作变化→主题回归→收势 | 身体动作、队形与灯光呼应 | 主体身份、服装、队形和动作方向 | 音乐节拍引导，精确同步后期校准 |
| 科普/教程 | 问题→演示→观察→结论 | 实验或操作的可见结果 | 装置结构、条件、步骤与数据含义 | 正确性与可读性优先 |

## 5. 三个泛化小样

仅演示跨题材的结构迁移，均未调用视频生成，**不是默认交付的细致程度基准**。实际完整任务按 [完整演出范本](template-full-performance-example.md) 展开。无参考标签的例子按 t2v 描述主体。时间只对应各自示例事件，段数与时长不作新任务配额。

### 情绪剧情：交还钥匙（12 秒，三段，克制节奏）

```text
【主体与空间】林岚穿米白针织衫，周远穿深灰衬衫，两人隔着餐桌相对而坐。唯一一把铜钥匙起初在林岚右手。窗在画面左侧，柔和阴天光，室内低饱和暖灰色。
【总目标】林岚把钥匙推还给周远，周远接过，两人保持沉默，以一次短暂对视结束。
【0–4秒】林岚看着掌心钥匙，把它放在桌上并缓慢推到桌面中央。固定双人中景，保留两人的视线关系。钥匙轻擦木桌，房间安静。
【4–9秒】承接桌面中央的钥匙。周远伸手将钥匙收进右手，林岚的手随之退回桌沿。镜头轻推至双方手部，让交接过程清楚可见。结束时钥匙完全在周远右手。
【9–12秒与结尾状态】切回双人中景，两人抬眼短暂对视；最后一秒林岚垂下视线，周远仍握着钥匙。只有窗外远处车流声。
【连续性与约束】人物服装、座位和窗光方向保持一致。钥匙沿林岚右手→桌面中央→周远右手转移，数量始终为一；交接后桌面不再留钥匙。画面不添加字幕或水印。
```

### 生活片段：夜读开灯（15 秒，三段，不等长）

```text
【主体与空间】一盏米白色折叠台灯，圆形底座、两节灯臂、扁圆灯头，位于胡桃木桌右侧，桌左侧摊开一本书。开场灯臂折叠，灯光关闭。暖灰背景与柔和侧光，金属表面反光克制。
【总目标】读者展开台灯并点亮书页，准备夜读；最终灯光稳定落在打开的书本上。
【0–5秒】近景中一只手扶住灯头，沿两个铰链把灯臂展开，底座保持贴合桌面。镜头小幅侧移，让铰链转动和灯臂连接清楚可见。结束时灯头朝向左侧书页。
【5–11秒】承接展开状态，同一只手轻触底座开关，灯头亮起，暖色光落在书页上。手退出画面，光照稳定。保持斜侧中近景，听到轻触声。
【11–15秒与结尾状态】缓慢后移至包含台灯与书本的中景，展示明暗关系；最后两秒稳定停留，灯臂和照明保持不变。
【连续性与约束】始终是一盏台灯，两个铰链与两节灯臂连接不变，展开与点亮分别发生后持续保留。背景无额外文案或水印，书页只作阅读环境，不安排可辨认文字。
```

### 风景展示：晨雾山谷（10 秒，一个镜头跨两个阶段）

```text
【总目标与风格】以一个缓慢前移的连续镜头，从湿润松枝之间逐渐看见晨雾中的山谷，画面冷绿，远处山脊受到暖色晨光照亮。
【0–4秒】前景松针带细小水珠，镜头从两侧枝叶之间向前移动；远处山谷起初被枝叶局部遮挡。轻微风声与零星鸟鸣。
【4–10秒与结尾状态】承接同一方向的移动，松枝自然退出两侧边缘，谷底河流和远山逐渐展开。晨雾缓慢流动，河流位置始终固定；最后两秒运镜逐渐放缓，停留在完整山谷景色。
【空间与约束】保持同一山谷地形、清晨光向和天气。景色通过前移与遮挡解除被揭示，山峰和河流不在镜头中变换形状。自然声贯穿，不添加人物、字幕或水印。
```

## 6. 交付前检查

- 素材标签真实存在，每份参考有职责、保留程度与排除项；资产板背景和多视图布局不进成片。
- 总目标、各段结果、结局与尾帧一致；主体可以是人、产品、动物、环境或抽象形态。
- 时间段连续，分段数量和演出负荷适合总时长；尾帧与转场计入预算。
- 每段主要变化可观察，镜头关注点明确，回应与下一段有因果或信息联系。
- 对照完整范本检查可执行性：具体动作、对象响应、镜头职责、必要视听与接续清楚；去重前后核对同时/先后、触发时机、持续动作与跨段相位是否等义。只删无新增约束的复述。
- 固定项、可变项和变化节点区分清楚；后果继承，无故复原、复制或身份互换被排除。
- 类型特有要求不误变成通用规则；安静、慢速、静镜、多场景、字幕、品牌和非写实风格按用户需要保留。
- 约束短而具体，优先用可执行的正向描述，与需要的经文、商标、字幕、结局或特效衰减不冲突。
- 平台的模式与参数经流程核验；编辑与延伸保留原工作流。无生成结果时只报告结构检查，效果待视听验收。
