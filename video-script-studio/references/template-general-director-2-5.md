# 跨类型完整导演提示词架构（含 Seedance 2.5 编译）

来源：用户提供的「小师妹六段仙法」范本。以下提炼的是编排方法，不是官方参数或已经过生成验证的效果结论。当前项目所有题材的完整视频提示词默认使用此格式与段内写法，包括剧情、动作、风景、音乐、动画、科普及其他类型；单镜头同样保留完整演出细节。原有 [模型指南](higgsfield-seedance-2-5.md)、[多参考模板](template-omni-reference-2-5.md)、[编辑与延伸工作流](higgsfield-seedance-2-5-mode-playbooks.md) 和全部其他模型能力继续有效。

本模板落实 [全包统一导演编排](narrative-planning.md)：八层既是通用规划信息，也是默认完整视频提示词的可见输出格式。各题材沿用相同栏目顺序与分段演出结构，改写具体内容。剧情阶段、镜头和生成片段分别决定；用户指定的 JSON、HTML、代码、局部编辑和延伸等专门格式仍保留，将完整演出内容映射到相应字段，不重复叠加模板。

**默认交付标准：**完整读取 [小师妹·五法归墟完整范本](template-full-performance-example.md)，再写新提示词。以该范本的动作展开、对象响应、视听层次、运镜、状态累积和尾帧细节作为基准。以下填空模板用于组织信息，不能替代完整演出正文；单镜头、安静剧情也不自动降为精简版。

## 1. 从原范本提取的八层架构

| 层 | 作用 | 泛化后的内容 |
|---|---|---|
| 资产锁定 | 明确谁、什么、哪里必须保持一致 | 角色身份、产品结构、道具归属、地点布局、参考职责、允许变化与排除项 |
| 一句话总合成 | 让全片围绕一个可见目标推进 | 视频类型＋主体＋环境＋核心事件＋阶段进程＋结局 |
| 全局视听与空间 | 统一画面规则，说明本生成片段的声音边界 | 风格、材质、光向、色彩、空间关系、运动速度；声源只在当前生成片段内指定 |
| 主体行为与节奏 | 定义主体怎样行动、环境怎样回应 | 主体目标、动作方式、配角/物体/环境响应、速度曲线、允许停顿与转场 |
| 分段演出 | 把目标变成可以观察的过程 | 承接状态→主要变化→响应/反馈→结果；配合景别、运镜、声音和转场 |
| 连续性与状态继承 | 确保上一段发生的事仍然成立 | 身份、数量、位置、朝向、持有关系、情绪、形变、损伤、液位；跨片段音频交后期衔接 |
| 结尾状态与交接 | 把结局落实到最后的画面与声音（输出目标，不是输入帧） | 主体位置与动作、最终物体/环境状态、余韵、停留时长或下一段接口 |
| 约束与排除 | 集中防止本任务最可能发生的偏离 | 少量具体问题，与前面正向目标一致；平台设置另列 |

核心循环：**起始状态 → 主体行动 → 可见响应 → 主体接续 → 结束状态 → 下一段继承**。响应可以来自对手、人物表情、物体运动、光影变化或环境，不必是冲突或特效。默认以连贯正文展开过程，不机械重复字段，也不将一个完整阶段压成一句概括。

## 2. 写作流程与适用边界

1. 继承用户已确认的素材、类型、剧情、结局、时长、画幅和速度。先按 [项目资产总表](asset-registry.md) 读取既有中文名称、调用名、文件和可用状态；资产锁定栏与分段正文均沿用总表，不重译或另起名称。没有上传的参考不能假装已绑定；规划阶段可保留占位符，提交生成前必须替换或删除。
2. 先判断模式：新生成用 t2v 或 omni_reference；编辑优先交代唯一母片、修改范围和原时间线继承；延伸先对齐前/后边界状态。后两者使用原模式工作流，再按需加入本架构的视听与阶段内容，不把它们改写为从头生成。
3. 每份素材明确「绑定对象、采用属性、保留程度、不采用内容」。已有平台真实资产标签可原样引用；否则用平台支持的素材编号。标签集中用于资产映射，分段正文用稳定主体名称＋必要可见标识，避免同一角色因换称谓被生成成多人。
4. 写一句总目标，先决定结局，再倒推必要阶段。**切段顺序由剧情事件、因果关系、信息揭示和状态变化决定；先问“哪里发生了一个新的可见事件或状态转折”，再决定是否开新段。**每段只承担一个主要变化；反应与微动作服务该变化，不再并列多个新事件。阶段数、单段时长和总段落长度由剧情需要与平台总时长共同决定，可不等长；不预设固定段数、固定秒数或每段相同长度。阶段不等于镜头，一个连续镜头也可跨多个阶段。
5. 每段展开关键状态、动作如何开始与发展、对象响应、主体接续、可见结果和下一段入口；用具体细节写清画面层次、镜头观察位置/景别/跟随方向与声音。同一次生成的段落可写本片段内声源的变化；独立分镜必须各自描述本镜需要的现场声，不写“继承全局声场”。特效片补主体形态、尺度、材质、运动及残留；无特效片以表演、道具、材料或自然变化落实同等可执行性。只在需要时加入对白或切镜。若演出无法在时段内清楚呈现，减少冗余或按已授权范围调整编排，不擅删已确认事件。
6. 时间段连续覆盖目标时长，转场计入段内；尾帧包含在最后一段，不额外加时。时间码表达剧情节奏、表演时机和状态交接目标，逐帧精确节拍需后期剪辑验证。
7. 相同地点内保持空间与后果；多场景片在切换处明确地点、时间和保留项。道具交接、换装、清理、修复、倒叙、复位可按剧情发生，但必须说明变化原因与发生节点。
8. 默认交付「独立平台设置＋完整可复制演出提示词」，不能仅因单一简单事件而改交精简版。只有用户明确要精简、只改局部或目标格式存在硬限制时才缩写/编译，完整任务保留演出母稿。检查重复、矛盾和超载，不为凑栏目增加剧情。适用时执行现有 Seedance lint；规则检查不代表生成效果验收。

### 不能从仙侠案例继承为默认值的内容

- 不继承六段、每段五秒或0帧爆发。模型、画幅与语言缺省采用 Seedance 2.5、16:9、中文；时长继承用户预算，未定则按内容自然估算。先确定镜头观看任务和切点，再估时并映射生成片段，不把30秒当默认或凑段目标。
- 全程悬浮、只放大招、魔潮递增、禁止停顿、满屏特效、禁慢动作和高速甩镜属于该片的动作设计。剧情允许沉默，道具特写允许停留，风景允许静镜，音乐视频可按乐句切分。
- 冰蓝/紫金/玄金、UE 风格、胶片颗粒、流体比例、六种法相是美术选择。其他任务改成自己的色彩、材质、照明与风格，不自动混入仙侠元素。
- 「每段视觉不同」指阶段能被辨认：可通过动作、信息、构图、景别、关系或物体状态区分。保持同一风格，也允许有意义的视觉重复、重复动作或音乐母题。
- 「永久保留破坏」泛化为「在所处时间线上继承应保留的结果」；不是所有视频都要产生损坏、磨损或残骸。
- 「高潮汇聚」可以是情绪回应、功能成果、空间揭示或主题回收，不要求叠加前段全部元素，也不强制每类短片都有高潮。
- 「最高优先级」用于提示词内部表达创作优先级，不保证像素级一致，也不改变模型或平台能力。

### 处理原范本的局部冲突

- 经文/符号属于场内图形；字幕、水印、界面属于画面叠加。需要经文时写清它不是字幕，不使用笼统的「禁止一切文字」。道具上的商标和需要的字幕同理，明确允许内容与位置。
- 魔潮持续填补适用于交战阶段，最终全部消散或倒下后切换为终场状态。残影、烟雾可衰减，破坏与残骸在未被处理前继续存在。
- 主体辨识优先于特效密度；需要识别人物的镜头留出面部可读窗口，不要求背拍、远景和刻意遮挡时都看清正脸。
- 特效占比、成千数量、极多运镜是设计意图，不能作为精确数量或执行承诺。用可见规模、空间层次和主次关系表达；用户要求精确数字时保留目标并列入视觉验收。
- 分辨率、帧率、HDR 与引擎版本不能靠文本保证。8K 等风格词不等于输出规格；按当前使用平台实际支持的设置填写参数，旧规格快照不能视作实时能力证明。不默认附加 60fps、8K 或某个平台的参数上限。

## 3. 可直接改写的完整模板

替换尖括号内容，删除无关字段与未使用参考。按 [统一规范的信息归属与去重规则](narrative-planning.md#规则优先级与信息归属) 写作：全局固定项一次交代，分段写行动与变化；括号里的候选细节不要求全部填写。八栏目和段内正文、画面与结果、运镜、声音保留，起始与衔接融入正文。独立生成块补足必要上下文，最终不留模板说明与占位符。
局部时序绑定不作冗余删除：需要时明确“在何动作过程中判断/反应”“待何条件成立才接下一动作”“另一主体此时仍在做什么”，并保留跨段动作相位。全局不停顿不能替代关键节点的具体绑定；不把所有动作强制并行，也不对每句机械补写约束。

```text
【资产与参考锁定】
<真实参考标签/编号> 对应 <主体名称>：采用 <身份/形态/服装/结构/材质等>，保留程度为 <完整保留/指定部分保留/属性迁移到指定对象/宽松引导>；不采用 <参考背景/多视图排版/无关人物等>。
<真实参考标签/编号> 对应 <道具或场景>：采用 <属性>，保持 <数量、归属、空间锚点>；允许 <有剧情依据的变化>，不采用 <无关内容>。
<如有动作或音频参考，分别指明继承的动作、节奏、声音和不继承的属性>。

【一句话总合成】
一支 <类型与风格> 视频：<主体> 在 <环境> 中完成 <核心事件>，由 <起点> 经 <关键变化> 到达 <明确结局>，整体节奏为 <节奏曲线>。

【全局视听与空间】
视觉：<光源方向、色彩、材质、景深或画面风格中真正必要的内容>。
空间：<主体与关键地标的位置、行进方向、前后层次；如需换场说明切换点>。
镜头基调：<固定观察/克制跟随/手持/快速运动等，服务于观看目标>。
声音：<只写本生成片段实际需要的现场环境声、对白和动作音效；默认 NO BGM。参考音频只用于指定属性，不保证其他独立片段声纹一致>。

【主体行为与节奏规则】
<主体的当下任务与动作方式；必要的速度、强度、停顿或呼吸基线。人物按原 acting/FACS 规则选择当前景别可读的线索，产品或环境写自身响应规律；具体触发与变化留在对应段落>。

【分段演出】
第1段（<起止时间>）<段落任务>
<从关键起始状态展开本段主要变化：触发、具体行动、对象响应、主体接续与可见结果，自然接入下一段。按需明确动作的同时/先后关系及仍在持续的过程；把目光、微表情、受力和气息绑定到发生它们的动作，不让模型另停一拍逐项表演>。
画面与结果：<仅补正文未交代的视觉层次、环境作用或持续后果，不复述动作；无需的形态、尺度、材质细节不填>。
运镜：<起始机位与景别> → <关注对象、实际路径与观看目的> → <结束构图>；<按需说明切镜依据>。
声音：<与事件同步的声音、对白或声音变化；不重复全局策略和已写清的呼吸过程，静音任务简写“静音”>。

第2段（<起止时间>）<段落任务>
<从上一段尚在持续的动作相位接入新的行动、响应与接续，不从准备姿势重演；有停顿或时间跳跃则按剧情明确。固定项沿用，变化写明，不能只剩招式名或抽象情绪>。
画面与结果：<正文之外需要强调的可辨视觉变化或持续结果>。
运镜：<机位/景别、关注对象、路径及结束构图；静镜写明固定观察什么>。
声音：<本镜可听的现场声与动作触发音效；同一生成片段内部可描述变化，独立生成时不写“沿用上一镜”>。

<按剧情事件与状态转折增减段落，并按每段演出负荷分配不等或等长时间；不要为了套用范本而补齐段数。最后一段完成结局并包含尾帧时间>。

【连续性】
<只提易丢失的关键跨段状态，如持有关系、伤势/疲劳、呼吸或环境后果；固定项引用资产锁定，不复述阶段剧情。需要清理、修复、换场或复位时写明节点与依据>。

【结尾状态与交接】
最后 <所需停留时间/瞬间>：<主体位置、朝向、姿态或持续动作>；<道具和环境最终状态>；<声音/光影余韵>。<如需接下一段，注明交接状态>。

【关键约束与排除】
<针对本任务最重要的少量排除项，如身份互换、产品结构漂移、道具无故复制、已发生结果复原、未要求的字幕或水印>。
<仅在需要时说明允许的场内文字、商标、字幕、镜头遮挡等例外>。
```

平台设置单独交付：所用平台与模型、模式、总时长、画幅、实际支持的分辨率/帧率、声音开关等；只列本模式可设置的项目。未核验的项目标为待核验，不填臆测值。若使用指南约定的音频语法，音乐用 `()`，音效用 `<>`，对白用 `{}`，字幕用 `【】`；只有有意生成的文字才写为字幕内容，模板栏目标题不是字幕指令。

### 单镜头精简写法（仅用于明确精简请求或硬限制下的提交版本）

本节保留短提示词能力；默认完整交付仍按上文和完整范本展开，不因只有一个镜头而自动使用本节。

```text
<参考映射及必须保持的属性，没有参考则删>。
<主体> 在 <环境> 中从 <初始状态> 完成 <主要动作>，<环境/对象的可见响应>，最后停留在 <结束状态>。
<光色与材质>；<景别、关注点与运镜>；<必要声音>。
全过程保持 <关键连续项>，排除 <本任务最可能的偏离>。
```

## 4. 不同类型的替换方法

以下类型全部沿用第3节的完整栏目及范本的逐段写法，不能把表中箭头直接当作最终提示词。剧情重点展开表演与关系回应，风景展开视线遮挡解除与自然运动，音乐舞蹈展开身体/队形/乐句呼应，教程展开可见操作与验证。每段仍交代画面与结果、运镜、声音与衔接；题材安静或没有人物，不降低细节要求。其他题材按同样方法组织。

| 类型 | 阶段推进示例 | 响应/反馈 | 需要继承的状态 | 运镜与结尾重点 |
|---|---|---|---|---|
| 动作/追逐 | 发现威胁→交锋→局势变化→结果 | 对手反制、障碍与受力结果 | 相对位置、武器归属、消耗与破坏 | 让攻防因果可见，按结局收束 |
| 情绪/剧情 | 建立关系→触发事件→选择→回应 | 视线、呼吸、手部与对方反应 | 情绪进程、道具交接、座位与轴线 | 留出表演时间，尾帧落在关系变化 |
| 美食/手作 | 原料/部件→操作→状态变化→成果 | 受热、折叠、混合、连接 | 数量、形态、熟度、台面与工具位置 | 关键步骤可辨认，不靠跳切伪造过程 |
| 旅行/风景 | 局部引入→空间展开→主体关系→余韵 | 云、风、光、水面与人流 | 地理关系、光向、天气和行进方向 | 可静可动，换场明确，不强制情节反转 |
| 音乐/舞蹈 | 乐句引入→动作变化→主题回归→收势 | 身体动作、队形与灯光呼应 | 主体身份、服装、队形和动作方向 | 音乐节拍引导，精确同步后期校准 |
| 科普/教程 | 问题→演示→观察→结论 | 实验或操作的可见结果 | 装置结构、条件、步骤与数据含义 | 正确性与可读性优先，文字按需求加入 |

## 5. 三个泛化小样

以下仅演示跨题材的结构迁移，均未调用视频生成，**不是默认交付的细致程度基准**。实际完整任务按 [完整演出范本](template-full-performance-example.md) 展开；用户明确要求简版时可采用这些短写法。无参考标签的例子按 t2v 描述主体；用户上传资产后再增加真实映射。时间只对应各自示例事件，段数与时长不得成为新任务默认配额。

### 情绪剧情：交还钥匙（12 秒，三段，克制节奏）

```text
【主体与空间】林岚穿米白针织衫，周远穿深灰衬衫，两人隔着餐桌相对而坐。唯一一把铜钥匙起初在林岚右手。窗在画面左侧，柔和阴天光，室内低饱和暖灰色。
【总目标】林岚把钥匙推还给周远，周远接过，两人保持沉默，以一次短暂对视结束。
【0–4秒】林岚看着掌心钥匙，把它放在桌上并缓慢推到桌面中央。固定双人中景，保留两人的视线关系。钥匙轻擦木桌，房间安静。
【4–9秒】承接桌面中央的钥匙。周远伸手将钥匙收进右手，林岚的手随之退回桌沿。镜头轻推至双方手部，让交接过程清楚可见。结束时钥匙完全在周远右手。
【9–12秒与结尾状态】切回双人中景，两人抬眼短暂对视；最后一秒林岚垂下视线，周远仍握着钥匙。只有窗外远处车流声。
【连续性与约束】人物服装、座位和窗光方向保持一致。钥匙沿林岚右手→桌面中央→周远右手转移，数量始终为一；交接后桌面不再留钥匙。画面不添加字幕或水印。
```

### 生活片段：夜读开灯（15 秒，三段，不等长）

```text
【主体与空间】一盏米白色折叠台灯，圆形底座、两节灯臂、扁圆灯头，位于胡桃木桌右侧，桌左侧摊开一本书。开场灯臂折叠，灯光关闭。暖灰背景与柔和侧光，金属表面反光克制。
【总目标】读者展开台灯并点亮书页，准备夜读；最终灯光稳定落在打开的书本上。
【0–5秒】近景中一只手扶住灯头，沿两个铰链把灯臂展开，底座保持贴合桌面。镜头小幅侧移，让铰链转动和灯臂连接清楚可见。结束时灯头朝向左侧书页。
【5–11秒】承接展开状态，同一只手轻触底座开关，灯头亮起，暖色光落在书页上。手退出画面，光照稳定。保持斜侧中近景，听到轻触声。
【11–15秒与结尾状态】缓慢后移至包含台灯与书本的中景，展示明暗关系；最后两秒稳定停留，灯臂和照明保持不变。
【连续性与约束】始终是一盏台灯，两个铰链与两节灯臂连接不变，展开与点亮分别发生后持续保留。背景无额外文案或水印，书页只作阅读环境，不安排可辨认文字。
```

### 风景展示：晨雾山谷（10 秒，一个镜头跨两个阶段）

```text
【总目标与风格】以一个缓慢前移的连续镜头，从湿润松枝之间逐渐看见晨雾中的山谷，画面冷绿，远处山脊受到暖色晨光照亮。
【0–4秒】前景松针带细小水珠，镜头从两侧枝叶之间向前移动；远处山谷起初被枝叶局部遮挡。轻微风声与零星鸟鸣。
【4–10秒与结尾状态】承接同一方向的移动，松枝自然退出两侧边缘，谷底河流和远山逐渐展开。晨雾缓慢流动，河流位置始终固定；最后两秒运镜逐渐放缓，停留在完整山谷景色。
【空间与约束】保持同一山谷地形、清晨光向和天气。景色通过前移与遮挡解除被揭示，山峰和河流不在镜头中变换形状。自然声贯穿，不添加人物、字幕或水印。
```
