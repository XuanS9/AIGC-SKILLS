# 动作演出范本：小师妹·五法归墟（当前格式，两条 Clip）

> 本范本把原「小师妹六段仙法」四段式长稿改写成当前块结构。原稿六招挤在一条 30 秒里，按 [一条只做一件事](template-general-director-2-5.md#模型可读性higgsfield--dreamina-seedance-25-标准) 拆成两条：Clip 1-1 是前三招（经文、凤凰、陨星），Clip 1-2 是后三招（裂隙、鲲鹏、归墟）。两条都按 [Clip 边界隔离](narrative-planning.md#clip-边界隔离强制) 开场和收尾。格式规则见 [跨类型导演模板](template-general-director-2-5.md)，剧情演出范本见 [完整演出范本](template-full-performance-example.md)。
>
> 学的是动作因果：起手与发力 → 对手响应 → 主体闪避或接续 → 可见命中或落空 → 空间与环境结果 → 下一招入口，以及实体破坏怎样累积。仙侠题材、招式数、配色和秒数只属本例，新任务按自己的剧情决定。本例尚未实际生成，生成效果待验证。

## 导演方案（块外）

```text
导演方案｜Clip 1-1、1-2
意图：观众看着一个人在断桥祭坛上把不断改道的魔潮一层层压下去；每一招都留下新的伤痕，最后五种力量合成一招清场。
立场：客观，观众和主角同时看到威胁。理由：动作戏的快感来自看清因果，不靠信息差。
拆条：原稿六招一条 30 秒，每招 5 秒、起手到余波都挤在一起。拆成两条，每条三招、每招约 8–9 秒，招式有完整的起势、敌方响应、命中和残留。
镜头表（1-1）：
  0-1s｜战场全景｜定位秒：主角、魔潮、祭坛、断桥、天门一次交代清楚｜切到第一招
  1-10s｜经文三段｜天幕成形 → 侧滑避袭 → 锁链拖回精英｜每段换景别看清一层因果
  10-19s｜凤凰三段｜成形 → 振翼推火浪 → 俯冲横扫｜翼面擦镜切出
  19-30s｜陨星三段｜云裂 → 连续落点 → 主角避开能量团，尾帧悬停｜Clip 结束
镜头表（1-2）：
  0-1s｜战场全景｜定位秒：从对岸看同一战场，陨坑与断桥缺口已在｜换角度开场
  1-9s｜裂隙三段｜拉开 → 三层纵深 → 下沉躲扑击｜裂口收窄
  9-19s｜鲲鹏两段｜云海隆起 → 巨浪与螺旋吸流｜翼缘掠过前景
  19-30s｜归墟三段｜五法汇聚 → 领域展开 → 余波尾帧｜Clip 结束
节奏：每招先让观众认出主体形态，再放大到大半画面；关键施法、命中和空间全貌处镜头短暂稳住。
揭晓：无，动作戏不设揭晓。
占位：祭坛直径约 30 米、断桥宽约 6 米、主角身高 165 cm、精英魔物身高约 5 米、鲲鹏翼展约 400 米，均为助手代定，待确认后写回 project.md。
```

声音：<层叠的经文低鸣从高空压近>，<尖翼划过空气的锐响>。
→ 结束：她已滑到画面中央，右掌向下，飞行魔物从她身侧掠过画面右下。

4s-7s｜切至俯视全景｜视场角84°｜固定

7s-10s｜切至侧前中景｜视场角47°｜固定
画面：精英魔物在画面右侧从祭坛中央跃起，撞向最下层经文；小师妹在画面左侧，右手抬在胸前。

表情：她收拢五指时下颌一紧，嘴唇抿成一线，翻掌时眼神抬向天门方向。
声音：<符文锁链收紧的锐响>，<石面闷裂声>。
→ 结束：精英被锁在祭坛左缘，石面有一圈裂纹和发光的经文烙印；她的右掌朝上，经文边缘在燃烧。

10s-13s｜切至侧前中近景｜视场角47°｜缓慢后拉
画面：小师妹在画面中央偏左，燃烧的经文碎片在她身后反卷成紫金色羽骨；背景是画面右上的残缺天门。

表情：她上升时眉眼舒展，呼吸放长，嘴角平静。
声音：<凤凰成形时的一声长啸穿过风压>。
→ 结束：完整凤凰在她身后张开双翼，冰蓝半透明的身体、紫金燃烧的翼缘和玄金羽骨纹路都看得清。

13s-16s｜切至断桥低角度全景｜视场角84°｜固定
画面：前景是画面下方断桥的桥面；中景是凤凰的双翼占满画面上半部；背景是祭坛和右侧断柱。

动作：凤凰第一次振翼，冰蓝火浪贴着桥面向画面右侧翻卷，前排魔物被掀起约 3 米；后排魔物攀上两侧断柱，从高处跃向凤凰腹部与小师妹之间的空隙。
表情：不适用，看不清人物的脸。
声音：<火浪翻卷的轰鸣>，<岩石受热爆裂的噼啪声>。
→ 结束：桥面留下一片黑蓝色琉璃焦土，经文烙印从焦土下透出光，魔物残骸被推积到断柱根部。

16s-19s｜切至翼侧跟拍中景｜视场角47°｜跟拍

## Clip 1-2｜裂隙、鲲鹏、归墟

## 生成风险（块外）

- 大运镜和大特效同段：13-16s 火浪、22-26s 领域展开都只给一个主运动并给足秒数；若出现跳切，备选是把这两段改成固定镜头。
- 巨型生物尺度漂移：鲲鹏翼展约 400 米，靠天门和主角的比例表现；若缩小成普通鸟鱼，备选是加一段只拍翼面与天门的固定大全景。
- 两条之间的状态：1-2 开场从对岸看同一战场，陨坑、焦土、断桥缺口都写进 [场景] 和第一段画面，不靠上一条的尾帧。
- 资产全部为 planned，没有参考图时主角特写最容易漂；提交前先出图并绑定。

## 从本例学什么

- **一招一个完整因果。**每招三段：成形 → 敌方响应与主角应对 → 可见结果；结果是下一招的起点（燃烧的经文变成凤凰羽骨，火羽变成星点）。
- **破坏只累积不复原。**经文烙印、焦土、陨坑、断桥缺口出现后，后面每段的画面都带着它们；烟尘和余光可以衰减。
- **太密就拆条。**原稿六招一条，每招 5 秒；拆成两条后每招约 9 秒，起势和余波都有时间。
- **每条第一秒锁站位。**两条都以约 1 秒的全景定位秒开场，`[声音]` 里小师妹轻声 `{Hm.}`；第二条换到对岸角度开场，不接上一条的动作。
- **特效写形态、尺度、材质、运动和残留。**凤凰写翼展和三层材质，陨星写直径和落点，裂隙写长度和断面，不写“炫酷特效”。
