# 失败诊断与验收

生成结果出现问题时，先找到最影响可读性的一个症状。每轮只修改动作、镜头或参考素材中的一类变量，方便判断修正是否有效。

验收依据为 [共享叙事规划规则](narrative-planning.md) 与 [动作导演指南](fight-director.md)：故事事件、因果、连续状态和呈现工作量决定分段与时长。旧数字示例不作为通过或失败阈值。

## 三类变量

### 动作变量

包括动作方向、目标部位、接触结果、身体回应、位移、速度、距离、资源和下一拍接口。

### 镜头变量

包括景别、机位、轴线、速度、切点、跟随对象、遮挡和镜头职责。

### 参考素材变量

包括首帧姿势、人物轮廓、武器可见性、角色与场景职责、素材顺序和首尾帧差异。

## 症状与首选修正

| 症状 | 优先检查 | 首选修正 |
|---|---|---|
| 双方各打各的 | 动作 | 补全发起、接触、回应、位移和下一拍接口 |
| 接触点看不清 | 镜头 | 改用侧向中景或短促接触特写 |
| 人物左右互换 | 镜头 | 固定轴线和屏幕方向，切镜前记录站位 |
| 动作自动减少 | 动作 | 减少装饰描述，保留关键动作与结果 |
| 身体融合 | 参考素材 | 更换轮廓分离、肢体完整的首帧 |
| 武器复制或变形 | 参考素材 | 使用完整武器图，并写明数量、长度、材质和握法 |
| 远程攻击凭空出现 | 动作 | 补充取用、装填或充能，交代路径和落点 |
| 远程角色突然近战 | 动作 | 增加后撤、侧移、掩体或副武器反制 |
| 受击没有力量 | 动作 | 写清接触部位、受力方向、位移和材质反馈 |
| 场景损伤恢复 | 动作 | 在后续时间段重复记录损伤状态 |
| 镜头随机跳切 | 镜头 | 减少机位数量，让每镜只承担一个职责 |
| 首尾帧过渡扭曲 | 参考素材 | 缩小姿势和机位差异，必要时增加中间落点 |
| 参考视频被完整复刻 | 参考素材 | 明确只继承动作轨迹或摄影机路径 |
| 特效没有来源 | 动作 | 删除特效或绑定到武器、装置、能力与接触点 |
| 无内容依据地套用固定段数或均分时间 | 镜头 | 按事件、因果与状态交接重定切点，以呈现工作量分配时长；用户或音乐需要的等长段有效 |
| 极速版凭空增加交锋或改变结局 | 动作 | 恢复固定事件与结果，通过更快执行和压缩冗余衔接加速 |
| 复杂事件被短块截断 | 镜头 | 按事件工作量延长或合并时间块，必要时在可承接状态处分镜 |
| 总时长容不下固定事件 | 动作 | 核对必要动作工作量并提出总时长或分批生成方案，不擅自删改剧情 |

## 交付前验收

### 角色与道具

- 角色数量符合用户要求
- 每名角色的外观锚点全程一致
- 武器与关键道具数量固定
- 多角度设定图没有生成额外分身

### 叙事分段与速度

- 三档强度和两档速度保留用户指定的事件、因果顺序、对白、关键招式、胜负与结尾
- 每个段落边界可由目标、因果、空间或状态交接解释，不来自预设数量或等长时间格
- 各段时长足以承载必要位移、接触、反应与信息识别，按工作量推导而非按总时长套表
- 镜头、时间块与故事段按实际需要对应，没有将骨架条目机械转换成固定段数
- 极速版通过动作执行与衔接加快体现速度，没有强制微动作增量、交锋或镜头配额
- 旧数字范围仅作可选示例，不要求标准版约四段或极速版五至六段
- 进入与退出状态完整记录，拆分生成时可从上一段结果自然接续
- TOTAL 与必要工作量及用户已定预算一致；未定则按内容自然估时，不设30秒或15秒默认。每镜有观看任务、切点依据与预计保留时长，生成片段按模型限制另行组织；禁止凑近30秒、统一长段或机械短切

### 动作因果

- 每次攻击都有目标和回应
- 接触、格挡或落空清楚可见
- 受力方向与位移结果一致
- 下一拍能够从上一拍的状态自然发生
- 不同角色的距离、移动和反制方式有明显区别

### 远程连续性

- 投射物或能量拥有可见来源
- 释放路径、命中或落点清楚
- 弹药、装填和充能状态连续
- 被贴身后的反制符合角色武器特点

### 空间与镜头

- 在动作依赖空间判断之前建立人物、路线和障碍位置，可结合开场事件呈现，不强制独立开场段
- 屏幕方向和人物左右关系稳定
- 镜头职责清楚，没有用运镜遮住动作
- 切镜继承姿态、速度、武器和环境状态

### 环境与声音

- 破坏从接触点沿受力方向扩散
- 损伤、碎片和余波在后续镜头继续存在
- 同步声与画面动作顺序一致
- 持续声场与场景相符

### 格式

- 时间段首尾连续并覆盖已确认的 TOTAL；没有为凑时长添加空白、重复动作或新剧情
- 单条提示词只使用一种模型时间格式：Seedance 连续整秒时间段，MiniMax-H3 精确时间码，通用模型使用其支持的格式
- 模型时间格式和容量限制没有被转换成固定叙事段数或等长片段
- 生成说明放在代码块外
- 提示词正文完整放在一个代码块内
- 默认无字幕、无水印

## 修正记录模板

```text
本轮主要症状：〔只写一个〕
归属变量：〔动作 / 镜头 / 参考素材〕
本轮唯一修改：〔具体改动〕
保持不变：〔其余条件〕
复测观察：〔修正后结果〕
```

如果连续两轮修正没有改善，重新检查问题是否分错变量。不要同时重写全部提示词。
