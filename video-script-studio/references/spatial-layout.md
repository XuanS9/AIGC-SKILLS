# 文字布局先锁定：场景与视频共享空间底稿

## 默认轻量路径

**先设计“什么在哪里、如何连接”，再分别写场景和视频提示词。**场景出图负责呈现布局，视频编排负责沿布局行动；两者从同一份 `asset-registry.json` 的 `layout` 取值，不各自猜位置。此规范用于场景提示词、相关视频/分镜及空间冲突诊断。

- 默认不要求用户回传所有场景图或基础资产图，不把助手看过实图设为文字交付前置条件。资产设定与文字布局确认后即可继续下一阶段、定稿文字提示词。
- 布局随场景样本一起确认，不单独增加审批、地图绘制或项目文件。基础资产尺度与场景通道在文字阶段协调；简单场景只保留实际需要的关系，不填无关坐标。
- 未看实图时，块外简注「基于已确认文字布局，实图未核对」。这不是文字设计未完成，也不必仅因未回传图而降为条件性预稿；不得声称生成结果已经吻合。
- 只有关键设计未确认、已有冲突未解决或任务依赖未知的参考内容时，受影响部分才为条件性预稿。缺实际素材/绑定影响可提交状态，不自动阻止文字设计定稿。
- 用户要求严格逐图验收，或报告明显空间偏差时，仅就相关场景/资产读取图片核对；不扩大为全项目补传。已知图文冲突不得以“轻量模式”忽略。

## 场景资产内容边界

**场景图只交付纯环境（强制，本节是唯一归属）。**S 只含地形、自然介质、建筑本体与固定结构。整张图不得混入人物、群演、剪影、倒影、动物或生物、家具、货物、灯具、独立器械、旗帜、船只或载具及剧情道具，远景、装饰或已固定的物件也不行。船舱是空舱壳体，船本体归 P。尺度用门洞、层高、台阶、透视和必要尺寸表现，不放人或道具作比例尺。

场景正文写环境、地标连接、固定结构与表面痕迹、空置通道、材质、天气、光色和可读构图。角色和道具的落位记 `video_staging` 并进入视频，不在场景正文点名“由视频加入”。人物和道具的光源只在视频里出现，场景可用自然光或场外照明效果。

## 1. 每个场景的一份空间底稿

先列下面适用的信息，再转成自然语言场景提示词。布局字段见 [总表规范](asset-registry.md#场景布局与批次复用)。

| 项目 | 写清什么 | 避免什么 |
|---|---|---|
| 基准视点 | 从哪个地标朝哪个地标看、观察高度；此视点用于定义场景母图 | 无观察基准的左右/前后 |
| 固定地标 | 稳定名称、必要数量、属于哪个区域、相对位置 | 只列“有桥、有树、有山” |
| 连接关系 | 哪条通道/桥/门连接哪两个区域，两端各在哪里 | 只说“远处有桥”却没有桥头 |
| 高度与尺度 | 谁高于谁，动作所需的相对宽度/落差；无需求不强加精确数值 | 空喊“宏伟”，或杜撰实测米数 |
| 行动区域 | 从哪里经哪里能到哪里，转身/站立/追逐所需空间 | 后续动作才凭空出现道路 |
| 可见性 | 场景母图需要看清的入口、出口、桥头及关键连接 | 核心通道被装饰物或雾完全遮住 |
| 光向 | 相对固定地标的光源侧；有需要再推导本镜顺/逆光 | 所有反打仍机械写“画面左侧来光” |

涉及剧情关键入口、道路或遮挡的未设计区域记为“未定义”，需承载关键动作时先补最少关系并同步描述。普通背景、未显示的墙面和同一路段可由视频模型补全，不要求为每个画外面设计或生成参考图。已读图片中的遮挡区域记为“图中不可确认”，不能把未观察到的内容写成视觉事实。用户确认的画外空间可作为设计保留，与实际观察分开记录。

## 2. 场景提示词写法

**先做依据卡。**场景按[资产设计依据](asset-design-basis.md)先确定世界与时代、场所用途、谁建造与使用、建材与施工方式、剧情要用的地标通道遮挡与已发生的痕迹，再写空间与画风。

**画风与空间同时编译。**写场景前默认读取 [视觉参考匹配](higgsfield-style.md#电影视觉参考匹配) 和项目美术记录，先继承媒介、时代文化与用户电影/剧集参考，再把建筑、材质磨损、光色和空气层次落实到每张独立正文。布局清楚但画风只写“写实电影/北地”仍是不完整的场景提示；风格不得新增剧情地标、挪动入口或给无光源场景添加魔法光。

场景基准光照先从剧情确定昼夜和季节，再从当前项目美术设定读取天气、亮度、色温与阴影关系；夜景依照已有光源交代地形和动作。跨时段复用图继承地点身份、固定结构与材质，视频按当前时段及门窗遮挡呈现受光。美术变更先更新项目设定，再同步受影响的场景与镜头。

默认顺序：**环境主体与身份 → 关键地标及连接 → 固定结构与表面使用痕迹 → 动作需要的通行/遮挡与相对尺度 → 光色/材质/天气 → 可读构图**。构图按需要选择，不强填画面左右、相机米数或完整空间坐标；精确尺度只用于已确认或确有动作接触意义的约束。只写该场景需要的信息；地标沿用布局中的稳定中文名，不强制为每块石头建立独立资产。

把空间关系、场所用途、建筑表面磨耗与空置通道写入可复制正文。居所和货舱为空置壳体，天然地点保留地貌；贫寒通过墙地修补、污损和磨耗表达。家具、货物、日用品、灯具、独立器械和全部角色/生物只在视频出现，其位置与光照变化写入对应时段。环境图采用自然光或场外照明效果，尺度以层高、门洞、台阶与透视说明，默认无文字与水印。

**反例：**“雨林山谷有木桥、瀑布、巨石，电影级光影。”

**正例（布局设计示例，不是实际出图报告）：**

```text
从入口平台朝瀑布平台观察的略俯视广角环境图。近景为入口平台，远景为瀑布平台，两座平台之间是深沟。唯一一座木桥沿画面纵深连接两座平台，桥面与两端平台接平并高于沟底。巨石位于入口平台、入口侧桥头的画面左侧；巨石与桥头之间留出连续开阔通道。瀑布位于对岸平台后方，水流落入沟底。两端桥头及连接通道均清晰可见，薄雾集中在沟底。白日天光照到湿润岩石、木材与雨林植被，桥面接触阴影自然。无人物、动物、文字或水印。
```

固定结构围绕场所功能组织，关键地标、出入口和空置通道保持连接。室内示例：“旧板墙有补缝，地面保留磨耗和潮盐，入口与后墙开口之间连续畅通；入口天光沿梁柱与空地形成明暗层次。”物件布置另写视频。

## 2.1 按环境内容划分参考图

**默认同一实际空间共用一张参考；画面环境内容明显不同时分别生成。**大场景名、剧本场号或图号前缀不是图数规则。场景图提供环境身份、结构、材质和必要连接，视频模型按动作补全机位、近景、局部及当前时段光照。

| 内容变化 | 默认处理 | 判断依据 |
|---|---|---|
| 山脚两侧追逐、同一路面正反向、棚角回看 | 共用所属空间图 | 环境主体仍是相同岩壁、道路或棚墙，主要变化是观察角度 |
| 面部/拳头/脚部特写、局部接触、常规反打 | 共用空间图 | 景别变化不新增环境身份 |
| 同一雪院白天改夜间、同一洞室暮色 | 共用空间图，视频描述光照 | 结构与内容不变，不只为天光变化补图 |
| 长屋内墙地、梁柱、门洞 → 门外立面、屋顶、雪院 | 单独生成环境内容参考 | 主体结构和可见环境明显改变，即使同属一座建筑 |
| 矿硐内部 → 泉旁草地和小径 | 分别生成 | 室内岩硐与室外地形承担不同动作空间 |
| 新路段出现参考未涵盖的重要桥梁、建筑群或新地貌 | 按内容差异单独生成 | 不是仅把原道路拍近；新环境内容影响剧情与连接 |

不为“图数少”合并完全不同内容，也不为“角度不同”扩张一套相似衍生图。同空间参考默认取一张最能建立身份与连接的环境图，不强求它展示每个未来机位。新图数以内容差异为依据，不按每镜、每角色、每30秒分配。

- 选定的实际图像是后续环境外观依据；视频继承相对关系，不另写一套相反屏幕左右。未看图时按文字设计推进并注明未核实，不能称图中已具备通道。
- 门内外分别出图时保持同一建筑、唯一入口、门框材质和连接，不为两个环境各造一套门。可以沿用关联参考做图生图，也可独立生成并保持已定身份；方法按实际素材和任务选择，不增加强制控制图流程。
- 实际采用图生图时直接交“基于输入图，改变什么、保持什么”的提示词，并登记真实直接源图；独立不同内容图的源图可为null，后缀编号不证明图生图关系。
- 日/夜、破坏、门开合等状态以视频当前时段为准，同一状态和事件跨镜连续。光照变化本身不是再出图理由；已有结果确实持续失败时再针对证据局部修输入，用户指定的参考策略优先。
- 单图与视频都有生成随机性。减少重复参考和相冲突坐标可降低冲突，不保证任意未显示区域的三维重建一致；实际穿帮按第5节局部诊断。
- **弃用图直接删除活动正文。**确认不再使用后，删除场景提示块、当前视图计划、别名、图号和生成任务，同步视频引用、使用时段、总数及项目当前索引；不留“可选”、备用或空块。原稿可归档，历史记录不作为活动图。

不同内容的图生图示例（只在确需输入图时使用，不是强制父级）：

```text
以输入的长屋室内图保持同一木框正门与建筑材料，生成门外雪院环境。构图以草皮屋顶、建筑立面、檐下与门前院落为主；村路接入雪院，正门连接原室内。门洞内保留原暖暗层次，室内空地的纵深通过门洞可辨。保持同一建筑身份和天气，墙地修补与磨耗延续原场所，空置门前通道可辨，建筑投影自然。无人物、动物、文字或水印。
```

## 3. 三种方向分开，视频只推导不另造

1. **固定空间关系**：木桥连接入口平台与瀑布平台；换机位也不改变。
2. **画面关系**：从入口看，瀑布平台在远景；从对岸反拍，入口平台变成远景。画面左右/前后随机位投影变化，不是场景地理坐标。
3. **主体朝向与视线**：人物面朝瀑布平台、背对入口平台；与“面对镜头”不是同一描述。

视频逐镜明确必要的 **起点、路径、终点、朝向/视线与空间关系**，终点写成该段看得见的结束状态，下一段从该状态接入（复制正文不写“下一镜继承”这类说明）；机位、角度、高度按观看任务选择，只在关键接触/遮挡确需时写到具体位置。固定镜头可继承已建立的机位，不机械重复全表。只提本镜参与动作的地标，不能把全场景资产清单塞进每个复制块。

**视频动作示例（仅演示空间写法，不是完整块结构交付）：**

```text
摄影机位于入口平台，朝瀑布平台拍摄。人物从巨石旁起跑，沿开阔通道抵达入口侧桥头，踏上木桥朝瀑布平台奔跑；镜头结束时人物到达桥面中段，仍面朝瀑布平台。
```

后续若从瀑布平台反拍，应写“摄影机位于瀑布平台，朝入口平台拍摄；人物从桥面中段继续向摄影机所在的瀑布平台跑来”，而不是让人物重新从巨石旁起跑。需要越轴时用可见运镜或重新建立镜交代，不因维持“左→右”而搬动地标。

### 3.1 大幅度空间转移必须显式交接

跨房间、跨建筑、室内外、多个地标或行动区域的移动属于**大幅度物理空间转移**，视频正文不写成单画面“从A到B”，按 [拆镜或甩镜过桥](directorial-shot-design.md#大幅度空间转移必须拆镜或用甩镜头过桥) 写成切镜、甩镜或有条件的一镜到底。

场景图仍只负责各自环境内容；视频正文负责空间转移和人物/道具的进出，不为一次转移强行合并完全不同的环境参考图。

总表不会传给生成模型，不能用“遵守 layout”“按场景布局”替代具体位置。视频可带本镜必要的空间关系与运动锚点，**这不属于禁止重复的资产外观描述**；仍不抄整段场景材质、装饰与全图布局。

### 3.2 进出门：门槛方向锁定

**进出门由角色跨门前后的所在区域决定，不由摄影机或门扇运动决定。**写分镜、视频及修复方向颠倒时必读本节；详细规则只在这里维护。

#### 先锁语义，再写画面

内部先提取：`角色｜哪一道门｜以哪个场所为进出对象｜起始区域 → 目标区域`。从剧本、确认布局与相邻末态取值；只说“门口”“走进去”“走出来”且无法确定对象时，先问清门连接的两处，不擅猜。房间之间的门以具名房间判断，不把走廊或另一房间误写成室外。

| 用户意图（以长屋为对象） | 起态 | 跨门方向 | 完成后的末态 |
|---|---|---|---|
| 出门／离开长屋 | 长屋门内 | 长屋内部 → 同一正门门槛 → 门外雪院 | 全身与双脚在雪院一侧，长屋及门槛在身后 |
| 进门／进入长屋 | 雪院、长屋门外 | 雪院 → 同一正门门槛 → 长屋内部 | 全身与双脚在长屋内部一侧，雪院及门槛在身后 |

- **镜头朝向独立推导。**门外朝门内拍摄可以拍出门，人物会接近镜头；门内朝门外拍摄也可以拍出门，人物会远离镜头。进门同样可以接近或远离镜头。正脸、背影、画面左/右、入画/出画都不是进出门的判据。
- **开门不等于跨门。**门扇向哪侧打开、人物推门还是拉门、用哪只手，按已定结构和持物取值；不能以“向外推门”代替“人从门内到门外”。门已开则继承已开状态，不重复开门。未设计的开合方向若不影响剧情，可只写“门洞已敞开”；涉及开门动作才补必要结构。
- **正文必须保留方向证据。**`画面：`交代角色起始在哪一侧及可辨区域；`动作：`写“从<起始区域>经<同一门槛>到<目标区域>”；`→ 结束：`写角色全身/双脚落在哪一侧。用自然语言放进现有分项，不能用内部方向卡或“按布局”代替。需要交代观察方向时，在`运镜：`写“从雪院朝长屋门洞内拍摄”等物理关系，不写“机位N”等内部标签。
- **先锁第一秒。**定位秒及`[角色]`本段状态必须位于本次动作的起始侧；不能让出门者开场已经在门外，或进门者开场已经在门内。明确拍的是跨门后结果时，直接写结果状态，不再重演进出门。
- **跨门仅发生一次。**按[空间转移交接](directorial-shot-design.md#大幅度空间转移必须拆镜或用甩镜头过桥)在同一Clip内拆镜；切前可以走到起始侧门槛，切后继续跨向目标侧，也可切前已跨完、切后只拍结果。后镜不得把人放回起始侧重跨一次，更不能写成反向进出。独立Clip边界不落在跨门中途，遵守既有边界隔离规则。
- **不用反向动作做负面提醒。**给模型的正文优先写目标区域与落脚结果，不写“不要进门”“不是出门”这类再次唤起相反动作的句子；`[生成目标]`与动作、末态必须同向，不在`[保持一致]`冻结本来要变化的门内外位置。

#### 交付前反向核对（人工语义检查）

遮住“进门／出门”等摘要动词，仅从正文还原`起始区域 → 跨门 → 结束区域`，与用户意图逐项对账。再核定位秒、映射块状态、前后镜与参考职责。只有“走向门口”“消失在门口”或“走入画面”而没有目标侧证据，不能算进出门已表达完整。只拍结果或遮挡切可以不展示全过程，但结果侧必须明确，不能宣称看见了未展示的跨门动作。

| 人工回归情境 | 应有判断／修复 | 失败信号 |
|---|---|---|
| 出门，门外向门内拍人物正面 | 门内 → 门外，人物靠近镜头，结尾在门外 | 因正脸或入画改成进门 |
| 出门，门内向门外拍人物背影 | 门内 → 门外，人物远离镜头，结尾在门外 | 因背影或出画改变目标区域 |
| 进门，门内向门外拍人物正面 | 门外 → 门内，人物靠近镜头，结尾在门内 | 把“朝镜头”解释为出门 |
| 进门，门外向门内拍人物背影 | 门外 → 门内，人物远离镜头，结尾在门内 | 把“远离镜头”解释为出门 |
| 出门者拉开向室内开启的门 | 门扇向室内，人仍从门内到门外 | 以拉门方向推断人进门 |
| 从走廊进入卧室 | 走廊 → 卧室门槛 → 卧室；两侧都在室内 | 擅自添加院落或街道 |
| 出门跨完后切门外反打 | 已在门外，只拍门外状态及后续动作 | 人重新从门内跨出或走回门内 |
| 用户只说“从门口出来”，场所不明 | 查上下文；仍不明确则问以哪处为对象 | 根据摄影机所在侧猜进出 |

以下两个6秒纯文字小样只用于方向回归，未生成、视觉未验收；不是默认镜长或正式剧情拍法。环境区域已按上述示例布局确定，门洞已敞开，开门动作不在本次范围。实际项目用已确认资产与布局替换。

### 方位描述：相对关系优先，构图按需固定

**固定地形关系，放宽屏幕构图。**“狼在她身后追赶”“外侧超越封住出口”“退靠近旁岩壁”描述实际关系；“她必须向画面右跑、岩壁必须在左边”规定构图。后者默认不必锁死，更不能与实际参考的投影相冲突。

- 优先以稳定地标与动作关系锚定：靠山侧/开阔侧、身后追兵/前方出口、门内/门外、近旁岩壁/远处道路。前后要说明相对谁，避免只有裸“左前方/右前方”而没有基准。
- 已锁构图、真实镜头接续或关键接触确需时，可以补当前画面左/右、纵深和地标；这是按需工具，不是每镜三坐标的强制模板。沿用同侧机位的镜头保持已建立方向，越轴须连续运镜或重新建立关系。
- **身体左右与画面左右分开。**左伤翼、右手持刀、同一松动支点是对象事实；向屏幕哪侧行进、支点落在构图哪侧由机位决定。优先以伤侧或构件特征辨认，不把身体左翼换成右翼来配合屏幕。
- **位置变化靠过程成立。**从空地到靠墙先建立墙在附近，再连续拍封路、急刹、转身与退靠；脚部特写可以补受力，不能代替必要路线。两步可达是动作尺度条件，未确认时不假装实测一米。
- 可放宽内容包括机位高度、斜拍角度、跟拍距离、景别和不涉及剧情的背景补全；不能放宽入口数量、道路连接、伤侧、追逃关系、持物或重要遮挡。

```text
她沿贴山雪路逃向外侧出口，狼从身后追来。一只狼沿开阔侧越过她，横身封住出口；她急刹，转身面对来狼，退两小步靠上近旁同一岩壁。摄影机同侧连续保留她、封路狼与岩壁，再切持刀手特写；奔跑转成围堵，地点未改变。
```

### 空间锁定不等于摄影机锁定

正式剧情按 [导演分镜方法](directorial-shot-design.md#剧情驱动的多景别与多角度覆盖) 选择多景别和机位：全景建立关系，表情、手部、道具、接触特写交付关键细节；固定广角只是一种空间测试方式，不是默认剧情拍法。保持已确认地理关系即可，不要求每个镜头复刻母图构图。

母图中关键连接可见的要求不等于每个视频特写都要露出整条桥/通道。近景可裁掉环境，但人物在哪、看向哪、物件由哪只手持有须由上下镜或本镜必要锚点明确；切回较大景别时承接同一动作状态。镜头职责、视线匹配、同侧/越轴与地标投影共同控制连续性，不因拍特写自动移动人物。

换到未定义的场景一侧若需要新结构/通道，先补文字设计并同步相关提示词，不强制额外出图；只是裁切、换景别或在已定义空间内换角度，无需重做场景资产或新增审批。

## 4. 轻量文本检查（默认必做）

- 每张复制正文是否带上项目视觉总纲拆解出的媒介、建筑文化、材料与光色，且不含片名、“写实电影”或只放块外记录？是否按[资产设计依据](asset-design-basis.md)写清场所用途、建造者/使用者、建材工艺与剧情需要的地标/通道/遮挡？用户多个参考是否明确各自职责并与世界观相容？
- 场景正文是否写出了关键地标的位置、连接、高差、行动通道与符合用途的固定结构；整张图是否无角色、生物和道具？
- 光色是否从项目影视参考与剧情时段共同推导，夜景必要信息是否可辨，人物携带光源是否写在视频相应动作？
- 关键入口/出口是否有落点，通道是否连通，行动所需尺度是否与资产设定相容？
- 视频所有起点/路径/终点是否来自同一版布局？是否新增了未定义地标或道路？
- 画面左右是否注明基准视点或当前机位？反打是否保持固定连接、高度关系而正确改变画面投影？
- 相邻镜头是否继承位置、朝向和已发生的移动/破坏？
- 进出门是否按[门槛方向锁定](#32-进出门门槛方向锁定)从正文还原起始侧与目标侧，且定位秒、跨门与末态同向？是否误以进出画、正背面或推拉门判定进出门？
- 独立图是否有环境主体/结构明显不同的依据？是否仅为角度、近景、昼夜重复出图，或按大场景名合并完全不同内容？弃用正文是否删除且引用无悬空？实际图生图的源图和适用Clip是否双向对应？
- 文字一致性、实图检查、素材绑定是否分别记录？仅文本核对通过不表示模型空间控制已通过；检查信息写项目记录，不塞进复制用提示词文件。

上述为助手语义检查；名称 lint 不验证几何、图像布局或模型执行效果。

## 5. 出现偏差才局部诊断

| 情况 | 处理 |
|---|---|
| 未回传图片，已有确认布局且无已知冲突 | 正常推进文字交付，不索要全部图片；块外标实图未核对 |
| 用户报告实际场景图明显偏离 | 只请求相关图片或先按具体差异说明诊断；未读取图片时说明依据是用户描述 |
| 实图偏离但仍支持剧情 | 经用户确认采用新布局，更新布局版本、场景提示词及受影响视频；保留旧版记录 |
| 实图缺桥、缺出口、通道受阻，关键动作不成立 | 优先修场景图；无法修复时经确认改动作/布局，不以相反文字强压原图 |
| 只是机位变化造成左右交换 | 改本镜画面方位，不移动固定地标；必要时补建立镜 |
| 进出门方向颠倒 | 先对照本节方向卡与正文起末侧；文字写反先修词。文字正确时只核相关参考/首帧的角色所在侧、门两侧内容与真实绑定；参考身份图不自动当动作首帧。未提供结果时诊断仅为假设；有证据冲突先改对应输入，不把意图反写来碰运气。再做单次跨门短测试，必要时在既有授权内拆成起始侧与结果侧两镜，锁定一镜到底的先提出备选，不承诺必成 |
| 图文已对齐，视频结果仍错位 | 检查实际参考绑定，简化同时调度或拆分生成，先做短片段测试；不承诺提示词能完全锁定空间 |

用户明确选择严格实图核对时，将其范围与等待项写进 `project.md`，该范围内按实际证据推进。默认模式仍是文字布局先锁定，严格模式与异常诊断不扩展成全项目必经关卡。
