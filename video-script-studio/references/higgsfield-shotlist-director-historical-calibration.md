# 历史校准附录：镜头时长、提示词密度与语料长度

本附录是 [Shotlist Director 指南](higgsfield-shotlist-director.md) 的**可选历史参考**，用于比较镜头节奏和提示词密度。它不定义当前默认、不证明实时平台能力，也不作为 lint 的时间或数量门槛。先按事件、因果、表演与状态交接规划，再按所选模型/模式组织生成片段。

当前项目的模型、画幅与语言缺省为 **Seedance 2.5、16:9、中文**；时长继承用户预算，未定则生成片段默认向模型单次上限（约 30 秒）凑。编辑继承母片，延伸按方向和模式处理。本页历史秒数仅为案例，不推出固定镜头数或时长。完整提示词内容与 HTML 映射按主指南和 [统一导演编排](narrative-planning.md) 执行。

## 来源与适用边界

- 原文密度分组标为 `[OFFICIAL — Higgsfield shotlist-builder + seedance-2-pro-director skills, 2026-07]`；这是来源标签，不将旧十五秒编排法升级为当前硬规则。
- 长度语料标为 `[FIELD — community harvest 2026-07-18]`，是历史项目观察。
- 总时长与镜头数建议标为 `[EMPIRICAL — third-party director-skill evaluations 2026-08-09; re-derived heuristics, unmeasured here]`，不是本项目测量结论。
- 所有秒数先区分**剪辑保留时长**和**单次生成时长**。短插镜可以从合法生成中裁切；长表演可以通过合法接续保留完整弧线。生成模式、素材上限和上传格式仍须单独核验。

## 提示词密度与风格参考

| 原始观察或例子 | 原文数值 | 当前可选用途与限制 |
|---|---|---|
| 剧本行数与提示词数量之比 | 1.4–4.7 行/提示词 | 说明生产项目不存在固定换算率；一行剧本不等于一个阶段、镜头或生成片段 |
| 写实叙事的旧十五秒片段 | 通常 1–3 cuts / 15s | 可比较叙事是否过载；不能倒推十五秒目标或默认切镜数 |
| 三维动画风格例子 | 6 shots / 15s | 只属于该蒙太奇示例；不要求动画一律六镜 |
| 产品蒙太奇例子 | 8–10 sections，含 0.3s 微距 cuts | 可用于功能明确的快速插镜；sections 不自动等于生成调用，0.3s 不作为 API 时长 |
| 完整无言表演弧线 | 5–7 个表演 beats 的反应例子 | 提醒保留渐进反应；不要求每次情绪变化都有固定拍数 |

风格示例入口：[Style Recipes](higgsfield-style.md#style-recipes--seven-proven-shapes)。正文的同人物、同空间、连续情绪与因果单元分组方法继续有效；旧文遇换场、出入画、换机位、插镜就拆的措辞，现用于检查可读性，只有内容或模型限制需要时才拆生成。不能为匹配比例切碎悲伤、对白或同一连续动作。

### 原复杂度诊断与时长阶梯

原复杂度提示是：超过2个强动作、2次运镜、3名重要人物、1个复杂特效事件或1次地点变化时，检查是否过载。它们是排查线索，不是超过数量就必须拒绝或拆分的模型硬限制。

| 旧时长阶梯 | 对应演出负荷例子 | 当前解释 |
|---|---|---|
| 4–8s | 一个强动作 | 动作、响应与结果读清所需时间由具体内容决定 |
| 8–12s | 一个动作加一次揭示 | 揭示需要可读窗口，不必机械延长至该区间 |
| 12–15s | 2–3个简单节拍 | 简单节拍可以共享生成；不推导固定拍数或默认十五秒 |
| 多提示词 | 复杂打斗、追逐或变身 | 先评估因果、空间、状态与所选模式承载力，再决定是否接续 |

原文一处写“固定长度、目标15秒”，另一处又允许4–15秒并优先避免填充。当前正文消除该冲突：十五秒是历史常见做法，既不是所有 Seedance 的固定长度，也不是本项目目标。局部参考范围不得覆盖当前模型/模式规格。

## 按镜头类型的剪辑时长参考

原始入口：[Shot duration by type](higgsfield-camera.md#shot-duration-by-type)。以下是**可选剪辑节奏范围**，不是生成参数，也不是从总时长均分镜头的公式。

| 镜头类型 | 历史示例范围 | 使用时关注 |
|---|---|---|
| 闪现式建立镜头 / 硬切引入 | 0.3–0.5s | 若需观众理解地理关系，应按可读性延长 |
| 一句中等长度对白 | 3–7s | 以实际台词、语速、听者回应和换气为准 |
| 带情绪弧线的无言反应 | 5–10s | 保留刺激、感知、身体回应与残留 |
| 插镜 / 广角 / 定格 | 0.3–2s | 仅是该类短用途示例；广角不必短，定格不必出现 |
| 完整情绪弧线特写（原例5–7个表演节拍） | 8–15s | 特写和节拍数都由内容决定；无需为展示微表情强插镜头 |

镜头可以跨多个阶段，一个阶段也可以有多镜；短于模型最小时长的剪辑片段从合法素材中裁出。超过单次上限的表演保留退出/进入状态，通过接续或支持的延伸工作流实现。

## 旧版总时长与镜头数校准

原文曾用“平均每镜约4–6秒”推算镜头数，并预留一个6–8秒 hero hold；同时禁止连续三个镜头使用相同景别和运镜。下表只保留原始对照数据，**不用于当前项目定额**。

| 原文总时长 | 原文粗略镜头数 |
|---|---|
| ≤15s | 约3镜 |
| 约20s | 4–5镜 |
| 约30s | 约6镜 |
| 约45s | 7–8镜 |
| 约60s | 9–11镜 |

当前执行方式：

- 先找事件与观看职责，再估算演出时间；不按此表推导段数或镜头数。尤其30秒不等于六镜或六段。
- hero hold 是可选表现手段，展示或情绪需要多久就保留多久；没有必须预留6–8秒的要求。
- 连续三个镜头同景别同运镜只是复核信号。有意的重复、静止与视觉母题可以保留，不为“丰富”而插入无功能切镜。
- 成片预算仍需精确对齐目标时间线；转场重叠、裁切、变速与尾帧计入一次。原始生成长度可以大于保留长度，具体剪辑与生成效果另行验收。

## 语料长度校准表

原文引用 [Field calibration — the 13-project production corpus](higgsfield-seedance.md#field-calibration--the-13-project-production-corpus)：13个共享项目、9名创作者、约4,000条经 API 获取并带参数的生产提示词。以下是其中英文 Seedance 提示词的历史词数中位数，**不是中文长度要求或建议目标**。

| 语料类型 | 英文词数中位数 |
|---|---|
| 技术演示 | 218 |
| 电视剧情 | 538 |
| 商业广告 | 779 |
| 类型短篇合集 | 955 |
| 冒险电影 | 1,433（p90：2,648） |
| 定格情绪剧情 | 2,059 |

原语料还记载：旗舰项目的1,240条 Seedance 提示词中约95%带 SHOT 标记，15秒是当时常见生成长度。它说明长块结构用于生产并经过后期选段，不说明新作品应复制其长度、词数、标记密度或参数。单镜头50–80词的旧经验与上述长稿属于不同写作情境；本项目完整演出母稿按可执行细节交付，不能为了落入任何词数区间删去因果或填充内容。

原文提及的中文1,800字符上限来自旧 house-format 输出契约。当前 [`../scripts/seedance_lint.py`](../scripts/seedance_lint.py) 仍在结构检查中对所有含中文文本执行这一阈值，`--regime block` 只豁免短提示词词数检查。该结果应如实记录，不能宣称为 Seedance 2.5 官方上限；完整母稿与必要的受限提交版本按 [主指南的 preflight 说明](higgsfield-shotlist-director.md#what-makes-this-outclass-a-bare-generator) 处理。本附录不修改或绕过脚本规则。

全局风格在历史语料中常逐个独立片段完整前置；当前映射为一个可编辑风格源、每份独立提交所需上下文，以及每个连贯提示词内仅一次的全局规则。分段只写变化和继承，避免重复整块风格挤占演出内容。
