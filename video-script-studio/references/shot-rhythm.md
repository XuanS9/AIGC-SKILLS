# 事件驱动的镜长与节奏

本页是镜长估时、切点依据与节奏复核的执行规范，服从 [入口的镜长与切镜计数](../SKILL.md#镜长与切镜计数)。**3秒是复核阈值，不是硬上限或固定镜长；每条Clip仍≤30秒。**用 `shot_rhythm_lint.py` 核当前镜文/区间证据；脚本通过不代替朗读、预演或实际剪接。不另建第二套输出格式，不增加用户审批。

## 写作顺序

1. **无时间码先写事件链。**锁定既定剧情、对白原句和必要先后；注明真实并行。例如：母亲说完叮嘱 → 孩子理解后点头 → 躲回帆后 → 母亲确认遮挡 → 出门。不是先生成十个3秒槽位。
2. **选择观看任务和切点。**先比较持续同框、镜内调度、切镜；说话人的气口、听者的判断和关系变化可以在同一镜中完整观察。点头与转身也可在同一关系镜中依次完成，不强制每个动词各一镜。空间需要重新建立时，切门口/目的地，而不是把窝边到港口变成单镜环境变形。
3. **按自然表演估时。**对白正常朗读，计断句、吸气和态度变化；动作按距离、负荷及完成条件估算。真正同步用共同窗口，串行加上必要间隔。没有读音频或真实排演时写“文字估算，待样片校准”，不虚报实测。英文每秒词数仅是筛查线索，不是替代语言、口型和表演判断的硬规则。
4. **分配可变镜长，再组Clip。**镜长由上一步产生，可以如2秒、4秒、2.5秒、3.5秒，也可以自然等长。不能故意加小数、随机打乱秒数让检查器闭嘴。超过3秒记录具体连续观察和切出依据；不因超过阈值强拆。
5. **检查30秒总预算。**超时先删冗余/无功能停留和重复操作，再并行兼容动作；必要表演仍超量，按授权拆组/顺延。不截台词、不让听者在信息未到时行动、不把长镜全改成倍速。
6. **连读与回归。**核对白→回应→行动的真实时钟；逐个切点问“换视角带来什么”。连续等长只是警告，回到任务与估时决定保留或重编。最后同步标题、秒轴、镜数、场景时段、对白真值、索引及覆盖记录。

## 复核记录（块外，复用现有导演工作单或总表）

每镜的观看任务、估时依据和切出理由都要内部可定位。对超过3秒的镜头以及等长警告，记录绑定当前文本的可计算证据；已有工作表无需另建强制目录，允许从同一总表导出JSON给校验器。

```json
{
  "file_sha256": "完整提示词文件的SHA-256",
  "shots": [
    {
      "clip_id": "1-1",
      "shot_id": 2,
      "time_range_seconds": [2, 6],
      "content_sha256": "该镜去掉时间码与镜号后的正文SHA-256",
      "watch_task": "完整观察叮嘱时的目光与口部，并看见孩子听到承诺后的判断",
      "timing_basis": "文字估算：两句八词英语约3秒，句间气口与说话后停顿约1秒；待自然朗读/样片校准",
      "cut_reason": "句尾及目光交接完成后切听者关系镜；在句中切会遮住承诺落点"
    }
  ],
  "equal_run_reviews": []
}
```

- `shots`中至少覆盖所有超过3秒的实际连续镜；可记录全部镜头。单镜分成多行仍累计，不靠改编号伪装切镜。哈希按节奏lint报告的`content_sha256`计算；重复同镜段落以换行连接正文后计算。
- 连续4镜及以上镜长相同，产生`等长镜头复核`警告；记录`equal_run_reviews`中的`clip_id`、完整`shot_ids`和具体`reason`。有节拍同步/同型操作等实际依据可保留，不要求故意改成不等长。
- 只写“情绪需要”“对白未完”“保持电影感”“凑30秒”不算有效记录。必须指出本镜可见行为/语言窗口和切点；字段存在不证明理由成立，仍人工复核。
- 哈希、镜号或区间变化，旧记录失效。普通短镜不要求虚构“长镜例外”；所有镜头仍核表演可读性和先后。

## 可计算检查与结论边界

```bash
python3 scripts/shot_rhythm_lint.py --file /path/to/prompt.md
python3 scripts/shot_rhythm_lint.py --file /path/to/prompt.md --review /path/to/review.json --strict-review --report /path/to/report.json
```

第一条用于发现长镜和等长警告，不把警告当实际失败。正式修改的范围使用第二条校验所需复核记录、范围、当前全文/镜文哈希及连续镜长；严格模式下缺失或漂移的记录失败，但仍不自动裁定时长真实、剪接自然或模型画面通过。局部任务可用`--clip 5-1`限定，并在复核JSON写`scope: ["5-1"]`，仍绑定完整文件哈希；也可只向工具传同范围Clip文本与证据；整批文件则列齐整批触发项，不能悄悄忽略其他警告。

结构检查继续负责块结构、对白字面覆盖与每条Clip≤30秒，节奏lint不改它的格式职责。项目检查器不得把`duration <= 3`写成无例外硬门槛；应调用此复核API或使用等效记录检查。历史定稿测试在其固定版本继续验证，不能用旧模板镜长约束当前创作。

## 人工回归情境

| 情境 | 正确处理 | 失败信号 |
|---|---|---|
| 完整叮嘱后孩子同意才躲藏 | 给句子自然语速和气口；说完后回应、再转身；门口另切 | 台词尾音仍在而孩子已藏好；三秒内同时揉头、说两句、躲藏、开门 |
| 对白与听者同框4秒 | 记录口部/目光关系与自然朗读依据，句尾交接才切 | 因到3秒就强反打；仅用“对白未完”作通用理由 |
| 四个等长镜头都有自然节拍 | 警告后逐项核任务并写复核结论，可保留 | 自动随机改秒数或强制增删镜头 |
| 一镜分成两行各2秒，同镜推近 | 按连续4秒复核并记同一镜头 | 分行或把第二行改编号就称两短镜 |
| 30秒放不下完整回应和行动 | 删冗余，仍不足就重分组 | 加速说话、截句、省回应或给Clip开超30秒例外 |

只有真实音频/预演或生成后的粗剪才能验证表演时长；没有媒体时只报告文字/记录检查通过。
