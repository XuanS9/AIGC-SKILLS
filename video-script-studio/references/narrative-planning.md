# 全包统一导演编排：从事件到镜头与生成片段

本规范用于 video-script-studio 的全部视频编排任务（动作、剧情、产品、风景、音乐、动画、分镜、编辑与延伸），统一创作决策，不新增模型能力。用户明确的剧情、结局、时长、镜头数、节拍与格式优先，模型和模式的真实硬限制必须满足。纯图像、角色资产、预算和工具任务保持各自流程，只在交接到视频时提供相关信息。

交付先遵循 [样本确认流程](sample-approval.md)：完整制作统一规划后，按场景/连续剧情的「基础资产 → 场景 → 视频」分阶段交付；共享资产先定稿，已确认未变内容直接复用。每阶段先给新写/改写/补镜/修词/单条交付的代表性样本，确认后展开当前阶段；文字设定与布局确认后推进，不要求回传全部实图。场景与相关视频任务完整读取 [文字空间布局](spatial-layout.md)，两类提示词从同版空间底稿取值。明确单类型请求只交该类；未回传图不阻止文字定稿，关键设计未定或已知冲突未解时才给条件性预稿。实图仅在明确要求或出现偏差时局部核对；只有明确要求快速预览时才联合交付预稿。视频参考栏只引用真实可用素材，缺项与待核对说明放块外。样本只规划选定镜头、保持局部因果，样本时长与成片时长分开记录；整体预算在规划时确定，视频样本确认后细化各事件分配。本规范的完整演出稿、四段式格式、全片时长要求用于视频阶段样本确认后的完整交付，不提前展开其他阶段。

### 导演决策到提示词

分镜与改写同时读取 [导演编译](director-compiler.md)：用内部决策卡对齐人物任务、银幕行为、五维工艺及落幅，之后映射到本页四段式；不把工艺卡变成额外栏目。控制图与生成失败再按需读 [导演控制与返工](director-control-retake.md)。不迁入全集确认、独立台账或另一套编号，保留本页原时长与节奏默认。

### 声音并入正文、惊恐写表情

声音不写成独立的“声音：”行、不用尾部 `<...>` 标签；把现场声、动作音效、环境声写进该镜动作描述句、紧贴发出它的动作。人声写成 `说话人+可见状态/气息/语气+说话动词「台词」`，让“怎么说”与可读的身体状态一起呈现。

惊恐、痛苦、迟疑等情绪不写抽象标签，改写当前景别能看清的可见表情与身体反应：瞳孔骤缩、眼睛瞪大、眉峰拧起、脸血色褪尽、嘴半张、下巴发抖、肩猛缩、手指抠紧、呼吸乱等。近景写脸部微表情，远景用头肩、姿态、步态与呼吸表达。

### 资产锁定不等于重复描述

独立资产负责形态与外观，视频四栏均不重写五官、发型、服装设计、固有色、纹理、材质、比例、解剖结构或建筑造型。【参考素材职责】只列本镜直接引用及必要职责、状态/年龄版本；【具体情节】写行动、表演、受力、位置、路径和变化；【全局补充】保留必要风格、连续性与声音开关。尚未生成/绑定不构成抄回外观设定的理由，素材状态留块外。未采用独立资产的纯文字任务才补主体描述。

分镜中需要强调的视觉信息必须是动态或叙事性的：湿污如何出现、伤势如何影响动作、道具何时进入手中、谁把什么交给谁、结构怎样受力破坏、人物如何改变位置。删除无关静态外观描述，但保留从共享布局提取的本镜必要地标关系、路径和空间锚点；不抄整段场景布局，也不因“去重”删掉动作所需方位。

资产文件与总表不会随提示词传给模型；【参考素材职责】只写 `@资产` 调用名与本镜新增/衍生内容，不写“沿用资产文件/asset-registry”“以资产图为准”“规划母稿/待绑定”等元描述。这些登记用语留在内部说明，不进入喂给模型的正文。

## 一套规划，按任务输出

所有题材的完整视频提示词按**四段式标准格式**交付：**【参考素材职责】→【一句话概述】→【具体情节】→【全局补充】**（对齐官方/社区“全参 Seedance 2.5”结构）。**核心原则：让模型先读懂本段事件，再沿时间轴完成具体演出；独立资产直接引用，必要状态、空间、动作与结束结果写清。**时长、画幅、分辨率不写进正文，在生成页/API 设。下表的七类规划信息重组进这四段、信息不减：

- **【参考素材职责】**（素材指代）：独立资产直接写 `@资产名`，按需补角色、场景、道具用途及本镜状态/年龄版本；不附基础形态和外观清单，也不逐条复制“仅采用主体、不采用背景/组板”的固定句。动作/声音等普通参考说明实际采用的职责。平台用真实上传槽位名（@图片N/@视频N/@音频N），项目中文名与实际槽位映射留总表；图中确有干扰时块外说明裁切、清理或换图。没有参考也保留本栏，简写“本段采用纯文字描述，无参考素材”；只有明确精简请求或实际提交硬限制才用下方短式，不因素材少自动省栏。
- **【一句话概述】**：用一个完整句子说明本片段的主要内容：谁在什么情境下，做了/经历了什么，产生什么关键变化或结果；地点按理解需要加入。只概括本段已覆盖事件，不写后续结果，不堆风格/景别/运镜/声音，不复制标题或泛化导演套话。例：`逃亡者在雪林中夺下追兵的火把逼退士兵，逃跑时踩塌覆雪朽木，连同火把一起跌入捕兽坑。`
- **【具体情节】**：**优先用秒级时间戳 `0s-3s：` / `3s-5s：`（比“镜头N”更贴 2.5）**，镜头数量与单镜时长按剧情、动作、对白及表演决定，不设固定镜数、3秒上限或均长配额；每个 Clip 总时长仍≤30秒。每个时间段写足：①景别+机位；②当前取景可见的空间层次与运动，不强填前/中/远三层；③主体动作（写肢体、幅度、速度、衔接）及当前景别可读的表情或物件细节（不写抽象情绪，不向脚部/道具特写硬塞脸部微表情）；④光影写入本段正文（光源方向、硬柔与对比，不另起栏目，比空喊“电影感”有效）；⑤运镜（起手→路径→落幅、与上镜衔接）；⑥声音写在其发生处、紧贴触发动作，台词统一使用 `「」`，非中文先注明语言（如“台词语言：美式英语。她压低气音说「Wait.」”）；⑦段末写明“结束时画面里能看到的明确状态/构图”。方位、朝向、视线、高度全程锚到场景地标（见“空间与方位的导演锁定”），不写观看任务、切点依据、作用注解等内部规划。**用导演思维增强画面丰富度：运镜借鉴 [higgsfield-camera](higgsfield-camera.md) 的运动类型与镜头/景深思路，但**用中文描述**（视点/景别→跟随对象与路径→落幅构图，微移标“行程+时间”如“缓慢推近约10厘米/2.5秒”）；**英文预设名（Dolly In、Orbit 等）只在实际使用 Higgsfield Cinema 等平台具名预设控件时才写，Seedance 等中文提示词正文一律用中文运镜词、不堆英文术语**；微表情援引 [higgsfield-facs](higgsfield-facs.md) 的 AU 与身体微动作（如 Duchenne 真笑 AU6+AU12、悲伤 AU1+AU4+AU15、喉结/呼吸/皮肤微动）**以可见的自然语言描写为主；确需精细控制时可附AU作辅助核对，编码可选且不保证执行**，不写情绪词；影调与质感援引 [higgsfield-cinema](higgsfield-cinema.md)/[表演](higgsfield-acting.md) 的布光与材质。这些是可选词汇库、服务本镜演出，不堆砌术语。**
- **【全局补充】**：全程不变的一致性——主体身份/服装/体型/固定站位一致、场景布局与光向不变、飞行/对峙方位与轴线不变；跨段状态继承。**无字幕、无水印（视频不出现字幕）；负向描述主要用于声音与字幕开关（“不要字幕”“无背景音乐，只保留对白、环境声与动作音效”）；其余限制优先转成正向事实而非禁令**。

平台设置（模型/画幅/时长/速度/声音开关）写在提示词代码块之外，正文不另加【模型与规格】等栏目。具体内容按题材重写，四个标题加梗概不算完整交付。

**声音统一写法（写在【具体情节】其发生处，不另设声音栏）：**

| 内容 | 写法 | 例 |
|---|---|---|
| 音乐（仅按用户要求） | 自然句，注明进入/退出与响度 | 门合拢时低音弦乐渐入，始终低于人声。 |
| 音效 | 紧贴动作，写声源/材质/距离 | 钥匙碰到柜台玻璃，近处响起一声轻响。 |
| 台词 | 说话人＋状态/语气＋说话动词＋`「原句」` | 她停下手中动作，压低声音说「等一下。」 |

旧式 `{台词}`、`<音效>`、`(音乐)` 标签不再用于本标准正文；原生 JSON 等字段结构仍按对应模板。无对白片段显式写“本段无对白（设计）”，默认 NO BGM。

**视频一律不出现字幕：**不写字幕内容、不用字幕符号，【全局补充】固定写“无字幕、无水印”（剧情需要的画内标牌/标志属可见景物、不是字幕）。

### 无参考/纯文本短式（仅明确精简请求或实际提交硬限制）

完整视频默认仍用四段式；以下是有授权的短式编译骨架，不是无参考任务自动降级标准：

```text
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```
短式按用户目标保留必要事件、状态、摄影与声音；无参考本身不改变完整视频契约。

| 规划信息 | 落点 |
|---|---|
| 资产与参考锁定 | 角色资产、Soul、参考映射、道具、场景与素材表；真实标签、采用属性、保留程度与排除项 |
| 总目标 | 场景目标、核心事件、功能演示或空间揭示，及已确认结局 |
| 全局视听与空间 | 风格与影像特征继承用户/项目已确认媒介，落到适配的光色与表现方法，不默认电影级写实；光照、摄影、音频、地理布局、轴线和主体关系按本镜需要提取 |
| 主体行为与节奏 | 表演、动作因果、强度、速度、音乐节拍、产品或环境响应 |
| 分段演出 | 剧情阶段、镜头清单、时间码、每次生成承担的可见变化，及身份/数量/归属/朝向/损伤/破坏的段间继承与声音接续 |
| 结尾状态与交接 | 本片结局与声音余韵；跨片段按动作、空间、声画状态接续；编辑保留源视频实际时间线，结尾是输出目标而非输入起点图 |
| 关键约束 | 仅本片高风险偏离；模型参数放设置，通用词库与验收项留内部 |

视频创作与完整改写完整读取 [完整演出范本](template-full-performance-example.md) 与 [跨类型完整导演模板](template-general-director-2-5.md)，沿用其演出细致程度（两范本均已按四段式组织）。**【具体情节】按时间轴分镜，每个时间段写足景别+机位、前/中/远景内容与运动、主体动作（幅度+速度）与表情/微表情、光线、运镜（起手→路径→落幅+与上镜衔接）、段末明确结束状态；声音写在其发生处、紧贴发声动作，对白用 `说话人+可见状态/气息/语气+说话动词「台词」`，音效与音乐用自然句，不单列声音栏、不堆片尾**；无特效题材将“特效与结果”写成“画面与结果”。段数、时长与镜头数按内容和演出负荷决定，不规定均长配额。

原生 JSON、HTML 分镜、Cinema 设置、代码动画、编辑与延伸格式：完整演出稿作为内容母稿，映射到原任务要求的字段，用户指定原生格式时不附加重复长稿。编辑先交代唯一母片、修改范围和保留项，延伸先交代方向与边界。资产、音频等子任务只输出所需部分。

## 规则优先级与信息归属

- 用户已确认的内容、格式与参数优先于创作默认；平台与模式硬限制单独核验。二者冲突时指出具体限制并沿授权编译或拆分。
- 本规范与完整演出格式优先于模块中的一般写作建议；模块专有输入、操作步骤、原生输出及模型硬限制继续适用。缺省设置见根入口；成片总预算与单条上限分开。每个 Clip／生成片段≤30秒，模型实际单次上限更短时取更短值；在合法范围内用兼容的连续内容编组，不靠延长单条解决超载。
- 200 词、1–3 句、一镜一动作、微动作频率、镜头密度等是各自短格式的经验策略，按需可用，不作固定配额，也不覆盖完整动作因果；多动作以时段内能否读清衡量负荷。
- 平台预设实际使用时才写精确名称；主体行动、摄影机运动和特效分别描述。运镜写起始机位/景别→关注对象与路径→结束构图，区分摇摄/平移、变焦/推进、依次/同时；距离、焦距与帧率仅在本任务需要且设置有效时补充。

| 栏目 | 写入正文 | 留在内部/按需调用 |
|---|---|---|
| ①资产与参考锁定 | 身份、素材职责、保留程度；声音参考的角色（原样/节奏/表演） | 完整角色档案、全部资产候选 |
| ②一句话总合成 | 本片段主要事件、关键变化或结果 | scene-engine 删除测试、序列反转、价值判断、修复层级 |
| ③全局视听与空间 | 本片固定的空间、光色与摄影；声音只声明本片段可控范围 | 跨镜音轨连续性的后期规划、声音库、混音方案 |
| ④主体行为与节奏规则 | 当下任务、动作方式、必要的表演/呼吸基线 | 八项动作档案、AU 表、微反应菜单 |
| ⑤分段演出 | 本段行动与响应、可见变化、镜头路径、对白与同步声音，及易丢失的关键跨段状态与允许变化节点 | 检查问题、推导过程、整段动作复述、完整状态检查表 |
| ⑥结尾状态与交接 | 最终构图、持续动作或接点、声音余韵，计入末段时长；是输出目标非输入图 | 全片剧情总结 |
| ⑦关键约束与排除 | 本片特有、前文未明确的少量高风险偏离；文字许可范围 | 通用缺陷长词库、平台参数、完整验收清单 |

**去重不减因果。**演出正文写过程，"画面与结果"只补未交代的视觉层次或后果；起始、承接、交接融入正文。声音内联进本片段的动作正文、写清实际声源及变化，静音要求仅在该片段范围内有效；每个独立复制生成的分镜带足本镜现场声，跨镜混音在后期。固定视觉信息在共享母稿写一次，独立提交仍带足身份、参考与起始状态。

**时序绑定属于演出指令，去重时保护。**在易被误生成为逐项停顿的节点，明确哪些动作同时发生、哪个须先完成、哪个仍在持续，以及跨段从哪个动作相位接上（如"转弯中判断并改步""借尚未消失的前冲推撞""箱子仍在落下时已起跑"）。感知、表情、气息和运镜可嵌在主动作中。只在存在歧义的节点用局部复述约束时机，不逐句加禁停指令，剧情需要的停顿照常保留。

保持四段式与【具体情节】每段“画面内容、主体动作与微表情、运镜、结束状态”的结构，按景别与时长选可读信息；声音内联进正文动作句（不单列"声音"栏），无变化的内容简写其持续状态。完整演出稿应读起来是可拍的过程，而非验收问卷：**正文只写画面内容、运镜、主体动作与表情（情绪靠动作和表情表达，不直写“很害怕”“立起压迫感”）；观看任务、切点依据、作用注解与操作方法属内部规划，不写进镜头正文。**

## 默认交付：完整演出稿

- 迁移范本的格式、细致程度与导演方法，题材、角色、招式、配色自定；时长与画幅遵循项目入口。除明确精简、指定其他格式、局部任务或硬限制外，默认交付同格式的完整可复制正文。
- 每段围绕一个主要变化展开连续动作：从哪里、由什么触发，主体怎样起手推进，对象如何响应，主体如何接续，以什么可见结果进入下一段。用具体过程而非"激烈战斗""情绪变化"等概括。
- 视听细节服务动作：特效说明形态、尺度、材质、运动、环境作用和残留；安静剧情写目光、呼吸、手部、道具与光影。环境、氛围、征兆类建立镜头（风景、气流、天气、空镜）同样写满四层，不因无人物动作就概括成一句：按前景/中景/远景分层写每层物体的运动方向与节奏；反常或关键细节点明不可见成因（如逆风、震动、光变）及其来源；写清光色、空气、材质与连锁后果；运镜给出揭示路径与节奏，声音按由远及近或由弱转强分层。没有特效的片段不加特效。
- 运镜说明观察位置、景别、跟随对象、方向、需看清的结果及转场依据；高速与静镜按题材选择。音效落在对应动作，结尾状态落实主体、道具、环境与声音的最终关系。
- 同一事件用丰富表演细节而非字数、切镜或新增事件凑密度。全局规则建立一次，分段写变化与继承。

## 人物表演：微表情、动作、气息与连续性

有人物表演的视频接入 [acting 模块](higgsfield-acting.md) 的身体、眼神、人物档案、场景适配和验收规则，并读取 [FACS 身体微反应](higgsfield-facs.md#physical-micro-beats--the-body-beyond-the-face)；精细表情、特写、对白读 FACS 工作流，有对白时按 [audio](higgsfield-audio.md) 对齐声音口型。这是默认环节，不等用户说"微表情"才触发；无人风景、纯产品或静音要求不加人物/呼吸声。

- **动机与反应**：每个在场角色有明确任务和注意对象。刺激先出现，角色感知、判断、回应；这是因果关系而非三个停顿段，必要时写明感知发生在哪个持续动作中。听者在听懂时开始反应。背景人物按距离与景深给相符回应。
- **眼神与微表情**：写视线落点、目标变化及必要眨眼，转头可由目光先到。眉眼嘴颌只选表达本次变化的少量线索，交代触发、发展与残留，不止写"害怕""真实"。近景见微表情，远景以头肩、姿态、步态和气息表达。微反应词表是选择菜单，整表不叠加。
- **身体与气息**：动作有预备、发力、接触/落空、缓冲和重心恢复，衣物道具受惯性跟随。按体力与压力安排吸气、呼气或屏息，胸腹起伏、口鼻状态、发力声与喘息声相互对应；奔跑者气息不无过渡地平稳。无声交付仍保留可见呼吸和动作关系。
- **跨镜头继承**：每个交接保留注意对象、**位置与相对方位、朝向与视线方向**、表情紧张度、呼吸急缓、身体负荷/伤势、重心和动作相位。持续运动疲劳累积；平复、疼痛减轻或情绪松动需时间或事件依据。跨时段剪辑写明时间经过与状态变化。
- **声音与说话**：不写固定音色描述，音量、语速、气息、断句随场景变化；有对白写开口前准备、说话中变化、句后反应与听者任务，口型对准当前说话者。无对白保留实际非语言发声，不加音色段落。

将这些融入四段式演出正文与段间状态承接；按 [表演证据验收](higgsfield-acting.md#表演证据验收) 提供落点，非人主体另读 [非人适配](higgsfield-acting.md#非人角色表演适配)。不另交抽象真人感清单，也不以微动作数量凑密度。验收逐项检查：反应有触发、细节在当前景别可读、身体与声音一致、前后状态接得上、背景人物不冻结、无无缘由的表情/气息复位。

## 阶段、镜头、生成片段分别决定

- **剧情阶段**：由一个主要事件、因果转折、信息揭示、表演变化或状态变化形成。动作与反应可在同一阶段闭合；安静停留、乐句、景观展开也能构成阶段。
- **镜头**：由观看对象、空间可读性、表演与剪辑需要决定。一个连续镜头可跨多阶段，一个阶段可含多镜。
- **生成片段**：一次模型调用的内容范围。可承载多个阶段/镜头，按模式兼容性、复杂度、素材与单次时长限制拆分。

写作顺序：继承已确认内容 → 定目标和结局 → 识别有效叙事线、故事时间与观众获知顺序 → 选择单线或交叉结构 → 找必要事件与状态变化 → 定成片镜头职责与切点 → 估算演出时间 → 按模型能力组装生成片段 → 核对各线状态、揭示与接缝 → 输出原生格式。

剧情阶段、镜头与生成片段的数量由内容决定，不预设定额；单镜时长不设3秒门槛。范本的六段五秒是该例剧情镜头组，不规定新任务必须六段、六镜或每镜五秒；可在同镜完成，也可按真实观看任务切分。**总时长不决定剧情段数或生成任务数。**

时长原则：用户成片预算优先继承，但每个 Clip／生成片段总时长≤30秒；模型单次上限更短时取更短值。先按演出负荷估时，相容镜头在该上限内合并以提高效率；较短片段可以成立，不以填满约30秒为目标倒推剧情。编辑继承母片，延伸只预算新增内容，交付的单条仍须遵守上限。

**镜头数量与单镜时长没有固定配额；取消单镜3秒上限，不把30秒换算成指定镜数。**追逐、接触与主动权变化可以快切，情绪、决定、对白及空间交代可持续观察或镜内调度；按真实演出负荷选择停留与切点。长对白可完整留在一镜，也可用有意义的反打或相关画面覆盖，不挤快语速。真实动作窗口、可读性与连续状态必须成立，快速交锋不为逐项特写让对手停住等待。**镜头按实际切换计数：同镜续写、推近、移焦、另起时间段仍累计同一镜长，不能只改编号伪装短镜。**

## 多线叙事与交叉剪辑

### 先选叙事结构

先看完整叙事单元及相邻段，不局限于单个Clip或原剧本场号。区分同一行动里的多人反应与真正可独立推进的行动线；有多个角色不自动等于多线。并行追逐、分头行动、救援与倒计时、异地危险、即将汇合等情形，必须比较单线与交叉呈现对紧张、信息差和情绪的作用。采用单线也须留下理由，如限知体验、突现揭晓、完整表演或时间关系不支持并行；不规定所有重要角色必须在前30秒出现。

在现有导演工作单/project.md中简记：

| 行动线 | 目标/阻力与地点 | 与其他线的故事时间关系 | 首次露出与观众已知 | 角色已知及揭示边界 | 回切新增信息/汇合点 |
|---|---|---|---|---|---|
| 按实际内容填写 | 不是全员资产表 | 同时/先后/跳时/尚未确定 | 区分声、局部、全貌 | 谁看见、听见或仍被遮挡 | 不写纯装饰插镜 |

时间关系不明时不凭剪辑制造同时发生；先标候选或确认关键依据。用户锁定的事件顺序、揭晓节点、限知视角与一镜到底优先；改变呈现顺序先更新上游方案、记录授权范围，不在编译时擅改已确认镜序。原剧本按场列出A再列B，不必然意味着成片必须等A全部结束才能看B。

### 设计露出与回切

- **观众知情与角色知情分开。**墙、岩角和距离可阻断角色视线，摄影机仍可切到另一侧；但此镜不是角色主观，不让角色无依据回应画外秘密。声音也只传递可听到的信息，不能自动告知身份、意图或道具内容。
- **每次回切推进信息。**可递进为首次建立困境→策略受阻→代价增加→接近汇合，不轮流给每人同一种表情，不为了交叉增添能力、伤势或新事件。
- **离画不是暂停。**按各线经过时间推导位移、阻挡、持物与伤势。切回从当前状态接续，不把奔跑/扫尾/射击/交接重新演一遍；无需拍满全部经过时间，也不能无依据冻结另一队等待。
- **连接有含义但不假造因果。**声音桥、动作匹配、尺度或处境对照可连接两线；有物理声源才让人物听见。主题性平行剪辑可以不同时间，明确区别于同时行动的交叉剪辑，不用声画误导制造未授权关系。
- **开场露出服从叙事承诺。**如果段落核心是两路汇合，应检查是否在汇合前建立必要的第二线；如果核心是跟随主角遭遇意外，延迟露出也可成立。理由是体验与揭示设计，不是“此Clip资产还没列到”。

### 再映射生成与交付

先锁成片切点，再选择按剪辑顺序同次生成或按空间分开生成后交叉剪辑。约30秒只用于相容素材的效率优化，不得挤掉另一条线、拖延揭示或注水。实用素材上限、空间切换与动作复杂度需核验；分开生成时在现有项目记录给出素材入出点→成片位置，不把生成时长之和当净片长，也不默认要求拆分。

同一图在片内多次回切时，可在现有 `scene_image_references` 中按连续区间重复登记相同image_id，`time_range_seconds`仍为单个起止对；这是多段使用，不是多张图。场景标题汇总这些区间，图号及源图不变。同步源剧本、制作说明、相关Clip的资产/图号/时段和接缝，其他内容不连带重写。工作表与理由留项目记录，生成正文只写明确切换、可见可听演出及必要状态。

### 必做语义自检

1. 已识别哪些有效行动线？为何采用单线或交叉？首次露出是否服务本段叙事，而非生成分组？
2. 每次回切是否交付新信息？是否误把“镜头多”当成“多线已建立”？
3. 观众获知与人物获知是否有各自依据？是否提前破坏已确认的揭晓或让人物隔墙看见？
4. 切离期间各线时间、动作、位置是否推进？同一接触、射击或交接是否重复？
5. 关键事件/对白是否覆盖，净时长及下游末态是否保持？场景图多区间使用是否与正文一致？

以上为导演语义检查，不能由四段式/时间轴lint或检测到“交叉剪辑”几个字替代。纯单线、完整情绪长镜等可不采用交叉，但不能略过适用性判断。

### 维护回归情境（人工评审，不是生成实测）

| 输入情境 | 应有判断 | 失败信号 |

## 导演先于拆镜：视觉弧线与镜头职责

在估时和拆镜之前，执行 [导演决策流程](directorial-shot-design.md#导演决策流程)，在同一份现有project/导演工作单留下主方案。本文负责故事时间、成片顺序与生成分组；戏剧主次、观察立场、调度和切/留/删并取舍由导演中枢统一判断，不复制另一套清单。

先看完整场景的目标、阻力、选择与结尾变化，分出核心重点、必要支撑与连接，再决定观众先知道什么、角色何时知情。一个Clip可能只承接支撑或余波，不能为每次生成都造高潮；密度随作用变，不按首条镜头复制。

随后为每个镜头写一个主要观看任务：建立空间、建立关系、交付信息、制造信息差、跟随位移、看清接触、捕捉反应、表现决定、揭示后果或完成转场。对关键节点比较持续观察、镜内交接与剪切，采用与本场重点最匹配的处理。

**切点由变化驱动，不由时钟驱动。**信息关注点、空间关系、主动权、接触结果、人物决定或情绪极性发生变化时评估剪切，原镜内已可读时也可以不切。在有信息交接的时刻选择切点；若同框或镜内调度已经可读，保留持续镜头，不因单镜超过3秒强制返工。“镜头数量不够”不构成切点；停留可以让等待和失去变得可感，不要求不断加微动作。

**景别丰富度由剧情信息驱动。**必要的表情、道具操作和受力结果须可见，运用 [多景别与多角度覆盖](directorial-shot-design.md#剧情驱动的多景别与多角度覆盖) 和 [主动补足镜头覆盖](directorial-shot-design.md#主动补足镜头覆盖) 查漏，菜单不变成镜头配额。完整表演、主观可见边界及锁定的一镜到底优先；制作上拆段不意味着成片也必须切镜。

估时计入真实动作、对白、信息阅读与反应余波；支持过程可在授权范围内省略/合并，核心因果不能被准备插镜挤掉。完成去说明、去镜头、换视角和整场连读后，再按下文分组与连续性规则映射到生成。

## 空间与方位的导演锁定（防穿帮）

**空间设计来自共同的文字布局，不由单镜另造。**场景生成前先按 [文字空间布局](spatial-layout.md) 锁定基准视点、地标位置与数量、连接、高差、行动通道、可见性和光向，再分别写场景与视频正文；默认不需要回传实图。未读图时仅报告文字一致性，不宣称实际场景已吻合。

**固定空间关系、画面方位、主体朝向必须分开。**同机位保留一致投影，反打/换机位时重新推导左右与前后；木桥连接哪两座平台、谁高于谁不随摄影机变化。母图中山峰在右上，不表示所有反打镜头也必须把山峰放在右上。修改布局先同步空间底稿和场景提示词，再更新受影响视频；已知图文冲突不能忽略，只针对相关图片诊断。

#### 大幅度空间转移的拆镜规则

**大幅度物理空间转移必须在成片上有分镜切换或甩镜头过桥。**跨房间、跨建筑、室内外切换、跨多个地标/行动区域，或起点与终点不能在同一清晰画面中保持可读关系时，不能只写“从A移动到B”。这类直述会让生成模型把两个空间同时合成在一个画面，出现建筑叠加、道路拉伸、人物瞬移和光线不连续。空间转移的“故事事件”可以是一句，但“镜头表达”必须拆成起点镜、交接和终点镜。

- **切镜方案**：A空间写离开前的动作、方向和末态；在动作匹配、前景遮挡或连续声源处明确切镜；B空间以入口/地标重新建立位置，写到达后的姿态、方向和经过时间。把多个时间段写出来不代表已经切镜，必须出现明确的切至/动作匹配切/遮挡切。
- **甩镜方案**：从A沿明确运动方向甩出，进入运动模糊；以同向模糊甩入B，在B的入口、地标或落点收住，再继续人物动作。甩镜是空间过桥，不是让A和B在同一清晰画面中渐变叠加。
- **一镜到底例外**：只有用户锁定一镜到底且空间路线确实可达时保留；内部必须补中间地标、路线、经过时间、摄影机路径和落幅，并标高风险。路线不可执行时，优先给拆镜或甩镜方案，不用“跟拍到另一处”掩盖空间跳跃。

可复制正文采用“起点—交接—终点”的正向写法，例如：`0s-2s：人物跑到院门并冲出画面；动作匹配切至室内入口。2s-4s：人物从同一方向冲入室内，经过门厅抵达楼梯口。`甩镜则写明甩出方向、运动模糊、同向甩入和B空间落幅。禁止把“镜头从必要空间关系转到另一空间”当成完成分镜；必须让模型读到实际交接。

分镜前，把下面几项在提示词里写到无歧义，避免画面穿帮：

- **方位锚到地标**：主体、对手、道具与出入口写成“锚到某地标”（如“在瀑布平台的岩台上”；使用“左前→右远”时同时注明当前机位），不写孤立、可漂移的“在左边”。
- **朝向与视线**：谁面朝/背对/侧对镜头、看向谁或什么；多个主体注视同一对象时，各自视线方向都指向该对象。
- **高度层**：涉及俯扑、坠落、攀爬、飞行时写清垂直关系（谁高于谁），使接触与扑击几何成立。
- **画面轴线（180°）**：锁定运动与对峙的左右方向，跨镜不无故翻转；需越轴时用运镜过桥或明确的重新建立镜。
- **接近/经过/离开的时空自洽**：运动物与目标的相对位置随时间连贯——接近即越来越近、经过后在另一侧；不出现“已离开却仍被够到”“飞过去了对手却仍在原处咬到”这类矛盾。
- **追逐同向锁定**：只要剧情是“狼追女生”，先写世界坐标关系：女生位于狼的前方、沿同一条道路向同一方向逃跑，狼在她身后沿她的路线追赶；不要只写“狼朝镜头跑”。正面机位只有在女生位于狼与镜头之间、双方仍同向朝镜头移动时才成立；否则改用侧后方/平行跟拍。狼位于女生前方、与女生相向奔来，或从正面迎面拦截，必须有明确的掉头、伏击或封路剧情依据。
- **投射物来源与路径锁定**：箭、矛、子弹或能量必须有发射者/武器/画外来源、释放时刻、连续飞行方向、目标接触点和命中后状态。箭从弓或持箭者手中开始；若镜头只拍已经插在地上的箭，必须明确它此前已落地并保持插入状态，不能把“从空中射来”与“从地面出现”混写。
- **固定站位/坐位锁定**：同一场景内的站位、坐位跨镜不无理由改变；确需移动的写明移动过程与去向。

### 追逐、投射物与景别切换的硬约束

- 追逐镜先建立“谁在前、谁在后、共同朝哪边、路线经过哪些地标”，再切换景别；每个机位都用世界关系描述，不用单独的“向镜头/向左”替代。
- 投射物按同一事件时钟写成“取用/拉弦或释放 → 飞行 → 接触/落点 → 余态”。中间切近景只能展示已经发生的相位，不能让箭在切镜后重新从地面或画外凭空出现。
- 景别切换必须有桥：沿动作相位切入、用同一视线/声音接入、用前景遮挡完成过渡，或在同一镜内推近/拉远。下一镜开场继承上一镜的主体位置、朝向、速度、持物和注意对象；没有桥接依据时减少切镜或先补一个重新建立空间关系的中景。

逐镜明确机位/观察方向、起点、经由路径、终点及适用的朝向/高度，下一镜继承上一镜末态。总表不会传给模型，不能只写“遵守布局”；本镜相关关系须进入可复制正文，未定义区域先补设计再用于动作。

这些是**导演判断**、不是套模板：方位由场景与剧情决定、运镜可灵活，但一经建立就跨镜自洽；宁可先在场景与开场建立镜把地理交清，再让后续快切在已知空间里展开。

## 按内容拆镜与估时

"合理"指切点和时长有可观察、可排演的依据，不承诺秒数保证完播率。文字估算是创作预估，实际节奏靠朗读、动作预演或粗剪校准。

### 1. 先定每镜观看任务

- 每镜一个主要观看任务：建立方位、跟随位移、看清接触、揭示后果、捕捉反应、表现决定或完成转场；可含多个连续动作。
- 信息关注点、空间位置、交锋主动权或人物决定改变时评估切镜，按实际信息交接选择时机；单纯分行改时间码不构成实际切镜。连续动作可跨镜保留相位与声音，也可在一个长镜内完成；不按固定镜数或单镜秒数强制拆分。
- 切点选在接触结果已读清、注意转移、动作匹配或有动机的遮挡处；跨镜时下一镜从同一接触相位继续。
- 独立生成过于复杂（多人反应、巨物接触、空间迁移同时争画面）时优先拆开任务。复杂度是诊断依据，非固定镜头数配额。

### 2. 按演出负荷估时

- 串行动作分别估起手、移动、接触、受力、恢复和结果的可读时间；真正同步的对白、表情、动作、运镜按共同占用时间估，不重复相加。
- 对白按语言自然朗读含气口、打断与听者反应；动作按起终位置、路径、速度和身体负荷预演；特写、道具、空间揭示只留看懂所需时间。
- 反应可发生在奔跑、转身或抓握中，剧情需要的静止与迟疑保留。快节奏不等于全片加速或删关键反应。
- 先得每镜预计剪辑保留时长，再累计段落与全片。预算不够先删重复与无功能停留，再调镜头组织，不改已确认事件适配长度。

### 3. 映射成生成片段

- 镜头号、生成片段号与剧情段落号分开：一段可多镜，一次生成可承载数个关联短镜，一个长镜可分次接续。
- 生成时长同时满足每个 Clip≤30秒与模型实际支持的范围或离散档位；模型允许更长也不提高30秒硬上限。短镜低于下限时选择不超过30秒的合法长度后裁切，或与同空间同状态的相邻短镜合并生成；没有合法档位时标提交受阻，不以超限生成后裁短规避。
- 长动作超过单次上限时在可交接的动作相位分段，保留位置、方向、速度、持有物、损伤与情绪；音频记录接点供后期衔接。优先合并相邻镜头到一次接近 30 秒的生成、兼顾可控连续性。
- 接续余量、重叠帧、转场区分原始生成长度与最终剪辑保留长度，成片重叠只计一次。时长档位和精确时间码由实际平台与剪辑验证。

### 单个Clip的30秒硬上限与超量处理

**每个 Clip／独立生成组总时长不得超过30秒，无超时例外；实际模型单次上限小于30秒时取更短值。**此上限同时约束标题／平台计划时长与片内时间轴，转场、停留、尾帧及接续余量全部计入；全片／整集可以由多个 Clip 组成，不把总片长预算当成单条时长。

- 内容超出时，由助手在已授权范围内直接选择压缩或顺延：压缩重复动作、同义反应、无功能停顿及连接过程，合并可同时发生的动作；保留关键因果、用户定稿对白、必要结果与可读表演，不靠加速对白或不合理动作速度硬塞。
- 压缩会损伤必要内容时，将超出的完整动作／对白单元顺延到下一个 Clip；在可交接的动作相位分界，下一条片内时间从0开始，继承位置、朝向、持物、伤势、动作与声音相位，不重演已完成事件。不截断一句对白，也不把余下内容塞成片尾摘要或直接丢弃。
- 顺延后若下一条也超过上限，继续向后重分配；需要时增加后续 Clip，不把任何一条改为31秒或更长。已有稳定编号保留映射，同步标题、秒轴、概述、参考作用时段、分配表与接缝；固定全片预算／条数同时被锁定且无法兼容时指出冲突，不擅改已确认内容，也不放宽单条上限。
- 30秒是上限，不是每条必须填满的目标；模型更短限制、真实动作窗口与必要叙事优先。检查每个 Clip 的声明时长、所有时间段终点与累计覆盖，任一超过上限都先返工，不能用“最后会裁掉”放行。

### 生成分组与短段例外验收

**默认尽量接近30秒，先合并兼容内容，不靠扩写或慢放凑时长。**此目标受单个 Clip≤30秒硬上限约束；上限不足30秒或只有离散档位时，按实际合法范围编组，内容超量按上节压缩或顺延，不能因用户全片预算或模式支持更长而延长单条。叙事镜头短，不等于必须独立生成一条短视频；默认效率目标不能因为精简动作而被静默撤销。

编译前执行：
1. 先锁成片镜序、对白与净保留时长，列出本轮待生成内容及已生成可复用内容；不为分组重排已确认剧情。
2. 检查相邻镜头、同场景素材或同一行动线能否合并：身份/参考一致、布局与光线可兼容、状态变化写得清楚、时长与实际附件容量合法、可剪接且不会使生成复杂度明显失控。**同场景不是自动兼容**；同场不同时间/伤势需要明确切换，不拼成连续实时。
3. 先尝试将兼容短段重组为接近30秒的一次生成；必要时从相邻段调整分界，但不截断关键对白、命中或表演。交叉剪辑可按行动线合并制作，再按原成片位置剪回；回切处继承经过时间和状态，不让角色复位。
4. 每条保留为短生成的片段，记录合并候选及不能合并的具体理由。如素材/模式容量、光照状态不兼容、局部返工必须保留其他成片、模型失败证据或仅剩必要尾段。**“剧情本来只有18秒”“不注水”不是完成合并核对的证明**；若确无兼容内容，说明候选为何不可合并即可，不虚构额外动作。
5. 重新检查生成输入、实际台词窗口、起止动作相位、参考图时段、成片入出点及累计时长。更少调用不是唯一标准，不为节约一次调用破坏表演或增加不可控输入。

沿用现有项目分配表，不新建目录或强制审批：

| 生成片段/版本 | 覆盖的成片镜头或既有Clip区间 | 生成片内区间→成片入出点 | 计划生成时长/净使用时长 | 参考与连续状态依据 | 合并候选与结果/短段理由 |
|---|---|---|---|---|---|
| 原有批-序编号或本次生成组对应编号 | 精确到秒段，允许多段使用 | 每个使用区间分别列出 | 余量/裁切不计入净长 | 当前总表与模式 | 不能只写“已优化” |

一对一时可用一行；一对多时在现有 `project.md` 或总表 `video_delivery` 下记录映射，只有实际需要才加可选生成组信息，不改 `schema_version` 或原资产必填字段。Clip号若已作稳定成片索引，则在同一表明确哪条是生成母稿及哪些旧短段只用于剪辑定位；**不能把合并后的母稿和被覆盖的短稿同时列作独立待生成任务**。若编号重排，保留旧新对照并同步引用。

通过条件：
- 当前范围每个成片使用区间均有来源；无遗漏、无意重复或重复收费任务，生成余量与净片长分别计数。
- 可兼容合并已落实；保留短段均有具体合并评估或用户明确的短样本/局部任务依据。样本不代表全片分组已经通过。
- 每个 Clip 的声明时长及所有片内时间段终点均≤30秒，且满足更短的模型上限；超量已压缩或顺延。计划生成时长、模式和附件条件有依据；实际能力未核验则提交层仍待核验。
- 合并后仍有完整人物表演和新相邻接缝核对，不把多个旧提示词直接拼成超长、冲突的复制块。

人工回归示例：连续同场12秒＋18秒、参考兼容且模型支持时，优先合成30秒，原两段只保留剪辑索引；两个短段若一段夜雨外景、一段日光内景且本模式无法可靠切换，则写明理由保留分开。例子不是固定切点或效果保证，实际合并仍需确认任务授权与模式能力。

### 4. 输出前记录复核

完整批次在提示词外附简明分配表；只交样本时仅记录样本范围：

| 剧情段落 | 镜头号／观看任务 | 起态→动作及响应→末态 | 切点依据 | 预计剪辑保留时长 | 生成片段号／计划时长 | 接续条件 |
|---|---|---|---|---|---|---|
| 按内容填写 | 编号与主要任务 | 保留因果 | 内容或技术原因 | 创作预估 | 依模型合法值 | 运动、空间、道具、情绪与声音 |

反向检查：按上文生成分组验收，叙事、状态与参考相容时优先合并，尽量接近30秒；短段须完成合并评估并记录例外，无需为凑长扩写。核对最终保留时长总和与预算相符，不把生成素材总长误报为成片长度。

## 动作同步接缝去重与整场节奏

### 1. 一个事件共用一只时钟

先列**必要先后**与**能够并行**，再拆机位：准备必须先于发力，命中必须发生在到达目标的窗口内；观察、判断、呼吸、手部操作往往可以与行进、对峙或对白并行。扑击、投射物、坠落不是可无限延长的状态。禁止“先扑出→切几秒观察/蓄力→才命中”却声称全程正常实时；将准备前置，或在同一连续镜内完成起跳—拦截—落地。文字秒段不必细分到每次肌肉动作，实际精度靠预演/生成验收。

新增操作与轨迹镜也用同一时钟：上弦、装填、锁定可放到既有准备时段，动作已完成就只拍待发相位；弩不按弓的拉放方式演。扣机、弦扣释放、短距离箭跟踪、命中可在同一秒段内明确快速切镜，飞行不跨几秒等待表情，不用换角度再次发射。主观回望、接触特写期间行进/承重继续，主观所见受当时视线与遮挡限制。秒段、镜头与生成任务分别管理，补覆盖不自动新增素材图或独立生成。

相互制约的双方必须共同演：一方伸手取物时，持刀者应立即挡、跟进或显出有理由的迟疑；不能让防守者冻结来展示物件。等待要有可见策略、阻力或代价；若依据不足，缩短/并行/删除展示，而不是新增伤害或把人物改成无能。局部特写只读动作中已经发生的信息，不再重复一次同样的触碰。

### 2. 前尾后首按事件而非用词去重

连读每条接缝的前尾与后首，记录**事件身份、完成状态、位置与动量、声源相位**。到达、上路、门开、落箭、羊铃骤响等若已发生，下段从“已在路上/门已开/余响/仍在抵抗”接；不能换角度再次启动同一事件。声音桥先交代同一声源，再接结果，不默认回放发声起点。

有意重叠用于回看时，先说明叙事理由与重复范围，成片只计净保留时间；不要将两段生成余量都剪进成片。仅检查相邻词句相似无法判定重复，命中后又出现第二次真实射击也不必然是错误，须对事件与因果逐项核实。

### 3. 对白间隔与整场节奏

在现有project记录实际成片起止，检查：**问句结束→回答开始**的累计间隔、关键行动线最后露出→再次露出的间隔，以及各整场的目标—阻力—变化。多个3秒反应串联也可能变成十几秒无依据等待；让群体反应并行、合并同义反应，保留有代价的抉择，不给所有角色依次分配特写。

行动线长时间离画并非自动失败：可为亲密/悲痛完整性、限知揭晓或省略行程。须说明未回切的理由，核对距离、昼夜、路线和下次露出的进展；**成片间隔不是故事行程时间**，不得据其精确推算速度。必要提醒优先放在情绪段落之间，并交付新进展；不机械每隔N秒插一次追兵，也不为补镜虚构新的追踪能力或受伤。

### 4. 修改后整体验证

先改上游动作/剪辑计划，再同步阅读稿、视频时间轴、场景图使用区间、对白落点与项目总长。保留稳定Clip编号时显式维护 `video_delivery.edit_order`；复制文件按该顺序排列。重排后逐一检查**新相邻接缝**，移走匹配镜后须移除“接上一镜手势”等失效说明。源场号若改名，维护源场旧新对照；资产的历史记录及确认依据不重写成新事实。

减掉的重复时间不再填回原30秒；用户只设上限时更新预计总长，有精确时长约束则报告差额、按授权重分配。保留原对白文本与说话人，授权重排造成对白顺序变化时记录例外，并对新版源稿重跑顺序核对。四段式和名称lint只能证明字面/结构，不证明实时物理或戏剧合理性。

### 人工回归情境

| 情境 | 应有处理 | 不能作为通过依据 |
|---|---|---|
| 近距离扑击中插入数秒准备特写 | 准备前置或合并即时拦截，保留落地结果 | 每镜都短于3秒 |
| 前段已踏上道路，后段再次从出口起步 | 后段沿路继续并继承离出口距离 | 机位不同所以不算重复 |
| 问完后连续多人反应才回答 | 累计问答间隔，按策略合并/并行 | 每个反应单独都自然 |
| 持刀阻止但任对方整理物件十几秒 | 动作即时制约或交代迟疑代价 | 道具特写完整 |
| 画外铃响后又重演到达和第一次铃响 | 从声源的持续状态接，或明确重叠回看 | 声音已经内联 |
| 追兵离画长、主线在亲密表演 | 检查整场弧线和行程，在段间选择必要提醒 | 一律加镜或一律维持30秒 |

## 时间与状态的统一交接

每段能回答：从什么状态开始、发生什么主要变化、谁作出可见响应、以什么状态结束、下一段继承什么。规划可用下表，交付可融入正文：

| 阶段及事件 | 起始状态 | 行动与响应 | 结束状态 | 镜头职责 | 时间及片段归属 |
|---|---|---|---|---|---|
| 按需增减 | 关键主体/物体/空间 | 本段主要变化 | 可见结果与接点 | 观众需看清什么 | 估时后填写 |

时间码连续覆盖成片时长，转场、停留、尾帧计入预算；多片段区分成片时间与片内时间，重叠帧只计一次。生成时长与剪辑保留时长不同则分别标明。

单个 Clip 放不下必要内容时，先压缩重复与无功能停顿，再调整可并行的表演与镜头组织；保留用户定稿对白、关键因果与结局，仍放不下就顺延到下一条，每条均不超过30秒。固定全片预算也放不下时明确报告整体冲突，可提出重分配、多片段或经授权精简方案；延长整体不等于允许延长单条。用连续动态内容填满接近 30 秒的片段，靠内容而非无关事件或留白。

身份、数量、位置、持有关系、损伤与资源跨段继承；交接、换场、清理、修复、消散、倒叙、复位写明节点与依据。分镜只写本镜真实可听的现场声、对白与动作音效，独立生成不用"继承上一镜声场"代替本镜声源；跨镜环境底噪、对白反应、音效尾音记为后期接点。独立分镜默认 NO BGM，用户要求的整片音乐另作后期音轨规划。

## 任务分支

- **动作**：保留三强度、标准/极速、角色档案、骨架、六项交锋因果、模型时间格式及动作诊断。按强度/速度改变动作密度与时长；微动作服务原剧情，数量示例不迫使新增招式或改结局。
- **分镜、摄影、风格与 Cinema**：先按事件定镜头与片段，再填入可编辑 HTML、场景设置或预设结构。主体可读性和有意重复有效，平台最多场景数是上限。
- **表演、FACS、对白与音乐**：保护完整表演和语义/乐句、分配可读时间；局部节拍、口型、音乐同步服从真实素材与后期校准。教程保留操作顺序，风景可只有缓慢揭示。
- **已有视频编辑/VFX**：先锁唯一母片、原时间线、修改区间、保留项及模式允许时长，按原片事件标注修改。生成式重拍按对应模式明确性能与时长继承。
- **延伸与接续**：向后延伸从原片尾状态继续；向前延伸先设计前情、新增部分结束状态接回原片首状态。继承动作相位、方向、速度、构图、光照和声音，新增内容分配该模式合法时长。
- **失败修正**：识别问题属内容超载、因果断裂、连续性、镜头、参考还是平台参数；保留诊断、单变量迭代及生成结果验收。

## 联合验收

每次修改后执行 [修改后标准复查闭环](production-checks.md#修改后标准复查闭环)，读回最终完整条目并核受影响接缝/依赖，修复后重跑适用检查。

1. 目标、阶段结果、结局和最终画面相符，已确认内容完整；执行上文多线叙事语义自检，不能仅凭单镜快切通过。
2. 每次切镜/拆生成有观看任务与切点依据，成片时长、生成时长、剪辑保留时长分别记录。按上文动作时钟与整场节奏检查动作窗口、累计等待和跨段重复；逐镜核验真实动作窗口、对白与表演可读性，不设固定镜数、默认镜长或3秒上限；同镜跨时间段仍按实际连续观察处理，不用全片均长代替逐镜判断。每个 Clip 总时长仍须≤30秒。内容压缩后释放的时长不回填无关动作；有固定总长时先记录缺口并按授权调整。
3. 时长来自演出负荷、合计与交付一致，平台/模式参数合法；编辑和延伸保留正确边界。
4. 参考真实且职责清楚，跨段状态可追踪，允许变化有节点。
5. 原任务功能和输出契约完整，执行对应模块检查及适用 lint；先确认检查器支持目标模型、模式与当前结构。
6. 演出保留可见动作与响应，镜头路径明确，关键状态接续。精简前后对照同时/先后、触发时机、持续背景动作与跨段相位；只删无新增约束的复述，内部档案与验收问题不混入正文。
7. 静态校验只证明文档/结构；未生成的画面、声音、身份一致性和精确节拍标为待验收。
