## 硬设定还是软设定（三个问题）

- 故事是否要求观众*掌握*规则？是 → **硬** / 否 → 软
- 你希望观众觉得*自己聪明*，还是感到*惊奇*？聪明 → 硬 / 惊奇 → 软
- 你愿意留下不解释的东西吗？愿意 → **软** / 不愿意 → 硬

> 这个世界是：☐ 硬  ☐ 软（影响提示词要写得多字面、多一致）
