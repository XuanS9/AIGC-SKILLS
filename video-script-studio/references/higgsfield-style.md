# Higgsfield 视觉风格（Higgsfield Visual Styles）

选择一个配方的镜头覆盖之前，先用 [共享叙事规划](narrative-planning.md)：**阶段**是一个戏剧事件或状态转变，**镜头**是两次切镜之间连续的摄影机覆盖，**生成片段**是一次模型输出。一个镜头可以跨几个阶段，一个阶段可能需要几个镜头，支持时一个片段可以包含多个镜头。风格定义画面；剧情事件、因果转折和表演决定分段和时长。除非故事要求改变，跨片段保持风格锚点。工作室格式里，风格写在 `[视觉风格]`，只写一次。

## 电影视觉参考匹配

这是项目视觉设计规则，适用于通用图像与视频任务，不要求使用 Higgsfield。

1. **先继承，再匹配，最后归入项目总纲。**场景图片任务默认读取本节和项目美术/风格记录；继承已定媒介、时代文化与用户指定电影/剧集。无现有参考时按题材、环境、情绪与动作规模推荐一个主参考，随本批次样本评估，不另设风格审批。用户给多个参考时全部尊重，并说明各负责的维度，避免相冲突的建筑、媒介或光色随机混合；不要只堆片名。
2. **将片名拆成可见特征。**记录媒介、时代文化/建筑、主色与点缀色、光源方向与反差、构图与体量、材质磨损和空气层次。每张场景的独立复制正文都写入其适用特征，不只放在总表或聊天说明；“北地、写实电影、低饱和、高清”不足以约束建筑与质感。当前场景选少量具体表现，避免复制大段世界观或形容词堆积。
3. **剧情定时段，美术设定定受光。**从剧本提取昼夜、季节、天气、室内外与可用光源，从当前项目美术设定读取直射/漫射比例、曝光、色温与阴影。各时段保留自身时间特征，光源支持必要的地形、表情和动作信息。单张地点图注明基准时段，跨时段视频继承结构并呈现当前受光。美术反馈先写回项目设定，再同步受影响的提示词，其他已确认内容继续继承。画幅按用户设置。
4. **纯环境与演出资产分开。**按 [入口规则](spatial-layout.md#场景资产内容边界)，场景只画地形、建筑本体和固定空间结构，整张图无人物/群演、生物、家具、货物、日用品、器械、船只或灯具道具。生活条件通过墙地磨耗和结构修补表达，尺度用门洞、层高、透视交代。道具落位、群体活动及其光源写入视频；场景只呈自然光或明确的场外照明效果。角色主参考与B/P独立资产保留各自规范。
5. **区分参考与复刻。**提炼摄影、美术和光色方法，不照搬参考片的角色、生物设计、道具、历史年代或具体构图，不改写已确认剧情。
6. **复制正文不写片名。**外部电影/剧集只用来拆解进项目视觉总纲；资产与场景正文写拆解后的媒介、材料、光色和空气层次，不写片名、剧名或“某作品质感/风格”，避免把画面拉向原作。片名只留在项目美术设定的来源记录里。
7. **如实标注依据。**没有实际图像时写“文字风格参考”；看过用户提供的图像后才描述该图的可见特征。片名不是平台预设，不虚构上传、模型参数或视觉验收。

### 项目美术设定的归属与更新

具体影片、地域风格与视觉取舍存放于项目自己的美术设定，沿用现有文件组织；`project.md`记录入口，总表记录来源路径与版本。已有设定直接读取，缺少时用[美术设定模板](template-style-sheet.md)整理到项目。通用Skill保留转译方法和字段结构，各项目填写自己的内容。

美术设定记录：`参考及适用地区/场景｜各参考职责｜媒介｜时代文化/建筑｜色彩｜天气与空气｜光源/曝光/明暗关系｜材质与陈设｜昼夜和季节适配｜参考形式与版本`。

确定风格时，将参考画面或用户描述转成这些可见特征；编写时选取当前场景适用的部分，写入独立可复制正文。更换风格时，更新项目美术设定、总表来源版本及受影响提示词。现有剧情、空间与身份按已确认范围继承。具体流程见[项目工作区](project-workspace.md)。

## 资产图先定画风与细节

**使用参考资产的视频，画风与静态细节优先在资产阶段解决，视频文字负责辅助继承，不另造一套美术。**先将用户/项目已确认方向落实到角色 C、生物 B、道具 P、场景 S 的独立图片提示词，再由实际采用的参考图承载。首个当前阶段资产样本同时验证画法、配色和细节表达，沿用原样本流程；不另做色卡、风格板或审批，不要求回传全项目实图，也不改变资产建立门槛。

- **共用画法，分配到具体部位。**把同一版已确认媒介、线条/画材/渲染方式、配色倾向与材质表现实际写进每张资产正文，不只写“沿用项目风格”。再将颜色、材料和细节落实到该资产部位，不能让模型各自选择画风。统一不等于所有对象同色；保留角色、阵营、物种和功能的已定差异。

| 资产 | 静态设计在图中应明确的内容（只取适用项） |
|---|---|
| C 角色 | 脸与体型比例、完整服装层次、各部位固有色与材料、配饰/扣具位置及数量、已有辨识痕迹 |
| B 生物/植物 | 完整比例和轮廓、皮毛/鳞片/枝叶的表现方式、背腹或区域色块/斑纹、关键可动结构 |
| P 道具 | 外形与尺度、部件数量和连接、握持/使用部位、分区颜色与材料、接缝及已有使用痕迹 |
| S 场景 | 建筑/地形形制、材料与环境主辅色、地标连接、固定表面痕迹、基准时段的受光与空气层次 |

- **细节为辨识和剧情服务。**按[资产设计依据](asset-design-basis.md)与[造型辨识度](asset-design-basis.md#造型辨识度与身材设计)，先组织体量、轮廓、主色块和记忆点，再写必要表面细节；写清部位、形状/数量/位置、材料表现，不用“精致、超细节、高清”代替设计。允许符合项目的原创审美候选，但不冒充剧本事实，不擅加损伤或统一做旧。细节要在对应视图尺度下可辨，多视图保持同一设计；沿原版式分配，不为增加细节强加额外组板或特写图。
- **固有色与受光分开。**C/B/P 保留适合识别的中性展示条件与各自背景规范；线条、色层或柔和布光要让固有色、轮廓及关键结构可读，不把剧情夜色、强偏色或厚雾烘进基础图。S 按剧情基准时段呈现环境光色；统一画风不等于统一灯位或明暗，基础图也不负责提前演出后续状态。
- **参考图有问题，先修输入。**已看过且确认采用的实图在指定职责内作为外观依据；文字设定、实际图和视频描述须相容。已知偏差先修相关资产，或经用户确认采用实图并回写设定，不期待视频里多加形容词就能覆盖冲突。未看图则注明实图未核对，不宣称已经锁定视觉。图对而视频漂移时再查绑定、参考职责、光照和视频编译；展示背景、排版、站姿及展示灯位不锁进演出。

## 全片风格短句

用简短文字将同一风格先落实到资产提示词，再辅助视频继承，不以视频文字替代资产图设计。默认不新增色卡文件、色号表、图片参考或审批。把项目已确认的**媒介/画法、整体配色及用法、明暗与质感倾向**提炼成一小段，通常一至三句即可；沿用现有美术设定或 `project.md` 保存。已有描述直接复用，尚未确定的视觉选择随当前样本确认，不擅自补成已确认设定。

- **每条都实际写入。**完整视频的 `[视觉风格]` 先原样复用同一段已确认短句，再补当前场景的时段、光源方向、硬柔与必要色温。只有局部光照、色温或“电影感”不算落实全片风格；不能用“同上”“沿用项目风格”代替实际描述。这里的“只写一次”是每条正文内一次，不是全片只写一次。
- **全局稳定，局部可变。**短句不混入仅某场成立的灯位、天气或昼夜；这些写在后面的场景补充里。已确认的梦境、闪回、地区或阶段风格例外按作用范围写清，单条有多个风格区间时注明各自时段，不让例外覆盖全片。源视频编辑/延伸按源片已定风格继承，不借补短句重新设计。
- **资产去重不删全片画风。**全局画法和调色不是人物服装、道具固有色或建筑造型的重复描述；有参考图也保留短句。角色、生物、道具和场景资产继承其中适用的媒介、配色与质感；中性资产背景和识别用布光仍按原模板，不强套剧情夜色或改变已定固有色。精简/原生格式在相应正文或字段保留这些信息，不强加块标签。
- **交付时人工对照。**逐条核短句是否实际进入正文、是否来自同版确认设定，局部补充是否冲突；不能把存在 `[视觉风格]` 标题当通过。文字一致不保证生成色彩一致，实际结果另验收。

局部写法示例（不是所有项目的默认风格；第一段为可复用短句，第二段为本场补充）：

```text
[视觉风格]
二维赛璐璐画风，清晰线条与平涂阴影。低饱和蓝灰、灰褐为主，琥珀暖色仅作小面积点缀；暗部保留层次，高光柔和。
本场为阴天室内，窗外漫射光从画面左侧照入，脸部与背景明度可辨。
```

## 核心平台风格（Core Platform Styles）

这五种风格是 Higgsfield 的具名预设。按准确名称引用。复制正文同时写出拆解后的可见特征（光、色、材质），不能只写一个预设名。

### Cinematic
**画面：**精致、高反差、鲜明的色彩、均衡的曝光：现代大片
**适合：**剧情、动作、叙事影片、广告、任何专业内容
**色彩倾向：**饱满、浓郁、干净
**提示写法：**“Style: Cinematic”
**搭配：**Dolly In、Arc、Crane Up

```
Example: A detective walks through a night market.
Style: Cinematic. Cold blue shadows, warm amber market stall light.
Shallow depth of field. 16:9.
```

---

### VHS
**画面：**复古录像带颗粒、渗色、轻微扫描线、模拟的不完美
**适合：**80/90 年代怀旧、恐怖、惊悚、复古 MV、闪回
**色彩倾向：**略微发白，暖黄和红，低反差
**提示写法：**“Style: VHS”
**搭配：**手持运镜

```
Example: Friends at a house party in 1987.
Style: VHS. Warm, grainy, slightly overexposed. 4:3 ratio.
```

---

### Super 8MM
**画面：**温暖的胶片颗粒、柔和暗角、低饱和的色彩、家庭录像感
**适合：**个人故事、爱情、怀旧、独立电影、家庭时刻
**色彩倾向：**温暖、金色、略微褪色
**提示写法：**“Style: Super 8MM”
**搭配：**手持、自然光描述、亲密场景

```
Example: A couple dancing in a sunlit backyard in the 1970s.
Style: Super 8MM. Warm grain, soft vignette edges. 4:3.
```

---

### Anamorphic
**画面：**超宽画面感（2.35:1）、横向镜头光晕、轻微桶形畸变、史诗尺度：经典好莱坞宽银幕
**适合：**动作、史诗奇幻、战争片、辽阔风景、强烈的戏剧
**色彩倾向：**高反差，深黑，饱满的高光
**提示写法：**“Style: Anamorphic”或“Style: Anamorphic, 2.35:1 widescreen”（2.35:1 是风格语域；输出画幅在平台设置里选枚举值）
**搭配：**Crane Up、360 Orbit、Super Dolly Out

```
Example: An army marches across a frozen plain at dawn.
Style: Anamorphic, 2.35:1. Deep blue-grey tones. Lens flare on the rising sun.
```

---

### Abstract
**画面：**非具象、超现实的配色、非常规的形状、艺术化
**适合：**MV、概念艺术、梦境段落、实验性内容
**色彩倾向：**鲜艳、出人意料，由概念而不是写实驱动
**提示写法：**“Style: Abstract”

```
Example: Fractured geometric shapes pulse to music in a void.
Style: Abstract. Electric blue and magenta on black. 1:1 ratio.
```

| 类型 | 描述 | 适合 |

| 黄金时刻 | 日出后或日落前温暖有方向的光 | 浪漫、史诗、美 |

| 低调光 | 大部分是暗的，只有小片光 | 恐怖、惊悚、黑色电影 |
| 高调光 | 明亮、均匀、阴影很少 | 喜剧、广告、生活方式 |

## 电影布光技法（Cinematic Lighting Techniques）

AI 模型反应良好的具体布光。直接在提示词里用这些术语，精确控制光怎样塑造场景。工作室格式写在 `[视觉风格]`：光源方向（画面左/右）、色温 K、反差、材质。

| 技法 | 效果 | 适合 |
|-----------|--------|----------|
| 伦勃朗光 | 暗侧脸颊上一个三角形光，一只眼被照亮 | 肖像剧情、人物登场、情绪化的访谈 |
| 蝴蝶光 / 派拉蒙光 | 顶光在鼻下投出阴影 | 魅力、时尚、美妆镜头、经典好莱坞 |
| 分割光 | 半张脸亮，半张脸全在阴影里 | 二元性、内心冲突、反派揭示 |
| 轮廓光 / 逆光 | 边缘光勾出主体轮廓 | 神秘、史诗揭示、与背景分离 |
| 有动机的光 | 场景里可见或暗示的光源（灯、窗、火） | 写实、叙事落地、自然主义剧情 |
| 实景光 | 场景内的光源（霓虹招牌、蜡烛、屏幕） | 夜景、赛博朋克、亲密的写实 |
| 明暗对照法 | 明暗区域极端对比 | 文艺复兴感、强烈戏剧、绘画式构图 |
| 高调光 | 明亮、阴影少、照明均匀 | 喜剧、广告、生活方式、干净的美感 |
| 低调光 | 深阴影占主导，小片光 | 黑色电影、惊悚、恐怖、心理紧张 |
| 黄金时刻 / 魔幻时刻 | 温暖的琥珀色定向光，长而柔的阴影 | 爱情、美、史诗风景、情感节拍 |
| 蓝调时刻 | 日落刚过冷的钢蓝色环境光 | 忧郁、过渡、安静的紧张、城市孤独 |
| 正午烈日 | 硬的顶光，阴影强烈清晰 | 沙漠、对峙、暴露的脆弱 |
| 阴天漫射 / 柔光箱 | 均匀柔光，没有硬阴影 | 肖像、纪录片、落地的写实 |

## 画幅指南（Aspect Ratio Guide）

| 比例 | 名称 | 适合 |
|-------|------|----------|
| 16:9 | 宽屏 | 标准视频、YouTube、影片 |
| 9:16 | 竖屏 | 抖音、Instagram Reels、Shorts |
| 2.35:1 | 变形宽银幕 | 史诗电影、最宽的宽银幕戏剧（风格语域；输出画幅以模型枚举为准） |
| 1:1 | 方形 | Instagram 帖子、艺术 |
| 4:5 | 竖幅 | Instagram 信息流、社媒肖像 |
| 4:3 | 经典电视 | 复古、VHS 感、怀旧 |

## 风格最佳实践（Seedance）（Style Best Practices (Seedance)）

这些原则适用于 Seedance 2.0 / 2.5，是对上面风格词汇的补充。

### 单一风格锚点规则（One Style Anchor Rule）

一个主要的风格锚点胜过五个形容词。超过 2–3 个风格词，模型注意力会被稀释，输出变得泛泛。

**错：**`Style: cinematic, anamorphic, moody, atmospheric, dramatic lighting, film grain, desaturated, noir-inspired, high contrast, vintage feel`

**对：**`Style: anamorphic, subtle grain, muted palette`

挑出你的锚点（最重要的那一个风格元素），加 1–2 个辅助词，停下。

### “Cinematic”什么也没做（"Cinematic" Does Nothing）

每个生成的视频默认都是“cinematic”的。这个词不增加任何信息。换成具体的镜头或反差描述：

- ~~“cinematic”~~ → `shallow depth of field, warm highlights, cool shadows`
- ~~“cinematic look”~~ → `anamorphic, 2.35:1, horizontal lens flares`
- ~~“cinematic quality”~~ → `35mm film stock, natural grain, Kodak Portra palette`

### 通过 @ 参考迁移风格（Style Transfer via @Reference）

视觉风格参考胜过描述性文字。一张参考图/一段参考视频承载的风格信息，比 10 个描述词还多：

```
Match the visual style, color grading, and film texture of @Video1.
A woman walks through autumn leaves in a park.
Camera: slow tracking alongside her.
```

风格参考用于：调色、胶片模拟、光照情绪、质感、特定年代的画面。工作室格式里，这一句按参考名称写在 `[动作与声音参考]` 的职责行，标签只在开头 `[参考资产]`，并写明不用参考里的人物与场景。

### CGI 材质约定（CGI Material Contract）

写 CGI 或产品渲染时，每个表面写明 2–4 个材质属性，避免默认的“塑料光泽”：

| 属性 | 选项 | 例子 |
|----------|---------|---------|
| 基材 | 金属、玻璃、布料、陶瓷、木头、皮革 | `brushed stainless steel` |
| 粗糙度 | 哑光、缎面、光面、镜面 | `satin finish` |
| 瑕疵 | 划痕、灰尘、磨损、指纹、包浆 | `fine scratches from use` |
| 边缘 | 斜切、锐利、圆润、倒角 | `soft rounded edges` |

**例子：**`A matte ceramic vase with hairline cracks and a subtle patina, soft rounded rim, resting on rough-hewn oak.`

### 年代控制（Period Control）

不要只写年代，要写出那个年代的**材料和光照**：

- ~~“1970s style”~~ → `Kodachrome warm tones, wood paneling, orange shag carpet, tungsten bulbs casting amber light`
- ~~“1940s noir”~~ → `high-contrast black and white, Venetian blind shadows, fedora silhouettes, wet asphalt reflecting streetlamps`
- ~~“1990s home video”~~ → `Hi8 camcorder grain, autofocus hunting, timestamp overlay, oversaturated greens`（工作室默认“无字幕、无水印”；时间戳叠加只在用户明确要求时写）

## 语域两极：风格旋钮有相反的两端（Register Poles — the style dial has opposite ends）

`[FIELD — 13-project community harvest, 2026-07-18]`：“照片写实电影感”不是一个语域。制作项目落在旋钮上*具名的两极*，而所处的那一极决定整套镜头语法：

| 语域极 | 镜头语法 | 质感叠层 |
|---|---|---|
| **电影语域**（剧情/爱情长片） | 呼吸感手持，允许不水平，自然的运动 | 35mm 颗粒、奶白低反差、片门抖动、光晕、“四角和中心一样亮” |
| **电视广播语域**（2000 年代初的剧集） | **锁定三脚架、正面构图、停住的反应节拍、每镜最多一个运镜** | 重度柔光、高光溢出、胶转磁颗粒、平淡中性的日光 |
| **定格 / 手绘动画** | 步进式运动：“真正的 12fps，一拍二：每个姿势停两帧然后跳到下一个，绝不滑动”+ 持续的绘画式抖动 | **分离运动规则：**氛围（雪、呼出的白气、烟）**平滑**运动，人物则一拍二地步进：这是一条明确的约束，对抗视频模型默认的平滑 |
| **日式动画 / 赛璐璐** | 每镜一个具名运镜，物理/皮肤块更少（模板收紧） | “Cel-shaded 2D, clean flat fills, two-to-three value cel shading — not painterly, not 3D, no CGI smoothness” |

**风格锚点这个位置按语域换词汇。**同一个位置，不同的语言：照片写实锚定在一种摄影/导演画面上（只限短格式；块式提示词改为描述画面，按 seedance 的可测量语言规则；工作室复制正文不写导演名或片名）· 日式动画锚定在一个**美术时代**（“2000 年代初的复古动画，老派赛璐璐比例”）· 定格动画锚定在**媒介物理**（“12fps 一拍二，绘画式抖动”）。绝不把一个语域的锚点带进另一个。

**一个饱和的点缀色，留给故事。**整个语料的色彩纪律：在低饱和的调色里，剧情关键道具独占唯一的饱和点缀色（一个酸绿色的装置、一盏黄绿色的遥控器 LED）；同样的保留也可以按时间用（“黄金时刻留给反转”；在那之前一切保持平淡中性）。把这个保留明确写出来。

## 风格配方：七种验证过的形态（Style Recipes — seven proven shapes）

`[OFFICIAL — Higgsfield cinematic-prompt-builder skill, 2026-07]`：起步配方，每一种是一份不同的渲染约定。可以自由组合和偏离；每一种的承重部分是**“是 / 不是”的声明**。下面来源里的镜头数和时长是可选的历史示例，不是规定的结构。先选需要的事件和覆盖，再按可读性和表演分配时长。不强加 15 秒时长、等长、固定的段数或必须的主角停留。模型时长限制作用于生成片段，与配方无关。

| 配方 | 画面声明 | 结构 + 标志 | 音频 |
|---|---|---|---|
| **真人史诗** | 8K 照片写实、变形宽银幕、细颗粒：“照片写实，**不是** 3D/游戏” | 一镜到底或多镜头；一个“钩子”事件触发一个停住的慢动作节拍，然后弹回；尺度对比（微小的人物对辽阔的主体） | 画内声音；慢动作时降成闷住的真空感加心跳，随一声呼啸弹回 |
| **三维动画长片** | 鲜艳光亮的 CGI、皮克斯级风格化、皮毛/皮肤的次表面散射 | 有动机的角度变化的蒙太奇；每镜一句写明演绎的台词；需要时落一个视觉笑点（来源示例：6 镜 / 15 秒，可选） | 允许轻配乐；常常仍以音效为主 |
| **游戏过场** | UE5 实时引擎渲染：“超真实，但一看就是**游戏渲染**，**不是**电影” | 由游戏事件推动的硬切（来源示例：3 镜 / 15 秒，可选）；**固定在屏幕上的 HUD，锁定一个点缀色 hex，每个元素都列出准确文字**，HUD 永不视差（只在用户明确要求画面文字时） | 无音乐；音效加细微的界面提示音 |
| **游戏实机画面** | AAA 街机（赛车）：超饱和的引擎渲染，“游戏内画面，**不是**电影底片” | 稳如磐石的追车镜头锁定车辆，全程**没有**慢动作，实时 HUD（转速、加速、小地图） | 引擎、换挡、加速、轮胎尖啸、界面提示音 |
| **FPV / POV 一镜到底** | 一个不间断的镜头，照片写实微距，变形宽银幕 | 一段文字里按时间码写节拍；一次具名变速（240fps 子弹时间节拍 → 跳回 24fps）；微距擦过表面 | 慢动作时把环境声换成放大的节奏声 |
| **视效合成**（在源片段上） | 照片写实的实拍特效真实感；构图 + 调色从源片段**继承** | 输入锁定：底片原样保留，摄影机精确继承；唯一的添加 = 新元素 + 它的光 + 接触阴影；视差锁定到一个锚定平面 | 新元素的画内声音叠在保留的房间底噪上 |
| **怪兽 / 生物** | 8K 照片写实变形宽银幕，**原创**设计（“不基于任何系列”） | 事件驱动的切镜，每切一套光学（来源示例：约 6 切，可选）；一个重复的细节可以把开场镜头连到下一个镜头的推近；**约束规则**（“始终在海面，从不升空”）让物理和尺度落地 | 只有画内声音：隆隆声、吼叫、水爆、次声轰鸣 |

引擎侧的完整对应：HUD 配方和输入锁定在 `higgsfield-seedance.md` 与 `higgsfield-seedance-vfx.md` 里，配有实用写法；约束规则同时也是安全构建规律（`higgsfield-seedance.md` § Build-safe construction）。
