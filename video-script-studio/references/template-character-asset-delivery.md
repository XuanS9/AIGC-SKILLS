# 角色资产与 Seedance 2.5 交付规范

本规范是整合版的项目约定，适用于角色资产提示词、参考图整理及后续视频提示词。与根 SKILL.md 一起执行；原模块提供的其他方法和能力继续保留。用户明确的新要求优先。

写样本和完整稿前先读取 [项目资产总表](asset-registry.md)。资产标题在六行提示词之外列出总表中的中文名称、唯一调用名和实际文件或待生成状态；六行内姓名沿用总表，不重新翻译命名。只交付文字提示词时记录为 `planned`，后续视频阶段读取同一条目。

只有用户要求资产提示词时才输出本模板的提示词，不附视频提示词。每次先执行 [样本确认流程](sample-approval.md)：默认选一个核心角色做正面或三分之四半身样本，用户明确确认本次样本的身份、造型、质感和光色后，再输出本批次完整六行资产提示词及其他所需资产。若验证多视图排版，则用一个角色的最小完整组板作为样本。已确认设定可以继承，但新增资产、改写、补充角度和局部修词均须先给本次样本，不用历史确认替代，不设跳过例外。样本阶段不批量展开。

## 1. 默认交付与模型

- 当前项目视频默认使用 Seedance 2.5，不主动提供其他视频模型的方案或混写其他模型参数；用户后续明确换模型时调用对应保留模块。图片工具沿用用户已确认的 image2.5 名称，不自行映射成其他产品或推断其 API 参数；未确认平台能力时只提供可复制提示词。
- 默认交付一张完整角色资产参考图：左侧正面面部特写，右侧无头部的全身正面、侧面、背面，按需补充关键细节局部图。左右分区清晰，所有视图属于同一角色。
- 默认只交一段完整可复制的精简图片提示词，按下方格式和阿德莱德案例组织。直接写“左侧是面部特写”和“左侧：正面面部特写”，不额外强调特写数量。不要要求用户自行拼接多个补丁，不默认附长负面词库或摄影参数清单。
- 表情参考由用户另行生成；默认只附一句备注，不自动生成、不混入资产参考图，不把缺少可选表情图作为普通任务的阻断项。左侧中性正面特写用于身份参考。
- 当前项目图片默认写实电影质感。以下版式面向人类角色；动漫、插画、非人角色、特定头饰/发型研究及用户指定版式仍调用原模块，按任务调整，不强加真人皮肤或人类身体模板。

## 2. 简洁提示词标准

### 固定结构与填写规则

按“总述→姓名与年龄性别→左侧面部→右侧身体服装→背景与一致性→灯光与质感”写六行，保持接近下方范本的长度。

| 部分 | 要写的信息 |
|---|---|
| 总述 | 完整角色资产参考图，左侧面部特写、右侧无头多视图 |
| 身份 | 角色姓名、年龄、性别及适用的身份信息 |
| 左侧 | 正面面部特写；五官、发型、面部辨识标记、表情与头部配饰 |
| 右侧 | 无头部的全身正面、侧面、背面；体型、完整服装、鞋履、配饰与道具，按需补关键细节局部图 |
| 背景与一致性 | 干净浅色背景，左右分区清晰，同一角色的面部与服装细节一致 |
| 灯光与质感 | 工作室灯光、电影级光影或柔和电影级边缘光、写实电影质感、8k、高清细节 |

- 头脸、发型和耳饰等头部配饰描述集中在左侧，体型、服装和道具集中在右侧。左侧面部与右侧身体必须属于同一角色。
- “无头部的全身”沿用用户范本用语，意图是展示头部以下至鞋底的完整身体与服装。右侧三个身体视图都不应出现头部；不表现身体断面。无需把这些解释扩写成默认提示词中的长篇裁切指令。
- 服装覆盖上身、下身或连身款式、鞋履及必要配饰。道具的数量、归属、连接关系及左右方向按角色自身判断；不对称细节在不同角度保持位置一致，侧面选择最能展示关键结构的一侧并写明。
- 关键细节局部图按需放在右侧下方，通常选 1–3 处最影响辨识或制作的结构，例如扣具连接、衣料接缝、纹样、道具握柄或鞋履构造。明确具体部位与可见细节，沿用主视图的颜色、材质、数量和左右归属；局部图不替代身体三视图，不重复画完整身体、不额外增加面部。没有必要时可省略；额外身体角度仍可按任务单独补充。
- 五官、肤色、发型、辨识标记及服装按实际角色替换。阿德莱德的皇室身份、金发、淡痣及酒红连衣裙只属于该案例，不设为其他角色的默认特征。
- 需要加强真实感时，只在对应区域补少量具体细节。可采用“部位或材料＋可见差异＋程度或分布＋受光表现”，例如“鼻翼毛孔较明显、外侧面颊更细”或“布料反光分散、皮革反光集中”。新衣不强行做旧，不擅改定稿身份，不以噪点、锐化、粗大毛孔模拟皮肤。
- 85mm、f/8、ISO 100、对焦、侧光与白平衡等摄影描述仍可按需要调用，不是每次必填项。“8k”和摄影术语是提示词中的质感描述，不代表实际输出分辨率或可用 API 设置。
- 默认采用干净浅色或浅灰色背景，不再强制旧版 #8a8a8a。所有资产图提示词（角色、表情、道具与场景）默认明确写入「画面不出现任何文字、字母、数字、姓名、视图标签、尺寸标注、签名或水印」，角色六行格式将此短句并入“背景与一致性”一行。提示词中的姓名、左右方位和视图名称仅用于描述，不在图上绘制。用户后续明确要求保留的品牌文字或场内文字可按指定范围例外处理，其余仍排除。

### 标准可复制格式

```text
一张完整的角色资产参考图，左侧是面部特写，右侧是无头多视图，
[角色姓名]，[年龄]岁[性别]，
左侧：正面面部特写，[详细五官+发型描述]，表情[中性/冷静等]，
右侧：无头部的全身正面、侧面、背面，[体型+完整服装描述]，右下方补充[按需选择的关键部位及局部细节]，
干净浅色背景，左右分区清晰，面部特征与服装细节高度一致，画面不出现任何文字、字母、数字、姓名、视图标签、尺寸标注、签名或水印，
工作室灯光，电影级光影，8k，高清细节
```

### 用户指定参考案例

```text
一张完整的角色资产参考图，左侧是面部特写，右侧是无头多视图，
阿德莱德，24岁欧洲皇室女性，
左侧：正面面部特写，浅金色波浪长发垂落至肩下，灰蓝色杏仁形眼睛，鼻梁挺直，鼻尖略圆，下唇稍丰满，左侧鼻翼旁有一颗淡痣，两侧眉峰略有高低差，白皙皮肤带浅暖色，鼻翼可见细小毛孔，外侧面颊偏哑光，嘴唇保留细纵纹，佩戴小型金色耳钉，淡妆，闭嘴，表情冷静自信，
右侧：无头部的全身正面、左侧面、背面，身高172cm，身形修长，肩部舒展，腰线清晰，穿深酒红色哑光绉布休闲连衣裙，细肩带、浅方领、合体腰身，裙摆至膝盖上方，角色自身左侧小开衩，背部隐藏式拉链，搭配细黑色皮腰带与黑色低跟露跟鞋，裙料可见细密织纹，腰部和裙摆有轻微垂坠褶皱，三个视图的肩带、腰带、开衩方向和鞋款一致，右下方补充腰带扣与穿带连接、左侧开衩收边和绉布织纹的局部特写，
干净浅灰色背景，左右分区清晰，所有视图属于同一名女性，面部特征、体型与服装细节高度一致，画面不出现任何文字、字母、数字、姓名、视图标签、尺寸标注、签名或水印，
柔和工作室灯光，电影级边缘光，保留鼻翼与衣褶的局部明暗，布料反光分散，皮革有小范围高光，写实电影质感，8k，高清细节
```

需要排除项时只针对实际问题补充短句；工具具有独立负面提示词栏时可移入该栏，不重复粘贴，不虚构通用 `--no` 参数。不因单次失败不断堆叠同义否定句，也不承诺换模板即可稳定去头或消除磨皮。

### 定稿、修复与其他资产

- **制作方式**：本批次当前样本确认后交付完整参考图提示词，不再逐个确认已覆盖的组成步骤。新请求补充角度、修改或修复提示词时先给本次样本。执行生成时可一次生成后验收；已有定稿正面特写时直接沿用。其他面部角度优先引用或编辑主参考制作，核对身份后作为独立辅助图。组板时不对已通过的面部做生成式重绘；排版需要缩放时尽量减少重采样。
- **单独大头照**：仅需主脸或需要先定稿时，将构图换为“单人正面面部特写”，保留实际身份、肩部衣领及适用的肤质与光线描述，删去其他视图，可独立生成。
- **视觉修复**：右侧出现头部时按下一节另存裁切修复版；不要为修右侧而重绘已定稿的左侧。皮肤过平时核对脸部画幅占比、原图分辨率、补光以及工具中的美颜或增强设置，再选择局部修复；像砂纸时减少纹理与锐化。生成式局部修复仍需重验身份与肤质。
- **道具与场景**：继续保留道具多角度及必要底部视图、真实尺寸、结构接缝、材质厚度、重力支撑与使用状态；独立资产保持中性背景。场景保留无人底图、三分之四纵深、可行动区域、光源方向、环境反射及接触阴影，不把人物参考背景要求搬进真实环境。
- **变体与比例**：换装、湿衣、损伤等反复出现的状态独立建图，沿用主脸与原有细节合成方法；同框比例参考、非人设计、头饰/后脑局部研究、多角度研究和试演能力全部保留。特殊参考单独标明职责，不混入默认参考图。

### 六行结构自动校验

交付角色六行组板前运行以下 Python 标准库检查（`text` 为即将交付的完整代码块内容），报告各失败项并修复后再交付；用户指定的其他格式不套此检查。六行顺序：总述→姓名/年龄/性别→左侧正面面部→右侧无头三视图→背景/一致性/无文字→灯光/质感；自动换行不算新行。

```python
def validate_character_sheet(text):
    import re
    lines = [line.strip() for line in text.splitlines() if line.strip()]
    if len(lines) != 6:
        return [f"六行结构失败：实际{len(lines)}行"]
    checks = [
        ("总述分区", all(x in lines[0] for x in ("角色资产参考图", "左侧", "面部特写", "右侧", "无头"))),
        ("独立身份行", bool(re.search(r"\d+岁.*(?:女性|男性|女|男)", lines[1])) and not lines[1].startswith(("左侧", "右侧"))),
        ("正面面部", lines[2].startswith("左侧：") and "正面面部特写" in lines[2]),
        ("无头三视图", lines[3].startswith("右侧：") and all(x in lines[3] for x in ("无头", "正面", "侧面", "背面"))),
        ("背景与同一身份", "背景" in lines[4] and "同一" in lines[4]),
        ("无文字约束", all(x in lines[4] for x in ("不出现", "文字", "字母", "数字", "姓名", "视图标签", "尺寸标注", "签名", "水印"))),
        ("灯光与质感", "光" in lines[5] and "质感" in lines[5]),
    ]
    return [name for name, ok in checks if not ok]
```

## 3. 视频参考：同一身份与区域职责

### 正面身份主参考

左侧正面定稿作为身份主参考，固定五官比例、发型与辨识标记。其他面部角度仅在任务需要时单独补充，核对为同一人后用于说明立体结构；角度辅助图不能重新定义身份，发现偏差先修复。

右侧三个无头身体视图负责体型、服装、道具及背部结构；局部图只补充对应部位的材质与连接细节，不提供额外面部身份或新增道具。多人场景为每名角色各自建立这套映射，不把同一角色的多个角度算成多个人。

通过视觉检查的组合图可供审阅归档及人物身份、体型和服装参考；只传递指明的属性，不把参考图当作视频起点。头饰或后脑确需局部图时可单独补充并限定用途。仅对旧图、用户要求的特殊带头设定图或生成失败结果另存修复版，原图保留。不以模糊、涂抹或无五官头部代替裁切。

可复制修复指令（仅在需要时使用，是图像编辑/裁切任务，不是视频剧情）：

```text
基于现有角色资产图另存修复版，保留左侧已定稿正面面部特写。
仅裁切右侧正面、侧面、背面的身体视图，使头部全部位于取景范围外，保留颈根以下的完整服装、手脚与鞋底，不表现身体断面。
保持同一角色的体型、服装颜色、道具数量与连接关系，三个身体视图比例一致，保留已有关键细节局部图，保持干净浅色背景和清楚的左右分区，不重绘左侧面部。
原图另存归档；修复图只用于人物参考，不负责视频镜头构图。
```

若原图缺少所需角度或关键细节，裁切不能补出缺失内容；说明缺项并按需单独补生成，不将局部放大图算作身体视图。素材未生成或无法查看时标记“待生成后验收”；右侧身体仍有头部，即使只见后脑也标记“待修复”，说明所在区域。

### 参考角色声明

实际槽位以用户上传后的编号为准。可以上传一张整理后的组合图，也可分别上传面部与无头身体参考；不要虚构已上传的素材。

```text
[人物参考]
@Image 1 的正面面部特写属于沈砚，作为身份主参考，固定五官比例、发型与辨识标记。
@Image 2 定义沈砚的体型、服装和道具结构，包含无头的正面、侧面、背面身体视图；若附有局部图，仅用于对应部位的材质与连接细节。
两份素材均属于同一个沈砚；本场景只有一位沈砚。
仅采用指定人物特征，排除参考图的浅色背景、边框、多视图排版及裁切构图；成片中的人物身体完整、头部自然连接。
```

以上人物名与槽位是格式示例，交付时必须替换成真实映射。若只上传一张组合图，合并成一个槽位并说明左侧正面特写与右侧身体区的职责。镜头开场的站位与构图由剧本和导演演出描述决定，不需另准备开头构图图像。

## 4. 表情参考：仅交单独生成备注

默认附在提示词代码块之外，清楚标注“用户另行生成，尚未附加”。备注包含：

- **来源**：使用已确认的正面主参考进行编辑或引用，不重新文生一个相似人物。
- **表情目标**：只选择剧情需要的一种明显表情，例如露齿笑或愤怒；说明眉眼、嘴角、张口幅度以及是否需要展示牙齿。
- **保留项**：五官比例、发际线、疤痕/痣位置、肤色、发型，以及主参考的角度、背景和光照。
- **职责**：仅补充表情肌肉变化、嘴形和牙齿结构，不提供第二套身份、服装或场景。
- **验收**：与中性主参考对照，确认是同一人；生成偏差大时返修，不将其当作身份变体。

交付备注示例：

> 表情参考备注（请另行生成）：基于定稿正面特写制作一张露齿笑特写，保持同一人的五官比例、发型、辨识标记、角度与光照。只改变笑肌、嘴角及张口程度，清楚展示牙齿结构。此图仅用于表情动态参考，身份仍以中性主参考为准。生成后再按实际上传槽位加入视频提示词；当前不引用此图。

同一身份可以有已核对的正面、3/4 侧面与单独表情参考；角度或表情辅助图不能重新定义身份。非人角色的张嘴/闭嘴参考能力仍保留，需要时同样作为单独备注交付，不擅自塞入人类资产模板。

## 5. 视频提示词的衔接标准

1. 生成说明统一标为 Seedance 2.5。生成模式、时长、画幅、分辨率在界面/API 设置；提示词中的文字不能代替参数设置，模式自动锁定的参数遵守该模式要求。
2. 已确认的参数直接继承。规格、枚举依照 [2.5 指南](higgsfield-seedance-2-5.md) 和原实时核验要求，不能把“建议设置”写成“已在线验证”。
3. 将身份描述与动作分开。先声明参考角色、保留程度和排除项；阶段动作使用人物名，首次出现可附一个辨识标记，不反复重述整张脸。
4. 内容覆盖主体、场景、动作、摄影机、视觉风格；有声音时单独编写音频。每阶段一个主要状态变化，明确起始状态、动作和结束状态，下一阶段延续。
5. 参考素材按镜头筛选；不引用缺席角色或尚未生成的表情图。多视图属于同一主体，角色数量、道具归属、方向与损伤状态持续一致。
6. 写可见表演和物理结果。人物设定板的背景、排版、裁切不能带入场景；视频中的身体必须完整连接。默认无字幕、无水印、不加未要求旁白。
7. 动作戏继续执行原三强度/两速度、因果交锋和连续性标准；纯表演任务不强制三套动作版本。短镜头与制作分块沿用各自的字数/结构规则。
8. 交付完整可复制代码块，生成说明及表情备注置于块外。实际视频提示词按原脚本帮助使用 seedance_lint.py 的 --preflight 与 --model seedance_2_5 检查；只陈述实际运行结果，静态 lint 不能证明视觉锁脸成功。

## 6. 交付前逐项验收

- [ ] 默认图左侧为正面面部特写；右侧为无头部的正面、侧面、背面三个完整身体服装视图，左右分区清楚；按需补充的关键细节局部图与主视图一致，不替代身体视图。
- [ ] 左侧五官、发型、辨识标记符合角色定稿；右侧无头部、后脑、耳朵或下巴残留，服装、手脚与鞋底完整，不表现身体断面。
- [ ] 若只编写提示词或无法查看图片，视觉检查明确标为“待生成后验收”，没有虚报通过。
- [ ] 服装、左右佩戴关系、道具数量与体型一致；案例人物特征已替换为当前角色，没有套用阿德莱德的身份与外观。
- [ ] 交付一段完整六行提示词，结构与用户范本一致，不额外强调左侧特写数量；使用干净浅色背景及灯光质感描述，没有默认叠加长摄影参数、肤质清单或负面词库。
- [ ] 资产图提示词已明确排除文字、字母、数字、姓名、视图标签、尺寸标注、签名和水印；实际图片生成后再检查有无误生文字，用户明确指定的文字仅在指定范围保留。
- [ ] 需要增强真实感时只补少量具体细节；无强行做旧、磨皮或用噪点、锐化、粗大毛孔制造纹理。
- [ ] 已定稿面部不因组板或右侧修复被重新生成；新角度与局部修复结果重新验收身份。
- [ ] 未把“8k”当作实际分辨率保证，也未把参考背景与灯光强加给真实视频场景。
- [ ] 表情参考仅备注、由用户另行生成；未混入默认设定板，未编造上传槽位。
- [ ] 多视图明确属于同一角色；参考职责、保留程度及背景/排版排除项齐全。
- [ ] 视频为 Seedance 2.5 `omni_reference`；人物、道具、场景、动作及声音参考各有明确职责和真实绑定，参数与提示词正文分开。
- [ ] 阶段结束状态、动作因果、运镜和声音符合任务；已执行的检查与待验证项如实区分。

## 7. 生物/道具资产的多视图与结构

`B`（生物/植物）与 `P`（道具）基础资产和角色一样是身份一致性参考，不能只交一张动态或单一角度图。默认采用中性展示姿态与多视图组板；以主体展示为主，可用干净中性的展示背景（中性灰阶或简洁棚拍展示环境），不强制透明或抠图底；不带具体剧情场景、环境道具、影子、人物或战斗动态。样本阶段先给主视图 + 一个补充角度的最小组板验证风格，确认后再交多视图完整资产。

### 生物/植物 `B`

- **姿态中性。**自然舒展、水平陈列或自然站立，展示完整体长与解剖比例；不摆战斗、攻击、盘绕缠斗、扑咬或张口嘶吼的动态姿态——动态留给视频提示词或状态衍生图。
- **多视图。**默认：侧面全身主视图（看清整体比例与轮廓）+ 头部特写（结构、眼、口鼻/喙）；按辨识需要补背面或俯视展示斑纹分布。四足或有肢体的生物补正面站姿；蛇形/长体生物侧面主视图水平陈列看清全长。
- **关键结构局部 1–3 处。**选最影响辨识与制作一致性的部位：鳞片/皮肤/毛发材质近观、背腹纹路与颜色分布、口部或牙/喙、爪/蹄/鳍/尾端。沿用主视图颜色、材质与比例，不新增主视图没有的特征。
- **展示项。**完整解剖比例（头/颈/躯干/四肢或体节/尾）、材质与反光、颜色与斑纹分布、关键辨识特征；植物则为主干/枝叶/花果结构与材质。
- **可复制格式（示例，替换尖括号）：**

```text
一张生物资产参考图，主体展示为主、干净中性展示背景、无具体剧情场景，
<生物名称>，<体长/体型比例>，中性展示姿态，自然舒展不做战斗或攻击动作，
主视图：侧面全身，看清完整体长、体节与轮廓比例，<整体颜色与斑纹分布>，
补充视图：<头部特写：结构、眼、口鼻/喙>；<背面或俯视：斑纹/背脊分布>，
关键结构局部：<鳞片/皮肤材质近观>、<腹部或颈部颜色>、<口部或爪/尾结构>，沿用主视图颜色材质比例，
干净中性展示背景（中性灰阶或简洁棚拍，不带具体剧情场景），画面不出现任何文字、字母、数字、标签、尺寸标注、签名或水印，
均匀工作室光线，清晰展示<材质与结构>，写实电影质感，高清细节
```

### 道具 `P`

- **多角度。**主视图（最能表达形状与用途的角度）+ 至少一个补充角度（侧/背/俯之一）；有开合、折叠或组合结构的道具补一个展开或关键机构角度。
- **结构局部 1–3 处。**部件连接、握持/使用部位、材质接缝或纹样；写明比例、数量、左右归属与连接关系。
- **展示项。**整体形状与比例、部件构成与连接、材质与反光、关键辨识细节；使用状态（点亮/开合/装填等）属衍生图，基础图用中性默认状态。
- **可复制格式（示例，替换尖括号）：**

```text
一张道具资产参考图，主体展示为主、干净中性展示背景、无具体剧情场景，
<道具名称>，<整体形状与比例>，中性默认状态，
主视图：<最能表达用途的角度>，看清整体结构与比例，
补充视图：<侧/背/俯之一>；<如有开合或组合结构，补展开或机构角度>，
结构局部：<部件连接/握持部位/材质接缝>，写明比例、数量与连接关系，沿用主视图材质颜色，
干净中性展示背景（中性灰阶或简洁棚拍，不带具体剧情场景），画面不出现任何文字、字母、数字、标签、尺寸标注、签名或水印，
均匀工作室光线，清晰展示<材质与结构>，写实质感，高清细节
```

### 交付前逐项验收（B/P）

- [ ] 生物为中性展示姿态，没有战斗/攻击/盘绕缠斗/张口的动态；道具为中性默认状态，使用状态留给衍生图。
- [ ] 提供主视图 + 补充视图 + 1–3 处关键结构局部，不是单一角度或动态图；各视图属于同一主体，颜色、材质、比例、斑纹/部件一致。
- [ ] 以主体展示为主，干净中性展示背景，无具体剧情场景、环境道具、影子、人物或叙事动作。
- [ ] 展示了完整解剖/结构比例、材质与颜色分布、关键辨识特征；无主视图之外的臆造特征。
- [ ] 提示词排除文字、标签、尺寸标注、签名与水印；未生成图片时视觉检查标为待验收。
