# 角色资产与 Seedance 2.5 交付规范

参考 [sd-asset-engine](https://github.com/lixiaoxiao9888-create/manju-laoli-skill/tree/main/sd-asset-engine) 的[人物立绘模板](https://github.com/lixiaoxiao9888-create/manju-laoli-skill/blob/main/sd-asset-engine/references/character-portrait-templates.md)（读取时文件 SHA：`807888b3dc306b678b9cd3ff980a5edd21746129`），吸收四格、单一面部锚点、完整全身与换装方法。沿用本地中文调用名、六行图片正文和项目登记，不引入外部总控、图N体系或场景九宫格。适用于角色资产提示词、参考图整理及后续视频提示词，与根 SKILL.md 一起执行；原模块的其他方法和能力保留，用户明确的新要求优先。

写样本和完整稿前先读取 [项目资产总表](asset-registry.md)，并按 [资产设计依据](asset-design-basis.md) 执行[剧本到设计的最小闭环](asset-design-basis.md#剧本到设计的最小闭环)：先分明确设定、推导与待核，再把世界与时代、身份处境、经历、服装来源、性格关系及剧情用途转成可见造型、功能结构和视图落点；每项显著选择有依据或候选说明。六行正文只写能被看见的设计，不把抽象性格词当作已经设计完毕。资产标题在六行提示词之外列出总表中的中文名称、唯一调用名和实际文件/待生成状态；六行内姓名沿用总表。只交文字提示词时记为 `planned`，后续视频阶段读取同一条目。角色设定在现有项目/总表中记清年龄、体型、面部锚点、发型、完整服装、穿戴配饰、画风及服装延续关系；剧本明确项直接继承，推导项标为候选，不把设计表或流程备注复制成图上文字。

基础资产请求或完整制作的基础资产阶段使用本模板，共享角色先定稿；默认不同时附场景与视频提示词。每次先执行 [样本确认流程](sample-approval.md)：默认选一个核心角色做完整六行组板样本，用户明确仅定脸或半身时采用局部样本，确认身份、造型、质感和光色后输出当前阶段完整六行资产提示词。验证多视图排版时用一个角色的最小完整组板作样本；已确认且未变的角色和提示词直接复用，新增、改写和补角度只对变化部分给样本；已明确授权且不改变确认设计的局部修词按样本流程的授权例外直接修复并复查。文字设定确认并交付提示词后即可推进依赖阶段，共用总表与场景文字布局，不要求回传全部资产图；实际生成图的身份、比例与结构按需核对，未看图不得声称视觉通过。只有关键设计未定或已知冲突未解时下游相关部分才作条件性预稿；明确要求快速预览时可联合交付预稿，不代替实图验收。

## 1. 默认交付与模型

- 视频默认 Seedance 2.5，用户换模型时调用对应模块。图片工具继承用户/项目已确认设置，不把历史项目的 image2.5 名称当通用默认；未确认平台能力时只给可复制提示词。
- 默认交付一张四格角色资产参考图：全图共 4 格，横向依次为正面面部特写、正面全身、90°侧面全身、背面全身。仅面部特写格有头部和清晰五官；三个全身格均为无头全身，画面上缘在颈部，头部不入画，颈部至鞋全部入画。同一人、同一服装、同一站姿，不增加独立大图或局部特写格。
- 图片正文仍为一段完整可复制的精简六行提示词，明确四格总数。图底细节条不计入四格，固定含声纹波形，每个角色都在波形旁加一行音色标签（见下文换装与声音交接）。除这行音色标签外全图无字。不默认附长负面词库或摄影参数清单；8K、高清细节等质量词可按需保留；六行中使用与内容题材及所选视觉风格一致的媒介锚点。
- 表情参考由用户另行生成，默认只附一句备注，不自动生成、不混入资产参考图。面部特写格的中性正面特写用于身份参考。
- 是什么风格就用什么风格：直接继承用户要求和项目已有风格，不默认真人、动漫或 CG，不因出图偏差重新选择风格。只有风格尚未确定时，才根据内容题材、叙事气质确定媒介。只有选定真人实拍方向时，才以“真人演员服装定妆照”锚定人类角色，多视图作为照片组板排版。以下版式面向人类角色；动漫、插画、非人角色、特定头饰/发型研究及用户指定版式调用原模块按任务调整。

## 2. 简洁提示词标准

按[造型辨识度与身材设计](asset-design-basis.md#造型辨识度与身材设计)先定身体/主体体量、大轮廓和主记忆点，再按[资产图先定画风与细节](higgsfield-style.md#资产图先定画风与细节)写画法、配色和结构；本模板的 C/B/P 是后续视频外观的主要输入，不是只供点名的身份图。中性站姿不削弱造型；沿既有版式表达，不新增色卡、组板或审批。

### 沿用目标风格，避免提示词污染

1. **继承优先**：用户明确指定 → 项目已确认的视觉风格/参考；已有风格直接沿用，不重新推荐或审批。仅缺少风格时，才根据内容题材、叙事气质与用途推荐适配媒介。题材不等于媒介：古装、奇幻、科幻、现实题材都可以用真人、二维或三维表现，不能仅凭“人类角色”“写实”“电影质感”自动判为真人。
2. **方向不明确时**：在当前角色样本外简述推荐媒介及题材依据，随原有样本一起确认；若存在明显冲突或无法合理判断，只问一个关键风格问题。不增加独立审批，不把候选风格写成已确认，不擅自改变已确认媒介。
3. **先选媒介，再选材质与光影**：以下是条件分支，不是题材到风格的一对一映射。

| 已选表现方向 | 角色资产媒介锚点 | 材质、光影与细节侧重 |
|---|---|---|
| 真人实拍（适合当前内容的现实、历史或幻想影视等） | 真人演员服装定妆照 | 自然肤质、真实服装材料与物理受光；按项目光色选择摄影方案，可用下节降低意外 CG 感的方法 |
| 二维动画、漫画、赛璐璐 | 二维动画角色设定图或漫画角色设定图 | 线条、色块、赛璐璐明暗、形体与比例统一；不强塞毛孔、镜头参数或胶片颗粒 |
| 水彩、水墨、绘本等插画 | 对应画材的角色设定图 | 笔触、纸张、晕染与色彩层次；不强制摄影布景、窗光或接触阴影 |
| 三维动画、游戏 CG（含写实三维） | 对应项目风格的三维角色设定图 | 按风格控制建模形体、表面粗糙度、材质反射与渲染光照；CG 本身是目标时不将“3D 渲染”列为排除项 |
| 定格、黏土、剪纸或混合媒介 | 指定工艺的角色设定图 | 工艺材料、手作痕迹及对应照明；混合媒介按已确认区域职责分配，不任意拼接 |

同批角色继承同一媒介与光色规则；有意混合须有内容依据并在样本中说明。降低 CG 感只针对意外偏离目标风格的问题，不是所有题材的共同目标。真人出现 CG 感时，优先排查正向提示词中的跨媒介污染，保持真人风格、身份与服装不变，删除或替换污染措辞，而不是换风格或添加负面提示词。

### 固定结构与填写规则

按"总述与四格→姓名与年龄性别→面部特写→三格全身与服装→背景、一致性与图底条→灯光与质感"写六行，保持接近下方范本的长度。

| 部分 | 要写的信息 |
|---|---|
| 总述 | 已选媒介与风格、角色资产参考图、全图共 4 格及四个视角 |
| 身份 | 角色姓名、年龄、性别及适用身份信息；身份写到职业、阶层与当下处境，而不是“平民”“贵族”这类泛称 |
| 面部特写 | 全图唯一清晰面部；脸型、眉眼、鼻唇、肤色、发型与辨识标记，头部占该格高度至少70% |
| 三格全身 | 依据卡里的劳损体态、旧伤与剧情要用的服装部件（左右与数量）；正面、90°侧面、背面；无头全身，画面上缘在颈部，头部不入画，颈部至鞋全部入画；身高、体型比例、完整服装、鞋袜与穿戴配饰 |
| 背景与一致性 | 按服装明度选的中性背景（深衣浅底、浅衣中灰底，明度差约30%），同一身份、体型与服装；图底声纹波形＋音色标签（所有角色，和对白无关），其余文字全部排除 |
| 灯光与质感 | 写出跨资产共用的具体画法、配色倾向与材质表现，再说明本图如何让固有色和结构可读；不只写“与项目风格一致”，不把剧情夜色烘进基础图 |

- **总述先锁头部数量**：复制正文第一行必须说明整张图只有一个头部，仅在第一格面部特写出现；后三个视图名称分别附“颈部裁切”，不能只在后文补去头要求。这里锁的是头部数量，不仅是清晰脸数量；侧面头部、后脑、模糊脸也不能出现在后三格。颈部裁切是摄影取景，身体正常完整，头部位于画框外；不画断颈、伤口或无头人偶。头发、五官和下颌描写放面部格，后三格仅保留服装领口等实际入画内容。此规则用于默认角色资产板，不限制视频人物头部。
- **四格及单一面部锚点**：只有面部特写格出现头部和可辨识五官。三个全身格去头：画面上缘在颈部，保留颈部、肩线与完整身体，头部不入画，这样视频模型只能从面部特写格读取身份。去头用取景实现，不用马赛克、打码或像素块。无头身体占各格高度约85%–95%，鞋袜直接画在全身格内。
- **身材先于服装，中性不等于平庸**：按[身材与辨识度详规](asset-design-basis.md#造型辨识度与身材设计)写骨架体量、肩胯/躯腿比例、必要肌肉/脂肪分布与稳定体态，不停在“身高＋匀称”。服装用合体度、活动余量和主要形体体现这个身体；标志造型写清位置、尺度与连接。全身格仍无头，三个观察角度保持同一身体、中性站姿与空手，儿童及非人设计沿已确认年龄、结构与媒介调整。
- **人物与独立道具分离**：只画人物及穿戴配饰；手持物、独立兵器、书本、器械等由P类资产提供。可摘配饰的离身状态另行登记，避免穿戴与手持双现。职业身份用具体服装形制、材质、标志配色和已有体态表达，不只写“制服”。
- **服装来自世界与处境**：材料、工艺、修补与磨耗按依据卡的时代、地区、阶层和经济来源决定；同一势力共用材料体系。用“谁做的、怎么得来的、穿了多久”推出可见痕迹，例如反复手缝的肘部补丁、买不起整块皮而拼接的披肩、制式配发的统一磨损，不写放在任何故事里都成立的通用古装/通用礼服。
- **服装覆盖完整**：交代服装层次、主辅色、面料、纹样、领袖/衣襟/扣具结构、使用状态、鞋袜与配饰；不对称结构按角色自身左右继承，侧面选展示关键结构的一侧并写明。细节直接并入对应格描述，不新增手、鞋或材质特写格。
- 五官、肤色、发型、辨识标记及服装按实际角色替换。阿德莱德的皇室身份、金发、淡痣及酒红连衣裙只属于该案例，不设为其他角色默认。
- 在对应区域写与已选媒介相容的可见细节，不能只堆“哑光、细腻、高清”。真人实拍可用“部位或材料＋可见差异＋程度或分布＋受光表现”，皮肤保留自然纹理与轻微不对称；二维侧重线条与色块，插画侧重画材，三维按项目风格控制材质。织物、皮革、金属的细节密度与使用状态匹配；新衣不强行做旧，不以噪点、锐化、粗大毛孔模拟皮肤。
- 仅在选定真人实拍方向且适配项目时，可用简短的“中画幅摄影、85mm 镜头观感、自然色彩”建立摄影约束，并非所有题材的必填参数；保持面部和各身体视图细节可辨；轻微胶片颗粒仅作整体摄影风格，不代替毛孔或织纹，也不遮盖细节。光圈、ISO、白平衡等仅按需补，不堆长参数清单。摄影术语不代表真实拍摄、API 设置或输出分辨率；不再默认追加“8k、高清细节”。用户已指定其他摄影方案时沿用。
- **背景按服装明度选，主体必须从背景里跳出来（强制）。**先看依据卡里服装的主色明度，再选中性无彩背景，两者至少差约 30% 明度：服装整体偏深或偏灰（灰褐、炭灰、深棕、煤黑、暗铁）→ 明亮的浅暖白灰背景（约 #E8E6E2），不用中灰或冷灰；服装整体偏浅（象牙白、香槟、浅灰、白纱）→ 中灰背景（约 #8C8C8C）；服装深浅混合 → 按占画面面积最大的服装层判断。背景保持无彩或极低饱和，不取服装同色相，也不用纯白或纯黑（高对比边缘易产生光晕与轮廓抖动）。轮廓再靠光分离：侧后方一道弱轮廓光或背景比主体略亮的柔光，让肩线、披衣边缘和鞋面与背景分开；不靠加饱和度或改服装颜色解决。交付前自查：把四格缩小到缩略图看，人物外轮廓是否一眼可辨。
- 背景具体表现随媒介：真人实拍可用摄影布景、轻微明暗渐变与脚下短而柔的接触阴影，二维/插画可用平色或画材底，三维按项目展示光照处理。画面整洁指没有杂物，不等于所有媒介都必须纯平或无阴影。采用窗光时，它只是光源，不要求画出窗户或房间。图底波形是视觉标记，不是音频输入；音色标签是全图唯一允许的文字，其余文字、字母、数字、姓名、视图标签、尺寸标注、签名与水印全部排除。其他资产仍执行各自无文字规范；用户另有版式要求时优先执行。

### 真人实拍分支：降低意外 CG 感的写法

仅适用于已选真人实拍方向的人类角色新建或本次修改提示词，不是全局默认。“写实三维”仍属于三维分支；动漫、插画、明确要求的 CG 风格及非人设计不强行转成真人摄影，已确认未变内容不自动重写。以下布光与摄影方案按题材及项目风格取舍，不要求一律窗光、85mm 或胶片颗粒。

| 容易引向渲染的写法 | 正向替换方向（按角色设定选择，不全量堆叠） |
|---|---|
| 只写“角色资产参考图、电影质感、高清” | 首句先写“真人演员的服装定妆照”，再交代多视图排版；三个全身格保持同一演员的体型与服装，无头取景，头部不入画 |
| 无瑕皮肤、下颌线由整齐短须勾勒 | 鼻翼细小毛孔、面颊轻微色泽差异、左右脸略不对称；有胡须者可写长短不一，少量灰白仅在年龄与设定适合时加入 |
| 只有“哑光布料、皮革” | 布料可见织纹、接缝受力褶皱；旧衣袖口少量起毛，皮革在关节处弯折起皱；旧披风毛面略蓬乱、靴缘少量干泥仅用于已确认的常年使用状态 |
| 规整铁片、窄幅冷亮反射 | 旧铁甲可写“做旧暗铁，表面氧化与细划痕使反光分散，以漫反射为主，仅边缘微弱反光”；手工铁片大小角度可略有差异，但片数、搭接和固定关系在各视图一致 |
| 中性工作室主光、弱补光保留体积、电影级边缘光 | 柔和漫射窗光从一侧照入，自然衰减；鼻翼、衣褶保留柔和明暗，鞋底与布景地面有接触阴影，浅色背景有轻微渐变 |

- **不完美有边界**：不改变已定稿五官比例、痣疤位置或服装结构；磨损属于该角色的材料/使用状态，不等于统一加脏、加伤、衰老。抛光金属保留其真实反射，不把所有金属改为暗铁；剧情新增泥污、破损仍走状态衍生图。
- **清理污染，不用负面提示词补救**：即使工具支持独立负面栏，也不为纠正真人的 CG 感添加风格负面词，不生成“不要 CG”或同义排除词库。回到正向正文，删除与目标风格冲突的渲染展示措辞及空泛质量词，替换成适配原定风格的媒介、材料与受光事实。四格、单一清晰脸、全身格去头与图面文字限制属于输出规格，仍保留，不等于风格补救负面词。
- **清理顺序**：先读回原定风格，再通读首句、角色形容、材料、布光、质量后缀及附加模板，找出混入的渲染展示语义；替换冲突描述（8K、高清细节等质量词可保留），最后核对正文是否仍有相反线索。不保留污染词再加一句“真人摄影”试图抵消，也不机械增加镜头参数或颗粒。上表是组合语义风险示例，不是禁词表；工作室灯光、金属反射或多视图本身不必然导致 CG，按上下文判断。保持风格、身份与版式不变，用同一角色小样验证；未见实图只能报告文字调整，不能声称已消除 CG 感。

### 定稿、修复与其他资产

- **制作方式**：本批次样本确认后交付完整参考图提示词。补角度、修改或修复先给本次样本；生成时可一次生成后验收，已有定稿正面特写直接沿用。组板不对已通过的面部做生成式重绘，缩放时减少重采样。
- **单独大头照**：仅需主脸或先定稿时换成"单人正面面部特写"，保留身份、肩部衣领及肤质光线描述，删其他视图和画外的脚下接触阴影描述，可独立生成。
- **视觉修复**：全身格出现头部或第二张脸时，只编辑该格，把头部移出画面或擦除，保留颈部与完整身体；不重绘定稿面部特写。皮肤过平时核对脸部画幅占比、原图分辨率、补光及工具美颜设置，再选局部修复。生成式局部修复需重验身份与肤质。
- **道具与场景**：道具保留多角度、必要底部视图、真实尺寸、结构接缝、材质厚度、重力支撑与使用状态，独立资产用中性背景。场景按 [纯环境规则](spatial-layout.md#场景资产内容边界) 保留无角色/生物/道具的空场底图、必要固定结构、材质与光色；用户要求简洁时省略方位与构图细节。
- **变体与比例**：换装、湿衣、损伤等反复状态独立建图，沿用主脸与原细节合成方法；同框比例参考、非人设计、头饰研究、多角度研究和试演能力保留，特殊参考单独标明职责。

### 换装与声音交接边界

**角色资产固定交付：图底声纹波形＋音色标签＋图外完整音色描述，和剧本、当前片段是否有对白无关。**只有用户明确要求删除或明确要求全图无字等对应例外时，才省略指定项目，并在块外记录例外范围；不能自行把未写台词、沉默镜头或外观样例当作省略依据。没有既有音色时给出候选，随同一资产样本确认，不虚构真实音频。图底波形是视觉标记，不是音频输入。

- **图上标签：**一行英文，`Voice: ` 开头，紧接性别词 `female,` 或 `male,`，再写音高/音质/共鸣/口音/节奏，全行不超过8个词，例如 `Voice: male, low husky baritone, slow drawl`。性别必须明写，不靠 mezzo、bass 等音域词暗示。不写 young、old、teen 等年龄词，年龄感用音色词表达。图像模型对短英文的文字渲染较稳定；用户指定中文时改为以“女声，”或“男声，”开头、不超过12字的中文一行。标签不写角色姓名。非人角色按已确认设定写性别，未设定性别时写 `creature,`。
- **完整描述（图外，登记用）：**同时在六行之外交一段完整描述，登记到项目/总表，供视频[角色]等状态块引用：

```text
音色：<女声/男声，中文一句，音高/音质/共鸣/口音/习惯语速>
Voice Description: <A female/male voice …, English, 1–2 sentences>
```

图上标签是完整描述的缩写，两者内容一致。修改外观、身材、版式、画风、换装或状态时，先读取并原样保留既有声音设定；逐条核第五行的波形与实际标签内容、图外完整描述，不以出现“声纹”二字当作交付齐全。明确的声音修改按授权范围处理。生成后核对标签文字是否拼写正确，错字按局部修复处理。音色登记到项目/总表的角色条目，换装和状态变体沿用同一标签与描述。视频中可在[角色]等状态块为说话角色引用这条描述；当下语气、语速、气息仍写在视频[声音]的计时发声行，固定音色不替代当下表演。

- **连近义词都不换：**音色标签和完整描述每次都从总表原样复制，不在镜头之间润色。把 warm 换成 rich、gravelly 换成 raspy 都会让生成的声音变样。需要改音色时先改总表条目并升版本，再统一替换所有引用。
- **2.5 与 2.0 写法不同：**Seedance 2.5 复用同一张角色图时，图同时承载外貌与音色，音色描述写在该角色的[角色]等状态块句里，不再在发声处重复；Seedance 2.0 或没有复用角色图的镜头，每次该角色说话都在发声处附同一句音色描述。两种情况都从总表原样复制。2.5 是每条提示词写一次还是整个项目写一次，上游也未测定；本工作室默认每条提示词在[角色]等状态块写一次。

`[voice rules adopted from OSideMedia/higgsfield-ai-prompt-skill v3.35.0 / v3.38.0, FIELD 级经验，未在本项目对照测试]`

实际音频参考或平台ID按真实用途单独登记；有真实音频参考时以音频为准，文字描述不与之冲突。

换装或状态变体另存版本，保持已定稿五官、肤色、年龄、体型与发色，只改指定服装、鞋袜、配饰或状态。默认继承同一四格布局；已有实图用局部编辑并保留定稿面部，未有实图时只交文字修改方案。新旧版本与变更点记入现有总表，不新建外部接线单体系。

## 4. 表情参考：仅交单独生成备注

默认附在提示词代码块之外，标注"用户另行生成，尚未附加"。备注包含：

- **来源**：用已确认的正面主参考编辑或引用，不重新文生相似人物。
- **表情目标**：只选剧情需要的一种明显表情（如露齿笑或愤怒），说明眉眼、嘴角、张口幅度及是否展示牙齿。
- **保留项**：五官比例、发际线、疤痕/痣位置、肤色、发型，及主参考的角度、背景和光照。
- **职责**：只补表情肌肉变化、嘴形和牙齿结构，不提供第二套身份、服装或场景。
- **验收**：与中性主参考对照确认同一人，偏差大时返修。

> 表情参考备注（请另行生成）：基于定稿正面特写制作一张露齿笑特写，保持同一人的五官比例、发型、辨识标记、角度与光照。只改变笑肌、嘴角及张口程度，清楚展示牙齿结构。此图仅用于表情动态参考，身份仍以中性主参考为准。生成后再按实际上传槽位加入视频提示词；当前不引用此图。

## 5. 视频提示词的衔接标准

1. 视频默认 Seedance 2.5，用户/项目已确认其他模型时继承并读取其资料。模式、时长、画幅、分辨率在界面/API 设置，提示词文字不代替参数。
2. 已确认参数直接继承。规格、枚举依对应模型指南，不把“建议设置”写成“已在线验证”。
3. 开头 `[参考资产]` 集中本条标签，[角色]等状态块按名称写必要状态/职责，不重复五官、发型、服装、材质或辨识标记；背景/组板干扰在块外安排裁切或清理。无独立资产的明确纯文字路径才补必要主体描述。
4. 完整视频采用Higgsfield 块结构（[参考资产]→[角色]…[生成目标]→[具体情节]→[视觉风格]→[镜头]→[声音]→[保持一致]）；[具体情节] 每段写画面、运镜、动作、表情与 → 结束，段头写景别、视场角和运镜；音效写在当段 `声音：` 行，对白写在 `[声音]` 的计时对白行。每段一个主要变化。
5. 参考素材按镜头筛选，不引用缺席角色或未生成的表情图。多视图属于同一主体，角色数量、道具归属、方向与损伤状态持续一致。
6. 写可见表演和物理结果。人物设定板的背景、排版、裁切不带入场景，视频中身体完整连接。默认无字幕、无水印、无未要求旁白。
7. 动作戏执行三强度/两速度、因果交锋和连续性标准；纯表演任务不强制三套动作版本。
8. 交付完整可复制代码块，生成说明及表情备注置于块外。每次修改后执行 [修改后标准复查闭环](production-checks.md#修改后标准复查闭环)，读回最终完整条目并核受影响依赖；视频块结构用 `director_contract_lint.py`，模型/引用用 `seedance_lint.py --preflight` 及实际模型参数检查，只陈述实际运行结果。

## 6. 交付前逐项验收

- [ ] 全图只有四格：一张清晰面部特写、正面/90°侧面/背面三个无头全身；不附加重复视角或局部特写格。
- [ ] 只有面部格出现头部和清晰五官；三个全身格无头，画面上缘在颈部，颈部至鞋全部入画，体型比例符合年龄与风格。
- [ ] 只编写提示词或无法查看图片时，视觉检查标"待生成后验收"，如实不虚报。
- [ ] 服装、左右佩戴关系、穿戴配饰数量与体型一致，双手空着；案例特征已替换为当前角色。
- [ ] 背景与服装主色明度差足够、无彩且不取服装同色相，缩略图下人物外轮廓一眼可辨；有弱轮廓光或背景亮度分离。
- [ ] 按[辨识度复查](asset-design-basis.md#辨识度复查)核角色身体比例、服装主轮廓和主记忆点实际进入正文，与同场角色有可见对照；不以换色或微小饰品代替形体。图未生成则不称缩略图/剪影已验证。
- [ ] 按[设计链与功能推演](asset-design-basis.md#从依据到可见设计)核对性格/身份如何体现为有依据的造型取舍，剧情特征实际进入对应视图，不能只出现在块外说明；基准图不提前出现后续破损，新增脸型/服装选择仍标为候选直到确认。
- [ ] 依据卡各项有来源或“推导/不适用”标注；剧本要用的可见特征逐条在正文或状态图计划中落点；正文无外部片名锚定。
- [ ] 六行提示词结构与范本一致；媒介按用户指定、项目风格或内容题材推荐选定，首句与材质/光影同属该媒介，无默认真人锚点或跨媒介堆词。候选媒介随样本说明，未冒充已确认。
- [ ] 每个角色资产图底均有声纹波形＋一行音色标签，图外有完整音色描述；不按对白与否省略，只有用户明确例外才按范围处理，标签以 female/male 开头、≤8个英文词、无姓名、无年龄词、与登记的完整描述一致，实图拼写已核对；除标签外全图无字；换装沿用身份与版式。
- [ ] 按[资产图先定画风与细节](higgsfield-style.md#资产图先定画风与细节)核首句画法、服装部位配色/材料与末行质感，三者属于同一项目；缩小后轮廓和色块可辨，关键细节在指定视图可读，不能只靠视频短句补设计。
- [ ] 面部与材料细节符合所选媒介，不仅写“哑光/高清”；真人实拍的毛孔与物理细节不硬套二维/插画；做旧、灰白胡须、泥痕符合角色状态，金属反射符合材质，无强行加脏、加伤或用噪点、锐化、粗大毛孔制造纹理。
- [ ] 已定稿面部不因组板或全身格修复被重绘；新角度与局部修复重新验收身份。
- [ ] 仅摄影方向按需用简短摄影锚点，其他方向用对应画材/渲染描述；颗粒不替代皮肤/织纹；不把摄影术语当 API 参数或分辨率保证，不把定妆照背景与灯光强加给真实视频场景。已通读正文及附加模板，删除或替换跨媒介污染；不以负面提示词抵消真人提示词中的 CG 诱导措辞。
- [ ] 表情参考仅备注、由用户另行生成，未混入默认设定板或编造上传槽位。
- [ ] 多视图属于同一角色；参考职责、保留程度及背景/排版排除项齐全。
- [ ] 视频沿用当前确认模型，默认 Seedance 2.5 `omni_reference`；人物、道具、场景、动作及声音参考各有职责和真实绑定，参数与正文分开。
- [ ] 每段 → 结束、动作因果、运镜和声音符合任务；已执行检查与待验证项如实区分。

## 7. 生物/道具资产的多视图与结构

`B`（生物/植物）与 `P`（道具）基础资产和角色一样是身份一致性参考，不能只交一张动态或单一角度图。默认采用中性展示姿态与多视图组板；使用与主体明度明显拉开的中性背景（主体偏深用明亮浅暖白灰、偏浅用中灰），不带任何场景、环境道具、影子、人物或战斗动态。本节是 B/P 的独立展示规则，不覆盖 C 按所选媒介确定的背景与光影（如真人实拍的布景渐变与脚下接触阴影）。样本阶段先给主视图 + 一个补充角度的最小组板验证风格，确认后再交多视图完整资产。

### 生物/植物 `B`

- **姿态中性。**自然舒展、水平陈列或自然站立，展示完整体长与解剖比例；战斗、攻击、盘绕缠斗、扑咬或张口嘶吼的动态留给视频提示词或状态衍生图。
- **多视图。**默认侧面全身主视图（整体比例与轮廓）+ 头部特写（结构、眼、口鼻/喙）；按辨识需要补背面或俯视展示斑纹分布。四足或有肢体的生物补正面站姿；蛇形/长体生物侧面主视图水平陈列看清全长。
- **关键结构局部 1–3 处。**选最影响辨识与一致性的部位：鳞片/皮肤/毛发材质近观、背腹纹路与颜色分布、口部或牙/喙、爪/蹄/鳍/尾端。沿用主视图颜色、材质与比例。
- **展示项。**完整解剖比例（头/颈/躯干/四肢或体节/尾）、材质与反光、颜色与斑纹分布、关键辨识特征；植物为主干/枝叶/花果结构与材质。
- **可复制格式（示例，替换尖括号）：**

```text
一张<已确认媒介与具体画法；与同项目角色/场景一致的材质表现>的生物资产参考图，主体展示为主、[按主体明度选的中性背景：主体偏深用明亮浅暖白灰、偏浅用中灰]、无任何场景背景，
<生物名称>，<体长、骨架/体量与各部分比例；主轮廓及关键辨识结构>，中性展示姿态，自然舒展不做战斗或攻击动作，
主视图：侧面全身，看清完整体长、体节与轮廓比例，<整体颜色与斑纹分布>，
补充视图：<头部特写：结构、眼、口鼻/喙>；<背面或俯视：斑纹/背脊分布>，
关键结构局部：<鳞片/皮肤材质近观>、<腹部或颈部颜色>、<口部或爪/尾结构>，沿用主视图颜色材质比例，
与主体明度明显拉开的中性背景（无任何场景、道具陈列或环境元素），画面不出现任何文字、字母、数字、标签、尺寸标注、签名或水印，
<已确认的整体配色倾向与明暗/色层处理>；均匀展示光让固有色与关键结构可读，清晰展示<各部位材质与可见受光表现>，各视图画法、颜色分区与细节尺度一致
```

### 道具 `P`

- **多角度。**主视图（最能表达形状与用途的角度）+ 至少一个补充角度（侧/背/俯之一）；有开合、折叠或组合结构的补一个展开或关键机构角度。
- **结构局部 1–3 处。**部件连接、握持/使用部位、材质接缝或纹样；写明比例、数量、左右归属与连接关系。
- **展示项。**整体形状与比例、部件构成与连接、材质与反光、关键辨识细节；使用状态（点亮/开合/装填）属衍生图，基础图用中性默认状态。
- **可复制格式（示例，替换尖括号）：**

```text
一张<已确认媒介与具体画法；与同项目角色/场景一致的材质表现>的道具资产参考图，主体展示为主、[按主体明度选的中性背景：主体偏深用明亮浅暖白灰、偏浅用中灰]、无任何场景背景，
<道具名称>，<整体形状与比例、主要机构形成的记忆点>，中性默认状态，
主视图：<最能表达用途的角度>，看清整体结构与比例，<各部件固有色、材料及反光差异>，
补充视图：<侧/背/俯之一>；<如有开合或组合结构，补展开或机构角度>，
结构局部：<部件连接/握持部位/材质接缝>，写明比例、数量与连接关系，沿用主视图材质颜色，
与主体明度明显拉开的中性背景（无任何场景、道具陈列或环境元素），画面不出现任何文字、字母、数字、标签、尺寸标注、签名或水印，
<已确认的整体配色倾向与明暗/色层处理>；均匀展示光让固有色与关键结构可读，清晰展示<材质、接缝与连接方式>，各视图画法、颜色分区与细节尺度一致
```

### 交付前逐项验收（B/P）

- [ ] 生物为中性展示姿态，无战斗/攻击/盘绕/张口动态；道具为中性默认状态，使用状态留给衍生图。
- [ ] 提供主视图 + 补充视图 + 1–3 处关键结构局部，非单一角度或动态图；各视图属于同一主体，颜色、材质、比例、斑纹/部件一致。
- [ ] 背景与主体明度明显拉开、轮廓可辨，无场景、环境道具、影子、人物或叙事动作。
- [ ] 按[设计链与功能推演](asset-design-basis.md#从依据到可见设计)核已定生态/能力或制作/归属/操作依据，剧情需要的转动、开合、握持或支撑有结构落点；原文、推导和未决问题不混写。
- [ ] 首句实际写出媒介与画法，部位配色、材料和结构与末行光影一致，并与同项目其他资产相容；不能只写“沿用项目风格”。
- [ ] 按[辨识度复查](asset-design-basis.md#辨识度复查)核主体体量/轮廓、关键形体和同项目主次；标志结构不妨碍既定功能，普通物件不被强制夸张。
- [ ] 展示完整解剖/结构比例、材质与颜色分布、关键辨识特征；无主视图之外的臆造特征。
- [ ] 提示词排除文字、标签、尺寸标注、签名与水印；未生成图片时视觉检查标待验收。
