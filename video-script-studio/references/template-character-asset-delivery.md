# 角色资产与 Seedance 2.5 交付规范

参考 [sd-asset-engine](https://github.com/lixiaoxiao9888-create/manju-laoli-skill/tree/main/sd-asset-engine) 的[人物立绘模板](https://github.com/lixiaoxiao9888-create/manju-laoli-skill/blob/main/sd-asset-engine/references/character-portrait-templates.md)（读取时文件 SHA：`807888b3dc306b678b9cd3ff980a5edd21746129`），吸收四格、单一面部锚点、完整全身与换装方法。沿用本地中文调用名、六行图片正文和项目登记，不引入外部总控、图N体系或场景九宫格。适用于角色资产提示词、参考图整理及后续视频提示词，与根 SKILL.md 一起执行；原模块的其他方法和能力保留，用户明确的新要求优先。

写样本和完整稿前先读取 [项目资产总表](asset-registry.md)。资产标题在六行提示词之外列出总表中的中文名称、唯一调用名和实际文件/待生成状态；六行内姓名沿用总表。只交文字提示词时记为 `planned`，后续视频阶段读取同一条目。角色设定在现有项目/总表中记清年龄、体型、面部锚点、发型、完整服装、穿戴配饰、画风及服装延续关系；剧本明确项直接继承，推导项标为候选，不把设计表或流程备注复制成图上文字。

基础资产请求或完整制作的基础资产阶段使用本模板，共享角色先定稿；默认不同时附场景与视频提示词。每次先执行 [样本确认流程](sample-approval.md)：默认选一个核心角色做完整六行组板样本，用户明确仅定脸或半身时采用局部样本，确认身份、造型、质感和光色后输出当前阶段完整六行资产提示词。验证多视图排版时用一个角色的最小完整组板作样本；已确认且未变的角色和提示词直接复用，新增、改写、补角度和局部修词只对变化部分给样本。文字设定确认并交付提示词后即可推进依赖阶段，共用总表与场景文字布局，不要求回传全部资产图；实际生成图的身份、比例与结构按需核对，未看图不得声称视觉通过。只有关键设计未定或已知冲突未解时下游相关部分才作条件性预稿；明确要求快速预览时可联合交付预稿，不代替实图验收。

## 1. 默认交付与模型

- 视频默认 Seedance 2.5，用户换模型时调用对应模块。图片工具继承用户/项目已确认设置，不把历史项目的 image2.5 名称当通用默认；未确认平台能力时只给可复制提示词。
- 默认交付一张四格角色资产参考图：全图共 4 格，横向依次为正面面部特写、正面全身、90°侧面全身、背面全身。仅面部特写格有清晰五官；三个全身格均保留完整头部，面部不刻画五官，头顶至鞋全部入画。同一人、同一服装、同一站姿，不增加独立大图或局部特写格。
- 图片正文仍为一段完整可复制的精简六行提示词，明确四格总数；不附音色描述或标签。图底细节条只含非文字波形，不计入四格；全图无字。不默认附长负面词库或摄影参数清单；六行中使用与内容题材及所选视觉风格一致的媒介锚点。
- 表情参考由用户另行生成，默认只附一句备注，不自动生成、不混入资产参考图。面部特写格的中性正面特写用于身份参考。
- 是什么风格就用什么风格：直接继承用户要求和项目已有风格，不默认真人、动漫或 CG，不因出图偏差重新选择风格。只有风格尚未确定时，才根据内容题材、叙事气质确定媒介。只有选定真人实拍方向时，才以“真人演员服装定妆照”锚定人类角色，多视图作为照片组板排版。以下版式面向人类角色；动漫、插画、非人角色、特定头饰/发型研究及用户指定版式调用原模块按任务调整。

## 2. 简洁提示词标准

### 沿用目标风格，避免提示词污染

1. **继承优先**：用户明确指定 → 项目已确认的视觉风格/参考；已有风格直接沿用，不重新推荐或审批。仅缺少风格时，才根据内容题材、叙事气质与用途推荐适配媒介。题材不等于媒介：古装、奇幻、科幻、现实题材都可以用真人、二维或三维表现，不能仅凭“人类角色”“写实”“电影质感”自动判为真人。
2. **方向不明确时**：在当前角色样本外简述推荐媒介及题材依据，随原有样本一起确认；若存在明显冲突或无法合理判断，只问一个关键风格问题。不增加独立审批，不把候选风格写成已确认，不擅自改变已确认媒介。
3. **先选媒介，再选材质与光影**：以下是条件分支，不是题材到风格的一对一映射。

| 已选表现方向 | 角色资产媒介锚点 | 材质、光影与细节侧重 |
|---|---|---|
| 真人实拍（适合当前内容的现实、历史或幻想影视等） | 真人演员服装定妆照 | 自然肤质、真实服装材料与物理受光；按项目光色选择摄影方案，可用下节降低意外 CG 感的方法 |
| 二维动画、漫画、赛璐璐 | 二维动画角色设定图或漫画角色设定图 | 线条、色块、赛璐璐明暗、形体与比例统一；不强塞毛孔、镜头参数或胶片颗粒 |
| 水彩、水墨、绘本等插画 | 对应画材的角色设定图 | 笔触、纸张、晕染与色彩层次；不强制摄影布景、窗光或接触阴影 |
| 三维动画、游戏 CG（含写实三维） | 对应项目风格的三维角色设定图 | 按风格控制建模形体、表面粗糙度、材质反射与渲染光照；CG 本身是目标时不将“3D 渲染”列为排除项 |
| 定格、黏土、剪纸或混合媒介 | 指定工艺的角色设定图 | 工艺材料、手作痕迹及对应照明；混合媒介按已确认区域职责分配，不任意拼接 |

同批角色继承同一媒介与光色规则；有意混合须有内容依据并在样本中说明。降低 CG 感只针对意外偏离目标风格的问题，不是所有题材的共同目标。真人出现 CG 感时，优先排查正向提示词中的跨媒介污染，保持真人风格、身份与服装不变，删除或替换污染措辞，而不是换风格或添加负面提示词。

### 固定结构与填写规则

按"总述与四格→姓名与年龄性别→面部特写→三格全身与服装→背景、一致性与图底条→灯光与质感"写六行，保持接近下方范本的长度。

| 部分 | 要写的信息 |
|---|---|
| 总述 | 已选媒介与风格、角色资产参考图、全图共 4 格及四个视角 |
| 身份 | 角色姓名、年龄、性别及适用身份信息 |
| 面部特写 | 全图唯一清晰面部；脸型、眉眼、鼻唇、肤色、发型与辨识标记，头部占该格高度至少70% |
| 三格全身 | 正面、90°侧面、背面；保留完整头部而不刻画五官，头顶至鞋全部入画；体型、头身比、完整服装、鞋袜与穿戴配饰 |
| 背景与一致性 | 简洁浅色背景，同一身份、体型与服装；图底非文字波形，全图文字全部排除 |
| 灯光与质感 | 与内容题材及已选媒介匹配的光影、色彩、材料表现；不通用堆叠摄影或渲染术语 |

- **四格及单一面部锚点**：只有面部特写格提供可辨识五官，三个全身格保留头型、发型、颈部与肩线，面部不刻画五官。生成正文不用“无头 / headless / 马赛克 / mosaic / pixelated / 打码”等词，不用裁头或像素块处理。全身人物占各格高度约85%–95%，鞋袜直接画在全身格内。
- **完整比例与中性站姿**：明确头身比；成年真人通常6.5–7.5头身，儿童、二维、三维及非人设计按已确认年龄与风格调整。三个全身格为同一人端正站立的不同观察角度，双手空着自然垂放。
- **人物与独立道具分离**：只画人物及穿戴配饰；手持物、独立兵器、书本、器械等由P类资产提供。可摘配饰的离身状态另行登记，避免穿戴与手持双现。职业身份用具体服装形制、材质、标志配色和已有体态表达，不只写“制服”。
- **服装覆盖完整**：交代服装层次、主辅色、面料、纹样、领袖/衣襟/扣具结构、使用状态、鞋袜与配饰；不对称结构按角色自身左右继承，侧面选展示关键结构的一侧并写明。细节直接并入对应格描述，不新增手、鞋或材质特写格。
- 五官、肤色、发型、辨识标记及服装按实际角色替换。阿德莱德的皇室身份、金发、淡痣及酒红连衣裙只属于该案例，不设为其他角色默认。
- 在对应区域写与已选媒介相容的可见细节，不能只堆“哑光、细腻、高清”。真人实拍可用“部位或材料＋可见差异＋程度或分布＋受光表现”，皮肤保留自然纹理与轻微不对称；二维侧重线条与色块，插画侧重画材，三维按项目风格控制材质。织物、皮革、金属的细节密度与使用状态匹配；新衣不强行做旧，不以噪点、锐化、粗大毛孔模拟皮肤。
- 仅在选定真人实拍方向且适配项目时，可用简短的“中画幅摄影、85mm 镜头观感、自然色彩”建立摄影约束，并非所有题材的必填参数；保持面部和各身体视图细节可辨；轻微胶片颗粒仅作整体摄影风格，不代替毛孔或织纹，也不遮盖细节。光圈、ISO、白平衡等仅按需补，不堆长参数清单。摄影术语不代表真实拍摄、API 设置或输出分辨率；不再默认追加“8k、高清细节”。用户已指定其他摄影方案时沿用。
- 默认简洁浅色或浅灰背景，具体表现随媒介：真人实拍可用摄影布景、轻微明暗渐变与脚下短而柔的接触阴影，二维/插画可用平色或画材底，三维按项目展示光照处理。画面整洁指没有杂物，不等于所有媒介都必须纯平或无阴影。采用窗光时，它只是光源，不要求画出窗户或房间。图底波形仅为非文字视觉标记；不附音色标签或图外音色描述，全图排除文字、字母、数字、姓名、视图标签、尺寸标注、签名与水印。其他资产仍执行各自无文字规范；用户另有版式要求时优先执行。

### 真人实拍分支：降低意外 CG 感的写法

仅适用于已选真人实拍方向的人类角色新建或本次修改提示词，不是全局默认。“写实三维”仍属于三维分支；动漫、插画、明确要求的 CG 风格及非人设计不强行转成真人摄影，已确认未变内容不自动重写。以下布光与摄影方案按题材及项目风格取舍，不要求一律窗光、85mm 或胶片颗粒。

| 容易引向渲染的写法 | 正向替换方向（按角色设定选择，不全量堆叠） |
|---|---|
| 只写“角色资产参考图、电影质感、高清” | 首句先写“真人演员的服装定妆照”，再交代多视图排版；三个全身格保持同一演员的体型与服装，头部完整保留，面部不刻画五官 |
| 无瑕皮肤、下颌线由整齐短须勾勒 | 鼻翼细小毛孔、面颊轻微色泽差异、左右脸略不对称；有胡须者可写长短不一，少量灰白仅在年龄与设定适合时加入 |
| 只有“哑光布料、皮革” | 布料可见织纹、接缝受力褶皱；旧衣袖口少量起毛，皮革在关节处弯折起皱；旧披风毛面略蓬乱、靴缘少量干泥仅用于已确认的常年使用状态 |
| 规整铁片、窄幅冷亮反射 | 旧铁甲可写“做旧暗铁，表面氧化与细划痕使反光分散，以漫反射为主，仅边缘微弱反光”；手工铁片大小角度可略有差异，但片数、搭接和固定关系在各视图一致 |
| 中性工作室主光、弱补光保留体积、电影级边缘光 | 柔和漫射窗光从一侧照入，自然衰减；鼻翼、衣褶保留柔和明暗，鞋底与布景地面有接触阴影，浅色背景有轻微渐变 |

- **不完美有边界**：不改变已定稿五官比例、痣疤位置或服装结构；磨损属于该角色的材料/使用状态，不等于统一加脏、加伤、衰老。抛光金属保留其真实反射，不把所有金属改为暗铁；剧情新增泥污、破损仍走状态衍生图。
- **清理污染，不用负面提示词补救**：即使工具支持独立负面栏，也不为纠正真人的 CG 感添加风格负面词，不生成“不要 CG”或同义排除词库。回到正向正文，删除与目标风格冲突的渲染展示措辞及空泛质量词，替换成适配原定风格的媒介、材料与受光事实。四格、单一清晰脸、完整头身与图面文字限制属于输出规格，仍保留，不等于风格补救负面词。
- **清理顺序**：先读回原定风格，再通读首句、角色形容、材料、布光、质量后缀及附加模板，找出混入的渲染展示语义；删除无用质量堆词，替换冲突描述，最后核对正文是否仍有相反线索。不保留污染词再加一句“真人摄影”试图抵消，也不机械增加镜头参数或颗粒。上表是组合语义风险示例，不是禁词表；工作室灯光、金属反射或多视图本身不必然导致 CG，按上下文判断。保持风格、身份与版式不变，用同一角色小样验证；未见实图只能报告文字调整，不能声称已消除 CG 感。

```text
柔和漫射窗光自然衰减，保留鼻翼与衣褶的柔和明暗，鞋底与布景地面有接触阴影，绉布反光分散，皮革弯折处有柔和反光，中画幅摄影、85mm 镜头观感，自然色彩，清晰定妆照质感，轻微胶片颗粒且毛孔与织纹可辨
```

上述风险分析仅用于内部清理，不复制进生成提示词。交付只保留原定风格的正向描述，不另附用于修复 CG 感的负面提示词栏。

### 定稿、修复与其他资产

- **制作方式**：本批次样本确认后交付完整参考图提示词。补角度、修改或修复先给本次样本；生成时可一次生成后验收，已有定稿正面特写直接沿用。组板不对已通过的面部做生成式重绘，缩放时减少重采样。
- **单独大头照**：仅需主脸或先定稿时换成"单人正面面部特写"，保留身份、肩部衣领及肤质光线描述，删其他视图和画外的脚下接触阴影描述，可独立生成。
- **视觉修复**：全身格出现第二张清晰脸时只编辑该格面部，完整保留头部与头身比；不重绘定稿面部特写。皮肤过平时核对脸部画幅占比、原图分辨率、补光及工具美颜设置，再选局部修复。生成式局部修复需重验身份与肤质。
- **道具与场景**：道具保留多角度、必要底部视图、真实尺寸、结构接缝、材质厚度、重力支撑与使用状态，独立资产用中性背景。场景按 [纯环境规则](../SKILL.md#场景图只交付纯环境强制) 保留无角色/生物/道具的空场底图、必要固定结构、材质与光色；用户要求简洁时省略方位与构图细节。
- **变体与比例**：换装、湿衣、损伤等反复状态独立建图，沿用主脸与原细节合成方法；同框比例参考、非人设计、头饰研究、多角度研究和试演能力保留，特殊参考单独标明职责。

### 换装与声音交接边界

角色资产不附英文音色描述或音色标签，图底仅保留非文字波形；波形是视觉标记，不是音频输入。视频只写当下说话/喊叫/喘息的行为，实际音频参考或平台ID按真实用途单独登记，不重新设计固定音色。

换装或状态变体另存版本，保持已定稿五官、肤色、年龄、体型与发色，只改指定服装、鞋袜、配饰或状态。默认继承同一四格布局；已有实图用局部编辑并保留定稿面部，未有实图时只交文字修改方案。新旧版本与变更点记入现有总表，不新建外部接线单体系。

### 六行结构自动校验

六行仍是文本长度约定，图面严格四格。以下检查只验证默认基础角色的图片正文及全图无字；不要求音色描述或标签。用户指定其他版式按对应例外单独核对。实图的格数、脸数、比例与无字仍需实际看图验收。

```python
def validate_character_sheet(text):
    import re
    lines = [line.strip() for line in text.splitlines() if line.strip()]
    if len(lines) != 6:
        return [f"六行结构失败：实际{len(lines)}行"]
    checks = [
        ("四格总数", "角色资产参考图" in lines[0] and "全图共 4 格" in lines[0] and all(x in lines[0] for x in ("面部特写", "正面全身", "90°侧面全身", "背面全身"))),
        ("独立身份行", bool(re.search(r"\d+岁.*(?:女性|男性|女|男)", lines[1]))),
        ("唯一面部锚点", lines[2].startswith("面部特写：") and all(x in lines[2] for x in ("正面面部特写", "唯一清晰面部"))),
        ("完整三视图", lines[3].startswith("三格全身：") and all(x in lines[3] for x in ("正面", "90°", "侧面", "背面", "完整头部", "面部不刻画五官", "头顶至鞋全部入画", "头身比", "站姿", "双手空着"))),
        ("背景与同一身份", "背景" in lines[4] and "同一" in lines[4]),
        ("图底非文字波形", all(x in lines[4] for x in ("图底", "非文字声纹波形", "不计入四格"))),
        ("无音色描述或标签", not re.search(r"音色速览标签|英文音色|Voice Description|Warm alto|固定声线", text, re.I)),
        ("图面文字限制", all(x in lines[4] for x in ("全图", "不出现", "文字", "字母", "数字", "姓名", "视图标签", "尺寸标注", "签名", "水印"))),
        ("灯光与质感", any(x in lines[5] for x in ("光", "明暗", "色块", "色层", "色彩")) and "质感" in lines[5]),
        ("旧版裁切与多格污染", not re.search(r"无头|headless|颈根以下|头部不入画|马赛克|mosaic|pixelated|打码|局部特写|右下方补充|独立大主图", text, re.I)),
    ]
    return [name for name, ok in checks if not ok]
```

## 3. 视频参考：同一身份与区域职责

面部特写是唯一身份主参考，固定五官比例、发型与辨识标记。三个完整全身格只负责头身比、体型、服装、穿戴配饰与背部结构；全身格不刻画五官是资产板处理方式，视频人物正常呈现完整五官。多人分别建立参考职责映射，组合板不作为视频起点。

生成失败时另存局部修复版：保留定稿面部特写，只清理全身格多余的五官，保留头型、发型、颈部、完整身体与鞋袜；缺头或缺脚时不能靠裁切补全，按同一身份补齐对应格后复核比例。原图保留，未生成或无法查看时标“待生成后验收”。旧版板只在本次要求迁移或已有问题时修改，不自动重做未变资产。

### 参考角色职责（内部绑定/素材整理示例，不是视频复制正文）

实际槽位以真实上传编号为准，可用一张组合板或拆分参考。以下仅供内部登记与素材清理，不直接附入四段式复制块，也不虚构已绑定素材。最终【参考素材职责】只保留本镜直接引用及必要状态/职责；背景、排版和标签的干扰处理留块外：

```text
[人物参考]
@Image 1 的正面面部特写属于沈砚，作为身份主参考，固定五官比例、发型与辨识标记。
@Image 2 的正面、90°侧面、背面完整全身视图只定义沈砚的比例、体型、服装及穿戴配饰。
两份素材属于同一个沈砚；本场景只有一位沈砚，五官自然完整。
仅采用指定人物属性，排除参考图的浅色背景、四格排版、全身格面部处理、图底波形；镜头构图由本段演出决定。
```

只上传组合板时合并为一个真实槽位，明确面部格与全身格的职责。不附音色标签或描述，音频实际绑定单独登记。

## 4. 表情参考：仅交单独生成备注

默认附在提示词代码块之外，标注"用户另行生成，尚未附加"。备注包含：

- **来源**：用已确认的正面主参考编辑或引用，不重新文生相似人物。
- **表情目标**：只选剧情需要的一种明显表情（如露齿笑或愤怒），说明眉眼、嘴角、张口幅度及是否展示牙齿。
- **保留项**：五官比例、发际线、疤痕/痣位置、肤色、发型，及主参考的角度、背景和光照。
- **职责**：只补表情肌肉变化、嘴形和牙齿结构，不提供第二套身份、服装或场景。
- **验收**：与中性主参考对照确认同一人，偏差大时返修。

交付备注示例：

> 表情参考备注（请另行生成）：基于定稿正面特写制作一张露齿笑特写，保持同一人的五官比例、发型、辨识标记、角度与光照。只改变笑肌、嘴角及张口程度，清楚展示牙齿结构。此图仅用于表情动态参考，身份仍以中性主参考为准。生成后再按实际上传槽位加入视频提示词；当前不引用此图。

同一身份可有已核对的正面、3/4 侧面与单独表情参考，角度或表情辅助图不重新定义身份。非人角色的张嘴/闭嘴参考能力保留，需要时同样作单独备注交付。

## 5. 视频提示词的衔接标准

1. 视频默认 Seedance 2.5，用户/项目已确认其他模型时继承并读取其资料。模式、时长、画幅、分辨率在界面/API 设置，提示词文字不代替参数。
2. 已确认参数直接继承。规格、枚举依对应模型指南，不把“建议设置”写成“已在线验证”。
3. 【参考素材职责】只写本镜直接 `@引用` 与必要状态/职责，不重复五官、发型、服装、材质或辨识标记；背景/组板干扰在块外安排裁切或清理。无独立资产的明确纯文字路径才补必要主体描述。
4. 完整视频采用【参考素材职责】→【一句话概述】→【具体情节】→【全局补充】；具体情节按秒轴写主体、空间、动作、摄影与适用光线，声音/对白内联进对应发声动作，不单列音频栏。每阶段一个主要变化，明确起始、动作和末态。
5. 参考素材按镜头筛选，不引用缺席角色或未生成的表情图。多视图属于同一主体，角色数量、道具归属、方向与损伤状态持续一致。
6. 写可见表演和物理结果。人物设定板的背景、排版、裁切不带入场景，视频中身体完整连接。默认无字幕、无水印、无未要求旁白。
7. 动作戏执行三强度/两速度、因果交锋和连续性标准；纯表演任务不强制三套动作版本。
8. 交付完整可复制代码块，生成说明及表情备注置于块外。每次修改后执行 [修改后标准复查闭环](production-checks.md#修改后标准复查闭环)，读回最终完整条目并核受影响依赖；视频四段式用 `director_contract_lint.py`，模型/引用用 `seedance_lint.py --preflight` 及实际模型参数检查，只陈述实际运行结果。

## 6. 交付前逐项验收

- [ ] 全图恰好四格：一张清晰面部特写、正面/90°侧面/背面三个完整全身；不附加重复视角或局部特写格。
- [ ] 只有面部格刻画清晰五官；全身格保留头型、发型、颈部和肩线，头顶至鞋全部入画，头身比符合年龄与风格。
- [ ] 只编写提示词或无法查看图片时，视觉检查标"待生成后验收"，如实不虚报。
- [ ] 服装、左右佩戴关系、穿戴配饰数量与体型一致，双手空着；案例特征已替换为当前角色。
- [ ] 六行提示词结构与范本一致；媒介按用户指定、项目风格或内容题材推荐选定，首句与材质/光影同属该媒介，无默认真人锚点或跨媒介堆词。候选媒介随样本说明，未冒充已确认。
- [ ] 图底仅非文字波形，全图无文字标签，不附音色描述；换装沿用身份与版式。
- [ ] 面部与材料细节符合所选媒介，不仅写“哑光/高清”；真人实拍的毛孔与物理细节不硬套二维/插画；做旧、灰白胡须、泥痕符合角色状态，金属反射符合材质，无强行加脏、加伤或用噪点、锐化、粗大毛孔制造纹理。
- [ ] 已定稿面部不因组板或全身格修复被重绘；新角度与局部修复重新验收身份。
- [ ] 仅摄影方向按需用简短摄影锚点，其他方向用对应画材/渲染描述；颗粒不替代皮肤/织纹；不把摄影术语当 API 参数或分辨率保证，不把定妆照背景与灯光强加给真实视频场景。已通读正文及附加模板，删除或替换跨媒介污染；不以负面提示词抵消真人提示词中的 CG 诱导措辞。
- [ ] 表情参考仅备注、由用户另行生成，未混入默认设定板或编造上传槽位。
- [ ] 多视图属于同一角色；参考职责、保留程度及背景/排版排除项齐全。
- [ ] 视频沿用当前确认模型，默认 Seedance 2.5 `omni_reference`；人物、道具、场景、动作及声音参考各有职责和真实绑定，参数与正文分开。
- [ ] 阶段结束状态、动作因果、运镜和声音符合任务；已执行检查与待验证项如实区分。

## 7. 生物/道具资产的多视图与结构

`B`（生物/植物）与 `P`（道具）基础资产和角色一样是身份一致性参考，不能只交一张动态或单一角度图。默认采用中性展示姿态与多视图组板；使用干净浅色或浅灰色背景，不带任何场景、环境道具、影子、人物或战斗动态。本节是 B/P 的独立展示规则，不覆盖 C 按所选媒介确定的背景与光影（如真人实拍的布景渐变与脚下接触阴影）。样本阶段先给主视图 + 一个补充角度的最小组板验证风格，确认后再交多视图完整资产。

### 生物/植物 `B`

- **姿态中性。**自然舒展、水平陈列或自然站立，展示完整体长与解剖比例；战斗、攻击、盘绕缠斗、扑咬或张口嘶吼的动态留给视频提示词或状态衍生图。
- **多视图。**默认侧面全身主视图（整体比例与轮廓）+ 头部特写（结构、眼、口鼻/喙）；按辨识需要补背面或俯视展示斑纹分布。四足或有肢体的生物补正面站姿；蛇形/长体生物侧面主视图水平陈列看清全长。
- **关键结构局部 1–3 处。**选最影响辨识与一致性的部位：鳞片/皮肤/毛发材质近观、背腹纹路与颜色分布、口部或牙/喙、爪/蹄/鳍/尾端。沿用主视图颜色、材质与比例。
- **展示项。**完整解剖比例（头/颈/躯干/四肢或体节/尾）、材质与反光、颜色与斑纹分布、关键辨识特征；植物为主干/枝叶/花果结构与材质。
- **可复制格式（示例，替换尖括号）：**

```text
一张生物资产参考图，主体展示为主、干净浅色或浅灰色背景、无任何场景背景，
<生物名称>，<体长/体型比例>，中性展示姿态，自然舒展不做战斗或攻击动作，
主视图：侧面全身，看清完整体长、体节与轮廓比例，<整体颜色与斑纹分布>，
补充视图：<头部特写：结构、眼、口鼻/喙>；<背面或俯视：斑纹/背脊分布>，
关键结构局部：<鳞片/皮肤材质近观>、<腹部或颈部颜色>、<口部或爪/尾结构>，沿用主视图颜色材质比例，
干净浅色或浅灰色背景（无任何场景、道具陈列或环境元素），画面不出现任何文字、字母、数字、标签、尺寸标注、签名或水印，
与项目已定媒介匹配的均匀展示光，清晰展示<材质与结构及可见受光表现>，各视图沿用同一媒介与光色
```

### 道具 `P`

- **多角度。**主视图（最能表达形状与用途的角度）+ 至少一个补充角度（侧/背/俯之一）；有开合、折叠或组合结构的补一个展开或关键机构角度。
- **结构局部 1–3 处。**部件连接、握持/使用部位、材质接缝或纹样；写明比例、数量、左右归属与连接关系。
- **展示项。**整体形状与比例、部件构成与连接、材质与反光、关键辨识细节；使用状态（点亮/开合/装填）属衍生图，基础图用中性默认状态。
- **可复制格式（示例，替换尖括号）：**

```text
一张道具资产参考图，主体展示为主、干净浅色或浅灰色背景、无任何场景背景，
<道具名称>，<整体形状与比例>，中性默认状态，
主视图：<最能表达用途的角度>，看清整体结构与比例，
补充视图：<侧/背/俯之一>；<如有开合或组合结构，补展开或机构角度>，
结构局部：<部件连接/握持部位/材质接缝>，写明比例、数量与连接关系，沿用主视图材质颜色，
干净浅色或浅灰色背景（无任何场景、道具陈列或环境元素），画面不出现任何文字、字母、数字、标签、尺寸标注、签名或水印，
与项目已定媒介匹配的均匀展示光，清晰展示<材质与结构及连接>，各视图沿用同一媒介与光色
```

### 交付前逐项验收（B/P）

- [ ] 生物为中性展示姿态，无战斗/攻击/盘绕/张口动态；道具为中性默认状态，使用状态留给衍生图。
- [ ] 提供主视图 + 补充视图 + 1–3 处关键结构局部，非单一角度或动态图；各视图属于同一主体，颜色、材质、比例、斑纹/部件一致。
- [ ] 干净浅色或浅灰色背景，无场景、环境道具、影子、人物或叙事动作。
- [ ] 展示完整解剖/结构比例、材质与颜色分布、关键辨识特征；无主视图之外的臆造特征。
- [ ] 提示词排除文字、标签、尺寸标注、签名与水印；未生成图片时视觉检查标待验收。
