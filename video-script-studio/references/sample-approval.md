# 按场景分批：样本确认与配套交付

## 范围与确认

完整制作、资产与视频一起编排的请求，默认按场景或连续剧情段落建立联合批次；资产提示词和视频提示词在同批交付，各用独立代码块。明确只要资产或只要视频时，仅处理指定类型。咨询、预算、纯诊断及 Skill 维护保持原任务范围。

所有批次先读取 [项目资产总表](asset-registry.md)，继承同一份 `asset-registry.json` 的名称、文件、状态及场景布局。登记、提示词交付、实际出图、平台绑定和视觉验收是不同阶段，分别记录。

**CHECKPOINT：本批配套样本 → 用户确认 → 完整交付本批 → 等待继续下一批。**新写、改写、补镜、修词和单条交付均执行样本流程。收到本批当前样本的确认后直接展开；批次内已确认的组成部分沿用，避免逐资产、逐镜重复审批。仅确认某一资产时，确认范围限于该项；修改影响造型、布局或视频演出时，更新受影响的配套样本再确认。

## 1. 分批与统一规划

1. 先列简明批次目录：批次号、场景/连续剧情范围、预计 Clip 数及需新增的资产；本轮只展开当前批，后续批只列范围。
2. 一批以一个场景或连续剧情段落为主；长段再按可交接的动作节点分批，保证每个 Clip 的演出细节完整。批次可含多个 Clip，并非一个批次就是一个镜头。
3. 先登记本批角色、生物、道具、场景及其职责；既有资产逐字复用 handle，只为新增或需修改的资产写生成提示词。
4. 同批场景资产与视频共用布局：固定地标、数量、位置关系、通道及观察基准。已有图按实际可见内容核对；只有文字时记录为待出图核对的设计，设计确认与图像核对分别记。
5. 视频只引用本片段需要的资产和状态；同批资产清单不是全片段出场表。后续批延续当前末态、道具持有关系与场景变化。

## 2. 配套样本

联合批次给一组能验证核心配合的样本：本场景资产样本、当前需要验证的新角色/生物/道具样本，以及对应视频片段样本。已定稿的共享资产列为复用。每条样本都可独立复制，保持其完整版式和演出细节。

| 任务 | 样本内容 | 主要确认项 |
|---|---|---|
| 人类角色 | 单角色六行组板：左侧正面面部，右侧无头正面/侧面/背面；明确仅定脸/半身时按该范围 | 身份、服装、版式、材质与光色 |
| 生物/植物 | 本体多视图及关键结构；保持适合物种的完整轮廓 | 比例、斑纹、材质与结构一致性 |
| 道具 | 主视图、补充角度和关键部件细节 | 形状、比例、连接与材质 |
| 场景 | 干净环境图提示词，与本批布局一一对应 | 地标、数量、通道、空间纵深、光色 |
| 视频 | 一个完整代表性片段，含动作因果、同步运镜、声源、连续性和末态 | 场景对应、节奏、表演及交接 |
| 编辑/延伸 | 体现修改效果或接续关系的局部片段 | 母片保留项、修改边界、接点 |

视频样本默认选约5–8秒的完整动作段；用户指定测试一个完整 Clip 时按其要求，未另定时以接近30秒为编排目标。完整批次的 Clip 同样以接近30秒为目标，并核对当前模型/模式实际支持的长度；样本长度不改写全片预算。

沿用 Seedance 2.5 `omni_reference` 的素材职责路由；无可用参考时用中文名称与已知设定提供条件性文本。模型与规格放代码块外，视频代码块直接从七栏目正文开始；运镜与时间戳内动作同步。风格按 [电影视觉参考匹配](higgsfield-style.md#电影视觉参考匹配) 转成光色、材质与空间设计，在本批样本内确认。

## 3. 标准交付顺序

样本与完整批次使用同一套顺序，内容规模分别对应样本范围与本批完整范围：

1. **批次范围**：编号/版本、场景、剧情区间、Clip 编号、样本/完整交付状态，必要的平台设置放在块外。
2. **资产与布局清单**：既有复用、新增、修改、待生成/待绑定分别标注，附同一份总表更新及场景布局。
3. **本批资产提示词**：仅新增/需修改项，按 S/C/B/P 分项，各自独立代码块；人类角色六行、生物/道具多视图、C/B/P 干净浅色背景、S 完整环境的规则保留。
4. **配套视频提示词**：逐 Clip 完整七栏目、连续时间戳和同等演出密度；尚未生成/绑定的资产用中文名称，规划 handle 留在清单。资产有真实文件并核对当前绑定后才编译为可提交标签。
5. **核对与交接**：简述预期效果、名称/lint/布局核对结果、待补素材和下一批接点。样本末请求确认；完整批次末等待继续下一批，已确认资产下批直接复用。

用户只要一类提示词时，保留其样本流程与适用栏目，省略另一类生成提示词。原生 JSON/HTML 等按各自 schema 交付，资产与视频用独立文件或 schema 支持的结构组织，审核说明放在允许的位置或旁附说明中。

## 4. 出图后的核对与修订

文字方案确认后即可交付本批完整提示词；素材未出图/未绑定的视频标为条件性稿。场景图出来后核对布局与动作所需通道，角色/生物/道具图核对外观和结构；差异用局部修图或经用户确认同步设计解决，再更新总表及相关片段。联合交付是文字编排一致性措施，不代表图像结果已经符合设计。

素材缺失、脚本不可运行或图片无法读取时，交付可评估的样本并记录待核对项；报告实际检查范围，视觉结果标“未生成，视觉未验收”或具体待核状态。用户选择先看实图时，等待该结果再做视觉确认。

在项目内记录批次范围、样本版本、确认依据、交付状态及相关资产，不向 Skill 安装目录写项目记录。跨会话读回总表和上批交接，保留既有名称、场景关系与连续状态。
