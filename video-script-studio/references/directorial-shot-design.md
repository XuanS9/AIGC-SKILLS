# 顶级导演分镜方法：从戏剧意图到镜头语法

> 本模块是 `video-script-studio` 的分镜与导演中枢。它不规定固定镜头数量、景别轮换或单镜秒数；**不设单镜3秒上限，镜头数量与时长按内容决定**。切点由戏剧目的、观众信息、人物关系、空间动作和情绪曲线推导；每个 Clip 总时长≤30秒，超量按叙事规划压缩或顺延，完成前逐条核验。
>
> 先执行下面的导演决策流程，主动组织戏剧重点、观众信息、人物调度与观看距离，再选具体拍法。事件类别只帮助检查遗漏，不能替代导演判断。

## 导演决策流程

本节是镜头设计的执行顺序。叙事规划负责事件与成片顺序，本文负责观众如何经历这些事件，编译负责将已定方案写入提示词，验收负责反向核对。新写、改写、补镜均主动执行，不等用户指出哪处需要特写。局部任务只复核受影响的场景及前后接缝，完整任务先看整场，再逐 Clip 落实；Clip 是制作边界，不是戏剧重点的边界。

### 1. 定变化与主次

读到场末，写出“谁想达成什么，遭遇什么阻力，经过哪次行为，局面/关系/观众判断从什么变成什么”。允许威胁持续、困局加深或关系保持含混；风景、产品、教程则写观看对象或理解的变化，不凭空加冲突。人物变化只能依据已发生的选择与代价，不能靠温柔近景、潜台词或摄影把仍逐利的人提前拍成已经悔改。

把本场内容分为：

- **核心重点**：决定局势、人物选择或观众判断的节点，必须被读懂并留下必要后果。
- **必要支撑**：让重点成立的空间、准备、刺激和持物关系，交代清楚即可。
- **连接过程**：已懂的重复、常规走动与操作，在授权范围内合并、略去或用画外声承接。

优先级是分配注意力的依据，不是每场固定只能一个高潮。长场可有多个递进重点，但须说清彼此如何铺垫、升级或回响。重点通过前后景别落差、构图中的距离/遮挡、动作停续、表演气口、声源变化或后果停留实现；不能把所有细节都放大成同等特写。文字细致度按动作负荷保持，镜头强度按主次变化。

### 2. 安排观众信息与体验

选定本段的观察立场：贴着人物感知、让观众提前知情，或暂留客观距离。分别列出观众与每个角色已经知道什么、此刻获得什么、仍不知道什么；揭晓属于谁、在哪次刺激后成立。

相同事件可以有不同合理方案：悬念可以先露威胁再等待人物发现；惊奇可以先跟人物、转角后同时揭晓；信任可以留在试探与等待，避免切到解释一切的旁观者。继承用户锁定的揭晓与视角；未锁定时，根据本场重点比较这些选择，采用一个有依据的方案，不能以“给所有人都拍一遍”代替取舍。

### 3. 用场面调度呈现变化

先安排可见行为与站位，再选镜头：谁占通路、谁退让、谁握住关键物件、谁能看见谁，距离如何因伸手/阻挡/转身改变。人物的目标通过动作和对手反馈成立，听者在判断，背景行为随实际感知变化；无需平均给每人反应镜。

摄影、光和声音共同引导注意：构图留出出口或压缩退路，焦点跟物件归属转移，已有光源在开门/遮挡后改变可见范围，真实声源可先于画面引出反应。局部被摄对象清楚、旁枝收敛，才有重点。空间参考的地形与光源位置保持，取景范围与焦点可主动选择。

### 4. 比较切镜、镜内交接与停留

每个候选切点都比较三种处理，简单任务可在内部简判，不向用户铺开全套备选：

| 处理 | 适用判断 | 选择后的要求 |
|---|---|---|
| 保持镜头 | 同框能读清因果/关系，停留使等待、犹豫、失去或危险更有分量 | 保住注意对象与经过时间；有意义的静止成立，不强加眨眼、手势或运镜 |
| 镜内交接 | 信息在同一空间流动，移动、调度、移焦或收放构图就能看清 | 写出注意如何从谁/何物交给谁/何物，不同时堆多个竞争动作 |
| 剪切 | 当前机位看不清核心变化，或另一个视角能改变知情、判断、距离感和主动权 | 明确切入对象与新增/深化的理解；继承动作相位、视线、声源和空间关系 |

切镜本身有代价：会打断时间体验、隐藏空间连接、抢走人物气口。近景可以靠近选择，也可以不切脸而停在仍没松开的手；远景可以强调代价，也可以打开逃路。用能读清本次变化的景别，不把情绪名称自动映射成固定景别。主观镜、跟踪镜、手部特写属于候选工具，由上面三步决定必要性；不要求凡追逐必主观、凡射击必跟箭、凡交接必手镜。

### 5. 在真实时长内形成节奏

按 [动作同步、接缝去重与整场节奏](narrative-planning.md#动作同步接缝去重与整场节奏) 核对事件时间与段间继承。按动作、对白、阅读信息和情绪消化所需时间估时，允许同步的过程共用时间；再检查整场的紧张累积、重点前的铺垫、重点发生和余波。切点落在观看任务交接处，镜头数量与时长随表演和信息负荷变化，不设3秒门槛或固定镜数，不机械等分。短镜未必紧张，长镜也可因无法逃开的关系持续加压。

技术准备是必要支撑时可以先完成、画外完成或简短交代，核心接触与选择要有读清窗口。已上弦的武器不为丰富重演上弦，箭的飞行不等人演完反应，告别不被操作插镜切碎。固定时长放不下时，先移除重复、合并支撑信息或调整镜内并行；如果仍不够，按既有授权处理预算与范围，不能把所有过程挤进一秒或任意慢放。

### 6. 反向审片式筛选

连读整场，只看银幕能出现的内容，执行以下检查后再编译和分组：

1. **去说明**：遮住一句话概述与潜台词，仅凭画面和声音能否理解重点、人物选择与后果？只能靠解释理解时，回调度或取景修复。
2. **去镜头**：暂去掉一个候选插镜，是否损失关键理解、情绪压力、关系变化或接缝？不损失则删/并；观众理解没变但等待的重量变了，可以保留，写清依据。
3. **换视角**：换成客观、主观或另一角色视点，会不会泄露秘密、错置知情或改变人物判断？选最符合本段体验的视点。
4. **看整场**：准备和操作是否抢过转折？是否每次都用同样的脸/手/物件三连切？重点后有没有余波？后段有没有信息贫乏或过度切碎？
5. **查物理与表演**：因果、动作窗口、手别、持物、空间与气息是否接续？新切点不能让对手暂停、对象瞬移或完成的动作重来。

内部留下短记录：`本场变化/重点 → 观众信息 → 调度证据 → 选用切镜/镜内交接/停留及原因 → 时长依据 → 删并结果`。沿用现有 project/导演工作单，不新增审批、文件夹或全套控制图。向用户交付已选合理方案与必要取舍，不能把本应由导演判断的每个机位变成用户问题。

### 同一素材的导演取舍示例

已定事件：一个被追者得到帮助者的包裹后离开，帮助者留下挡追兵。下面比较的是镜头方案，事件与结果相同：

| 方案 | 观众体验与代价 | 判断 |
|---|---|---|
| 操作细节铺满 | 解带、张布、装包、抓带、抬脚都单独切，追兵每拍一反应 | 操作虽全，托付选择被淹没；合并连接过程，保留真正吃力的接物与分离 |
| 持续关系镜为主 | 两人和开放的退路同框，受助者本可走却回身接包；接触停留到主动松手，再打开距离 | 若重点是接受责任，优先采用；关键重量或不舍看不清时才切近景 |
| 威胁交叉为主 | 提前交代追兵准备，托付完整发生后快速接近/命中，回到受助者欲返却受包重所限 | 若本段重点转向牺牲代价，可采用；准备不插在关键分离中，不能让追兵预知包内容 |

执行时按场的当前重点选主方案，必要支撑可借另一方案的最少镜头，不把三套相加。长对白、悬念、日常和非叙事画面用同一判断流程，拍法由内容决定。

## 一、导演先决定观众经历什么

写分镜前，先用一句话回答本段的导演意图：

> **观众此刻应该先看到什么、后知道什么；应该先放松、期待、害怕、误判、疼痛、信任，还是释放？**

随后确定四个东西：

1. **观众信息**：观众比人物知道多，还是少？异常先给观众，还是先让人物发现？
2. **情绪方向**：本段从什么情绪到什么情绪？如“安全→危险”“希望→误判”“疼痛→继续行动”“戒备→允许靠近”。
3. **人物主动权**：谁在看、谁在逼近、谁在判断、谁在失去控制、谁在改变策略？
4. **视觉命题**：本段用什么视觉关系表达主题？如“暖色客舱被冷色巨物包围”“人被钢栏切割成格子”“狭窄板根逐渐打开成黎明高地”。

如果这四项没有确定，先不要切镜。镜头越多，越容易把没有意图的内容剪得更热闹。

### 多线先于镜头表

按 [多线叙事与交叉剪辑](narrative-planning.md#多线叙事与交叉剪辑) 先确定有效行动线、故事时间关系、观众获知与角色获知，再选择单线/交叉和首次露出、回切、汇合。多角色反打不等于多线；快切不等于交叉剪辑。按场景制作、接近30秒生成均不能决定成片呈现顺序；若已锁定揭晓/限知视角，则不以丰富为由提前露出。

## 二、镜头不是单位，镜头职责才是单位

每个镜头先写一个**观看任务**，再决定景别和运镜。常用观看任务包括：

- **建立空间**：让观众看清人物、威胁、出口、遮挡物和路线的相对位置。
- **建立关系**：让观众看见谁照顾谁、谁调侃谁、谁回避谁、谁掌握距离。
- **交付信息**：给出异常、道具、线索、敌人身份或人物决定。
- **制造信息差**：观众先看见危险，人物尚不知道；或人物知道，观众还不完整知道。
- **跟随位移**：让观众清楚谁朝哪里移动、速度如何变化、路线是否被封锁。
- **看清接触**：咬、抓、撞、拉、递、切、失手、受击的接触点与结果。
- **捕捉反应**：只在反应改变理解、关系或下一步行动时切入表情、手、呼吸或姿态。
- **揭示后果**：展示接触之后的伤势、破坏、位置改变、资源损失或新的出口。
- **表现决定**：用人物停手、放下、回头、伸手、拒绝、靠近或离开完成危机选择。
- **完成转场**：用动作、声音、物体、光线或视线把观众带入下一空间。

> “给每个角色一个惊恐特写”不是观看任务；“让观众看见父亲意识到飞机无可挽回地失控，并因此把母亲拉入怀中”才是观看任务。

## 三、先做视觉弧线，再做镜头表

每个连续剧情段先写一条视觉弧线，格式如下：

```text
起始视觉状态 → 观众期待 → 第一次可见变化 → 主动权转移 → 情绪/信息高潮 → 结尾状态
```

例如《绝境雨林》开场：

```text
暖色客舱安全感
→ 观众先发现雨林异常
→ 巨型森蚺进入飞机航线
→ 艾莉娅终于察觉
→ 巨口咬住机尾、空间秩序崩塌
→ 残骸翻扣在临水斜坡
```

以下是视觉弧线的可选处理，不是题材到拍法的固定映射；先按导演决策流程明确本场重点：

- **安全感阶段**：可稳定观察生活状态、关系或环境；有意义的平静可以停留，不为了避免静止凭空加入危险暗线。
- **潜伏阶段**：少量大景、慢推、遮挡揭示和暖冷对切，给观众时间期待危险。
- **爆发阶段**：接触、受力与后果可能需要快切，也可在清楚的连续动作镜里完成；关键是及时看懂变化。
- **悲痛阶段**：切分重新收住，给脸、手、遗物和空位时间，不能用快切消化情绪。
- **信任阶段**：近景和中近景停留在试探、等待、放低武器、递水和触碰许可上。
- **逃亡阶段**：快切服务路线、策略和主动权变化，而不是单纯增加速度。
- **释放阶段**：镜头逐渐打开，空间变宽，运动变稳，给结尾余韵。

## 四、景别是心理距离，不是镜头装饰

景别变化必须改变观众与人物、威胁或道具的关系：

| 景别/视角 | 适合表达 | 不该做成 |
|---|---|---|
| 大远景/大全景 | 体量、孤立、路线、环境权力、人物渺小 | 只有漂亮风景、没有空间任务 |
| 高位/俯视 | 人物被监视、路线选择、捕食关系、局势全貌 | 无原因的“上帝视角” |
| 中远景 | 人物与环境的关系、动作路线、群体状态 | 看不清动作结果的安全距离 |
| 中景 | 人物互动、完整身体动作、持续位移 | 把所有场景都拍成同一种距离 |
| 近景 | 目的、判断、关系变化、道具交接、动作准备 | 只拍演员“演害怕” |
| 特写 | 信息落点、触发、伤口、握力、视线、关键反应 | 为丰富画面而重复表情 |
| 主观/过肩 | 人物正在看什么、信息差、威胁逼近 | 无明确视线对象 |
| 遮挡/框中框 | 被困、监视、囚禁、关系隔绝、信息延迟 | 把关键动作遮到看不懂 |

同一段不要求覆盖所有景别。只选择能表达本段视觉命题的景别。

### 剧情驱动的多景别与多角度覆盖

**空间统一，摄影自由。**正式剧情主动设计景别落差与观察角度，不把空间测试的固定广角当成默认拍法。先从已确认剧情中找出环境/关系、行动、关键物件、接触、人物反应和决定，再选最能交付信息的景别与机位；不是先凑镜头数量。

- **环境与行动**：全景/中远景建立必要路线、尺度与关系，中景/跟拍看清行动及互动。已经建立且未变化的空间无需每段重复空镜。
- **角色表情近景/特写**：当眼神、嘴角、呼吸、下颌或手部变化决定观众如何理解人物时，给可读的近景；写清刺激源、视线目标与可见变化，并让后续行动承接判断。脸被遮挡、背拍或远景时不塞不可见的瞳孔/嘴角细节。
- **特殊道具/手部特写**：聚焦取出、取得、交接、使用、异常、损坏、遗失、辨认或伏笔回收；交代谁的哪只手、物件在哪、什么部件怎样变化、下一步受什么影响。不把剧情道具拍成无功能的产品展示，不为增加特写擅自新增道具、线索或能力。只写当前阶段已发生的状态，不提前泄露后续才出现的物件。
- **接触/受力细节**：脚踩木板、手指压扳机、锁舌卡住、绳扣松动等，以近景/特写呈现明确接触与结果；选用已确认事件，不靠插入镜头凭空制造新故障。一个镜头能读清则不拆成反复接触。
- **机位选择**：低机位可服务力量/威胁或接触观察，俯拍可服务路线/困局，过肩可建立关系与目光目标，主观镜头可揭示人物发现的线索，侧拍可读清运动/交接。每次换角度必须交付新信息或改变理解，不用无动机的环绕、俯仰和倾斜凑花样。
- **两类连接都可用**：切镜可由动作、视线、声音或遮挡触发，也可在一个镜头内推近/移焦完成信息交接。选择哪种取决于当前观看任务；不把每次景别变化都强制变成剪切。

内部可用「建立目标 → 细节揭示 → 人物反应 → 行动选择/后果」检查因果覆盖，但不把它固定成四镜顺序或要求每段全有。观众可先于人物看到异常，也可通过人物视线后知；顺序服从信息差设计。用户明确的一镜到底、固定机位、风景/纯氛围等保留其形式，通过内部调度或细节变化推进；不因本规范强制加人物或道具特写。

### 主动补足镜头覆盖

**扩写单镜描述与设计切镜是两项工作。**先完成[导演决策流程](#导演决策流程)的整场重点与信息安排，再逐 Clip 检查是否漏拍关键变化。下表是遗漏诊断菜单，不是每类事件必须拍齐的清单；准备、手部、主观、轨迹和反应是否切出，由戏剧重点、知情与时长决定。已够清楚的镜头可保留，支持动作可合并/省略，理由留现有项目记录；不设每 Clip 必须增加几镜。

| 事件触发 | 可选覆盖（按本场重点取舍） | 选用时的正文落点 |
|---|---|---|
| 追逐、围堵、迫近威胁 | 路线/距离镜、被追者反应、其视线里的威胁近景、脚/手受力、出口变化 | 主观镜是谁在什么位置、朝哪看；狼的露齿、压耳、鼻息、前爪推进等具体行为；切回仍在跑或仍被围 |
| 弓弩、投射物、远程命中 | 操作者准备、上弦/装填与锁定、瞄准、释放细节、短轨迹/落点、命中与余震 | 武器实际机制和弹药来源；上弦先于装填/释放，已装填者只拍当前相位；箭跟踪仅覆盖实际飞行的一瞬 |
| 拿取、交接、偷取、交易、藏物 | 双方关系中景、操作/持物特写、接触后的手、知情者反应 | 哪只手拿什么、谁松手、归谁、状态何时改变；听者/旁观者只回应已看见的信息 |
| 伤势、负重、攀爬、失衡 | 身体与支点中景、伤手/落脚/绷带/背带接触、脸或呼吸反应、路线恢复 | 力从哪里传到哪里；特写期间仍在承重，切回继承已完成的接触，不重新跌落或再踏同一步 |
| 隐藏、侦查、辨认线索 | 观察者、主观/过肩所见、线索细节、判断后的行动 | 真实可见范围，隐藏对象不因主观镜提前暴露；被遮住的威胁可以客观插入，但不冒充人物已看见 |
| 器械维修、开关门、日常操作 | 空间中景、机制/手指/接触点特写、声音刺激、结果/听者 | 切到改变状态的部件；放工具后再腾手，先发生声源再接反应，操作仅发生一次 |
| 对话、信任、告别、无意识状态 | 说话者/听者、注意对象、关系中景或持续接触 | 保留完整语句与感知后的反应，不为加角度切碎告别；睡者只保留呼吸、姿态和受移动影响 |

**主观视角有归属与可见边界。**人物正面、过肩或贴近物体不自动成为第一视角。奔跑回望时，主观机位位于被追者眼位、朝身后，摄影机随其前进而远离追兵，追兵仍同向追来；面前拦截须先有超越/掉头/埋伏依据。用回望/注视→实际所见→反应/下一行动连接；方向不同则用明确转头、客观建立镜或连续移动过桥。不可在主观镜中同时拍到观察者自己的完整面部，也不可借此看穿实墙或岩角。

**准备与高速接触用同一事件时钟。**弩在真实机构上拉弦、扣弦、装箭后才能释放，不能照弓的动作一边拉一边放；重弩需要工具时必须继承实际参考机制，未知机构不新增绞盘来凑镜。上弦镜前置到已有准备时间，可与其他人在别处的持续行动交叉；已经待发则只补瞄准/弦扣/扳机细节。释放→短距离箭侧跟踪→接触可在一个秒段内明确快速切镜，飞行不能占满几秒等待人物反应，不能用换角度重射。轨迹镜只在方向、速度或落点需要突出时使用，无此作用可保持射线同框。

**把切镜写进时间轴。**确需拆开的镜头用连续秒段，或在同一动作窗口内明确“切扳机特写→动作匹配切短轨迹→切命中”，写每次机位、景别、相位和衔接。单纯加“缓推/上摇/电影感”不算补齐缺失角度。短瞬间的描写按可见任务保留细节，不按字数强行拉长；时间段数量、镜头数量与独立生成任务数量分别记录，不能把每个插入镜都当新生成。

**交付前逐 Clip 反向核对。**仅看正文，能否定位关键事件的必要空间、刺激/威胁、操作、接触结果与反应？若关键细节仍混在看不清的中远景，调整角度或切镜；反向删掉重复展示、不可见细节和打断必要停留的插入。核对新增切点的轴线、手别、弹药/物件归属、余态、对白窗口及光向，再核整批后段的覆盖；证据与保留理由留 project/现有导演工作单，不增加审批或控制图。

### 事件突出与细节特写

**事件发生只是起点。**重要事件还要让观众看见它改变了什么：谁先感知、谁作判断、谁采取保护或拒绝、环境/群体如何响应、结束后留下什么。先找已有剧情里的这些层次，再决定取景；没有必要时不强行给每个角色反应或增加未确认情节。

可用“事件准备/危险 → 关键动作或接触 → 不同角色的反应与选择 → 环境余波/关系变化”作内部检查。它不是四镜模板，顺序可由信息差改变，一镜也可用调度完成多层。不能每个动作都套一遍，更不能为了拍反应让扑击、箭飞行或下坠停在半空。

| 观察对象 | 要交付的新信息 | 可用细节 |
|---|---|---|
| 威胁制造者 | 谁发令、谁瞄准、距离如何收紧 | 手势引追兵补步，稳弩与逃者失衡对照 |
| 承受者 | 事件怎样改变身体与下一步 | 喘息失序、握力变化、欲返却被重量牵住 |
| 保护者/关系另一端 | 为什么继续、拒绝或放手 | 伤翼塌回后颚间蛋仍稳、鼻端接触结束后的空隙 |
| 已在场旁观者 | 人群/另一角色的态度怎样变 | 停勺、转目、撤步、手停扳机；反应彼此有差别 |
| 环境与物件 | 压力或代价留下的具体痕迹 | 出口露出、爪下雪沟、凳被推回、光越过门槛 |
| 事件余波 | 动作结束后什么没有回来 | 等不到下一次吸气、空位仍暖、接触离开后布凹痕舒展 |

环境参与不能靠凭空加暴雨、震山或爆炸；用已设空间、道具及真实接触产生的变化。现场声音先于反应、跨镜延续或在事件后消失，可以引导注意；不随意加配乐、旁白、魔法音或整场绝对静音。

**细节特写的可执行写法：**

```text
景别/可见取景 → 谁的脸、哪只手或哪个接触点 → 刺激源/注意对象 → 可见动作变化 → 结果与后续动作 → 动作/视线/声音衔接
```

- **脸部**：选两三个可读线索，随刺激变化，如急近爪声引后扫目光、吸气中断、下唇轻颤；随后看回出口继续跑。仅写“疲惫惊恐的脸”不足，不堆瞳孔、汗、泪、牙、肌肉清单。
- **手部**：明确手别与持物、伤势、承重；指节攥紧、压布、停扣机或松手必须回应当下任务。跑者手部特写保留摆臂与喘息，不能忽然停步摆拳；托蛋的手不能同时取刀。
- **接触与道具**：写压力、松脱、滑动和受力结果，像鼻端贴布、爪抓雪又滑开、刀尖挡在壳与袋之间。完整动作已能同框读清时，不拆成反复接触。
- **景别落差**：中远景看距离和退路，中景看互动与位移，近景/特写看微反应和接触；依据当前信息选两类或数类，不机械按全→中→近轮换。
- **切回**：特写期间双方仍在移动/承重；切回时继承经过时间、位置、持物、追兵距离和气息，必要位移先拍连续过程。悲痛/信任留住一拍余波，爆发段不靠延长同一命中凑时长。

追逐编排示例（假定已确认角色左臂受伤、右手空着；秒数只是此例，不是固定规则）：

```text
0s-2s：低位中远景，人物沿贴山路逃向出口，狼从身后追近，狼爪雪粉逼向后靴；侧向跟行保持双方距离可辨。
2s-4s：动作匹配切侧前脸部特写，她张口急喘，眉间绷紧；身后爪声急近，眼睛短扫身后又立即看回出口，头肩仍随奔跑起伏。
4s-5s：切摆动中的右手特写，手指攥紧、指节发白，下一次摆臂又松少许；披衣擦拳背，喘息和爪声不中断，左伤臂仍贴胸。
```

另一类事件可用：硬壳磕桌 → 勺停与目光投来 → 她解释不出 → 推回空凳；敲木硬响 → 小生物缩起 → 敲者停手垫布 → 闷响下它重新探头。例子说明因果观察，不要求所有项目添加硬壳、凳子或生物。

导演意图、观察对象选择和验收说明留内部/项目记录；提交正文只写景别、可见演出、声音与衔接，沿原四段式，不新增“镜头职责/情绪配额”栏目。

### 大幅度空间转移：必须拆镜或用甩镜头过桥

**物理空间发生大幅度转移时，默认不能把起点、长距离移动和终点写成一个连续画面。**这里的“大幅度”包括跨房间/建筑/室内外、跨越多个地标或行动区域、从近处跳到远处地点，以及原画面无法同时保持起终点关系的移动；判断依据是空间内容和观众定位是否发生明显变化，不用固定米数。直接写“人物从A跑到B”“镜头跟着他来到另一处”而没有实际切点，模型容易把两处空间压在同一画面、拉伸道路或让人物瞬移，形成穿帮。

先把空间转移编译成**成片上的真实镜头交接**，再写生成片段：

1. **切镜/分镜过渡（默认）**：前镜在A空间交代离开动作、方向和末态；在动作、遮挡或声音桥处切断；后镜在B空间重新建立入口/落点，承接到达状态、经过的时间和运动方向。时间轴分成两段不等于实际切镜，正文必须明确“切至/动作匹配切/遮挡切”等交接。
2. **甩镜头过桥**：前镜从A空间沿明确方向快速甩出，画面进入连续运动模糊；后镜以同向运动模糊甩入B空间，在B的可辨地标和到达状态上收住。甩镜只负责隐藏空间跳转，不把A和B的建筑、地面或角色状态同时写进一个清晰画面；甩入后必须给B一个可定位的落幅。
3. **用户锁定一镜到底时**：不静默改成切镜，但要标为高风险例外，并写出真实可达路线、中间地标、经过时间、摄影机路径与落幅；若这些条件无法成立，先提出拆镜或甩镜方案。只写“连续跟拍到另一地点”不算可执行的一镜到底。

空间转移提示词应使用正向的起点—交接—终点结构，例如：`0s-2s：人物在院门前跑出画面；动作匹配切至室内。2s-4s：室内入口处，人物从同一运动方向冲入并在楼梯口停下。`或：`院门前侧后跟拍，人物甩向开阔侧形成横向运动模糊；同向甩入室内走廊，运动模糊收在门框和楼梯口，人物继续向上跑。`不要用“镜头从A平滑移动到B”替代切点、甩动和到达状态。

这一规则不要求每个换角度都切镜：同一实际空间的近景、反打、局部和短距离调度仍可镜内完成。只有当空间身份、尺度、连接或行动区域发生大幅变化时才触发；切换后仍须继承主体身份、持物、朝向、速度、光向与声音相位。

### 多角度连续性与可见性

以 [文字空间布局](spatial-layout.md) 为地理依据，每镜选择观察位置与轴线侧。母图的基准视点不是永久摄影机位置；换机位时重推画面左右与光线投影，保持地标连接、高差、人物位置及动作相位。视线正反打要明确人物看向谁/什么，越轴用连续运镜或重新建立镜交代。

**追逐的运动方向先于机位选择。**被追者在前、追兵在后，双方沿同一路线同向移动；“向镜头跑”只描述摄影机关系，不能取代世界坐标。正面机位必须明确被追者位于追兵与镜头之间，追兵从远处沿其脚印逼近；否则用后方跟拍、侧向平行跟拍或高位路线镜。迎面奔来只适用于相向拦截、掉头或封路，并在剧情中写明依据。

**景别切换要有桥接动作。**切入近景时从上一镜正在进行的步伐、转头、拉弦、飞行或受力相位接入；切回中/全景时保留同一位置、朝向、速度、持物和注意对象。可用连续视线、同一声源、动作匹配、前景遮挡或镜内推近/拉远完成过渡；没有桥接依据时先补空间建立镜，或减少切镜。不能在脚部/道具特写后让主体、追兵或投射物重置到新的位置。

特写也要有上下文：道具沿同一持有链传递，手别、接触点、数量与损坏状态继承；切入脸部时其他持续动作不自动暂停，切回中/全景时从当前动作相位继续。特写无需露出整条路线，但下一次空间变化应让观众重新定位，不能靠一直拍脸/脚掩盖人物瞬移。

前/中/远景、面部微表情等字段只写当前构图可见且有用的内容。道具微距不强塞全脸，脸部特写不强塞完整峡谷；光源方向、硬柔与对比写到本镜可辨尺度，不因换机位改变场景光源位置。

### 内部编排示例：过桥察觉异响

以下仅演示导演推导，新增“木板异响”是候选情节，不自动覆盖项目剧情。秒数和镜头数不是配额，也不是完整可提交提示词：

| 观看任务 | 可选景别/机位 | 可见内容 | 接续 |
|---|---|---|---|
| 建立目标与路线 | 入口侧斜后方全景 | 人物从巨石旁抵达近端桥头，前方木桥通向对岸 | 下一镜承接踏桥动作 |
| 发现异常 | 桥头同轴线侧的脚部特写 | 鞋底压上木板，板面微沉并发出吱声 | 足部落定，声音触发注意 |
| 判断危险 | 同轴线侧的面部近景 | 垂眼看脚下、眉间收紧，随后抬眼望向对岸 | 判断引出调整步幅 |
| 决定继续 | 后侧过肩中景 | 人物缩短步幅沿桥中央前进，对岸保留在前方 | 末态供下一镜继承 |

这个例子的特写给出了“为什么改变走法”，而不是重复拍同一次迈步或一张害怕的脸。实际交付将景别、机位、可见动作与切换衔接写进【具体情节】；“观看任务/剧情作用/切点理由”留在内部或块外说明。

## 五、切点由变化驱动，不由时钟驱动

满足以下任一条件时才考虑切镜：

1. 观众需要从“看空间”转为“看接触”。
2. 注意对象从人物转向威胁，或从威胁转向人物反应。
3. 人物主动权改变，策略失效或新策略启动。
4. 接触结果已经读清，需要看受力/后果。
5. 一个道具或视线完成信息交接。
6. 情绪从暖转冷、从希望转恐惧、从惊恐转决断。
7. 新人物/新生物/新空间进入，原构图无法同时清楚表达。
8. 遮挡、动作匹配或声音为切换提供自然动机。

以下情况不构成切镜理由：

- “已经过了两秒”。
- “需要多几个特写”。
- “镜头数量不够”。
- “想让画面更丰富”但没有新的观看任务。
- 同一个反应换一个角度重复一次。

## 六、长镜头与有意义的停留

长镜头和有意义的停留是正常可选拍法，不设单镜3秒上限；按事件、对白、关系变化与经过时间决定持续多久。每个 Clip 总长仍不超过30秒，放不下时压缩或顺延；分行、编号、推近或移焦不自动变成新镜头，也不要求靠切镜凑固定数量。

持续镜头可以靠调度推进，也可以让观众承受等待、犹豫、缺席或失去。先判断停留的作用；不要求每秒添加表情、手势或移动。需要镜内推进时，可选：

- 人物关系动作链：抓扶手→被安抚→松手→被调侃→主动合影。
- 空间揭示：从人物动作带出窗外异常，或从局部移动渐渐显出完整威胁。
- 视线推进：人物先看道具，再看对方，再看出口/危险。
- blocking变化：人物靠近、错开、遮挡、让位、扶住、放下。
- 背景信息变化：后景鼓起、灯光扫入、烟雾打开、远处物体进入航线。
- 声音变化：远处声源逐渐逼近，人物笑声被环境声吞没。

长镜头验收问题：

> 如果缩短或移去这段停留，是否损失等待压力、人物判断时间、关系变化或事件余波？若没有任何损失就缩短；若经过时间本身使选择/失去被感受到，就保留，即使构图与动作很少变化。

## 七、反应镜头的导演标准

反应镜头不是“演员做一个表情”，而是让观众看到角色的判断正在改变。

一个有效反应镜头应包含：

```text
刺激出现 → 视线/身体捕捉 → 信息进入 → 判断改变 → 下一动作准备
```

例如巨型森蚺咬机：

- 不先连续切四张惊恐脸。
- 先看机尾被咬，观众明白失控原因。
- 切父亲抓住母亲，表达保护本能。
- 切卢卡斯压低艾莉娅，表达快速判断。
- 切艾莉娅看见舷窗外巨眼，表达她终于理解威胁尺度。
- 回到驾驶员拉杆，表达补救失败。

反应镜头必须改变观众对局面的理解，或证明人物下一步为什么这样做。

**把情绪写成可见表情，不写标签。**惊恐不写“惊恐”，写瞳孔骤缩、眼睛瞪大、脸血色褪尽、嘴半张、下巴发抖、肩猛缩、手指抠紧；配合人声状态（猛吸气后失声、颤声、屏住呼吸）。声音并入这镜的动作描述、不单列声音行。

## 八、好莱坞级动作段落的五层覆盖

动作大片的镜头丰富，不是因为切得多，而是因为同时管理五层信息：

1. **尺度层**：大景让巨兽、飞机、山峰、河谷或营地体量可信。
2. **空间层**：中远景交代路线、出口、遮挡和相对位置。
3. **接触层**：近景/特写看清咬、抓、绳、锁、门、脚、武器的真实接触。
4. **人物层**：反应、保护、判断、失手和关系变化。
5. **结果层**：碎片、泥浪、伤势、位置改变、资源损失和下一次威胁。

五层不要求平均分配，也不要求每个镜头全都有。动作高潮前优先保证尺度与空间，接触发生时优先保证接触与人物反应，结果出现后重新建立空间。

## 九、好莱坞级空间与摄影机原则

- **先建立可读空间，再允许碎切。**观众不知道人物在哪，快切只会制造混乱。
- **大景不是空镜。**大景必须让观众看见体量、路线、威胁或主动权。
- **摄影机运动有动机。**跟随谁的目标、逃离谁的威胁、揭示什么空间、承接什么受力，都要写出来。
- **镜头运动不能替动作完成任务。**先写清人物怎么动、对象怎样响应，再写摄影机怎样看见。
- **切在动作上，但不要切掉后果。**接触瞬间可以切，受力结果必须被读清。
- **保持轴线与屏幕方向。**尤其是追逐、兽袭、飞机航线、笼舍逃脱和溪沟路线。
- **用前景遮挡制造压力，不遮住关键接触。**叶片、栏杆、笼网、板根和舷窗都可以成为叙事框架。
- **每个大场面要有一个记忆构图。**例如“笑脸手机后景鼓起树冠”“标枪贯穿翼兽钉在树上”“冷白探照灯照出猿人编号”“晨光中并肩背影”。

## 十、场景决策与片段执行记录

先在现有 project/导演工作单中按[导演决策流程](#导演决策流程)记整场结论，再按 Clip 展开执行。简单场景可用几句，复杂场景用表；不为同一内容重复填写多份表格。与[导演编译](director-compiler.md)共享这些决策，五维工艺与落幅是执行校验，不替代戏剧判断。

```text
本场变化、人物目标/阻力与代价：
核心重点 / 必要支撑 / 可合并连接：
有效行动线与故事时间关系：
单线/交叉选择及理由：
各线首次露出、回切新增信息、汇合/揭晓点：
观众/角色各自知情、切离期间各线如何继续：
空间锚点、调度及表演证据：
主方案：停留 / 镜内交接 / 切镜；选择理由：
重点与前后支撑的景别/声光关系：
真实动作、对白、阅读及余波时间：
删除/合并/保留的镜头及原因：

| Clip/时段 | 观看任务与主次 | 可见行动/响应 | 景别/视点/调度 | 切或留的理由 | 时长/接缝 |
```

落幅核对：地标位置、身体朝向/视线、左右手持物、动作相位/动量、可见情绪与气息。控制需求按具体风险选最少输入；未生成仍注明视觉未验收。决定与证据归入[统一调用与验收总表](production-checks.md#统一调用与验收总表)，不混入复制用四段式正文。

## 十一、交付前导演自检

从整场回到 Clip，依次核对，发现问题回到最早缺失决策处修复：

1. 核心变化与重点是否仅靠画面/声音即可成立？人物的选择、代价及知情有依据，摄影没有替剧本宣布未经发生的转变。
2. 重点与支撑是否有主次？连接过程是否抢走转折/后果时间？先做删除与合并，再判断缺失覆盖。
3. 为什么选现在的观察立场、景别和时机？主观归属与遮挡正确，观众知情和角色知情分开，揭晓未被技术镜泄露。
4. 切、镜内交接与停留是否经过比较？每次切换让信息、关系、压力或理解推进；有意义的静止和重复有保留依据。
5. 关键接触、表情和后果在取景里可读？不能硬写当前看不见的脸、伤手或背景，不能只加景别词证明设计。
6. 动作同步、接缝去重与整场节奏是否成立？扑击/飞行/跌落不等反应拍完，武器准备继承真实机制，伤势/负重/持物不因特写重置。
7. 全场与全批是否都复核？段间情绪与行动线离画有依据，后段不缩水，也不复制首段的拍法和密度。
8. 镜头数量与时长是否来自实际观看任务、动作和表演，而非固定镜数或3秒切点？同镜续写/推近/移焦是否仍按连续镜头理解？每个 Clip 总长是否≤30秒，超量是否已压缩或顺延且接缝成立？
9. 成片时段、生成分组、场景图双向映射与素材状态是否一致？四段式/对白lint证明字面，不证明以上导演质量或生成效果。

## 十二、禁止的机械化分镜习惯

- 每30秒固定五镜、七镜、十一镜。
- 每隔两秒自动插一个特写。
- 景别按大全景→中景→近景→特写轮换。
- 每个角色平均分配惊恐表情。
- 用快速切镜掩盖空间不清和动作因果不足。
- 无依据地拖长停留，或为有意义的静止硬加微动作。
- 每次受击都加镜头震动、白闪或慢动作。
- 先决定镜头数量，再把剧情硬塞进去。
- 用“大片感、震撼、电影级”代替尺度、位置、受力、光线和镜头职责。

> **顶级导演的判断不是“我还能再切几个镜头”，而是“观众此刻最需要看清什么，以及我应该让他在什么时刻看见”。**
