# 导演编译：把分镜决策转成块结构提示词
镜长、切点与节奏复核见 [事件驱动的镜长与节奏](shot-rhythm.md)。


本模块吸收 Seedance 分镜师 3.0 的导演三重表征、分镜卡、五维工艺与状态交接方法，作为 `video-script-studio` 的内部编译层；不是新流程、不是另一套输出模板。与 [导演分镜](directorial-shot-design.md)、[叙事规划](narrative-planning.md) 配合，控制图与修复另见 [控制与返工](director-control-retake.md)。

动作、对峙、对白及跨Clip改写同时执行 [动作同步、接缝去重与整场节奏](narrative-planning.md#动作同步接缝去重与整场节奏)：先后/并行共用事件时钟，前尾后首不重演，按整场累计问答等待与行动线缺席；剪辑顺序改变后复核新接缝。

## 1. 不变的交付契约

- 完整视频仍为Higgsfield 块结构（[参考资产]→[角色]…[生成目标]→[具体情节]→[视觉风格]→[镜头]→[声音]→[保持一致]），模型、时长、画幅等设置在复制块外。默认秒级时间轴，不迁入九段式或无秒数 B 轨。
- 阶段与样本按 [样本确认流程](sample-approval.md)。下述工作卡和检查由助手执行，不增设全剧拷问、全集镜头表确认或实图门禁。
- 保留 `project.md`、`asset-registry.json`、`prompts/`，Clip 使用 `批-序`，不创建第二份资产索引或连续性总账；用户已有分镜表时引用其原路径。
- 保留中文资产名；所有 `@中文名` 集中在复制正文第一块 `[参考资产]`，每项一行 `@资产 对应 名称。介绍/本段状态/参考用途：…`，原有职责、持物、伤势、尺寸与用途紧随标签保留。其余块只用名称补充群演、关系与空间，不重复资产行已有信息；人物首次出场附一个可见标记。`中文名@中文名` 仅用于资产/场景身份标题。平台槽位只有在真实文件及绑定映射明确时才输出，不编造槽位。固定位置与去重见[固定资产入口](template-general-director-2-5.md#固定资产入口)。
- 保留用户预算、接近所选模型单次上限的默认编排目标、紧张题材快慢波浪节奏与动作强度/速度轴。近上限必须有真实内容支持，不靠重复动作、放慢或无意义停顿凑长；内容不足或负荷过高按现有规则合并/拆分。源包的时长、主体数和重抽次数经验不升级为平台硬限制。
- 原生 JSON、HTML、图像、纯音频按各自格式；本模块仅映射相应内容，不额外附一份块结构长稿。

## 2. 同一内容的三个层面

先继承 [导演决策流程](directorial-shot-design.md#导演决策流程) 的已选主方案：场景变化、核心重点/必要支撑/连接、观众知情、调度、切或留取舍与时长。尚缺这些决策时先完成判断再写正文，不能由编译阶段用更多特写代做导演选择。每场先判断：**人物要什么、什么阻挡、行为如何改变局面，观众因此先看到/后知道什么。**然后同时对齐：

| 层面 | 应解决的问题 | 信息落点 |
|---|---|---|
| 戏剧意图 | 目标、策略、代价、信息差、情绪方向 | 导演工作单/块外摘要；确认的结论进 project.md |
| 银幕表现 | 可见动作、可听事件、空间关系、观察角度和节奏 | 分镜决策及起态→动作→末态 |
| 生成表达 | 本次素材职责、时序、动作与运镜、必要约束 | 块结构复制正文 |

反向读回：只看正文，能否还原分镜的关键行为？这些行为是否仍完成原意图？不能就修转换，不用更多形容词掩盖。编译只转换表达，不擅改确认对白、剧情、镜数或顺序；必须改动时先更新对应规划并按样本流程呈现受影响范围。

多线任务先读取 [多线叙事与交叉剪辑](narrative-planning.md#多线叙事与交叉剪辑)。分别对齐故事事件顺序、成片呈现顺序和素材生成顺序；按确认的成片计划编译，不按角色或资产清单重新分组。区分观众看见与人物获知，切离期间的状态推进也须进入回切落点。生成分开时保留现有项目内的剪辑入出点映射；不新增独立交付体系。

编译前完成 [生成分组验收](narrative-planning.md#生成分组与短段例外验收)，每次修改后执行 [修改后标准复查闭环](production-checks.md#修改后标准复查闭环)，读回最终完整条目并核受影响接缝/依赖；交付前按 [统一调用与验收总表](production-checks.md#统一调用与验收总表) 检查实际正文。人物直接调用已有表演与FACS适用部分；非人按其适配，不能在编译时漏掉情绪/听者要求。

## 3. 精简分镜决策卡（内部）

引用导演中枢已有的场景决策和片段执行记录，编译时仅补缺少的工艺与衔接，不重复抄一遍大表。下列项按需合并到原记录；不适用项注明原因，不能为填格加剧情。

| 项 | 最低有效内容 |
|---|---|
| 定位与任务 | Clip 批-序、片内镜序/时间段、所服务的场景重点、该镜改变/深化的理解 |
| 起态与材料 | 在场主体、关键持物、地标关系；只取本镜所需 |
| 行动与表演 | 刺激→策略/判断→行为→反馈，写到可拍的部位与落点；多人按[互动闭环](higgsfield-acting.md#双人和多人互动闭环)补关键听者/旁观者的反应过程、余态与主体接续 |
| 台词与声音 | 原句、说话人、语气、触发动作、声源；无对白明示 |
| 摄影与光学 | 景别、机位/轴线侧、焦点、主运镜及终点；景深按需 |
| 光线 | 世界内光源、相对机位的方向、硬柔、对比；曝光取舍按需 |
| 时间与呼吸 | 动作/对白/反应的预算，串行与并行关系 |
| 意图证据 | 人物任务与物理行为成对；为什么切/留、为何删并的依据来自场景重点，不能只报新增几镜 |
| 落幅与衔接 | 位置、朝向与视线、左右手持物、动作相位、可见情绪落点 |
| 控制需求 | 不加图/构图帧/站位图/动线控制，具体风险及用途 |

这张卡是本次编译依据，不是第二套真相源。已确认镜头计划的数量、顺序、对白与交接状态，必须在正文找到对应落点。未要求交镜头表时只呈关键抉择摘要，不把内部卡混入提示词。

## 4. 五维工艺核对

### 表演：先给人物任务，再选微动作

内部用 **目标→障碍/代价→策略→变拍→潜台词** 理解行为；不把主题或导演愿望当演员任务。近景微表情是任务的结果，不是每镜固定加“咬牙、眨眼、握拳”。

- 目光有具体对象：看门锁确认出口、观察对方指尖是否松开，而非无缘由左右扫视。换目标与转头的先后只在当前动作需要时写。
- 听者与旁观者按[互动闭环](higgsfield-acting.md#双人和多人互动闭环)编译，不是只给主体写满演出后补“其他人看着”。核当前任务、信息到达、可见响应与持续状态；主体感知到反馈后有合理接续。听者单独入镜时其反应写进动作/表情；不给昏迷者、背影或画外角色硬塞面部反应。
- 潜台词通过分层行为表达：脸上维持礼貌，收回的手却攥紧袖口；不同时堆相反的夸张表情。
- 全片既定表演幅度优先。累积疲劳、伤势、气息与已确认关系影响下一场，不自动恢复初始状态。
- 写成 **动作动词＋肢体＋方向/目标＋速度/力度＋时序＋落点/反馈**。一次主变化可含有因果的动作链；“同时”必须真能并发。
- 复杂动作用明确相位减少歧义，不宣称模型只能演静态。只有前镜已交代准备、或用户授权省略时，才能以动作中段开场；不得跳过关键接触与后果。

### 空间：底图与机位分层

固定地理以共享场景总表 `layout` 或单次场景的已确认文字布局为准；本镜实例化机位侧、轴线、地标绑定、画面方位、可见范围、站位变化与越轴路径。无需复制整幅地图。起点→路径→终点与身体朝向、视线分开写；换机位重推画面左右，不改变地理连接。

角色进出门先执行[门槛方向锁定](spatial-layout.md#32-进出门门槛方向锁定)，再编译到定位秒、动作与结束状态；内部机位标签不进入正文，但“从门外朝门洞内拍摄”等必要观察关系进入`运镜：`，不能因去元语言删掉方向证据。

**大幅度空间转移先编译成切镜或甩镜头，不写成单画面空间插值**：编译时按 [拆镜或甩镜过桥](directorial-shot-design.md#大幅度空间转移必须拆镜或用甩镜头过桥) 写出 A 空间离开末态、明确交接方式（动作匹配切、遮挡切或同向甩镜）与 B 空间入口/地标落幅。时间轴分行不等于真实切镜，反向检查时确认正文出现了交接方式和 B 空间落幅；一镜到底例外的条件也以该节为准。

每条有人物的 Clip 按 [Clip 边界隔离](narrative-planning.md#clip-边界隔离强制) 以约1秒定位秒开场，`[声音]` 写 `0s-1s｜<名字>轻声：{Hm.}` 锁定站位。新空间的其余建立信息可以在后续有剧情动作的镜头内完成，不必再插静止全员照。

### 摄影：一种主导运动，起手和落幅都明确

按已选切/留方案编译，再用 [主动补足镜头覆盖](directorial-shot-design.md#主动补足镜头覆盖) 查遗漏：核心重点在画面里有没有读清，支撑镜有没有喧宾夺主，连接能否合并。主观/操作/接触/反应镜只在需要时独立切出，镜内交接也须具体可执行。主观镜写观察者位置与实际所见，武器操作写当前相位，轨迹镜接同一次释放到命中；不增加每Clip镜头配额。

先写人物怎么动，再写镜头怎样看清。主运镜说明观察位置→跟随对象/路径→终点构图；复合运动必须由同一动作因果衔接，不能并列堆“环绕、推近、上摇”。固定机位明确写固定。中文正文用中文摄影语言；光学写可见结果，如背景逐渐虚化或前后关系保持清晰，不强加不可执行的设备参数。

### 光：有来源，有曝光立场

沿同版布局指定的窗、灯、天空等光源写方向＋硬柔＋对比。剧情确定昼夜，影视参考及其地区、季节确定受光和曝光；夜景交代必要地形、表情与动作信息。人物携带火把或移动灯具时，在对应动作中写移动路径、照到的对象和光线变化；环境图写实际已有的天光与固定光源。剪影或逆光按叙事需要保留明暗层次，换角度继承光源位置，开门、遮挡和灯灭按实际事件改变光线。

物理反馈写到控制点：重量转移、受力方向、摩擦、衣物延迟、碎屑/湿污残留。既服务动作，也让光影随物体变化；不额外虚构损坏。

### 声音：随动作发生，保留说话权

对白逐字写进 `[声音]`：先 `对白语言：英语。`，再每句一行 `起s-止s｜说话人＋可见状态/气息/语气＋说话动词：{英文原句}`（Higgsfield 写法）；非英文注明语言。说话人、画外声与旁白区分清楚，未要求不新增旁白。听者用自然倾听动作，不跟口型。

音效由动作＋材质＋距离/方位＋相对强弱构成；画外声音允许保留，但须明确来源方位，不为解释声源把人物提前入画。环境底声按场景简洁取用，动作声在触发处叠加。默认 NO BGM；用户要音乐时写进入/退出节点及与人声的关系。严格静音优先，不为五维齐全硬加声音。

对白 `{原句}` 写在 `[声音]` 的计时对白行，音效 `<…>` 写在当段 `声音：` 行，环境声与音乐（仅用户要求）`(…)` 写在 `[声音]`；`动作：`/`表情：` 行只写看得见的发声动作（张口、喘气、手拍桌面）。跨 Clip 混音仍可走现有后期交接，已登记的音色描述可写入[角色]等状态块，已有音频参考按真实职责使用。

## 5. 从决策卡编译到块结构

| 原信息 | 块结构落点 | 不进入正文 |
|---|---|---|
| 素材绑定、控制图与参考声明 | 开头 `[参考资产]`：每项一行，所有标签集中；其余状态块按名称写职责与排除项 | 磁盘路径、待绑定状态、审批记录、全库资产名单、剧情与状态变化 |
| 本片段主要事件、关键变化或结果 | `[生成目标]`，用一个具体句子便于模型理解本段 | 风格/运镜堆叠、导演自评、空泛过程套话、后续片段结果 |
| 摄影、空间、表演、光、接触音效 | `[具体情节]` 的对应时间段，用景别词与“切至”，不编号；对白进 `[声音]` 的计时对白行 | 内部任务名、评分、切点论证、镜头编号、机位/落幅/起幅等术语、“省略/承接/完成后才”等说明 |
| 末态、入点、Clip 边界 | 每段末句写一个看得见的结束状态；Clip 最后约1秒动作完成、镜头静止；下一条第一段换镜头，用定位秒把位置、朝向、持物、光写到位（见 [Clip 边界隔离](narrative-planning.md#clip-边界隔离强制)） | 另增结束状态/衔接栏目、引用其他段或其他 Clip、动作/运镜/台词跨过 Clip 边界 |
| 当前片段固定项及开关 | `[视觉风格]` 按[全片风格短句](higgsfield-style.md#全片风格短句)复用已确认画风/配色，再补本场光照；`[镜头]` `[声音]` `[保持一致]` 分别放切镜锁定、声音开关、连续性 | 长篇负面清单、范围外角色与物件、情节复述 |

**全片画风不属于资产外观去重项。**按[全片风格短句](higgsfield-style.md#全片风格短句)把实际短句放进每条 `[视觉风格]`；不能因为已有角色/场景参考而删掉，也不能只剩本场色温和灯位。这是对资产已定画法与配色的辅助继承，不是视频阶段的二次设计；已知图文偏差按[资产图先定画风与细节](higgsfield-style.md#资产图先定画风与细节)回相关输入处理，不堆视频风格词强压冲突参考。

**资产外观归资产，单次对象留视频。**先执行[独立视频提示词门槛](asset-registry.md#资产建立门槛按独立视频提示词计数)：共享资产负责形态与外观，单次未建资产者可在映射块的文字行与相关画面中写足必要身份、外观／结构和场景关系，不编造 `@`，不因无独立图省略可读信息。已采用独立参考的对象沿用下述去重要求。对已采用独立参考的资产，视频各块均不重写五官、发型、服装设计、固有色、纹理、材质、比例、解剖结构或建筑造型。[角色]等状态块只列本镜直接引用及必要职责、状态/年龄版本；[具体情节] 各段写行动、表演、受力、位置、路径和变化；[保持一致]保留必要风格、连续性与声音开关。未生成／未绑定的素材状态留块外，不抄整段资产提示词来冒充已具备参考。纯文字提交或本对象没有实际参考时，从已确认的共享设定编译必要可见描述；单次未建资产者按其文字设定描述，二者都不重新设计身份。

分镜中需要强调的视觉信息必须是动态或叙事性的：湿污如何出现、伤势如何影响动作、道具何时进入手中、谁把什么交给谁、结构怎样受力破坏、人物如何改变位置。删除无关静态外观描述，但保留从共享布局提取的本镜必要地标关系、路径和空间锚点；不抄整段场景布局，也不因“去重”删掉动作所需方位。

资产文件与总表不会随提示词传给模型。所有标签及其原有介绍、状态、尺寸、音色与参考用途集中在开头 `[参考资产]`；后续块只补没有参考的对象和未交代的关系/空间，不再重复 `@` 或删去功能。未绑定状态、素材路径和审稿说明留项目记录，不进入模型正文。

**概述归事件。**概述用一个完整句子说明本段谁经历什么、发生何种变化/结果；镜头与风格回 `[具体情节]` 或 `[视觉风格]`。逐条删除空泛模板句，不能把标题加通用摄影过程当概述。

**固定项少而稳定，变化项有过程。**同场只复用本片段所需的风格、地标、光源及真实声音来源，不复制整套角色外观或场景陈设。每条独立复制必须自包含，不能只写“同上”“继承上一镜”；也不能把后续才用到的内景、角色、道具提前带入。

**可跟随不等于简略。**删同义反复、抽象解释和看不见的细节，保留触发、接触、反馈、持物、时序和结束状态。重点不同可有不同句长，但批量后段不能缩水为梗概。情绪气口计入时长；同一事件不能因换机位再演一次。

### 转换示例（仅局部，不是完整交付）

已确认事件：递还钥匙后等待对方接住。

- 弱：她悲伤地递出钥匙，电影感运镜。
- 可执行：她右手捏住钥匙环递到柜台中央，指尖仍勾着环；镜头从柜台侧面中景轻推至双手近景，钥匙碰到玻璃发出一声轻响。
- 任务可读：对方伸手时，她的指尖才松开钥匙环，目光从对方的手移到门口；镜头停在柜台同侧，侧窗柔光沿指背滑过，玻璃反光保持低对比。钥匙已在对方掌心，她的右手收回柜台外缘。

最后一版让“为何停留、何时放手、归谁持有”可见，而不是多塞几个表情词。实际秒数须按项目镜头节奏分配。

## 6. 连续性与交付核对

连续相邻 Clip 按[独立生成与同场切镜](narrative-planning.md#独立生成与同场切镜)核对故事状态和剪辑依据；不要求相邻独立生成的首尾姿势逐帧相等，也不做首尾无缝衔接。同场剧情、问答、搜查可跨段，但每条按 [Clip 边界隔离](narrative-planning.md#clip-边界隔离强制) 在静止的尾镜收住，下一条换镜头、用定位秒写足自己所需状态；持续飞行、奔跑在边界前收住。默认先切镜后调分段，不为每段闭合另造换场或跳时；真实跳时仍须有剧情依据。

内部逐缝核对五项：**地标位置｜身体朝向/视线｜持物及手别｜动作相位/动量｜可见情绪与气息**；再检查持久变化：伤势、湿污、服装、破损、场景破坏、时间天气和未收回道具。动作匹配缝保留动势，不能为“明确终点”强迫落地收势；段落结束才按剧情停稳。动作相位核对用于防止重演、复位与因果失配，不等于要求独立生成接准尾帧；“停稳等下一步”也不是接缝已修复的证据。

### 穿帮高发点逐项排查

五维与五项落幅通过后，再按下面各类排查最常见的穿帮（通用，不限动作）；每类只在适用镜检查，不逐镜套全部。

| 类别 | 要问的问题 | 典型穿帮 | 修法 |
|---|---|---|---|
| 视点可见性 | 本机位真能看见写出的东西吗？背拍、过肩、窄缝、遮挡、特写各自能看到和看不到什么？ | 背对镜头却描述其身后物件；窄缝/实墙后却看清门内；脚部或道具特写硬塞不可见的脸或远处中箭 | 删掉当前取景看不见的信息，或换到能看见它的机位；画外信息只用可听声或下一镜交代 |
| 物理可达与手别 | 这只手此刻空着吗？单手能同时完成几件事？交接双方在可及距离内吗？ | 一只手同时提袋又取刀；隔开数米却完成递接；持续撑住的手又去做别的 | 先写放下/腾手/换肩的过渡动作；交接双方先进入同一可及位置；承重的手保持占用 |
| 资源守恒与归属 | 这件道具/钱/食物一开始归谁、有几份？用掉或交出后数量对吗？ | 同一份钱先在A手又在B手；同一份食物被装两次；交出后又凭空持有 | 写明初始持有人与数量，消耗/交接写在发生节点，之后不再凭空出现 |
| 进出门方向 | 按[门槛方向锁定](spatial-layout.md#32-进出门门槛方向锁定)还原起始侧与目标侧，是否符合用户意图？ | 用入画当进门、出画当出门；门外拍正脸却让出门者返回门内；切镜重跨 | 回该节核语义、定位秒、跨门动作与末态，按同一门两侧修复，不以摄影机方向推断进出 |
| 通行姿态与通道 | 门/横木/洞口的真实高宽允许这样通过吗？遮挡物此刻是开、合还是半开？ | 低矮门口直身穿过；实木挡板未移开人却进出；门状态在相邻镜自相矛盾 | 按布局尺度写屈身/侧身/移板动作；进出前先交代遮挡物当前开合状态 |
| 距离与行程 | 已经离开的人/物，按经过时间应在哪里？能回到画面吗？ | 已上路的人下一镜瞬移回原地去扶另一主体；追兵离画后无依据地立刻折返 | 按离画时长推导位移；回到画面须有合理行程或改为伸手不及的反应 |
| 进出介质与声音 | 换了地面／空间，脚步声、风声、光照介质跟着变了吗？ | 已进室内却仍是雪地脚步声；进背风处风声不减；换机位主光跟着搬家 | 介质变化写进该镜声／光；室内外、背风／迎风、昼夜按布局固定项推导 |
| 空间关系与构图自由 | 固定地标、靠山/开阔侧、追逃前后是否清楚？屏幕坐标是否确有必要且匹配参考？身体左右和画面左右是否分开？ | 图像与视频各规定一套相反左右；伤侧随机位翻转；脚部特写后人物突然靠墙 | 按 [相对关系优先](spatial-layout.md#方位描述相对关系优先构图按需固定) 保持连接与追逃关系，构图按需锁定；关键退靠、超越连续拍清，特写保留动作与持物 |
| 复制镜残留 | 这段是从相邻镜复制改写的吗？被复制段的状态／光效／情绪句都仍然成立吗？ | 有泪镜的“眼泪”被复制进没有流泪的邻段；“取近景”等上一镜措辞残留 | 复制后逐句核对：删掉本镜不存在的状态（泪、伤、持物）、改掉照搬的景别／机位措辞 |
| 群演与配角身份唯一 | 执行某动作的配角是不是指向唯一一个人？和同场其他镜说法一致吗？ | 群演行写“牵狼者之一或循迹猎人”并列二义，模型随机选人；同一人跨镜身份漂移 | 身份只留一个，并与同场其他 Clip 的人员清单对齐（如“五人中的另一名猎人”） |
| 同框道具可辨识 | 会在同一镜／相邻镜同时出现的道具，颜色、形状是否可区分？ | 包扎布与裹食布都写“浅麻灰”，同框分不清；两件布被当成一件 | 同框道具给可区分的颜色／形状并写进资产或构件行（如包扎布浅麻灰、裹食布生麻米白泛黄） |
| 阵营与称谓一致 | 正文、群演行、相邻镜对同一队伍用的是同一称谓吗？ | 正文写“佣兵”、群演行写“灭烬团”，读者／模型当成两拨人 | 固定一个主称谓，另一处用括注对齐（如“灭烬团群演（正文称佣兵）”） |

排查结论并入下方交付自检与 [统一调用与验收总表](production-checks.md#统一调用与验收总表) 的空间/连续项;属语义检查,名称与块结构 lint 不覆盖。

在 `project.md` 现有 Clip 序列附近记当前场末快照和未解线头；逐条需要时引用正文末句与版本，不另写一份文学性总结。资产状态文件仍按总表登记，只有实际需要状态参考图才新增衍生图，不为每次状态变化强制生图。

交付自检：
1. 结构、时长、镜序、对白覆盖和引用是否与确认稿一致？
2. 去掉概述和意图说明，只读正文，场景重点、选择与后果能否成立？切/留/删并的原因能回溯已定方案？五维在正文能定位，或有不适用说明，不能靠五项齐全代替戏剧重点？双人/多人另遮住主体描写，关键听者和有关系旁观者是否仍有可追溯的刺激、响应与余态，主体又是否合理接续？
3. 持物/动作是否重复、重置或凭空转移？结尾能接下一条？主观镜是否看得见所述对象、弩的上弦装箭是否先于释放、箭跟踪是否把瞬间飞行拖成等待？
4. 每条独立复制能执行，且未泄漏范围外内容/上游注释？
5. 如有缺陷，给定位、原文证据、影响和最小修复；先修文本再交付。

自动检查只证明结构与字面覆盖；人物意图、空间、绑定、真实口型及画面质量必须另核。无生成结果写“未生成，视觉未验收”，没有审核子代理则如实写单代理核对，不新增工具门禁。
