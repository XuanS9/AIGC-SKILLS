# 动作摄影机指南

本文件提供通用摄影术语和选镜方法，不提供可直接套用的固定剧情句。摄影机需要服务动作可读性，不能代替动作本身。

按 [共享叙事规划规则](narrative-planning.md) 与 [动作导演指南](fight-director.md)，先确定事件、因果和连续状态，再按呈现工作量推导切点、镜头数量与时长。不预设镜头数、单镜时长或等长块，故事段、时间块和镜头也不必一一对应。

## 镜头句式

每条运镜尽量写全六项：

```text
〔景别或焦段〕 + 〔机位高度与角度〕 + 〔运动速度〕 + 〔摄影机方向〕 + 〔跟随对象〕 + 〔本镜职责〕
```

示例格式中的占位符需要按当前场景填写：

```text
〔焦段〕低机位中景，摄影机以〔速度〕沿〔方向〕跟随〔角色或物体〕，让〔接触、距离或结果〕保持清楚。
```

## 镜头职责

| 职责 | 画面需要回答的问题 | 可选方式 |
|---|---|---|
| 建立空间 | 人物、出口、障碍分别在哪里 | 大全景、俯拍、侧向全身景 |
| 追随位移 | 谁朝哪里移动，速度怎样变化 | 平行跟拍、侧后跟拍、贴地跟拍 |
| 看清接触 | 动作是否命中，接触点在哪里 | 侧向中景、短促特写、动作匹配切 |
| 表达反制 | 主动权怎样发生变化 | 反应近景、轴线同侧切入、回接双人景 |
| 表达失衡 | 受力方向和身体姿态怎样改变 | 倾斜、短幅翻滚、沿受力方向追随 |
| 展示弹道 | 释放者、路径和目标怎样关联 | 过肩景、长焦压缩、高位距离景 |
| 揭示结果 | 谁获得位置优势，环境发生什么变化 | 快速后拉、升镜、遮挡物移开 |
| 稳定收尾 | 结果清楚后保留哪些运动 | 固定构图、稳定跟随、慢速轨道移动 |

按当前事件实际需要覆盖镜头职责，不以镜头数量触发额外任务。“四镜以上尝试覆盖不同职责”仅是可选设计示例，不是补镜要求。相邻镜头连续执行同一职责时，需要有明确理由；同一长镜可以随状态变化调整构图并承接事件。

## 按动作事件选择镜头

以下是按需选择的摄影方法，不是固定阶段序列，也不要求每项单独成镜。切换观看位置应帮助看清事件、因果或状态变化；同一动作内可切镜，连续事件也可在镜内完成。

### 起动

- 用全景或中景同时建立角色、路线和第一步动作。
- 需要速度时，摄影机沿主角前进方向移动。
- 需要空间判断时，使用高位或侧向机位。
- 纯打斗入口在动作条件具备时尽快出现有效动作；既定剧情需要观察、辨认或等待触发时，保留其信息与因果任务，压缩无任务停留。

### 距离变化

- 横向移动使用平行跟拍，保留双方间距。
- 折线逼近使用高位景，交代掩体与路线。
- 高度变化使用低机位起跳加高位落点承接。
- 改变机位时保持屏幕方向和人物左右关系。

### 接触与格挡

- 接触前用能够看见双方身体的景别。
- 接触瞬间可以短促推近、轻微震动或切到侧向特写。
- 接触后立即承接受力、位移和环境结果。
- 不在接触即将发生时用遮挡或过近特写藏住动作。

### 远程攻击

- 释放前交代武器、手部或能量来源。
- 用过肩景或长焦景同时建立射手、路径和目标。
- 关键投射物可以短暂追随，普通投射物优先直接切到落点。
- 命中或落空后回到释放者，交代换位、装填或资源变化。

### 反制

- 反应镜头保留上一镜的视线方向和动作状态。
- 切到对手侧时维持轴线，随后回接双人景确认接触。
- 特写只拍正在变化的状态，例如握力、重心、视线或武器角度。

### 受击与结果

- 摄影机沿受力方向承接失败方的移动。
- 先拍身体接触部位，再拍墙面、地面或道具反馈。
- 结果明确后拉开景别，同时保留尘土、碎片、衣摆或其他余波。

## 三档强度搭配

| 阶段 | 高强度 | 中间型 | 慢节奏 |
|---|---|---|---|
| 起动 | 低机位快速跟随 | 中景定向后切入 | 长镜建立路线 |
| 位移 | 贴地或侧后跟拍 | 平行跟拍 | 轨道移动 |
| 接触 | 动作匹配切、短促推近 | 接触特写加双人回接 | 侧向全身景 |
| 反制 | 轴线同侧快速切入 | 反应近景 | 长镜内部改变构图 |
| 远攻 | 落点切回、短暂弹道追随 | 过肩景、高位距离景 | 长焦保持路径关系 |
| 受击 | 沿受力方向快速追随 | 中景承接位移 | 长镜看完整结果 |
| 收尾 | 快速拉开后稳定 | 中景转全景 | 稳定轨道离开 |

极速版补充：三档强度都加快动作执行和镜头衔接，可优先使用快速跟随和有空间依据的摇甩；慢节奏压缩无叙事任务的慢速轨道开场，仍保留完整的发力与受力过程。特写可缩短冗余停留，例如 0.4 至 0.8 秒的短推近，仅为可选示例，实际时长由关键接触与状态识别工作量决定。默认不使用慢动作，必要的决定性命中强调遵循指南的可读性规则。不得为了极速版增加切镜配额、改变固定剧情或截断对白与反应。

## 连续性记录

每次切镜前记录至少以下信息：

- 人物左右位置
- 面朝方向和身体姿态
- 运动方向与速度
- 武器所在手、角度和完整状态
- 弹药、能量或道具数量
- 对手是否还能行动
- 场景损伤和移动物体
- 仍在持续的尘土、火花、液体或光效

切镜只改变观看位置。已经发生的事件不能因机位变化被重置。

## 声音配合

- 每个分镜只控制本镜：写明需要听到的现场环境声、对白和随可见动作触发的音效。独立生成的镜头不能读取上一镜音轨；不能只写“沿用上一镜”“继承全局声场”。
- 同一地点的风雨等声源仍存在时，本镜可用一句话重新说明该声源；这只定义本镜听感，不承诺两次生成的声纹、音量或相位相同。声音变化须有本镜可见的依据，例如进入室内后雨声变闷。
- 普通镜头按可见动作选择同步声；极短镜头只保留必要声源，不为填写声音栏新增无关音效。每个音效应能在画面或场景中找到来源。
- 默认 NO BGM，不在分镜中生成连续配乐；用户明确需要整片配乐时另列后期音轨与混音需求。跨镜环境声、对白接点和音效尾音的连续性在剪辑/后期按成片统一处理，不能靠分镜提示词保证。

## 常见误用

- 连续快速切镜导致左右位置交换
- 摄影机运动过多，身体动作被遮住
- 每次命中都使用震动，画面失去层次
- 普通投射物全程跟随，压缩了角色反应时间
- 慢动作覆盖完整倒地过程，节奏被拖散
- 收尾只剩静止姿势，没有保留任何环境运动
