【六大招演出铁律】

镜头组一（0—5秒）【万道经文·镇天狱】

开场即在战斗中。@小师妹悬浮于断桥上方，右掌已经向下压出；断桥下的魔潮向祭坛奔涌，两只飞行魔物从她左后方俯冲。

第一层玄金古文在她身后竖向展开，第二层沿天空横向铺开，形成具有上下距离的巨大经文天幕。经文不是贴在画面上的文字，而是具有厚度、透光边缘与空间遮挡关系的法术实体。

飞行魔物逼近时，她向右侧滑移，身体旋转避开尖翼，手掌仍保持向下的施法方向。上层经文随手势压入魔潮，前排流体躯体被压低、核心暴露，后排立刻沿两侧石阶绕行。

大型精英从中央强行跃起，撞裂最下层经文。她五指收拢，断裂文字沿其身体两侧重组为符文锁链，将它拖回祭坛边缘，撞出第一圈石面裂纹。

特效与结果：玄金经文分层下落，紫金波纹沿石面传播，冰蓝雾气被压力推向四周。天门残柱和祭坛边缘留下持续发光的经文烙印，被压碎的魔物残骸留在裂缝之间。

运镜：背侧中景随主角侧移 → 顺着下压手势快速俯视 → 短暂广角看清天幕与祭坛 → 回到侧前中景，看见她翻掌引燃尚未落下的经文。

声音：<层叠低鸣由高空压近，锁链收紧锐响，石面闷裂>

镜头组二（5—10秒）【凤凰涅槃·焚万军】

承接翻掌动作，尚未落下的经文转为紫金燃烧的羽骨，从空中反卷到@小师妹身后。她向天门方向斜上方加速，羽骨沿同一运动方向展开，构成完整凤凰的头颈、躯干与巨大双翼。

凤凰第一次振翼，将冰蓝火浪沿断桥表面推出。火浪贴着石面翻卷，前排魔物被掀起，后排立刻攀上两侧断柱，从较高位置跃入。

第二次振翼时，紫金火羽从翼缘分离，沿弧形轨迹穿过这些跃起的魔物。飞行魔群趁双翼抬起，从凤凰腹部与主角之间的空隙高速穿入；她旋身上提，一只尖翼擦过原先肩部位置，衣摆被气流甩向镜头。

凤凰随后俯冲，沿断桥至祭坛的方向横扫，迫使地面魔潮向右侧浮岛边缘退挤。

特效与结果：凤凰保持冰蓝半透明灵体、紫金燃烧翼缘和玄金羽骨纹路。扫过区域形成黑蓝色琉璃焦土；此前经文烙印仍从焦黑石面下透出，已经倒下的魔物残骸被火浪推积到断柱根部。

运镜：侧前中近景看凤凰成形 → 拉开至广角读清双翼轮廓 → 沿翼侧跟随俯冲 → 凤凰翼面擦过镜头形成转场。

声音：<凤凰长啸穿过风压，火羽密集掠空，岩石受热爆裂>

镜头组三（10—15秒）【星河倾覆·彗星陨狱】

凤凰翼面离开镜头后，摄影机位于主角侧下方，远处仍可看见同一座残缺天门。@小师妹抬指指向苍穹，凤凰残余火羽向上飞散，成为云层裂口边缘的星点。

第一颗巨大冰蓝陨星穿出云层，紫金熔核在晶体外壳内脉动。它先落向祭坛外缘的魔物密集区，撞击产生向外滚动的石浪；随后多颗陨星从不同高度沿交错轨迹坠下，形成连续推进的落点。

魔潮向尚未受击的断桥底部与右侧石台逃窜，大型精英停在残柱后方，向空中投出暗红能量团。主角横向急移避开能量团，再向上拔升，让一颗陨星从她下方穿过，撞中正在追赶的飞行魔群。

特效与结果：陨星具有清楚的实体体积、长尾和落点，冲击波沿已有焦土扩散。祭坛外缘形成巨坑，断桥中部进一步崩落；原有经文烙印随石块一同断开，不能完整悬在已经消失的桥面位置。

运镜：低角度中景看抬指与云裂 → 跟随第一颗陨星俯冲但在撞击前侧移避开 → 广角看清连续落点 → 沿上冲尘浪抬回主角。

声音：<陨星掠空的低沉啸声，错落连续的撞击，桥体崩塌>

镜头组四（15—20秒）【一指天隙·次元斩裂】

承接向上翻涌的陨击尘幕，@小师妹从尘幕侧缘横向飞出。她没有停住蓄力，右手沿飞行方向划过，第一道巨大裂隙在她身后被逐渐拉开。

裂隙边缘呈不规则紫金断面，内部为没有实体纹理的深黑空间。第二道裂隙在祭坛右侧竖向出现，第三道倾斜贯穿魔潮的退路，三者处于不同纵深，不组成平整法阵。

飞行魔群从第一道裂隙上方绕入；地面精英利用陨坑作为掩护，从下方跃起。她突然下沉避过扑击，再向侧后方折返，原位置紧接着被暗红触须贯穿。随着她手腕转动，裂隙之间的空间发生错位，将来袭魔物分流卷入。

特效与结果：魔物流体躯体被拉长、分解为黑红能量后吸入裂隙，不出现写实残肢。右侧浮岛边缘断裂下坠，原有陨坑被截去一角；裂口收窄后留下微亮的空间疤痕，主体轮廓仍可见。

运镜：侧向跟随手势与裂隙同时展开 → 横移展示前中后三层裂口 → 跟随主角下沉躲避 → 从裂隙外侧绕至云海方向，不穿入深黑虚空造成无依据换场。

声音：<紧绷的空间锐响，低频撕裂，碎石落入云海>

镜头组五（20—25秒）【北冥开界·鲲鹏吞潮】

主角从浮岛外缘折返到云海上方，双臂短促向两侧展开。此前掉入云海的发光碎石突然被上升气流托起，整片云层沿巨大弧面向两侧隆起，显露鲲鹏背部的玄金纹路。

鲲鹏先露出脊背与头部，再展开遮住远处天门一部分的巨翼；体量通过它与天门、浮岛和主角的比例表现。第一次振翼把云海推成冰蓝巨浪，巨浪冲过浮岛边缘，将魔物卷离石面。

尚未被卷走的飞行魔物贴着巨翼逆风前冲，精英魔物伸出暗影触须锚住断柱。主角沿鲲鹏肩背上方加速侧移，避开交叉触须，再将双掌向中心收拢。鲲鹏张口，流向由横向冲刷转为朝口部汇聚的螺旋吸流，触须被绷直、断开，残余魔群失去支点。

特效与结果：吸流中能分辨魔物、碎石与黑雾的轨迹。仍有一批魔物处于外围，尚未被完全吞没。云海被推开形成持续旋转的巨大空洞，露出浮岛下方断裂岩层；经文、焦土、陨坑与空间疤痕继续存在。

运镜：广角看云层隆起与鲲鹏完整出现 → 沿巨翼侧面高速跟随 → 转向主角收掌动作 → 鲲鹏翼缘掠过前景，衔接终招。

声音：<鲲鹏低频长鸣，气流由外推转为内吸，触须绷断>

镜头组六（25—30秒）【五法归一·无上归墟】

翼缘遮挡结束，@小师妹位于中央祭坛正上方高空，远处残缺天门作为方位锚点。前五招的力量从各自遗留位置重新显现：石面经文升起，凤凰残焰沿空中重组，陨坑内的星核发亮，空间疤痕张开，鲲鹏在下方保持展翼。

25—27秒，五种力量向主角周围汇聚，保留各自形态和空间层级。玄金经文构成领域边界，凤凰沿边界回旋，星辰悬于上方，裂隙连接上下空间，鲲鹏托住领域底部。

外围剩余魔物同时发起最后一次冲锋。地面魔群从陨坑间跃起，飞行魔物从天门两侧俯冲，精英沿断柱残端扑向主角。她向侧面短促闪避一只逼近的飞行魔物，随即转正身体，将右掌压向下方祭坛。

27—29.5秒，终焉领域向整个战场展开：经文首先限制魔潮的冲锋路径，凤凰火浪沿经文间隙席卷，星辰穿过裂隙落向不同高度，鲲鹏海潮自下方托起，将仍在挣扎的魔物送入交叠力量中。五种力量共同作用，不能简化成一团无法辨认的巨大爆炸。

最后冲击越过浮岛，魔物核心暗红光芒依次熄灭，躯体塌落到石面或随重力落向低处。主角身前的粒子被冲击推开，面部和蓝色神纹重新清楚显露。

运镜：中近景看五种力量汇聚与主角避击 → 快速后撤为广角，完整展示领域和既有战场 → 沿冲击扩散方向短距离推进 → 落到稳定的侧前中景作为尾帧。

声音：<五种法术声逐层叠合，终焉冲击形成一次低沉巨响，随后转为余波风声和残骸落地声>

【结尾状态与交接｜包含在最后0.5秒内】

@小师妹仍悬浮于画面中央偏上，身体保持刚完成下压施法的姿态，右掌缓缓止住，黑发、衣摆与蓝色饰带被余波吹向同一方向。额间神纹明亮，周身冰蓝薄雾与少量紫金雷纹持续存在。

后方五种法相逐渐衰减，不能突然全部消失。下方清楚保留破裂经文烙印、琉璃焦土、巨大陨坑、断桥缺口、倒塌石柱和浮岛断面。云海涡旋仍在缓慢转动，玄黑暗红残骸分布在祭坛、坑沿和断柱根部。

没有新的魔物补入。主角不落地、不转身离开、不收剑，以仍具压迫感的悬浮状态结束。

- 新任务必须重写角色、资产职责、目标、空间、行为和分段演出；不能仅替换姓名并保留本例的招式、颜色、敌群与废墟。
