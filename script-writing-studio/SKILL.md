# 剧情短剧文案工作室

和用户讨论清楚之后再开始。讨论确认前先明确用户要创作或修改的内容、核心方向和关键限制；信息不足且会改变剧本结果时先讨论，不直接输出正式剧本。

本Skill可独立使用，面向3–30分钟的奇幻人兽斗剧情单片或单集，长期服务同一主题下的多部作品：人类、兽人、异兽、魔兽、远古生物、实验体及其他非人智慧生命之间的生存、冲突、合作、追猎、守护、背叛或情感关系。每部作品可以更换世界、人物、冲突机制、情绪方向和结局，不预设固定的起承转合、人物组合、反转类型、价值终点或镜头套路。默认只创作明确成年的角色（18岁以上），年龄、外形与性别组合服从人物功能和用户设定，不自动年轻化或美化。用户明确要求涉及未成年人、学校或亲子关系时，先核对具体设定与风险边界；不得用“少年/少女/学生感”制造年龄模糊，也不让未成年人出现在危险、暴力、受伤、追逐、被威胁或被生物攻击的剧情中。

## 1. 核心目标：稳定控制视频节奏

用户提供参考视频时，优先提炼其**节奏、信息组织和情绪推进**，不把参考作品的生物、场景、人物关系或剧情链直接变成模板。

重点检查和创作：

1. **开场进入速度**：在奇幻人兽斗主题内，尽早让观众看见人类与非人生命的关系、当下目标或异常，以及局面为何不能照常继续。可以是追猎、领地、交易、囚禁、救援、误认、战争、契约、繁殖/幼崽保护、资源争夺或关系压力，不规定必须用灾难开场。
2. **有效变化密度**：每个戏剧单元至少推进事件、关系、信息、策略、情绪或选择之一。节奏不是单纯语速、切镜数量、音量或反转频率。
3. **持续变化而非重复加码**：前一个行动造成后果，后一个人物因此改变策略、处境、理解或关系。连续刺激必须改变问题性质，不能只是更大的同类障碍。
4. **刺激与反应配比**：强事件后保留足以理解因果、人物判断和情绪回落的时间；安静段也必须有信息、关系或选择变化。不能为了“快”删掉关键反应，也不能用空镜和重复哭喊拖时长。
5. **悬念的承诺与兑现**：前置异常、线索或未完成动作，在中段获得局部回报，结尾兑现主要承诺；开放结尾只能扩展新的问题，不能用截断掩盖核心问题未解决。
6. **情绪曲线**：根据题材安排恐惧、希望、压迫、亲近、误解、释放、悲伤或兴奋的转向，不要求固定顺序，也不要求每场反向翻转。
7. **人物驱动节奏**：变化来自人物目标、判断、选择和阻力，而不是作者连续投放事件。对手可以强硬、恶意或自私，但必须拥有能实际改变局面的资源或行动。
8. **信息负担控制**：画面能表达的内容不重复解释；必须说出的信息要在会改变行动的位置出现。复杂世界观通过可见行为、限制、道具和后果逐步建立。

## 2. 参考视频的可复用节奏模型（服务主题，不规定剧情模板）

用户提供的雨林人兽斗案例可作为同一主题下的一种**高密度奇幻动作节奏参考**。它提供的是节奏基准，不是每部作品都必须复用的故事结构：

- 先以强烈异常打破平静，再快速补足人物关系与环境风险；
- 在同一空间或连续行动中叠加多个危险信号，让观众形成“危险正在逼近”的预期；
- 重大灾变改变人物目标，从原任务转为求生；
- 每次暂时脱险都带来新处境，而非简单回到原点；
- 中后段通过一个看似更危险的角色改变观众判断；
- 用动作、道具和伤痕完成关系与身份信息，不依赖解释性旁白；
- 在高强度追逐之间插入短促但有效的喘息，让信任、恐惧或疑问累积；
- 结尾兑现一次主要情绪回报，再留下能够自然延续的世界问题。

以上只约束节奏质量，不固定六段结构、固定食物链、固定“怪物救主”、固定五幕比例、固定人兽关系或固定结局。可以写高密度追逐，也可以写领地谈判、囚禁试探、族群战争、共同狩猎、契约破裂、怪物保护幼崽或人类被迫依赖兽人；关键是主题始终属于奇幻人兽斗，具体起承转合服从本部作品的冲突机制、情绪目标、世界规则和人物选择。

## 3. 叙事与人物质量

- 先明确人物此刻想得到、保住、逃离、证明或拒绝什么；再设计阻力和后果。
- 冲突通过行动、拒绝、试探、误判、施压、反击或选择发生，不靠所有角色轮流发表观点。
- 反转需要前置证据，并改变观众对人物、事件或下一步风险的理解；不为追求“炸”而凭空添加秘密。
- 对手动机可以不正当，不强制洗白；主角也不必每次成长、胜利或道德升华。
- 重要情绪落在可见行动、距离、道具、声音和选择上，不把“他很善良”“她很痛苦”当作场面本身。
- 每场都检查“因此/但是”关系：行动带来什么结果，结果怎样迫使下一步改变。
- 根据本部奇幻人兽斗故事决定使用动作、奇观、对白、沉默、误会、关系试探、族群规则或环境危机；不强加灾难、死亡、反派、食物链或某一种人兽关系。

## 4. 写作前故事梗概表与导演预演

凡是进入正式剧本正文写作（从零创作、续写、重写或大范围改编），在正文之前必须先给用户一张“故事梗概表”，让用户先看到故事骨架。梗概表不是空泛简介，也不是把正文提前写一遍，至少应呈现。表中还必须标注全片预计时长、各主要段落的大概时长、开场承诺出现时间和首个有效变化的预计时间，用于提前发现开场铺垫过长、信息重复或节奏风险：

- 故事承诺：开场让观众期待什么、核心危险/问题是什么。
- 主角目标与代价：主角想得到或保住什么，失败会失去什么。
- 主要阻力与对抗关系：谁或什么阻止主角，以及阻力如何实际改变局面。
- 关键事件链：按因果列出开场、推进、升级、转折、高潮和结尾回报；不强制三幕或固定段数，并为每个主要段落标注大概时长。
- 信息与伏笔：哪些信息先以画面、声音、道具或行为埋下，何时局部兑现或改写理解。
- 人物选择：每个关键节点由谁做出什么选择，选择怎样产生下一步后果。
- 情绪路线：观众在主要段落中经历的期待、紧张、误判、希望、恐惧或释放。
- 结尾状态：本片承诺如何兑现，留下什么新的问题或余韵。
- 时长与开场节奏：全片预计时长、各段预计时长、开场承诺最迟出现位置、首个有效变化最迟出现位置，以及可能造成退出的啰嗦、重复解释或无变化停留。这里是创作预估和风险检查，不是平台数据承诺。
- 制作初判：关键地点、演员/生物、复杂动作、特效、特殊道具和可拍性风险。

建议使用表格，字段可按作品缩减，但不得省略故事骨架、因果链、结尾状态、预计时长和开场节奏检查。时长采用“预计/约”而非实测；若开场在前置环境、人物介绍或解释性对白上停留过久，必须在梗概阶段提出压缩、前置异常、合并信息或改用画面表达的方案。若信息不足以写表，先集中询问会显著改变题材、时长、结局或核心关系的事项；非关键细节可标为暂定。新增细节必须服务用户已给的冲突和结局，不另造无关的高风险支线；幼崽、未成年角色或未成年人处境只有在用户明确要求并核对边界后才能写入。用户未确认梗概表时，不进入正式正文。用户已明确要求直接续写已确认骨架时，可先用极简表复述继承内容，不重复阻塞。

### 故事梗概与完整剧本的边界
故事梗概表与完整剧本是两个不同交付阶段，不得用一种交付物冒充另一种：
- **故事梗概表的目的，是确认剧情走向。**它应呈现故事承诺、人物目标、阻力、关键事件的因果链、选择与后果、信息释放、情绪路线、结尾状态和预计时长；动作只写到能判断事件及结果的程度，不展开连续攻防、空间调度、受力过程、表演反应或完整对白。
- **完整剧本的目的，是展示剧情细节并使其可执行。**它必须把已确认的事件扩写为完整场次和连续动作—反应回合，写清人物如何行动、躲避、失手、受伤、利用环境、改变策略以及动作结果如何引出下一步；同时交付完整对白、声音、转场、场末状态和连续性。
- **大纲里的动作名场面不是动作剧本。**例如“豹人以标枪击杀翼兽并救下女主”属于梗概事件；完整剧本还要展示翼兽如何逼近、女主为何无法脱身、标枪从何处出现、命中后的惯性与二次危险、豹人如何利用结果继续解围，以及女主的反应和关系变化。
- 用户确认梗概，表示确认剧情骨架和明确设定，不表示已确认完整剧本的动作细节、对白或制作拆解；进入正式剧本后，助手应在不擅自改变已确认走向的前提下补足细节，并明确这是正文草案。

正式正文前必须进行一次导演预演：先设计观众应该先看到什么、后知道什么，以及镜头如何制造期待与反差，再安排人物对白解释。开场和重大危险不默认按“人物先聊天→危险突然出现”的顺序书写。可优先考虑：

- 先展示危险、异常、结果或空间关系，再切入人物处境，制造信息差。
- 用大景/俯视/远景建立环境与威胁，用近景道具、声音或动作埋伏笔，再切人物反应。
- 让镜头顺序服务悬念、反差、因果和情绪，不为凑镜头而切镜。
- 人物对话必须同时承担目标、关系或必要信息；能由画面表达的内容不重复解释。
- 重大事件前检查空间、路线、视线、声源、光源、道具和行动顺序，确保观众能理解危险如何逼近。

例如“贵族家庭乘直升机进入雨林”不能机械写成先拍机舱聊天、再突然被森蚺攻击。若森蚺是核心威胁，可先用雨林大俯视展示巨蛇穿行、积水和可能的降落区域，再切到机舱内家族因某个具体目的进入雨林；两者形成尺度与安全感反差，并为事故预埋空间或行为原因。具体顺序仍服从本故事的因果和情绪，不把该例固化成所有作品的模板。

### 任务类型快速判定

| 用户请求 | 默认处理 | 正式改写/制作门槛 |
|---|---|---|
| “帮我看看这个剧本” | 会诊，指出证据、影响和可行修订 | 不擅自重写全文 |
| “把这个剧本改好” | 先明确保留项与改动范围，再做实质性再创作 | 重大方向先确认；局部授权可直接执行 |
| “按原稿做视频” | 保持剧情、人物和对白，转入制作交接 | 文案确认后委派 `script-package-production` |

| “只润色这段对白” | 只改对白与必要表演提示；若未提供需要润色的原句，先索取原句。用户明确授权根据情境新写时才拟写对白，并标明是新写 | 不擅自改变事件结果或人物关系 |

## 6. 默认规格与边界

- 适用：3–30分钟单片或单集；具体片长由用户指定，不偷偷默认5分钟。
- **角色年龄与外形边界**：默认使用明确成年的角色（18岁以上）。年龄、外形、性别组合和吸引力服从人物功能、题材气质与用户要求，不自动年轻化、美化或固定为“年轻男女”；不得出现年龄不明的少年角色，涉及未成年人、学校或亲子关系时先核对具体设定与风险边界。
- 默认输出：M1影视正文采用剧本总表 + 场次表，不交散乱段落；中文写场景和动作，英文写对白，用户指定语言或格式优先。
- 默认先核对：题材、核心情绪、受众、单片/单集、具体时长、语言，以及必须保留或允许改变的内容；缺失且会改变成品时再集中询问，非关键细节可合理暂定。
- 在保持奇幻人兽斗主题的前提下，不固定三幕、五幕、起承转合顺序、反转次数、钩子频率、切镜数量、对白密度、演员数量或结局类型。参考资料中的现实、历史、家庭和专业案例只用于抽取叙事机制，不自动改变题材，也不要求每个作品强行加入生物冲突。
- 不承诺完播涨幅；节奏判断是创作分析，不等于平台数据或观众实测。
- 历史、知识、安全和专业题材仍需按适用资料核验；奇幻和虚构不能掩盖现实专业误导。

## 7. 交付与确认

对外交付读取 `references/06-writing-delivery.md` 的结果格式契约；正文格式以 `references/04-screenplay-format.md` 为准。只交本次请求范围，表格组织正文/设定/诊断，完整替换结果优先于修改说明。完整正文包含标题、预计时长、场号、地点/时间、人物、可见动作、必要对白、声音/转场和结尾状态。交稿标明 `copyVersion`、草案/待确认状态、改编或虚构边界、节奏策略、待决定项及真正影响制作的风险。

交稿前检查：开场承诺是否清楚；变化是否有效而非重复；刺激、判断和反应是否匹配；人物是否依据目标和能力行动；线索是否前置并获得回报；对白是否重复画面；结尾是否兑现本片主要期待。用户明确确认具体版本后，才进入制作阶段；新稿不覆盖旧确认版生产配置。

测试案例：`tests/story-writing-cases.md`；本 Skill 本地结构与链接检查：`python3 tests/validate_skill.py`。工作区级检查（若存在）：`python3 .pi/tests/check_drama_skills.py`，不作为本 Skill 可移植运行的前置依赖。

## 8. 独立安装与整合后的交接兼容

本包已完整保留原有 20 份主题资料、资料索引、测试案例与校验脚本；单独安装即可执行本 Skill 的全部文案工作。以上各项创作、审稿、版本确认和交付约定继续适用。

本次三套整合包中的制作提示词入口为 `video-script-studio`。文案确认后，用户需要资产准备、分镜或视频提示词时，若该 Skill 可用，可按名称交接给它，传递已确认的 `copyVersion`、剧本正文、人物/世界设定、不可改项、预计时长、已知制作规格和待决定项。后续先核对制作规格，再执行对应任务；不把文案确认当作模型生成、消费额度或发布的授权。

原资料中的 `script-package-production` 与 `canvas-production` 名称仍保留，供已有这些能力的环境使用；它们并未包含在用户提供的源目录里，不是文案 Skill 的安装前提。`video-script-studio` 可承接其自身支持的资产/分镜/提示词工作，但不假定它实现原外部 Skill 的全部私有接口。画布交接要区分 Higgsfield Canvas 与其他产品画布，不把两者混用。环境没有可调用的制作或画布能力时，仍完整交付确认文案和制作交接说明，明确尚未执行的步骤，不虚构委派成功。
