# 3–30分钟：片长、场序与人物发展

## 1. 先确认时长单位

适用范围为3–30分钟的单片或单集，不是一次生成的时长，也不是默认全季总长。创作前明确单片/单集/全季、具体目标及允许浮动；不从3–30中偷偷选5分钟、30分钟或中间值。已明确的旧项目目标直接继承。整季任务记录每集目标与集数；局部修改继承原片长，不重问全项目。

M1影视正文为默认；横竖画幅、平台、类型、真人/动画不由时长推定。系列与独立作品都可写，3–30分钟不等于全部是高密度爽剧。用户明确需要范围外作品时说明其属于扩展任务，不强行缩到30分钟。

## 2. 时长改变容量，不规定套路

下表是组织取舍，不是每档必须采用的结构或固定分幕时间：

| 片长范围 | 优先检查 | 常见风险 |
|---|---|---|
| 3–8分钟 | 主行动与必要关系是否清楚；关键选择有铺垫、反应和结果 | 用解释对白塞进过多背景；只剩反转，没有人物过程 |
| 8–15分钟 | 情节能否持续改变策略/关系；中段有新的信息和局部回报 | 把5分钟故事拉长，反复争论同一个问题 |
| 15–30分钟 | 场与场的因果接力、人物策略演变、主副线汇合与充分回报 | 副线游离；前半反复铺垫，后半靠独白或巧合收尾 |

15分钟既可完成一个集中冲突，也可容纳多场发展；30分钟不强制副线、群像或三幕。3分钟也可有完整人物选择，不等于必须快剪。非线性、单场长谈、无对白、群像和喜剧均按其机制设计。

## 3. 场序与情绪曲线

完整创作内部建立场序账：场号、当下欲望/阻碍、入场条件、行动与新结果、关系/信息变化、预计时长、对下一场的影响。记录本场让人物改变什么，不逐场凑反转或高潮。

- 开场尽早让观众获得明确观看理由，可来自处境、承诺、关系、异常或情绪吸引力；不规定3秒冲突、15秒反转、30秒爆点。
- 中段让行动产生后果、迫使人物调整策略。主线推动时可同时改变关系；副线有自己的目标，并在信息、行动、关系或主题上与主线相互作用，不能只填时长。
- 强弱节奏有因果：攻击后给必要反应，重大决定前保留判断过程，安静段也有关系/信息变化。长片不能一直吼，短片不能省掉情绪可信度。
- 设置与回报台账只追真正承诺过的事项。人物可成长、退化或保持立场，不强制和解、洗白或统一升华。
- 非终集先有本集实质兑现，再留下新后果；终集/单片允许闭合与余韵，不用未完成动作代替结局。

## 4. 自然时长核算

按场估计对白、旁白、阅读/观察、操作、沉默与转场。并行动作与对白计算实际占用区间，不重复相加；串行动作、必要停顿和独立片头/片尾另计。自然语速结合人物、语言、术语和情绪，不用文学字数或一页一分钟机械估算。

英文120–160词/分钟、中文3–5字/秒只可作初估起点，不是保证。重要长谈/激烈争论宜朗读或排练计时；未知则写估算及误差，不冒称实测。无对白按动作和观察时间估，不把时长记为零。

输出区分：用户目标、自然表达估算、排练实测（若有）。超出允许浮动时集中给保留内容/改变目标/精简或拆集的选项；拆集改变交付结构，必须经用户同意。不要把5分钟变5分40秒，也不要把30分钟变一份5分钟摘要。

## 5. 长稿完整性与接续

全片先有完整因果与结尾方案，正文按稳定场号展开。需要分批时沿自然场界交付，不截断对白；接续记录人物所知、情绪、道具、伤势、时间与未兑现承诺。批次不是分集，不新增每批悬念来迎合输出窗口。

明确已交场次/估时、未交范围和接续点；摘要不能冒充剩余正文，先写完的几场不代表全稿确认。只确认部分则记录部分，完整文案确认后下游才处理对应范围。持续完成已授权范围，不逐批询问继续，不承诺后台自动续写。

本模块只设计叙事与估时，不读取模型秒数或拆生成任务。修改与确认按 `16-copy-confirmation.md`；具体语言和表演按 `13-dialogue-polish.md`。
