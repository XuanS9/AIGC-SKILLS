# 知识情绪型剧情：让知识成为戏剧的发动机

## 与通用叙事的关系

`15-dramatic-tension.md` 是跨题材叙事底座；本模块只增加知识因果、事实/改编与领域准确性，不把所有故事锁定为科普、历史、4–5 分钟或强冲突。创作/会诊继承 叙事张力 的承诺回报、情感张力和观众追看检查，再执行本模块；事实与安全不能被完播目标覆盖。

## 1. 触发与边界

凡知识科普故事或用户要求“有张力、有看点、调动观众情绪，同时分享知识”时，与当前的 创意开发 / 正文写作 / 文案会诊 / 对白精修 模块组合使用。覆盖历史人物、商业改革、科技发明、工厂作业与安全生产、驾驶、婴幼儿照护、家庭安全等，不限于历史。不是新的强制全流程，也不替代常规虚构剧本能力。历史题材按需读 `17-history-facts.md`；安全生产/驾驶/婴幼儿/健康等题材从创作阶段起读 `18-professional-facts.md`，不能等到分镜阶段才纠正知识。

用户提供的案例只用于识别有效机制，不是情节模板或事实来源。用户后续纠正优先于早期风格分析。不得默认锁死为“伟人金句开场—提出发明—成功伤害工人—加薪—普通人购买产品”；双重决策、小人物视角、道具回扣、4–5 分钟都只是可选设计。本Skill面向3–30分钟作品，按 `00-preflight.md` 明确具体时长与单片/单集单位，不借同类案例替用户选片长。

目标：**冲突吸引注意，悬念维持追看，知识带来认知变化，人物选择兑现情绪。** 不承诺播放量、完播率或爆款效果。

## 2. 写作前的最小设计

信息足够就直接创作。内部先明确下面六件事；用户要正式稿时，只简短展示必要假设，不先输出一整套咨询问卷。

1. **观众入口**：观众先替谁担心、对什么不公愤怒，或被哪个异常吸引？
2. **具体欲望与损失**：人物现在必须完成什么，失败会失去什么？损失通过账单、订单、身体、职位、关系或操作结果体现。
3. **知识承诺**：看完能用自己的话解释哪一个机制？通常围绕一个核心认知，辅以少量必要事实，不堆百科。
4. **戏剧发动机**：目标和哪一项现实限制冲突？对手、制度、物理条件、资源或人物误判怎样推动下一步？
5. **情绪变化**：起始感受、关键转折后的感受、最终余韵；不要把“愤怒”写成全片不变的音量。
6. **真实与制作边界**：哪些是已核事实，哪些需核实，哪些是戏剧化场面？演员、场景、机器运动的预算风险在哪里？

可用的一句话检验：

> 为了____，人物必须____，但____；当____暴露后，他/她只能在____与____之间选择，观众由此理解____。

这是一项内部诊断工具，不要求每次按这个句式交稿。

## 3. 知识嵌入因果，而不是对白讲课

每个核心知识点建立一条可追踪链：

`K 编号 → 原有误判/未知 → 可见证据或试验 → 机制解释 → 改变的行动/选择 → 后果及适用边界`

- **删掉测试**：去掉这条知识，人物是否仍会做同一个决定、剧情是否原样成立？若是，它可能只是装饰性科普，改成行动证据或移到片尾资料。
- **因果测试**：先后发生不等于因果；工资、成本、产量、利润、需求之间不能只凭几句台词画等号。交代必要条件，避免把多因事件归功于一个人的一次灵光。
- **理解测试**：至少给观众一个可以看懂的例子、对比、操作或后果。专业术语随后命名即可，不让两位专家互讲早已知道的基础知识。
- **数字测试**：每个数字需明确年份、单位、比较基准、测量对象和适用条件。“底盘装配时间”不能扩写成“整车从原料到交付耗时”。真实政策中的资格限制也不能为了爽感省掉。
- **结尾测试**：观众最后带走的是可准确复述的知识，而不只是“某人伟大”。传播点可以是反直觉机制、日常物件的新理解或真实两难，不必硬塞金句。

## 4. 张力与悬念的设计工具

按故事选择，不必每项都用：

| 机制 | 可执行设计 | 失效写法 |
|---|---|---|
| 时间或资源耗尽 | 最后一批材料、真实存在的交付期限、仅够一次试验的预算 | 随意编造历史倒计时或假死亡威胁 |
| 两难选择 | 两条路各有可见损失，主角无法同时保全 | 明显正确的一边对抗集体降智 |
| 信息差 | 观众先见危险，角色未察觉；或角色知道证据但观众尚未看清 | 隐瞒视角人物自然会说出的信息，只为最后反转 |
| 证据反转 | 提前展示线索，新证据改变对问题的理解与行动 | 无铺垫揭身份、路人忽然递来解决一切的答案 |
| 胜利的代价 | 效率、可靠性、成本或人的处境暴露新限制 | 每个故事都强加“创新伤害某个工人” |
| 不可撤回的行动 | 签字、公开试验、退回订单、交出权利等改变局面的动作 | 每场开会争论，结束后一切照旧 |

开场优先选择具体危机、反常结果、当场两难、利益冲突或行动悬念。身份和年代通过必要字幕或场景简短定位，不先铺人物生平。不伪装成实录，不用与核心故事无关的血腥、羞辱或假危机吸引注意。

一个悬念的回报必须与承诺相关。局部答案可以引出更深的问题，但不能一直欠答案。

## 5. 结构与情绪不套模版

选择最适合真实材料的一种结构，或合理组合：

- **危机解题**：具体故障 → 初步办法 → 试验揭示更深限制 → 付代价的选择 → 有边界的结果。
- **认知悬疑**：异常结果 → 几种解释交锋 → 证据排除错误解释 → 机制揭示 → 重看开场。
- **利益碰撞**：各方合理利益 → 方案让利益冲突显形 → 谈判/试验/拒绝 → 得失同时结算。
- **成功与失落**：技术解决问题 → 制度、市场或传播阻碍 → 人物选择 → 个人命运与长期影响形成反差。
- **普通人的现场**：使用者/工匠遭遇问题 → 参与改造或见证变化 → 以其生活中的具体动作结束。不要虚构普通人亲历其不可能见到的全部重大事件。

情绪路线可为紧张—希望—挫败—释然，憋屈—反击—代价—尊严，惊叹—不安—重新理解，或好奇—误判—恍然大悟。真实材料不支持愤怒时，不强造恶人。

对手必须有成立的理由：预算、技术风险、职责、现实利益、时代认知。主角可以误判，但不得把没有依据的恶行、罪行、秘密动机写到真实人物身上。区分事实行为、戏剧化对话与作者解读。

短暂幽默、沉默和温情是可用的调节手段。高潮由代价与选择产生，不以喊叫、哭泣或配乐音量替代。

## 6. 节拍与对白执行

分段记录以下必要信息，短稿可内部完成：

`段落/预计时长 | 可见事件与选择 | 观众原先以为→现在知道 | K编号 | 情绪起点→终点 | 留下的问题/兑现的答案`

- 开场用适合题材的处境、关系或异常建立观看理由，尽早明确欲望与阻碍；不固定前几秒爆点或3/15/30秒检查配额。
- 每约 20–40 秒可检查一次是否有信息、行动、立场或情绪的实质变化；这是排查停滞的方法，不是必须按时反转。重要试验、沉默和选择可更长，只要持续提供张力。
- 高密度是有效信息和行动密度，不是词数、剪辑数或争吵次数。一个可读懂的操作长镜头，可以比六个看不清的切镜更有吸引力。
- 对白主要承担试探、拒绝、争取、掩饰、警告、承诺、决策。角色用自己关心的东西说话，不全员用编剧口吻总结。
- 允许短句交锋，但插入会改变局面的动作、观察和打断，避免全片“你问我答”。身体感受、证物、失败操作能表达的信息，不再重复解释。
- 金句不是配额，必须属于这个角色与这个时刻。历史人物戏剧化台词不冒充有出处的名言。
- 说明与动作默认简体中文，对白默认英文；用户指定中文对白或其他语言时遵从。不因中文参考稿自动改写已确认的对白语言。
- 时长按实际对白语言估算：英文可先用约 120–160 词/分钟作为排练起点，中文约 3–5 字/秒作为起点；均非硬上限。技术词、情绪、停顿、无对白动作另计；可同时发生的动作不重复累加。超时先删重复信息或调整段落，不靠机械倍速。

## 7. 事实与创作分层（跨领域通用）

事实台账建议字段：

`F编号 | 主张及年代/地点/范围 | 来源标题/机构/URL/定位 | 来源支持的具体内容 | 已核实/有争议/待核实 | 对应K/场次`

- 用户转录稿只能作线索；明显错字先按语境识别，不能据此确定人物原话、数字或事实。
- 历史主干、关键数字、发明优先权、政策条件、关键装置结构先检索核实。优先原始档案、专利、同期材料，再用博物馆、专业研究或可靠历史综述交叉判断。企业自述可用，但涉及功劳与经营神话时标注视角并尽量交叉核实。
- 搜索摘要不等于核实；打开相关原文，记录支持主张的段落或页码。来源冲突要解释范围差异或保留争议。
- 戏剧化对话、虚构/合成人物、时间压缩、合并场面列为 `D编号`，给出改编范围；不能把不同年份的因果变成“当天决策、当天见效”。在作品说明或适当字幕注明根据历史事件戏剧化改编。
- 无法查证的关键事实不得写成确定事实。可以先交付带待核项的工作稿，但对应事实结论、原理镜头和成品提示词不能标“已核验/生成就绪”。不影响关键机制的细节可合理复原并标明性质。
- 事实来源与戏剧化说明集中放片外附注或资料节点，保持剧本可读；但会改变观众理解的关键限制应进入正文。

## 8. 会诊与交付门槛

文案会诊 按以下问题做内部检查，只输出与任务相关的真实问题；不凑问题数、不捏造评委分歧、不用总分掩盖致命错误。

**致命问题（先修再宣称就绪）**：核心史实错误或未核；因果倒置；知识点误导；主角行为不成立；虚构指控冒充事实；关键历史机器/操作错误；对白与时长明显不相容。

**重要问题**：开场承诺不兑现；对手降智；连续讨论没有行动；知识可删除而不影响剧情；情绪只靠羞辱或喊叫；反转无前置证据；结尾只剩旁白总结。

**可选优化**：让某句对白更有角色感、增加视觉记忆点、缩减制作成本、用克制的动作替代解释。

每项按 `位置/原文证据 → 对观众理解或情绪的影响 → 优先级 → 可直接替换的动作/台词或改法` 交付。用户说“优化改写”时同轮调用 正文写作/对白精修 完成，不只给评价；只要求会诊时不擅自重写整稿。

默认最小交付：简短假设（仅必要时）→ 用户要求的大纲/正式剧本/改稿 → 精简事实与改编附注 → 影响制作的风险与下一步。内部节拍表、审稿表不强制全部展示。如需同步，按 Skill 名称委派 `canvas-production`，本模块不处理真实生成输入。

## 9. 小型验收示例

以下为虚构机制示例，不描述真实人物或特定历史事件。

**问题稿**：老板说效率低；工程师解释分工能提高效率；大家赞同；旁白宣布成功。

**改写方向**：交付铃响时工位停着，工人却在找零件。工程师把零件送到手边，第一轮更快；第二轮错误规格混入，返工堆起来。经理要求恢复旧流程，工程师必须先解决供料与检验，而不是继续命令工人加速。

**有效性**：知识从“效率口号”变成供料/检验如何约束产出的可见机制；对手承担交付责任而非专职阻挠；动作产生反证与新选择。若改编历史，必须另行核实这些试验是否发生，不得把此示例移植成福特实录。

**反套路检查**：把人物名和产品名替换后若能原样套用多个项目，重选独有的技术限制、历史环境、冲突与结尾；不要只换外皮。

## 10. 非历史题材的适配
知识来源不仅是历史档案：现代生产、驾驶、照护等以适用地区、对象、设备型号及当前有效指南/规程核验。F 记录事实和适用条件，D 记录虚构情节；专业操作与风险依据用 专业核验 的 SR 卡管理。历史核验 的 HR 仅用于历史，不把所有场景强套年代复原。
同一叙事质量标准可以服务于风险识别、日常预防、技术理解和行为改变。不是每条都需要反派、事故或受害者；不要强造惨剧、羞辱家长或制造育儿焦虑。知识结论能改变人物行动即可形成看点。
安全纠正必须在本条内清晰兑现，不能为了追看把正确处理留到下集。错误动作需要及时辨明，不因“剧情虚构”降低专业正确性。简短警示不能代替正确操作和必要条件。
现代安全/健康资料的版本、年龄范围、现场条件与法域应进入来源记录；关键结论和专业动作未核实，按致命定稿问题处理。
