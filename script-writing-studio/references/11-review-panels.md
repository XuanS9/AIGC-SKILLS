# 文案会诊 可选多视角库与会诊示例

## 使用边界

这是同一助手的分析视角工具箱，不是真实受众、专家团队或独立证据。用户要圆桌或复杂取舍需要时读取；人数和组合按问题决定，不固定天团。观点一致不触发强行反对，不虚构从业经历、过审结论、平台偏好或流量数据。

## 视角库（保留可选能力）

| 视角 | 重点检查 | 容易遗漏，需其他角度补足 |
|---|---|---|
| 商业制片 | 制作成本、可执行性、卖点与资源匹配 | 作者表达与长期意义 |
| 文艺制片 | 风格、主题、人物过程 | 交付与预算约束 |
| 平台适配 | 受众定位、承诺与追看、指标口径 | 不能猜平台算法 |
| 类型编剧 | 类型期待、反转铺垫、规则与回报 | 不把惯例当硬模板 |
| 剧本编辑 | 因果、信息顺序、重复与结构 | 现场执行风险 |
| 内容规范 | 适用地区、平台、年龄与现行规范 | 需查来源，非官方裁定 |
| 核心受众 | 本题材期待和情绪兑现 | 不代表全体观众 |
| 轻度观看者 | 低背景知识下的可理解性 | 不以阶层标签代替偏好 |
| 初次观看者 | 开场方向、人物入口与理解负担 | 长线回收 |
| 追剧者 | 阶段回报、长期悬念与疲劳 | 新观众入口 |
| 重看者 | 线索、细节、回看意义 | 首遍可读性 |
| 影评视角 | 主题、视听、文化语境 | 制作条件 |
| 切片传播 | 可独立理解的场面与标题承诺 | 不牺牲全片因果 |
| 表演视角 | 角色动作、潜台词与发挥空间 | 全剧结构 |
| 营销视角 | 一句话卖点、封面与正文一致 | 不把点击承诺当已兑现 |
| 法律/版权 | 原型、素材、改编与授权范围 | 需核实，不作终局法律判断 |
| 失败风险复盘 | 最可能失败的机制与前置条件 | 不虚构失败项目履历 |
| 套路疲劳 | 重复情节、过早可预测、换皮模板 | 不为新奇破坏因果 |
| 竞争性反对 | 主角凭什么得到结果、方案漏洞 | 不将嫉妒当证据 |
| 逻辑挑错 | 空间、时间、常识与人物行为漏洞 | 不以嘲讽取代修法 |

旧名称如“失败片导演”“疲劳编辑”“嫉妒同行”“找茬解说”按其分析功能兼容，不执行虚构自述。用户可指定新视角。

## 组合建议（无人数配额）

关系戏可选表演+剧本编辑；悬疑可选类型+初看/重看；强对抗可选核心受众+逻辑挑错；制作评估可选制片+技术执行；专业知识需加事实/专业核验，不以模拟专家代替真实审阅。圆桌之外，普通会诊直接合并意见。

## 虚构会诊示例

材料：主角出示证据，反对者立刻道歉并放弃控制；前文已表明反对者明知真相仍想获利。

- **判断**：不是解释不清，而是利益阻力没有被解决。道歉与既有动机不连贯。
- **保留**：证据出示是有效进展，不必撤掉。
- **改法**：让证据先改变旁人的支持或对手的施压能力，再由对手换策略、退让或付代价。具体选择服从定稿关系与结局。
- **边界**：如果前文唯一阻力本来就是误认事实，可信证据可以直接促成改变，不应强加第二重冲突。

这只是桌面示例，不是观众测试、真实平台数据或必须套用的剧情。
