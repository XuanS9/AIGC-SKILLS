# 戏剧节奏与作品形态

适用3–30分钟的单片/单集。执行 `15-dramatic-tension.md` 与 `19-runtime-structure.md`：节奏是有效变化的密度，不是语速、切镜数、反转频率或音量。格式、片长、集数、平台与节奏分别决定，不再用R1–R6旧菜单把长短、类型和发布渠道混为一谈。

## 1. 按段落选择密度

| 候选档位 | 可选用途 | 保持项 |
|---|---|---|
| 电影感中速 | 自然交锋、空间探索、情绪累积 | 动作、判断与反应完整可读 |
| 紧凑高信息 | 明确决策、证据变化、多方策略交锋 | 每一步改变局面，不以快读代替推进 |
| 强动作或强交锋 | 追逐、关键揭示、正面对抗 | 空间、受力、语言攻防与结果可信 |
| 舒缓但有发展 | 等待、试探、喜剧停顿、治愈或完整操作 | 能指出信息/关系/情绪如何累积与变化 |

按当前段落选，不给整部片套固定档。镜头少、对白少或画面静都不自动判慢；多个快切也可能毫无推进。删重复不能误删有效攻击、关键反应、读图时间、安全步骤与回报。

## 2. 作品形态

- **独立单片**：本片愿望、行动、结果与情绪回报成立；开放结尾可以保留解释空间，但不以欠缺结果冒充余韵。
- **连续剧单集**：本集体验与跨集主线并重，人物策略和关系有阶段变化。不重复拖延同一答案，不强制每集固定悬念数量。
- **单元剧**：单元问题与回报自足，按需继承世界、人物或主题；不机械每隔几集抛主线。
- **群像/多线**：每条线有可追踪的目标与切换理由，在因果、行动、信息或关系上汇合；不因片长达30分钟就必须添加副线。
- **单场/无对白/非线性**：可在同一空间或有限人物内完成复杂变化；明确事件时间与人物已知信息，不强制三幕、固定演员数或大量转场。

三幕、循环、多视角或段落式均为按需工具，不以是否踩中标准分钟数评判质量。长片不等于舒缓，短片不等于爽剧。

## 3. 开场、中段与回报

开场让人理解在看什么以及值得继续看的理由，不规定前3/15/30秒必须反转。中段行动带来新后果和策略调整，重要关系变化要有触发与反应；悬念、喜剧与情感题材按各自机制兑现期待。

片长增长应增加事件/人物发展的容量，不把5分钟冲突稀释为20分钟反复争吵。时间表用于检验已设计故事，不先画固定格子再塞事件。单场长谈也可通过权力、信息、意愿的变化推进。

发布平台确有要求时再适配开场、字幕、片段导出和观察窗口；不能把短视频推广片的节奏覆盖到完整剧集。没有数据不声称某秒后观众必然离开，也不承诺完播提升。

## 4. 格式与估时

M1/M2都可紧凑或舒展；文学叙述字数不是屏幕时长。对白以自然语言朗读/排练估时，动作和对白重叠不重复计时；无对白按动作与观察时间核算。需要改目标或拆集交用户决定，不暗中倍速或删戏。
