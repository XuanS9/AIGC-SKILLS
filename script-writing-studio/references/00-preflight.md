# 文案执行前确认

本Skill可独立使用：接受灵感、口述、外部大纲或剧本，不要求其他Skill、特定项目档案、模型、图片、画布或本地文件。职责为3–30分钟剧情作品的创意、正文、会诊与对白，不承担生成分段。

## 先读后问

先分清维护、讨论、参考分析和作品任务；维护不修改案例作品。查已有材料与决定，分清用户确认、授权助手选择、助手暂定、已核事实和待核项。集中询问缺失、含糊或冲突的关键项并等待回答，不代答后立即开工。已明确/已授权选择的事项继承或选择并说明，不重复问；非关键细节可说明暂定。

当前任务必要时确认：
- 任务范围：从零创作、来稿再创作、只会诊、只改对白或继续已确认作品。
- 题材、核心情绪与受众；用户未定可先给不同方向，不把候选当确认。
- 单片/单集/全季、具体目标时长及允许浮动、集数。3–30分钟是适用范围，不是已选片长；语义含糊时先问单位。见 `19-runtime-structure.md`。
- 语言、必须保持的人物/关系/结局/事实、允许改动范围。默认简体中文说明、英文对白，已有默认可直接说明，不逐次追问。
- 发布平台或画幅只有会显著改变表达且未确定时再问；不默认竖屏、短视频或高密度。既有项目规格不因Skill更新失效。

局部修改只问影响该范围的信息，不升格整项目问卷。来稿默认实质性再创作，不等于逐句审批；明确锁定稿、只诊断、仅参考和维护案例受保护。

## 输出与授权

完整稿含正文、自然估时和必要事实/改编附注，按 `16-copy-confirmation.md` 标版本及待确认范围。文案明确确认才可进入对应范围的正式制作，事实核验与用户确认分开。新内容不自动继承旧版确认。

此阶段不要求选择Seedance版本。只路由实际需要的后续任务，不要求用户先执行三套流程。可以只写文案并结束；用户需要制作时交清楚正文和确认范围即可。

写入审批、文件落盘、生成和费用均独立于创作授权；不自动生成、不绕过工具拒绝。作品同步按已知授权委派画布Skill，文案模块不写真实生成输入。维护Skill不写作品画布。
