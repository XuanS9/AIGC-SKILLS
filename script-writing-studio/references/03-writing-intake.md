# 写作材料与自然语言指令

先执行 `00-preflight.md`。复用已有材料；独立输入只需足以支撑当前人物、情节与范围，不要求固定标题、至少两名角色或特定项目档案。

- 已有充分大纲/任务直接写；可发展灵感需要时读 `01-story-development.md` 补最小设定。
- 缺非关键细节可以合理暂定并说明；题材、受众、具体时长、结局或核心设定不明先集中问。
- 新旧确认内容冲突指出影响；用户精确指定替换并授权执行的不重复问同一问题。开放式修改完成后回交确认。

## 独立解析的条件

- 格式：M1标准影视正文（默认）或M2小说化叙事，见 `04-screenplay-format.md`。
- 交付单位：单片、单集、连续剧/单元剧多集，按用户任务确定；“剧”不自动等于分集，“30分钟”不自动等于整季。
- 时长：3–30分钟范围内的具体目标、允许浮动与单集/全片单位，见 `19-runtime-structure.md`。
- 节奏：电影感中速、紧凑高信息、强动作/强交锋、舒缓蓄积等可以混用，详见 `05-dramatic-pacing.md`。不由平台或时长自动决定。
- 风格/语言/既定设定：继承用户决定；DNA只约束明确锁定部分，无报告不阻塞。

自然语言足以启动，不展示固定问卷或三轮菜单。例如：

```text
写一部12分钟的家庭剧情片，单片，英文对白
把这份25分钟单集改好，保留结局和母女关系
继续第3场，沿用已确认的设定
只会诊中段，先别改正文
改成小说化叙事 / 精修第4场对白 / 压缩重复解释
```

不强制用户输入旧R编号、菜单编号或特定命令。旧称“短剧/微电影/短视频”仍按自然语言理解，但不据此替用户选片长、画幅、密度或集数。

收到继续按当前任务和已知接续点处理，不重新跑前置问卷。缩字无目标先删重复，不默认压缩固定比例；是否改已完成正文不明且影响重大时才问范围。
