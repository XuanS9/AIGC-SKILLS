## 使用顺序

1. 核对用户要的是讨论、设定、梗概、正式正文、会诊、局部精修还是制作交接。
2. 读取 `00-preflight.md`，继承已确认的版本、范围和不可改项。
3. 只读取与本次问题直接相关的主路由；需要时再读取补充资料。
4. 正式正文或剧情改写前，先确认故事梗概表和关键限制；已确认的续写不重复阻塞。
5. 文案确认后，如用户需要制作，按 Skill 名称委派 `script-package-production`；需要画布同步时委派 `canvas-production`。本 Skill 不直接操作画布或生成媒体。

## 资料性质

本目录的案例和方法服务于默认的奇幻人兽斗剧情创作，但其中的现实、历史、家庭和专业案例只提供可迁移的叙事机制。它们不会自动改变题材，也不要求每个作品强行加入生物冲突。所有用户已确认的题材、人物、世界规则、关系、语言和结局优先于默认建议。

制作 Skill 的名称是路由标识，不依赖当前目录之外的脆弱相对路径。模型、画布、平台和生成参数不是本 Skill 的前置条件。
