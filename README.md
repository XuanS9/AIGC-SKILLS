# 三个独立 Skill

本仓库以三个 Skill 目录为交付源。每个目录都可以单独安装，且只有根目录一个 `SKILL.md`；详细功能按任务读取。视频 Skill 使用 `SKILL.md + references/ + scripts/`。更新直接提交到 Git 仓库，不再制作或提交 ZIP；安装时复制整个目录。

| 原文件夹 | 整合后的独立 Skill | 功能范围 |
|---|---|---|
| 剧本创作 | `script-writing-studio` | 保留原文案工作室全部能力：故事开发、梗概、正文、续写、改稿、节奏会诊、对白精修、事实核验、时长与交付管理 |
| 剧本优化 | `screenwriting-optimizer` | 精简为21个影视模块：电影、短片与剧集结构、人物对白、改编、编剧室、喜剧、各国影视方法、案例、行业与项目状态；已移除戏曲及舞台剧专章 |
| 视频脚本 | `video-script-studio` | 融合动作导演与 Higgsfield：三强度/两速度动作编排、角色/道具/场景参考图与参考视频/音频的全能参考编排、分镜、角色、表演、摄影、音频、模型、制作流程、费用预估、诊断与本地工具；已移除记忆、营销及宣发功能 |

## 安装与使用

将需要的目录复制到工具的 Skill 目录，例如 Codex 的 `~/.agents/skills/` 或 Claude Code 的 `~/.claude/skills/`。三包可以分别安装，也可以一起安装；不必安装旧模块。当前工作区原有的三份来源目录保持原样，整合包尚未安装到任何全局目录。

调用示例：

- `$script-writing-studio`：根据已确认的设定创作短剧，或诊断现有文案。
- `$screenwriting-optimizer`：分析结构、人物与对白，按媒介调用对应方法，并给出修订。
- `$video-script-studio`：把已确认剧本及角色、道具、场景参考图、参考视频和音频编排成分镜与全能参考视频提示词；动作任务同时应用动作设计与对应平台约束。

包内脚本以该包目录为工作目录执行。需要 Higgsfield 在线生成、CLI、MCP 或外部画布时，仍需使用环境具有相应工具、账户和权限；整合资料不等于已连接服务。源文件中的模型目录、价格或额度等是原资料的时间快照，继续沿用其实时核验规则。

## 保留方式与核验资料

- 本仓库只发布三个可安装的 Skill 目录、使用说明和本次优化记录。本地工作区的 `维护归档/`、`source-manifest.json`、`source-link-baseline.json`、`preservation-report.json` 与 `验证报告.md` 保存来源核验资料，不属于安装文件，也不随此仓库提交。剧本优化包按原范围移出戏曲与舞台剧专章，视频包按原范围移出记忆、营销和宣发功能。
- 原功能指南按需加载。入口中的路由表用于定位全文，不能代替全文里的工作流、细则与输出要求。
- 重叠规则按任务适用范围协调；尤其保留动作导演三套强度方案与标准/极速两档，并在 Higgsfield 联合任务中执行平台格式、参数与连续性检查。
- 创作包的 `MERGE-NOTES.md` 提供功能覆盖与路径说明；视频包当前功能入口见其 `SKILL.md`。本地来源核验记录保留在工作区，不随安装目录发布。

结构校验和脚本测试用于核实文件保留、路由、链接及工具可用性；创作质量和在线生成结果仍需在具体任务中验收。
