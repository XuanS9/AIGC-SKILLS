# 影视剧本优化工作室

将整个 `screenwriting-optimizer` 文件夹复制到工具的 Skill 安装目录，只注册根 [SKILL.md](SKILL.md)。本版聚焦电影、短片与电视剧，内部21个模块按任务读取。

## 包内内容

- [SKILL.md](SKILL.md)：统一入口、任务路由与交付要求。
- `references/`：21份方法文件和29份配套参考资料、工作表与术语表，按需读取。
- [LICENSE.md](LICENSE.md) 与 [NOTICE.md](NOTICE.md)：许可和原文引用的权利归属说明。

原项目：[jtydhr88/screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills)。本包将原内部 SKILL.md 改为 `references/<模块名>.md`，由根入口协调，保留各模块工作流、工作单和输出契约。未实现或待补充的方法仍以原文标注为准。

已移除板腔体、曲牌体及两套全本案例、契诃夫舞台剧专章，共5个模块及配套资料；同步清理其路由、专用工作表与术语。影视结构、人物、对白、类型、改编、剧集和行业方法保留。影视方法中的通用戏剧理论、改编来源和必要案例仍按适用范围使用。

旧配置、完整备份和移出资料保存在工作区包外的维护归档，不是安装依赖。上传只需本目录或同名 ZIP；包内全部为 Markdown 纯文本。

## 多语言支持

功能正文保留一份中文，输出语言跟随提问；剧本正文保持作品既定语言。术语依据 [术语表](references/sw-workflow-terms.md) 对齐原词，没有对应词时保留原词并附释义。无需为不同输出语言安装平行模块。
